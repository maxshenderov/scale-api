# Двухэтапный подход: Размещение + Реслот

**Дата:** 2026-07-24  
**Статус:** ⏳ Тестируется

---

## Идея

После начального размещения (без реслота) запустить второй этап с включённым реслотом для улучшения результата.

### Почему это может помочь?

1. **ЭТАП 1 (холодный старт):** Solver размещает паллеты последовательно, без права переставлять
   - Может застрять в локальном оптимуме
   - Некоторые паллеты не размещаются из-за неудачного выбора секций

2. **ЭТАП 2 (реслот):** Solver видит уже размещённые паллеты и может их переставить
   - Разрешено двигать до 10% размещённых паллет (до 324 штук)
   - Может найти лучшую конфигурацию через перестановки
   - Небольшая задача: 170 новых + возможность двигать 324 существующих

## Реализация

### ЭТАП 1: Начальное размещение

```python
req = OptimizationRequest(
    optimizationId="S7-COLD-START-001",
    mode="place",
    occupancy=occupancy_s7,  # Пустые секции
    newPallets=floor_pallets,  # Все 3406 паллет
    settings=OptimizationSettingsSchema(
        allowReslot=False,  # Нет реслота
        maxOperations=5000,
        timeLimitSeconds=180,
    ),
)
```

**Результат:** ~3236/3406 за 248s

### ЭТАП 2: Реслот не размещённых

```python
# Построить occupancy из результата ЭТАПА 1
occupancy_after_stage1 = ... # Заполнить секции из operations

# Не размещённые паллеты
not_placed_pallets = [p for p in floor_pallets if p.id in not_placed_ids]

req_reslot = OptimizationRequest(
    optimizationId="S7-COLD-START-002-RESLOT",
    mode="place",
    occupancy=occupancy_after_stage1,  # Секции с размещёнными паллетами
    newPallets=not_placed_pallets,  # Только не размещённые (~170)
    settings=OptimizationSettingsSchema(
        allowReslot=True,  # ВКЛЮЧАЕМ реслот
        maxReslotPercent=10,  # До 10% существующих можно двигать
        maxOperations=5000,
        timeLimitSeconds=120,
    ),
)
```

**Ожидается:** +5-15 паллет за 120s

### Итоговый результат

```python
total_placed = initial_placed + resp_reslot.metrics.placedPallets
total_time = initial_time + resp_reslot.executionTimeSeconds
```

## Преимущества

✅ **Две попытки** — если первая не нашла оптимум, вторая может улучшить  
✅ **Меньше переменных на ЭТАПЕ 2** — 170 новых паллет vs 3406  
✅ **Гибкость** — реслот позволяет исправить неудачные решения ЭТАПА 1

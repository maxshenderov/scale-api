## 2026-07-24: Откат BUCKET_CHUNK_SIZE из-за критической регрессии

### Результат первой итерации: ❌ РЕГРЕССИЯ

**Параметры:** `BUCKET_CHUNK_SIZE=5, AGGREGATION_THRESHOLD=100k, timeLimitSeconds=180`

| Метрика | Baseline | После | Изменение |
|---------|----------|-------|-----------|
| Размещено | 3239 | 3114 | -125 (-3.7%) ❌ |
| Время | 188.3s | 247.2s | +58.9s ❌ |
| NARROW_AISLE_MISMATCH | 64 | 155 | +91 (+142%) ❌❌ |

### Причина

`BUCKET_CHUNK_SIZE=5` сломал размещение узкопроходных паллет:
- Группировка секций по 5 → потеря точности при дезагрегации
- Суммарные ограничения width/weight для бакета из 5 секций → переоценка вместимости
- Узкопроходные паллеты не разместились в свои секции

### Действие

**Откат:**
```python
_BUCKET_CHUNK_SIZE = 1  # Вернули исходное значение
```

**Сохранили:**
```python
AGGREGATION_THRESHOLD = 100_000  # Было: 300_000
timeLimitSeconds = 180  # Было: 120
```

**Новый тест запущен:** Параметры `BUCKET=1, THRESHOLD=100k, TIME=180`

**Ожидается:** ~3239-3245 размещённых за ~240-260s (baseline качество + дополнительное время solver)

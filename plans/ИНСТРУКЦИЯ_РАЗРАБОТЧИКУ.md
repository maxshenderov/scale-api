## 🔧 Как запустить проект локально

### Предварительные требования

- Python 3.11+
- Docker и Docker Compose (опционально)
- API ключи: Anthropic Claude, OpenAI

### Вариант 1: Локальный запуск (без Docker)

```bash
# 1. Перейти в папку services
cd services

# 2. Создать виртуальное окружение
python -m venv venv

# 3. Активировать окружение
# На Windows:
venv\Scripts\activate
# На Linux/Mac:
source venv/bin/activate

# 4. Установить зависимости
pip install -r requirements.txt

# 5. Создать .env файл
cp .env.example .env
# Отредактировать .env и добавить API ключи

# 6. Запустить приложение
python -m uvicorn api.main:app --reload --host 0.0.0.0 --port 8000
```

API будет доступен на `http://localhost:8000`

### Вариант 2: Запуск с Docker Compose

```bash
# 1. Перейти в папку services
cd services

# 2. Создать .env файл
cp .env.example .env
# Отредактировать .env и добавить API ключи

# 3. Запустить контейнер
docker-compose up

# 4. Проверить здоровье приложения
curl http://localhost:8000/health
```

## 🐛 Troubleshooting

### Ошибка: `ModuleNotFoundError: No module named 'anthropic'`

**Решение:** Установить зависимости
```bash
pip install -r requirements.txt
```

### Ошибка: `ANTHROPIC_API_KEY не установлен`

**Решение:** Создать `.env` файл и добавить ключ
```bash
cp .env.example .env
# Отредактировать .env
```

### Ошибка: `Port 8000 is already in use`

**Решение:** Использовать другой порт
```bash
python -m uvicorn api.main:app --port 8001
```

### Ошибка: `CORS error from 1С`

**Решение:** Проверить настройки CORS в `api/main.py`
```python
app.add_middleware(
    CORSMiddleware,
    allow_origins=["http://localhost:1570"],  # Добавить IP 1С
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)
```

## ШАГ 1: Подготовка структуры (5 минут)

### 1.1 Откройте 1С:Конфигуратор

```

Путь: d:\project\OKIL\1c\ERP\Конф
```

### 1.2 Добавьте реквизиты к обработке ТестLLM

1. **Обработки → ТестLLM → Реквизиты**
2. Добавьте два реквизита:

| Имя | Тип | Длина | Описание |
|-----|-----|-------|---------|
| `Заказ` | СправочникСсылка.ЗаказКлиента | — | Ссылка на заказ |
| `htmlЗаказ` | Строка | Неограниченная | HTML-результат анализа |

### 1.3 Добавьте кнопку на форму

1. **Обработки → ТестLLM → Форма → Дизайнер**
2. Добавьте кнопку:
   - **Имя:** `АнализЗаказа`
   - **Заголовок:** `Анализ заказа`
   - **Действие:** `АнализЗаказа`

### 1.4 Сохраните и скомпилируйте

```
Ctrl+S — сохранить
F7 — скомпилировать
```

## Что дальше?

### Использование

1. Откройте обработку ТестLLM
2. Выберите заказ в поле "Заказ"
3. Нажмите кнопку "Анализ заказа"
4. Просмотрите результат анализа в поле `htmlЗаказ`

### Типы анализа

Если вы выбрали расширенную версию, при нажатии кнопки появится диалог выбора типа анализа:

- **Полный** — полный анализ (технолог + экономист)
- **Технолог** — анализ технолога
- **Экономист** — анализ экономиста

### Оптимизация

Для улучшения производительности:

1. **Используйте кэширование** — выберите версию с кэшированием
2. **Оптимизируйте JSON** — исключите ненужные данные
3. **Используйте асинхронный анализ** — для больших заказов

## Решение проблем

### Проблема: Кнопка не работает

**Решение:**
1. Проверьте, что процедура `АнализЗаказа` добавлена в модуль
2. Проверьте, что кнопка привязана к процедуре
3. Проверьте консоль на ошибки (Ctrl+Shift+F9)

### Проблема: Заказ не выбирается

**Решение:**
1. Проверьте, что реквизит `Заказ` добавлен
2. Проверьте, что реквизит имеет тип `СправочникСсылка.ЗаказКлиента`
3. Проверьте, что заказ существует в базе

### Проблема: LLM не отвечает

**Решение:**
1. Проверьте подключение к интернету
2. Проверьте, что LLM доступен: `aichat-okil-sato.kartochka.tech`
3. Проверьте журнал регистрации (Сервис → Журнал регистрации)

### Проблема: HTML не отображается

**Решение:**
1. Проверьте, что поле `htmlЗаказ` добавлено на форму
2. Проверьте, что поле привязано к реквизиту `Объект.htmlЗаказ`
3. Проверьте, что поле имеет тип "ПолеТекста" или "HTMLДокумент"

# Резюме: Этап 0 (MVP) — Кнопка AI-Ассистент в 1С

## 🎯 Цель Этапа 0

Создать **MVP (Minimum Viable Product)**, который анализирует **существующий заказ** в 1С и возвращает HTML-форму с технической и экономической оценкой.

**Не требуется:** Создание заказа из PDF, RAG-поиск, OpenRAG.

---

## 🔄 Поток данных

### 1. Пользователь нажимает кнопку в 1С

```
Форма ЗаказКлиента
  ↓
[Кнопка] "AI-Ассистент технолога"
  ↓
Модуль Лико_АИАссистентКлиент
  ↓
Процедура ОткрытьАИАссистентТехнолога()
```

### 2. 1С собирает данные и отправляет в API

```
Модуль Лико_АИАссистентДанные
  ↓
Процедура ПолучитьДанныеЗаказа()
  ├─ Получить реквизиты заказа
  ├─ Сериализовать табличные части
  └─ Вернуть JSON
  ↓
Процедура ПолучитьФайлМакета()
  ├─ Получить PDF из хранилища
  ├─ Закодировать в base64
  └─ Вернуть base64-строку
  ↓
Процедура ОтправитьВАИСервис()
  ├─ HTTP POST на http://localhost:8000/api/v1/analyze
  ├─ Отправить JSON + PDF + тип анализа
  └─ Получить HTML ответ
```

### 3. FastAPI обрабатывает запрос

```
POST /api/v1/analyze
  ↓
1. order_normalizer.normalize_order()
   ├─ Извлечь шапку заказа
   ├─ Извлечь табличные части (Цвета, ВидыРабот, Товары)
   ├─ Извлечь производственные данные
   └─ Вернуть структурированный JSON
  ↓
2. pdf_processor.analyze_pdf_with_vision()
   ├─ Декодировать base64
   ├─ Извлечь текст из PDF
   ├─ Отправить в OpenAI Vision API
   └─ Вернуть анализ макета
  ↓
3. claude_client.analyze_order()
   ├─ Выбрать промпт (технолог или экономист)
   ├─ Отправить данные в Claude API
   ├─ Получить структурированный ответ
   └─ Парсить JSON
  ↓
4. html_generator.generate_assessment_html()
   ├─ Рендерить техническую оценку
   ├─ Рендерить экономическую оценку
   ├─ Рендерить анализ макета
   ├─ Рендерить чек-лист готовности
   └─ Вернуть HTML-строку
  ↓
HTTP 200 OK
{
  "html": "<html>...</html>",
  "status": "success"
}
```

### 4. 1С отображает результат

```
Модуль Лико_АИАссистентКлиент
  ↓
Процедура ОтобразитьРезультат()
  ├─ Открыть модальное окно
  ├─ Отобразить HTML
  ├─ Добавить кнопки (Закрыть, Сохранить, Отправить)
  └─ Сохранить результат в заказе
```

## 🎓 Ключевые концепции

### Нормализация JSON
Преобразование сырого JSON из 1С в структурированный формат для обработки.

### Vision API
Анализ PDF макетов с помощью компьютерного зрения (OpenAI Vision).

### LLM-интеграция
Использование Claude API для анализа заказа и генерации оценок.

### HTML-генерация
Преобразование результатов анализа в красивую HTML-форму для отображения в 1С.

### CORS
Настройка кросс-доменных запросов для безопасного взаимодействия 1С и FastAPI.

## 🔀 Альтернативные потоки

### Поток 1: Заказ не выбран

```
Пользователь нажимает "Анализ заказа"
         ↓
Проверка: Если НЕ ЗначениеЗаполнено(Заказ)
         ↓
Сообщить("Выберите заказ для анализа")
         ↓
Возврат (процедура завершена)
```

### Поток 2: Ошибка при получении JSON

```
ПолучитьДанныеЗаказаДляАИ()
         ↓
Ошибка: Реквизит не найден
         ↓
Попытка...Исключение
         ↓
Сообщить("Ошибка: " + ОписаниеОшибки())
         ↓
Возврат (процедура завершена)
```

### Поток 3: Ошибка при отправке в LLM

```
ОтправитьЗапросКLLM()
         ↓
Ошибка: Нет соединения с сервером
         ↓
Результат.Успех = Ложь
         ↓
Сообщить("Ошибка анализа: " + Результат.ОписаниеОшибки)
         ↓
Возврат (процедура завершена)
```


## 🎯 Критические точки

1. **Выбор заказа** — Если заказ не выбран, процедура должна завершиться с сообщением об ошибке
2. **Формирование JSON** — JSON должен быть валидным и содержать все необходимые поля
3. **Отправка в LLM** — Должна быть обработка ошибок сети и API
4. **Отображение HTML** — HTML должен корректно отображаться в поле htmlЗаказ

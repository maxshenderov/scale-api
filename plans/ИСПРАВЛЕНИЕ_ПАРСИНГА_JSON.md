# Исправление функции ИзвлечьJSONИзОтвета

## Проблема
LLM возвращает JSON с префиксом ` ```json` и суффиксом ` ``` `, что вызывает ошибку парсинга:
```
Непредвиденный символ при чтении JSON
```

## Решение
Замените функцию `ИзвлечьJSONИзОтвета` в модуле формы на следующую версию:

```bsl
//+Лико m.shenderov 06.05.2026
// Извлекает JSON из ответа LLM с четырёхуровневой защитой
&НаСервере
Функция ИзвлечьJSONИзОтвета(СыройОтвет) Экспорт
    // Попытка 1: прямой парсинг
    Попытка
        ЧтениеJSON = Новый ЧтениеJSON;
        ЧтениеJSON.УстановитьСтроку(СыройОтвет);
        Результат = ПрочитатьJSON(ЧтениеJSON);
        Возврат Результат;
    Исключение
    КонецПопытки;

    // Попытка 2: убираем ```json ... ``` и другие markdown-блоки
    Очищенный = СыройОтвет;
    
    // Удаляем ```json в начале (с пробелами)
    Очищенный = СтрЗаменить(Очищенный, "```json", "");
    Очищенный = СтрЗаменить(Очищенный, "``` json", "");
    
    // Удаляем ``` в конце (с пробелами)
    Очищенный = СтрЗаменить(Очищенный, "```", "");
    
    // Удаляем пробелы и переносы строк в начале/конце
    Очищенный = СокрЛП(Очищенный);

    Попытка
        ЧтениеJSON = Новый ЧтениеJSON;
        ЧтениеJSON.УстановитьСтроку(Очищенный);
        Результат = ПрочитатьJSON(ЧтениеJSON);
        Возврат Результат;
    Исключение
    КонецПопытки;

    // Попытка 3: ищем первую { и последнюю } и извлекаем JSON
    Поз1 = СтрНайти(Очищенный, "{");
    Поз2 = СтрНайти(Очищенный, "}", НаправлениеПоиска.СКонца);
    Если Поз1 > 0 И Поз2 > Поз1 Тогда
        Фрагмент = Сред(Очищенный, Поз1, Поз2 - Поз1 + 1);
        Попытка
            ЧтениеJSON = Новый ЧтениеJSON;
            ЧтениеJSON.УстановитьСтроку(Фрагмент);
            Результат = ПрочитатьJSON(ЧтениеJSON);
            Возврат Результат;
        Исключение
        КонецПопытки;
    КонецЕсли;

    // Попытка 4: если всё ещё не получилось, логируем и возвращаем Неопределено
    Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Ошибка парсинга JSON. Первые 300 символов: " + Сред(СыройОтвет, 1, 300));
    Возврат Неопределено;
КонецФункции
```

## Ключевые изменения

1. **Удалён `ЧтениеJSON.Закрыть()`** после `ПрочитатьJSON()` — это вызывало ошибку
2. **Добавлена очистка ```` ``` json ````** (с пробелом)
3. **Улучшена обработка исключений** — каждая попытка парсинга независима
4. **Добавлена 4-я попытка** с логированием для отладки

## Где находится функция

Файл: `1c/ERP/Обраб/AIАссистент/AIАссистент/Forms/Форма/Ext/Form/Module.bsl`

Строки: 1290–1334 (примерно)

## Как заменить в 1С

1. Откройте обработку **AIАссистент** в конфигураторе
2. Перейдите в форму **Форма**
3. Откройте модуль формы (Ext/Form/Module.bsl)
4. Найдите функцию `ИзвлечьJSONИзОтвета` (Ctrl+F)
5. Замените весь текст функции на код выше
6. Сохраните (Ctrl+S)

## Результат

После замены LLM сможет возвращать JSON с markdown-блоками, и парсинг будет работать корректно.

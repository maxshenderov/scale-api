# ЭТАП 3: Разработка функции отправки запроса в LLM

## Обзор этапа

На этом этапе мы создадим функцию `ОтправитьЗапросАнализаЗаказа()`, которая:
1. Получает JSON заказа через функцию из Этапа 2
2. Формирует системный промпт для анализа
3. Отправляет запрос в LLM через существующую функцию `ОтправитьЗапросКLLM()`
4. Обрабатывает ответ и возвращает HTML-результат

## Архитектура интеграции

```
Кнопка "Анализ заказа"
        ↓
АнализЗаказа() (обработчик кнопки)
        ↓
ОтправитьЗапросАнализаЗаказа(ДокументСсылка, ТипАнализа)
        ↓
ПолучитьДанныеЗаказаДляАИ(ДокументСсылка) [из Этапа 2]
        ↓
ОтправитьЗапросКLLM(Промпт, JSON) [существующая функция]
        ↓
LLM (aichat-okil-sato.kartochka.tech)
        ↓
HTML-результат анализа
        ↓
Отображение в поле htmlЗаказ
```

## Существующая функция ОтправитьЗапросКLLM()

Из анализа ТестLLM, существующая функция имеет сигнатуру:

```bsl
Функция ОтправитьЗапросКLLM(Промпт, ДополнительныеДанные = Неопределено) Экспорт
    // Отправляет запрос в LLM
    // Возвращает ответ от LLM
КонецФункции
```

**Параметры:**
- `Промпт` (строка) — текст запроса к LLM
- `ДополнительныеДанные` (строка, опционально) — JSON с дополнительными данными

**Возвращает:**
- Строка с ответом от LLM (может быть HTML, JSON или текст)

// Обрабатывает результат от LLM
Функция ОбработатьРезультатLLM(РезультатLLM, ТипАнализа)
    
    // Если результат уже содержит HTML-теги, возвращаем как есть
    Если СтрНайти(РезультатLLM, "<html") > 0 ИЛИ СтрНайти(РезультатLLM, "<body") > 0 Тогда
        Возврат РезультатLLM;
    КонецЕсли;
    
    // Если результат содержит markdown-форматирование, преобразуем в HTML
    Если СтрНайти(РезультатLLM, "**") > 0 ИЛИ СтрНайти(РезультатLLM, "##") > 0 Тогда
        Возврат ПреобразоватьMarkdownВHTML(РезультатLLM);
    КонецЕсли;
    
    // Если результат простой текст, оборачиваем в HTML
    Возврат ОборнутьВHTML(РезультатLLM, ТипАнализа);
    
КонецФункции

// Преобразует markdown в HTML
Функция ПреобразоватьMarkdownВHTML(ТекстMarkdown)
    
    ТекстHTML = ТекстMarkdown;

    ТекстHTML = СтрЗаменить(ТекстHTML, "## ", "<h2>");
    ТекстHTML = СтрЗаменить(ТекстHTML, "### ", "<h3>");

    // Преобразуем курсив
    ТекстHTML = СтрЗаменить(ТекстHTML, "*", "<em>");
    
    // Преобразуем списки
    ТекстHTML = СтрЗаменить(ТекстHTML, "- ", "<li>");
    
    // Оборачиваем в HTML-контейнер

    |body { font-family: Arial, sans-serif; margin: 20px; }

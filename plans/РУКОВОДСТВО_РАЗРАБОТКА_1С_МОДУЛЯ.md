## Обзор

Вы разработаете серверный модуль `Лико_АИАссистентДанные`, который:
- Преобразует данные ЗаказКлиента в JSON для AI-сервиса
- Получает файл макета в base64
- Отправляет данные в Python-сервис
- Сохраняет результаты анализа

**Время разработки**: ~2-3 часа
**Сложность**: Средняя
**Требуемые знания**: BSL, 1С:Конфигуратор, HTTP-запросы

## Пошаговая разработка

### Шаг 1: Создание общего модуля

**Действие:**
1. В 1С:Конфигураторе откройте **Общие модули**
2. Создайте новый модуль с именем `Лико_АИАссистентДанные`
3. Установите флаги:
   - ✅ **Серверный модуль** (обязательно)
   - ❌ Клиентский модуль
   - ❌ Внешнее соединение
   - ✅ **Глобальный модуль** (для доступа из других модулей)

**Результат:** Модуль готов к редактированию

## Решение проблем

### Проблема 1: "Реквизит не найден"

**Симптом:**
```
Ошибка: Реквизит "ШиринаЭтикетки" не найден
```

**Решение:**
1. Проверьте, что реквизит существует в ЗаказКлиента
2. Если реквизита нет, добавьте его в конфигурацию
3. Если реквизит имеет другое имя, измените его в коде модуля

**Как найти правильное имя реквизита:**
1. Откройте форму ЗаказКлиента в режиме редактирования
2. Щелкните правой кнопкой на поле → **Свойства**
3. Найдите **Имя** в свойствах

---

### Проблема 2: "Регистр сведений не найден"

**Симптом:**
```
Ошибка: Регистр сведений "Лико_ЗаказЦвета" не найден
```

**Решение:**
1. Проверьте, что регистр сведений существует в конфигурации
2. Если регистра нет, создайте его или используйте другой источник данных
3. Если регистр имеет другое имя, измените его в коде

---

### Проблема 3: JSON содержит null значения

**Симптом:**
```json
{
  "header": {
    "order_id": "ЛК006640049",
    "manager": null,
    ...
  }
}
```

**Решение:**
1. Это нормально - null означает, что реквизит не заполнен
2. Если нужно исключить null значения, добавьте проверку:

```bsl
Если ЗначениеЗаполнено(ДокументОбъект.Менеджер) Тогда
    ШапкаСтруктура.Вставить("manager", ДокументОбъект.Менеджер);
КонецЕсли;
```

---

### Проблема 4: Ошибка при преобразовании в JSON

**Симптом:**
```
Ошибка: Невозможно преобразовать значение в JSON
```

**Решение:**

2. Если значение имеет неподдерживаемый тип, преобразуйте его:

# 📋 План разработки: Анализ заказа в обработке ТестLLM

**Дата**: 5 мая 2026  
**Статус**: 🔄 В планировании  
**Цель**: Реализовать функцию анализа заказа с преобразованием в JSON и отправкой в LLM

---

## 🎯 Обзор задачи

### Что нужно сделать
Добавить в обработку **ТестLLM** функциональность анализа заказа:
1. Выбрать заказ (ЗаказКлиента) в поле "Заказ"
2. Нажать кнопку "Анализ заказа"
3. Система преобразует заказ в JSON
4. Отправит JSON в LLM с промптом анализа
5. Отобразит HTML-результат в поле "htmlЗаказ"

### Входные данные
- **Документ**: ЗаказКлиента (номер, дата, реквизиты, табличные части)
- **Регистр**: Лико_ЗаказЦвета (операции печати)
- **Справочники**: Лико_ТехнологияПечати, Лико_ВидыСекций и др.

### Выходные данные
- **JSON**: Структурированные данные заказа для анализа
- **HTML**: Результат анализа от LLM (техническая оценка, риски, рекомендации)

### 4.1-4.5 Процедура АнализЗаказа

**Расположение**: Модуль формы (Module.bsl)

```bsl
&НаКлиенте
Процедура АнализЗаказа(Команда)

КонецПроцедуры
```

**Логика**:
1. Проверить, что заказ выбран:
   ```bsl
   Если НЕ ЗначениеЗаполнено(Заказ) Тогда
       Сообщить("Выберите заказ для анализа");
       Возврат;
   КонецЕсли;
   ```

2. Вызвать функцию анализа:
   ```bsl
   Результат = ОтправитьЗапросАнализаЗаказа(Заказ, "technologist");
   ```

3. Проверить результат:
   ```bsl
   Если Результат.Успех Тогда
       htmlЗаказ = Результат.Ответ;
   Иначе
       Сообщить("Ошибка анализа: " + Результат.ОписаниеОшибки);
   КонецЕсли;
   ```

4. Обработать ошибки:
   ```bsl
   Попытка
       // Код анализа
   Исключение
       Сообщить("Ошибка: " + ОписаниеОшибки());
   КонецПопытки;
   ```

## 📞 Вопросы и ответы

### Q: Где хранится JSON заказа?
**A**: JSON формируется в памяти при каждом анализе. Не сохраняется в БД.

### Q: Можно ли сохранить результат анализа?
**A**: Да, добавьте реквизит в ЗаказКлиента и сохраняйте HTML-результат после анализа.

### Q: Как изменить промпт анализа?
**A**: Отредактируйте текст в функции `ОтправитьЗапросАнализаЗаказа`.

### Q: Какие реквизиты ЗаказКлиента обязательны?
**A**: Номер, Дата, Партнер, Организация. Остальные опциональны.

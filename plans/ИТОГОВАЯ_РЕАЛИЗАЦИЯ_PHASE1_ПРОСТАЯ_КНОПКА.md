## 🧪 Как использовать

### Пошаговая инструкция

1. **Откройте обработку AIАссистент**
   - Путь: `Обработки → AIАссистент`

2. **Перейдите на вкладку "Заказ"**
   - Нажмите кнопку "..." (ВыбратьФайлМакета)
   - Выберите файл: `*.pdf`, `*.jpg`, `*.png`, `*.docx`, `*.txt`

3. **Нажмите кнопку "🧪 Тест Phase1"**
   - Система загрузит файл с диска
   - Отправит на локальный Docling сервис (`http://localhost:8001`)
   - Вернет результат

4. **Просмотрите результат в HTML**
   - Откроется окно браузера с красивым HTML-выводом
   - Увидите:
     - Имя файла
     - Confidence процент (0-100%)
     - Тип файла
     - Извлеченный текст (первые 500 символов)
     - Количество таблиц/изображений (если найдены)

## 📊 Структура результата Phase1

**Возвращаемая структура** из [`Фаза1ИзвлечьТекстМакеты()`](../1c/ERP/Обраб/AIАссистент/AIАссистент/Forms/Форма/Ext/Form/Module.bsl:4153):

```
Результат = Структура
  ├─ Успех           : Булево             (true/false)
  ├─ Текст           : Строка             (извлеченный текст)
  ├─ Confidence      : Число (0-1)        (0.92 = 92%)
  ├─ ТипФайла        : Строка             (pdf/jpg/png/docx/txt)
  ├─ Изображения     : Массив             (найденные изображения)
  ├─ Таблицы         : Массив             (найденные таблицы)
  └─ ОписаниеОшибки  : Строка             (при Успех=false)
```

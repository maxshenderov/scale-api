# ⚡ Quick Reference: Agent Loop с инструментами

**Версия:** 1.0  
**Дата:** 06.05.2026  
**Для:** Быстрого поиска информации

---

## 🎯 Что это?

**Agent Loop** — система анализа заказов типографии через LLM с поддержкой **function calling** (инструментов).

```
Заказ → LLM → Инструменты → LLM → JSON → HTML
```

---

## 🚀 Быстрый старт (2 минуты)

### 1. Откройте форму заказа
```
Документы → ЗаказКлиента → Форма
```

### 2. Нажмите кнопку "Анализ заказа"
```
[Анализ заказа] → Выберите тип → [OK]
```

### 3. Выберите тип анализа
- **technologist** — для технолога
- **economist** — для финансиста
- **full** — комплексный анализ
- **educational** — для обучения

### 4. Получите HTML-отчёт
```
Вердикт → Риски → Технология → Экономика → Качество
```

## 📊 Типы анализа

### 1. Technologist
```
Для: Технолога
Фокус: Риски, сложность, оптимизация
Выход: risks, technology, timeline
```

### 2. Economist
```
Для: Финансиста
Фокус: Рентабельность, затраты, цена
Выход: economics, cost_breakdown
```

### 3. Full
```
Для: Главного технолога + финансиста
Фокус: Всё
Выход: Все секции
```

### 4. Educational
```
Для: Преподавателя
Фокус: Объяснение простым языком
Выход: order_overview, process_steps, glossary
```

## 🎨 HTML-секции

| Секция | Содержит |
|--------|----------|
| verdict | Вердикт (accept/reject/conditional) |
| risks | Таблица рисков с уровнями |
| technology | Технология печати и краски |
| timeline | Таймлайн производства |
| economics | Структура затрат и рентабельность |
| resources | Материалы и персонал |
| quality_checkpoints | Контрольные точки качества |
| order_overview | Описание заказа (educational) |
| process_steps | Пошаговое объяснение (educational) |
| glossary | Словарь терминов (educational) |

## 🔍 Поиск по проблеме

### Ошибка: "Непредвиденный символ при чтении JSON"
**Решение:** [`ИСПРАВЛЕНИЕ_ПАРСИНГА_JSON.md`](ИСПРАВЛЕНИЕ_ПАРСИНГА_JSON.md)

### LLM не вызывает инструменты
**Проверьте:**
1. Провайдер поддерживает function calling (Claude, GPT-4o)
2. Инструменты описаны в `ОписаниеИнструментов()`
3. Системный промпт содержит инструкцию использовать tools

### HTML не отображается
**Проверьте:**
1. JSON успешно спарсен
2. Функция `JSON_Анализа_в_HTML()` вызвана
3. Тип анализа соответствует структуре JSON

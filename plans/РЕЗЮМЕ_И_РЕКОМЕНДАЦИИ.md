## ⚠️ Критические моменты

### 1. Сериализация табличных частей в 1С

**Проблема:** Табличные части возвращаются как строки "ТаблицаЗначений"

**Решение:** Использовать функцию сериализации в 1С
```bsl
ТаблицаЗначений = Объект.Цвета;
JSON = СериализоватьТаблицу(ТаблицаЗначений);
```

### 2. Передача PDF в base64

**Проблема:** PDF может быть большим (до 10 МБ)

**Решение:** 
- Ограничить размер до 10 МБ
- Использовать multipart/form-data вместо JSON
- Кэшировать результаты анализа

### 3. Timeout при анализе

**Проблема:** LLM может долго анализировать сложный заказ

**Решение:**
- Установить timeout 30 сек
- Показать прогресс-бар в 1С
- Реализовать асинхронную обработку

### 4. Качество LLM-анализа

**Проблема:** LLM может дать неправильный анализ

**Решение:**
- Использовать production-промпты
- Валидировать результаты
- Human-in-the-loop (пользователь может отредактировать)

### 5. Безопасность API-ключей

**Проблема:** API-ключи могут быть скомпрометированы

**Решение:**
- Использовать `.env` файл
- Не коммитить ключи в git
- Ограничить доступ к API-ключам
- Использовать rate-limiting

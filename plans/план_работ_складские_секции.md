## 1. Функция `ОшибкиРазмещенияВАдрес(Ячейка, Высота, Ширина, Глубина, Вес)`

### 1.1 Изменить правило ширины паллета

- **Было:** Если ширина паллета > **1/2** ширины секции → только один паллет, только в средний адрес (2)
- **Стало:** Если ширина паллета > **2/3** ширины секции → только один паллет, только в средний адрес (2)

### 1.2 Добавить проверку признака `ЗапретРазмещения`

Если у секции установлен реквизит `ЗапретРазмещения = Истина` — запрещать размещение во **все** адреса данной секции (возвращать ошибку независимо от адреса).

### 1.3 Добавить проверку габаритов по справочнику `Лико_Стеллажи`

Получать из связанного стеллажа секции реквизиты:

| Реквизит            | Описание                        |
|---------------------|---------------------------------|
| `МинШиринаПаллета`  | Минимально допустимая ширина    |
| `МаксШиринаПаллета` | Максимально допустимая ширина   |
| `МинГлубинаПаллета` | Минимально допустимая глубина   |
| `МаксГлубинаПаллета`| Максимально допустимая глубина  |

**Логика проверки** (применять **только если значение реквизита ≠ 0**):

- Если `МинШиринаПаллета ≠ 0` И `Ширина < МинШиринаПаллета` → ошибка
- Если `МаксШиринаПаллета ≠ 0` И `Ширина > МаксШиринаПаллета` → ошибка
- Если `МинГлубинаПаллета ≠ 0` И `Глубина < МинГлубинаПаллета` → ошибка
- Если `МаксГлубинаПаллета ≠ 0` И `Глубина > МаксГлубинаПаллета` → ошибка

## 2. Функция `ПодобратьЯчейку(Склад, Высота, Ширина, Глубина, Вес, ОбратныйПорядокВремени = Ложь)`

### 2.1 Синхронизировать запрос со всеми условиями из `ОшибкиРазмещенияВАдрес`

В запрос выборки подходящих ячеек добавить фильтрацию по всем условиям:

| Условие | Источник данных |
|---|---|
| Секция без признака `ЗапретРазмещения` | Реквизит секции |
| Если `Ширина > 2/3 * ШиринаСекции` — выбирать только средний адрес (2) | Вычисляемое условие в запросе |
| `МинШиринаПаллета = 0 ИЛИ Ширина >= МинШиринаПаллета` | Реквизит стеллажа |
| `МаксШиринаПаллета = 0 ИЛИ Ширина <= МаксШиринаПаллета` | Реквизит стеллажа |
| `МинГлубинаПаллета = 0 ИЛИ Глубина >= МинГлубинаПаллета` | Реквизит стеллажа |
| `МаксГлубинаПаллета = 0 ИЛИ Глубина <= МаксГлубинаПаллета` | Реквизит стеллажа |

> ⚠️ **Цель:** `ПодобратьЯчейку` **никогда не должна возвращать адрес**, в который `ОшибкиРазмещенияВАдрес` вернёт ошибку — логика обеих функций должна быть консистентной.

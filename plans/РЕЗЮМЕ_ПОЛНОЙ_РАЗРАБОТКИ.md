# РЕЗЮМЕ ПОЛНОЙ РАЗРАБОТКИ: Анализ заказов в ТестLLM

## Обзор проекта

Проект реализует функцию анализа заказов типографии с использованием LLM (Large Language Model). Система преобразует данные заказа в JSON, отправляет в LLM для анализа и отображает результат в виде HTML.

**Статус:** Полная разработка завершена (5 этапов)
**Версия:** 1.0
**Дата:** 05.05.2026

### ЭТАП 3: Разработка функции отправки запроса в LLM

**Файл:** `plans/ЭТАП_3_КОД_ОТПРАВКИ_В_LLM.md`

**Основная функция:** `ОтправитьЗапросАнализаЗаказа(ДокументСсылка, ТипАнализа)`

**Вспомогательные функции:**
1. `ПолучитьСистемныйПромпт(ТипАнализа, ДанныеЗаказаJSON)` — формирование промпта
2. `ОбработатьРезультатLLM(РезультатLLM, ТипАнализа)` — обработка результата
3. `ПреобразоватьMarkdownВHTML(ТекстMarkdown)` — преобразование markdown в HTML
4. `ОборнутьВHTML(ПростойТекст, ТипАнализа)` — оборачивание текста в HTML
5. `ПолучитьОшибкуHTML(СообщениеОбОшибке)` — формирование HTML ошибки

**Типы анализа:**
- `"Полный"` — полный анализ (технолог + экономист)
- `"Технолог"` — анализ технолога
- `"Экономист"` — анализ экономиста

**Результат:** Функция отправляет JSON в LLM и возвращает HTML-результат анализа

## Обработка ошибок

Система обрабатывает следующие ошибки:

| Ошибка | Обработка |
|--------|-----------|
| Заказ не выбран | Сообщение пользователю |
| Заказ не найден в БД | Сообщение пользователю |
| Не удалось получить JSON | HTML с сообщением об ошибке |
| LLM недоступен | HTML с сообщением об ошибке |
| LLM вернул пустой результат | HTML с сообщением об ошибке |
| Исключение при выполнении | Логирование и сообщение пользователю |

## Исправление 1 — N+1 запросов в зонах приёмки/отгрузки (КРИТИЧНО)

### Проблема
В методе `РендерЗагрузкиСтеллажаНаСервере` (строки 724–776) в цикле по `ЗоныСтеллажа`
для **каждой зоны** выполняется отдельный запрос к `Лико_ПаллетыВСекциях`. При N зонах — N запросов к БД.

### Решение
Собрать все адреса зон в массив **до** цикла, выполнить **один** пакетный запрос,
построить индекс `Адрес → массив паллетов`, использовать его в цикле.

### Код ЗАМЕНИТЬ (строки 724–776):

```bsl
// === ДО (текущий код — N+1 запросов) ===
ЗоныСтеллажа = СтеллажОбъект.ЗоныПриемкиОтгрузки;
Если ЗоныСтеллажа.Количество() > 0 Тогда
	HTML = HTML + "<div class=""zones-title"">Зоны приёмки/отгрузки:</div>";
	HTML = HTML + "<div class=""zones-row"">";
	
	Для Каждого СтрокаЗоны Из ЗоныСтеллажа Цикл
		ИмяЗоны = Строка(СтрокаЗоны.АдресХранения);
		
		// Запрос ВНУТРИ цикла — проблема!
		ЗапросЗоны = Новый Запрос;
		ЗапросЗоны.Текст = "ВЫБРАТЬ ... ГДЕ Адрес = &Адрес";
		ЗапросЗоны.УстановитьПараметр("Адрес", СтрокаЗоны.АдресХранения);
		РезультатЗоны = ЗапросЗоны.Выполнить();
		...
	КонецЦикла;
КонецЕсли;
```

```bsl
// === ПОСЛЕ (один запрос для всех зон) ===
ЗоныСтеллажа = СтеллажОбъект.ЗоныПриемкиОтгрузки;

				КлассПЗ = "pallet-occupied";

				Если ДанныеПЗ.Заблокирован > 0 И ДанныеПЗ.Количество = 0 Тогда
					КлассПЗ = "pallet-reserved";
					СтатусЗ = " [резерв]";

					+ "<div class=""pallet-label"">П" + НомерП + СтатусЗ + "</div>"

	КонецЦикла;
```

## Исправление 2 — Жёсткое ограничение на 3 адреса

### Проблема
Массив `Адреса` всегда содержит 3 элемента (`[Адрес1, Адрес2, Адрес3]`).
При `КоличествоАдресов = 1` или `= 2` в массиве находятся пустые/незаполненные ссылки.
Также логика позиционирования через `СреднийИндекс = Цел(КоличествоАдресов / 2)`
для `КоличествоАдресов = 2` даёт `СреднийИндекс = 1` — оба адреса ошибочно
трактуются как «центральный», а не «правый».

### Решение
Строить массив адресов динамически по `КоличествоАдресов`, а позиционирование
определять правилом: `0` = левый, `последний` = правый, `средний нечётного` = центр.

### Код ЗАМЕНИТЬ (строки 543–553 и 575–668):

**Вместо:**
```bsl
ЕстьПаллетВСекции = Ложь;
Адреса = Новый Массив;
Адреса.Добавить(СекцияДанные.Адрес1);
Адреса.Добавить(СекцияДанные.Адрес2);
Адреса.Добавить(СекцияДанные.Адрес3);
```

**Написать:**
```bsl
ЕстьПаллетВСекции = Ложь;

// Строим массив только из заполненных адресов с учётом КоличествоАдресов
Адреса = Новый Массив;
Все3Адреса = Новый Массив;
Все3Адреса.Добавить(СекцияДанные.Адрес1);
Все3Адреса.Добавить(СекцияДанные.Адрес2);
Все3Адреса.Добавить(СекцияДанные.Адрес3);
Для ИА = 0 По КоличествоАдресов - 1 Цикл
    Адреса.Добавить(Все3Адреса[ИА]);
КонецЦикла;
```

**Вместо (внутри цикла ячеек, позиционирование паллета):**
```bsl
СреднийИндекс = Цел(КоличествоАдресов / 2);
Если ИндексАдреса = СреднийИндекс Тогда
    СмещениеПаллетаPx = (ШиринаСекцииPx - ШиринаПаллетаPx) / 2 - ИндексАдреса * ШиринаЯчейкиPx;
ИначеЕсли ИндексАдреса = 0 Тогда
    СмещениеПаллетаPx = 0;
Иначе
    СмещениеПаллетаPx = ШиринаЯчейкиPx - ШиринаПаллетаPx;
КонецЕсли;
```

**Написать:**
```bsl
// Позиционирование: 1 адрес → центр; 2 адреса → левый/правый;
// 3 адреса → левый/центр/правый
Если КоличествоАдресов = 1 Тогда
    // Единственный адрес: паллет по центру всей секции
    СмещениеПаллетаPx = (ШиринаСекцииPx - ШиринаПаллетаPx) / 2;
ИначеЕсли ИндексАдреса = 0 Тогда
    // Левый адрес: прижат к левому краю
    СмещениеПаллетаPx = 0;
ИначеЕсли ИндексАдреса = КоличествоАдресов - 1 Тогда
    // Правый адрес: прижат к правому краю ячейки
    СмещениеПаллетаPx = ШиринаЯчейкиPx - ШиринаПаллетаPx;
Иначе
    // Средний адрес (только для 3+): центр секции
    СмещениеПаллетаPx = (ШиринаСекцииPx - ШиринаПаллетаPx) / 2 - ИндексАдреса * ШиринаЯчейкиPx;
КонецЕсли;
```

**Аналогично исправить расчёт свободного пространства (строки 659–668):**

**Вместо:**
```bsl

    РасстЛевоСтр = Формат(Окр((ШиринаСекцииМм - ШиринаПаллетаМм) / 2, 0), "ЧН=0; ЧГ=0");
    РасстПравоСтр = РасстЛевоСтр;
ИначеЕсли ИндексАдреса = 0 Тогда

    РасстПравоСтр = Формат(Окр(ШиринаСекцииМм - ШиринаПаллетаМм, 0), "ЧН=0; ЧГ=0");
Иначе
```

```bsl
    РасстПравоСтр = "";
Иначе
    // Средний (3 адреса) — свободно с обеих сторон
    РасстЛевоСтр = Формат(Окр((ШиринаСекцииМм - ШиринаПаллетаМм) / 2, 0), "ЧН=0; ЧГ=0");
    РасстПравоСтр = РасстЛевоСтр;
```

## Исправление 3 — Несоответствие легенды реальным цветам паллет

### Проблема
CSS-классы определяют:
- `.pallet-occupied` — `background: rgba(255,255,200,0.7)` (жёлтый), `border: 2px solid #888` (серый)
- `.pallet-reserved` — `background: rgba(255,255,220,0.5)` (светло-жёлтый), `border: 2px dashed #888`

Легенда (строки 780–784) показывает ***розовый/малиновый*** цвет — `rgba(255,105,180,0.5), #ff1493`.
Это явное несоответствие — легенда вводит пользователя в заблуждение.

### Решение
Синхронизировать цвета в легенде с фактическими CSS-значениями.

### Код ЗАМЕНИТЬ (строки 780–784):

**Вместо:**
```bsl
HTML = HTML + "<div class=""legend"">"
    + "<b>Обозначения:</b><br>"
    + "<div class=""legend-item""><span class=""legend-color"" style=""background:rgba(255,105,180,0.5);border-color:#ff1493""></span> Занят паллет</div>"
    + "<div class=""legend-item""><span class=""legend-color"" style=""background:rgba(255,182,193,0.4);border:2px dashed #ff1493""></span> Зарезервирован (заблокирован, не стоит)</div>"
    + "</div>";
```

**Написать:**
```bsl
HTML = HTML + "<div class=""legend"">"
    + "<b>Обозначения:</b><br>"
    + "<div class=""legend-item""><span class=""legend-color"" style=""background:rgba(255,255,200,0.7);border:2px solid #888""></span> Занят паллет</div>"
```

## Исправление 4 — Устранение повторного расчёта процента загрузки

### Проблема
При клике на стеллаж вызывается `РендерЗагрузкиСтеллажаНаСервере`, которая
на строке 281 снова вычисляет `ПолучитьПроцентЗагрузкиСтеллажа` — это два
запроса к БД, хотя процент уже был рассчитан при построении кнопки.

### Решение
Передавать процент загрузки параметром в `РендерЗагрузкиСтеллажаНаСервере`.
В `ВыбратьСтеллаж` получать его отдельным серверным вызовом, либо хранить
в атрибуте формы `ПроцентЗагрузкиТекущегоСтеллажа`.

**Вариант А — параметр функции (рекомендуется):**

Изменить сигнатуру `РендерЗагрузкиСтеллажаНаСервере`:
```bsl
// Было:
&НаСервере
Процедура РендерЗагрузкиСтеллажаНаСервере(СтеллажСсылка)

// Стало:
&НаСервере
Процедура РендерЗагрузкиСтеллажаНаСервере(СтеллажСсылка, ПроцентЗагрузки = -1)
```

Внутри процедуры заменить строку 281:
```bsl
// Было:
ПроцентЗагрузки = ПолучитьПроцентЗагрузкиСтеллажа(СтеллажСсылка);

// Стало:
Если ПроцентЗагрузки = -1 Тогда
    // Рассчитываем только если не передан снаружи
    ПроцентЗагрузки = ПолучитьПроцентЗагрузкиСтеллажа(СтеллажСсылка);
КонецЕсли;
```

В `ЗаполнитьГруппуСтеллажейНаСервере` при последующем нажатии кнопка уже знает
процент из своего заголовка — но для простоты достаточно Варианта А.

## Исправление 5 — Вынести коэффициент масштаба в атрибут формы

### Проблема
Коэффициент `КоэфМасштаба = 0.05` (строка 275) захардкожен в BSL-коде.
Пользователь не может влиять на базовый размер элементов без правки кода.
JS-слайдер (20–300%) масштабирует уже готовый HTML — он удобен, но крупные
стеллажи при базовом масштабе 0.05 отрисовываются слишком мелко.

### Решение

#### Шаг 1. Добавить атрибут формы `МасштабМм` в `Form.xml`
```xml
<Attribute name="МасштабМм" id="17">
    <Title>
        <v8:item>
            <v8:lang>ru</v8:lang>
            <v8:content>Масштаб мм/px</v8:content>
        </v8:item>
    </Title>
    <Type>
        <v8:Type>xs:decimal</v8:Type>
        <v8:NumberQualifiers>
            <v8:Digits>6</v8:Digits>
            <v8:FractionDigits>3</v8:FractionDigits>
            <v8:AllowedSign>Any</v8:AllowedSign>
        </v8:NumberQualifiers>
    </Type>
</Attribute>
```

#### Шаг 2. Добавить поле ввода в `Form.xml` (рядом с полем Склад)
```xml
<InputField name="МасштабМм" id="13">
    <DataPath>МасштабМм</DataPath>
    <Title>
        <v8:item>
            <v8:lang>ru</v8:lang>
            <v8:content>Масштаб (мм/px)</v8:content>
        </v8:item>
    </Title>
    <MinValue>0.01</MinValue>
    <MaxValue>1.0</MaxValue>
    <ExtendedTooltip name="МасштабМмРасширеннаяПодсказка" id="14"/>
</InputField>
```

#### Шаг 3. Инициализировать в `ПриСозданииНаСервере`
```bsl
&НаСервере
Процедура ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)
    //+Лико m.shenderov 15.05.2026
    ДинамическиеЭлементы = Новый СписокЗначений;
    МасштабМм = 0.05; // 1мм = 0.05px (стеллаж 2000мм → 100px)
КонецПроцедуры
```

#### Шаг 4. Использовать в `РендерЗагрузкиСтеллажаНаСервере`
```bsl
// Было:
КоэфМасштаба = 0.05;

// Стало:
КоэфМасштаба = МасштабМм;
Если КоэфМасштаба <= 0 Тогда
    КоэфМасштаба = 0.05;
КонецЕсли;
```

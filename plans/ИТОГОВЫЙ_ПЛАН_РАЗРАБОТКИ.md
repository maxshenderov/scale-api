## 🔧 Параллельная разработка Python-backend

Пока вы разрабатываете 1С-модуль, можно начать подготовку Python-части:

### Фаза 1.3-1.5: Завершение инфраструктуры (1 час)

**Файлы для создания:**

#### 1. `services/.env.example`
```
ANTHROPIC_API_KEY=sk-ant-...
OPENAI_API_KEY=sk-...
1C_API_URL=http://localhost:1541
LOG_LEVEL=INFO
DEBUG=false
```

#### 2. `services/Dockerfile`
```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

CMD ["uvicorn", "api.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

#### 3. `services/docker-compose.yml`
```yaml
version: '3.8'

services:
  ai-service:
    build: .
    ports:
      - "8000:8000"
    environment:
      - ANTHROPIC_API_KEY=${ANTHROPIC_API_KEY}
      - OPENAI_API_KEY=${OPENAI_API_KEY}
      - 1C_API_URL=${1C_API_URL}
      - LOG_LEVEL=INFO
    volumes:
      - ./:/app
    command: uvicorn api.main:app --host 0.0.0.0 --port 8000 --reload
```

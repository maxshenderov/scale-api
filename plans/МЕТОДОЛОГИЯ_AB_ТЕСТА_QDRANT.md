## 0. Концепция

Прежде чем индексировать всю базу — контролируемый эксперимент:

```
Исторические заказы (исключая последнюю неделю)
        ↓
    Индексируем в Qdrant (train set)
        ↓
Заказы за последнюю неделю (test set — НЕ в Qdrant)
        ↓
    Для каждого: формируем два варианта описания
        ├─ Вариант A: «слепой» — только размеры + название
        └─ Вариант B: «полный» — + клиент + категория
        ↓
    Каждый → embedding → поиск в Qdrant
        ↓
    Система предлагает: машину, технологию, количество цветов
        ↓
    Сравниваем с РЕАЛЬНЫМИ данными из 1С (ground truth)
        ↓
    Метрики: точность машины (top-1, top-3), точность технологии
```

## 1. Разделение данных

| Набор | Период | Что делаем |
|-------|--------|-----------|
| **Train** | `Дата < Сегодня - 7 дней` | Индексируем в Qdrant |
| **Test** | `Дата >= Сегодня - 7 дней` | НЕ индексируем, слепой тест |

## 2. Два варианта запроса (A/B)

### Вариант A — «Слепой» (blind)

Только то, что видно на макете:

```
label_name + size_width_mm + size_height_mm
```

Пример: «Этикетка СССР 1,35 л _ 295x80 мм»

### Вариант B — «Полный» (rich)

Добавляем клиента + категорию продукта:

```
label_name + size + client + product_category
```

Пример: «Этикетка СССР 1,35 л _ 295x80 мм. Клиент: КАВКАЗСКИЙ БЮВЕТ ООО. Категория: алкоголь»

## 3. Что сравниваем (ground truth vs prediction)

| Параметр | Источник в 1С (эталон) | Что предсказывает Qdrant |
|----------|------------------------|--------------------------|
| **Машина** | `ЗаказКлиента.РабочийЦентр` | top-1 payload.work_center |
| **Технология** | `ЗаказКлиента.Лико_ТехнологияПечати` | payload.technology |
| **Цветов** | `ЗаказКлиента.Цвета.Количество()` | payload.colors_count |
| **Ламинация** | `ЗаказКлиента.Лико_Ламинация` | payload.has_lamination |
| **Топ-3 машин** | N/A | Первые 3 результата Qdrant |

## 4. Метрики успеха

| Метрика | Формула | Цель |
|---------|---------|------|
| **Top-1 Machine Accuracy** | `correct_machine / total` | > 60% |
| **Top-3 Machine Accuracy** | `machine_in_top3 / total` | > 85% |
| **Technology Accuracy** | `correct_tech / total` | > 80% |
| **Color Count MAE** | `avg(abs(predicted - actual))` | < 1.5 |

### 5.2 Алгоритм (BSL)

```bsl
//+Лико m.shenderov 08.05.2026
&НаСервере
Процедура ЗапуститьТестQdrant() Экспорт
    
    // 1. Получить test-заказы (последние 7 дней, НЕ в Qdrant)
    ТестовыеЗаказы = ПолучитьТестовыеЗаказы();
    
    // 2. Для каждого заказа
    ТаблицаРезультатов = Новый ТаблицаЗначений;
    ТаблицаРезультатов.Колонки.Добавить("Заказ");
    ТаблицаРезультатов.Колонки.Добавить("РеальнаяМашина");
    ТаблицаРезультатов.Колонки.Добавить("ВариантA_Машина");
    ТаблицаРезультатов.Колонки.Добавить("ВариантA_Точность");
    ТаблицаРезультатов.Колонки.Добавить("ВариантA_Топ3");
    ТаблицаРезультатов.Колонки.Добавить("ВариантB_Машина");
    ТаблицаРезультатов.Колонки.Добавить("ВариантB_Точность");
    ТаблицаРезультатов.Колонки.Добавить("ВариантB_Топ3");
    ТаблицаРезультатов.Колонки.Добавить("РеальнаяТехнология");
    ТаблицаРезультатов.Колонки.Добавить("ВариантA_Технология");
    ТаблицаРезультатов.Колонки.Добавить("ВариантB_Технология");
    ТаблицаРезультатов.Колонки.Добавить("НазваниеЭтикетки");
    ТаблицаРезультатов.Колонки.Добавить("Размеры");
    ТаблицаРезультатов.Колонки.Добавить("Клиент");
    
    Для Каждого Заказ Из ТестовыеЗаказы Цикл
        
        Строка = ТаблицаРезультатов.Добавить();
        Строка.Заказ = Заказ.Номер;
        Строка.РеальнаяМашина = Строка(Заказ.РабочийЦентр);
        Строка.РеальнаяТехнология = Строка(Заказ.Лико_ТехнологияПечати);
        Строка.НазваниеЭтикетки = Строка(Заказ.Лико_ТипЗаказа);
        Строка.Размеры = Строка(Заказ.ШиринаЭтикетки) + "x" + Строка(Заказ.ДлинаЭтикетки);
        Строка.Клиент = Строка(Заказ.Контрагент);
        
        // --- Вариант A: слепой ---
        ТекстА = Строка.НазваниеЭтикетки + " " + Строка.Размеры;
        ВекторА = ПолучитьЭмбеддинг(ТекстА);
        
        Если ВекторА.Количество() > 0 Тогда
            РезультатыА = ПоискПохожихЗаказов(ВекторА, Неопределено, 3);
            Если РезультатыА.Количество() > 0 Тогда
                Строка.ВариантA_Машина = РезультатыА[0].payload.work_center;
                Строка.ВариантA_Технология = РезультатыА[0].payload.technology;
                
                // Топ-3 машины
                Топ3А = "";
                Для Каждого Рез Из РезультатыА Цикл
                    Топ3А = Топ3А + Рез.payload.work_center + "(" + Формат(Рез.score, "ЧЦ=2") + "); ";
                КонецЦикла;
                Строка.ВариантA_Топ3 = Топ3А;
            КонецЕсли;
        КонецЕсли;
        
        // --- Вариант B: полный ---
        ТекстB = Строка.НазваниеЭтикетки + " " + Строка.Размеры + ". Клиент: " + Строка.Клиент;
        ВекторB = ПолучитьЭмбеддинг(ТекстB);
        
        Если ВекторB.Количество() > 0 Тогда
            РезультатыB = ПоискПохожихЗаказов(ВекторB, Неопределено, 3);
            Если РезультатыB.Количество() > 0 Тогда
                Строка.ВариантB_Машина = РезультатыB[0].payload.work_center;
                Строка.ВариантB_Технология = РезультатыB[0].payload.technology;
                
                Топ3B = "";
                Для Каждого Рез Из РезультатыB Цикл
                    Топ3B = Топ3B + Рез.payload.work_center + "(" + Формат(Рез.score, "ЧЦ=2") + "); ";
                КонецЦикла;
                Строка.ВариантB_Топ3 = Топ3B;
            КонецЕсли;
        КонецЕсли;
        
        // Точность
        Строка.ВариантA_Точность = ?(Строка.ВариантA_Машина = Строка.РеальнаяМашина, "✓", "✗");
        Строка.ВариантB_Точность = ?(Строка.ВариантB_Машина = Строка.РеальнаяМашина, "✓", "✗");
        
    КонецЦикла;
    
    // 3. Вывести статистику
    ВывестиСтатистикуТеста(ТаблицаРезультатов);
    
КонецПроцедуры
```

### 5.3 Функция сбора тестовых заказов

```bsl
&НаСервере
Функция ПолучитьТестовыеЗаказы()
    Запрос = Новый Запрос;
    Запрос.Текст = "
    |ВЫБРАТЬ
    |   ЗаказКлиента.Ссылка,
    |   ЗаказКлиента.Номер,
    |   ЗаказКлиента.Контрагент,
    |   ЗаказКлиента.РабочийЦентр,
    |   ЗаказКлиента.Лико_ТехнологияПечати,
    |   ЗаказКлиента.ШиринаЭтикетки,
    |   ЗаказКлиента.ДлинаЭтикетки,
    |   ЗаказКлиента.Лико_ТипЗаказа
    |ИЗ
    |   Документ.ЗаказКлиента КАК ЗаказКлиента
    |ГДЕ
    |   ЗаказКлиента.Проведен
    |   И ЗаказКлиента.Дата >= &ДатаНеделюНазад
    |   И ЗаказКлиента.Лико_ТипЗаказа <> """"
    |   И ЗначениеЗаполнено(ЗаказКлиента.РабочийЦентр)";
    
    Запрос.УстановитьПараметр("ДатаНеделюНазад", ТекущаяДата() - 7 * 86400);
    
    РезультатЗапроса = Запрос.Выполнить();
    Возврат РезультатЗапроса.Выгрузить();
КонецФункции
```

### 5.4 Статистика в HTML

```bsl
&НаСервере
Функция ВывестиСтатистикуТеста(ТаблицаРезультатов)
    Всего = ТаблицаРезультатов.Количество();
    ВерныхА = 0; ВерныхB = 0;
    Топ3А = 0; Топ3B = 0;
    ТехА = 0; ТехB = 0;
    
    Для Каждого Строка Из ТаблицаРезультатов Цикл
        Если Строка.ВариантA_Точность = "✓" Тогда ВерныхА = ВерныхА + 1; КонецЕсли;
        Если Строка.ВариантB_Точность = "✓" Тогда ВерныхB = ВерныхB + 1; КонецЕсли;
        Если СтрНайти(Строка.ВариантA_Топ3, Строка.РеальнаяМашина) > 0 Тогда Топ3А = Топ3А + 1; КонецЕсли;
        Если СтрНайти(Строка.ВариантB_Топ3, Строка.РеальнаяМашина) > 0 Тогда Топ3B = Топ3B + 1; КонецЕсли;
        Если Строка.ВариантA_Технология = Строка.РеальнаяТехнология Тогда ТехА = ТехА + 1; КонецЕсли;
        Если Строка.ВариантB_Технология = Строка.РеальнаяТехнология Тогда ТехB = ТехB + 1; КонецЕсли;
    КонецЦикла;
    
    HTML = "<html><head><meta charset='utf-8'><style>
    |body { font-family: Arial; margin: 20px; background: #1a1a1a; color: #e8e8e8; }
    |h2 { color: #21A1DE; }
    |table { border-collapse: collapse; width: 100%; margin: 10px 0; }
    |th { background: #333; padding: 10px; text-align: left; }
    |td { padding: 8px; border-bottom: 1px solid #333; }
    |.ok { color: #2da55b; } .fail { color: #ff6b6b; }
    |.metric { font-size: 24px; font-weight: bold; }</style></head><body>
    |<h2>Результаты A/B теста Qdrant-поиска машины</h2>
    |<p>Всего тестовых заказов: " + Всего + "</p>
    |<h3>Метрики</h3>
    |<table>
    |<tr><th>Метрика</th><th>Вариант A (слепой)</th><th>Вариант B (полный)</th></tr>
    |<tr><td>Top-1 Machine Accuracy</td>
    |<td class='metric'>" + Формат(ВерныхА / Макс(Всего, 1) * 100, "ЧЦ=1") + "%</td>
    |<td class='metric'>" + Формат(ВерныхB / Макс(Всего, 1) * 100, "ЧЦ=1") + "%</td></tr>
    |<tr><td>Top-3 Machine Accuracy</td>
    |<td class='metric'>" + Формат(Топ3А / Макс(Всего, 1) * 100, "ЧЦ=1") + "%</td>
    |<td class='metric'>" + Формат(Топ3B / Макс(Всего, 1) * 100, "ЧЦ=1") + "%</td></tr>
    |<tr><td>Technology Accuracy</td>
    |<td class='metric'>" + Формат(ТехА / Макс(Всего, 1) * 100, "ЧЦ=1") + "%</td>
    |<td class='metric'>" + Формат(ТехB / Макс(Всего, 1) * 100, "ЧЦ=1") + "%</td></tr>
    |</table>
    |<h3>Детальные результаты</h3>
    |<table>
    |<tr><th>Заказ</th><th>Реальность</th><th>A (слепой)</th><th>B (полный)</th><th>Этикетка</th><th>Размер</th></tr>";
    
    Для Каждого Строка Из ТаблицаРезультатов Цикл
        КлассА = ?(Строка.ВариантA_Точность = "✓", "ok", "fail");
        КлассB = ?(Строка.ВариантB_Точность = "✓", "ok", "fail");
        HTML = HTML + "
        |<tr>
        |<td>" + Строка.Заказ + "</td>
        |<td>" + Строка.РеальнаяМашина + "</td>
        |<td class='" + КлассА + "'>" + Строка.ВариантA_Машина + "<br><small>" + Строка.ВариантA_Топ3 + "</small></td>
        |<td class='" + КлассB + "'>" + Строка.ВариантB_Машина + "<br><small>" + Строка.ВариантB_Топ3 + "</small></td>
        |<td>" + Строка.НазваниеЭтикетки + "</td>
        |<td>" + Строка.Размеры + "</td>
        |</tr>";
    КонецЦикла;
    
    HTML = HTML + "</table></body></html>";
    Возврат HTML;
КонецФункции
```

## 6. Итерации улучшения

После каждого прогона теста:

1. **Посмотреть на ошибки** — какие заказы система путает?
2. **Скорректировать категории продукта** — добавить ключевые слова
3. **Настроить вес полей** — важнее размеры или название?
4. **Добавить payload-фильтры** — technology, has_lamination
5. **Повторить тест**

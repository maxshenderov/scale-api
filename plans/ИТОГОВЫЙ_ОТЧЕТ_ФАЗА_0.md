## 🚀 Как начать разработку

### Вариант 1: Начать со стороны 1С (рекомендуется)

1. **Откройте конфигурацию в 1С:Конфигураторе**
2. **Создайте модуль `Лико_АИАссистентДанные`**
3. **Скопируйте код из [`ПЛАН_1С_МОДУЛЬ_ПРЕОБРАЗОВАНИЯ.md`](ПЛАН_1С_МОДУЛЬ_ПРЕОБРАЗОВАНИЯ.md)**
4. **Протестируйте в консоли 1С**
5. **Сообщите результаты**

### Вариант 2: Начать со стороны Python

1. **Создайте файлы конфигурации** (.env.example, Dockerfile, docker-compose.yml)
2. **Создайте базовую структуру FastAPI** (main.py, routes.py)
3. **Запустите контейнер**: `docker-compose up`
4. **Протестируйте эндпоинт**: `curl http://localhost:8000/health`

### Вариант 3: Параллельная разработка

1. **1С-разработчик** создает модуль преобразования
2. **Python-разработчик** создает FastAPI backend
3. **Встречаются** на эндпоинте `/api/v1/analyze`

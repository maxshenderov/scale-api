## 2️⃣ Цикл Agent Loop (пошагово)

```
START
  │
  ├─► Инициализация
  │   • Получить параметры задачи
  │   • Собрать системный промпт
  │   • Инициализировать историю сообщений
  │
  ├─► ЦИКЛ (макс 10 итераций)
  │   │
  │   ├─► Отправить запрос к LLM
  │   │   • Системный промпт
  │   │   • История сообщений
  │   │   • Описание инструментов
  │   │
  │   ├─► Получить ответ от LLM
  │   │
  │   ├─► Проверить тип ответа
  │   │   │
  │   │   ├─ TOOL_CALLS (LLM запрашивает инструменты)
  │   │   │  │
  │   │   │  ├─► Выполнить инструменты
  │   │   │  │   • get_order_header
  │   │   │  │   • get_colors
  │   │   │  │   • get_economics
  │   │   │  │   • и т.д.
  │   │   │  │
  │   │   │  ├─► Добавить результаты в историю
  │   │   │  │
  │   │   │  └─► Продолжить цикл
  │   │   │
  │   │   ├─ CONTENT (LLM возвращает JSON-анализ)
  │   │   │  │
  │   │   │  ├─► Парсить JSON
  │   │   │  │   (4-уровневая защита)
  │   │   │  │
  │   │   │  ├─► Рендерить HTML
  │   │   │  │   (JSON → HTML)
  │   │   │  │
  │   │   │  └─► Вернуть HTML
  │   │   │
  │   │   └─ ERROR
  │   │      └─► Ошибка
  │   │
  │   └─► Проверить условие выхода
  │       • Если content → выход
  │       • Если итерация > 10 → ошибка
  │       • Иначе → продолжить цикл
  │
  └─► END
```

## 5️⃣ Типы анализа и их персоны

```
┌─────────────────────────────────────────────────────────────────┐
│                      ТИПЫ АНАЛИЗА                               │

│                                                                  │
│  1. TECHNOLOGIST (Технолог)                                     │

│  2. ECONOMIST (Экономист)                                       │
│     ┌──────────────────────────────────────────────────────┐   │
│     │ Персона: Финансовый аналитик                         │   │
│     │ Фокус: Рентабельность, структура затрат             │   │
│     │ Выход: economics, cost_breakdown, price_scenarios   │   │
│     │ Пример: "Маржа 47%, рентабельность отличная"        │   │
│     └──────────────────────────────────────────────────────┘   │
│                                                                  │
│  3. FULL (Комплексный)                                          │
│     ┌──────────────────────────────────────────────────────┐   │
│     │ Персона: Главный технолог + финансовый директор      │   │
│     │ Фокус: Технология + экономика + ресурсы             │   │
│     │ Выход: Все секции                                    │   │
│     │ Пример: Полный анализ заказа                         │   │
│     └──────────────────────────────────────────────────────┘   │
│                                                                  │
│  4. EDUCATIONAL (Образовательный)                               │
│     ┌──────────────────────────────────────────────────────┐   │
│     │ Персона: Преподаватель полиграфии                    │   │
│     │ Фокус: Объяснение простым языком без жаргона         │   │
│     │ Выход: order_overview, process_steps, glossary       │   │
│     │ Пример: "Этикетка печатается на флексографской...   │   │
│     └──────────────────────────────────────────────────────┘   │
```

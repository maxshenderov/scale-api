# План: WMS AI Expert — Phase 1

> Интеграция WMS-знаний в чат-интерфейс обработки ЗагрузкаСклада.

## Контекст

Обработка [[ЗагрузкаСклада]] имеет работающий чат с LLM (страница «Асистент AI»). Поля `Требования`, `ЧерновикТЗ`, `ТехническоеЗадание` уже созданы как атрибуты формы, но не подключены к LLM-потоку. Кнопки «Сформировать ТЗ» и «Экспертиза» отсутствуют.

4 макета MD-знаний WMS созданы и закоммичены. Требуется BSL-интеграция.

## Текущая архитектура (ключевые точки)

| Функция | Строка | Роль |
|---------|--------|------|
| `ЗадачиДляLLM()` | 3255 | Определяет список задач (сейчас 1: АналитикСклада) |
| `ВыполнитьЗапросКLLМ()` | 1487 | Клиентский обработчик: строит system prompt, вызывает сервер |
| `ОтправитьЗапросLLMНаСервере()` | 1540 | Сервер: создаёт историю, вызывает СпроситьLLM |
| `НоваяИсторияДиалога(СП, Формат, ПостоянныйКонтекст)` | 2279 | Создаёт историю с system-сообщением |
| `СпроситьLLM(История, Вопрос, Настройки, Инстр, Формат, Контекст)` | 2339 | Оркестратор LLM-запроса |
| `ДобавитьСистемныйПузырьНаСервере(Текст)` | 1721 | Системное сообщение в чат |

## Шаги реализации

### Шаг 0: Сформировать MD-контент макетов

**Источники:**

| Макет | Источник |
|-------|----------|
| `WMS_ПодобратьЯчейку` | wiki [[Лико_ПодобратьЯчейку]] + BSL `ManagerModule.bsl:51-408` |
| `WMS_ОшибкиРазмещения` | wiki [[Лико_СкладскиеСекции]] + BSL `ManagerModule.bsl:429-576` |
| `WMS_ВремяДоступа` | BSL `ManagerModule.bsl:579-616` |
| `WMS_Топология_ЛК_Высотный` | `Топология_Склада_Ликофлекс_Высотный_ПОЛНАЯ_2.md` |

**Критерий:** каждый MD — самодостаточный документ. LLM понимает алгоритм без чтения BSL.

**Файлы:** `Templates/<Имя>.xml` (дескриптор) + `Templates/<Имя>/Ext/Template.txt` (контент)

**Проверка:** открыть `Template.txt`, убедиться что содержит сигнатуру, алгоритм, все правила, без маркеров «TBD».


**Проверка:** вызвать из теста, убедиться что возвращает непустой MD.

### Шаг 2: `ПолучитьSystemPromptWMS(Склад)`

**Файл:** `Form/Module.bsl`
**Где:** рядом с Шагом 1

```bsl
&НаСервере
Функция ПолучитьSystemPromptWMS(Склад) Экспорт
    Результат = ПолучитьТекстМакета("WMS_ПодобратьЯчейку") + Символы.ПС + Символы.ПС
        + ПолучитьТекстМакета("WMS_ОшибкиРазмещения") + Символы.ПС + Символы.ПС
        + ПолучитьТекстМакета("WMS_ВремяДоступа");

    СоответствиеСкладТопология = Новый Соответствие;
    СоответствиеСкладТопология.Вставить("ЛК Высотный", "WMS_Топология_ЛК_Высотный");

    Если ЗначениеЗаполнено(Склад) Тогда
        КлючСклада = СокрЛП(Склад.Наименование);
        ИмяМакета = СоответствиеСкладТопология.Получить(КлючСклада);
        Если ИмяМакета <> Неопределено Тогда
            Результат = Результат + Символы.ПС + Символы.ПС
                + ПолучитьТекстМакета(ИмяМакета);
        КонецЕсли;
    КонецЕсли;

    Возврат Результат;
КонецФункции
```

**Проверка:** выбрать склад «ЛК Высотный», вызвать — возвращает 4 MD-документа одной строкой.

**Файл:** `Form/Module.bsl`

```bsl
ПараметрыЗадачи = Новый Структура;
```

### Шаг 4: Кнопка «Сформировать ТЗ»

**Файлы:** `Form.xml` (кнопка + команда) + `Form/Module.bsl` (клиент + сервер)

#### Form.xml — команда
```xml
<Command name="СформироватьТЗ" id="7">
    <Title><v8:item><v8:lang>ru</v8:lang>
        <v8:content>Сформировать ТЗ</v8:content></v8:item></Title>
    <ToolTip><v8:item><v8:lang>ru</v8:lang>
        <v8:content>Сформировать техническое задание из требований</v8:content></v8:item></ToolTip>
    <Action>СформироватьТЗ</Action>
</Command>
```

#### Form.xml — кнопка (в `Группа3`, id=86)
```xml
<Button name="СформироватьТЗ" id="226">
    <Type>UsualButton</Type>
    <CommandName>Form.Command.СформироватьТЗ</CommandName>
</Button>
```

#### Form/Module.bsl — клиентский обработчик
```bsl
&НаКлиенте
Процедура СформироватьТЗ(Команда)
    Если Не ЗначениеЗаполнено(Требования) Тогда
        Сообщить("Введите требования на вкладке Требования.");
        Возврат;
    КонецЕсли;
    ДобавитьСистемныйПузырьНаСервере("Формирование ТЗ...");
    Результат = СформироватьТЗНаСервере();
    ДобавитьСистемныйПузырьНаСервере(Результат);
КонецПроцедуры
```

#### Form/Module.bsl — серверная функция
```bsl
&НаСервере
Функция СформироватьТЗНаСервере() Экспорт
    WMS_SP = ПолучитьSystemPromptWMS(Склад);
    СистемныйПромпт = "Ты — WMS-эксперт. Сформируй техническое задание в Markdown. " +
        "Разделы: 1.Цель 2.Требования 3.Объекты 4.Алгоритмы 5.Риски 6.Тест-кейсы";

    Настройки = ПараметрыПровайдера(Провайдер, Модель);
    История = НоваяИсторияДиалога(СистемныйПромпт, "markdown", WMS_SP);
    РезультатLLM = СпроситьLLM(История, Требования, Настройки, , "markdown");

    Если РезультатLLM.Успех Тогда
        ЧерновикТЗ = РезультатLLM.Текст;
        Возврат "ТЗ сформировано. Проверьте вкладку Черновик.";
    Иначе
        Возврат "Ошибка: " + РезультатLLM.ОписаниеОшибки;
    КонецЕсли;
КонецФункции
```

**Проверка:** ввести требования → нажать «Сформировать ТЗ» → поле `ЧерновикТЗ` заполняется Markdown-текстом.

### Шаг 5: Кнопка «Экспертиза»

**Файлы:** `Form.xml` (кнопка + команда) + `Form/Module.bsl` (клиент + сервер)

#### Form.xml — команда
```xml
<Command name="Экспертиза" id="8">
    <Title><v8:item><v8:lang>ru</v8:lang>
        <v8:content>Экспертиза</v8:content></v8:item></Title>
    <ToolTip><v8:item><v8:lang>ru</v8:lang>
        <v8:content>Экспертиза ТЗ (Критик / Адвокат / Судья)</v8:content></v8:item></ToolTip>
    <Action>Экспертиза</Action>
</Command>
```

#### Form.xml — кнопка (в `Группа3`)
```xml
<Button name="Экспертиза" id="228">
    <Type>UsualButton</Type>
    <CommandName>Form.Command.Экспертиза</CommandName>
</Button>
```

#### Form/Module.bsl — серверная функция
```bsl
&НаСервере
Функция ЭкспертизаНаСервере() Экспорт
    Если Не ЗначениеЗаполнено(ЧерновикТЗ) Тогда
        // авто-формирование ТЗ если черновик пуст
        СформироватьТЗНаСервере();
    КонецЕсли;

    WMS_SP = ПолучитьSystemPromptWMS(Склад);
    Настройки = ПараметрыПровайдера(Провайдер, Модель);

    // Критик
    СП_Критик = "Ты — WMS-эксперт-КРИТИК. Найди противоречия, ошибки, риски.";
    ИстК = НоваяИсторияДиалога(СП_Критик, "markdown", WMS_SP);
    ОтвК = СпроситьLLM(ИстК, "Проанализируй ТЗ:" + Символы.ПС + ЧерновикТЗ, Настройки, , "markdown");

    // Адвокат
    СП_Адв = "Ты — WMS-эксперт-АДВОКАТ. Защити решение, объясни бизнес-логику.";
    ИстА = НоваяИсторияДиалога(СП_Адв, "markdown", WMS_SP);
    ОтвА = СпроситьLLM(ИстА, "Защити ТЗ:" + Символы.ПС + ЧерновикТЗ, Настройки, , "markdown");

    // Судья
    СП_Суд = "Ты — WMS-эксперт-СУДЬЯ. Вынеси вердикт: ПРИНЯТО / ДОРАБОТКА / ОТКЛОНЕНО.";
    ИстС = НоваяИсторияДиалога(СП_Суд, "markdown", WMS_SP);
    Сообщение = "## ТЗ\n" + ЧерновикТЗ + "\n\n## КРИТИК\n" + ОтвК.Текст + "\n\n## АДВОКАТ\n" + ОтвА.Текст;
    ОтвС = СпроситьLLM(ИстС, Сообщение, Настройки, , "markdown");

    Возврат ОтвС.Текст;
КонецФункции
```

**Проверка:** нажать «Экспертиза» → три последовательных вызова LLM, результат в `ОтветLLMHTML`. При вердикте «ПРИНЯТО» — копирование `ЧерновикТЗ` в `ТехническоеЗадание`.

## Проверка (по шагам)

1. Открыть ЗагрузкаСклада → Склад «ЛК Высотный» → Асистент AI → Задача «WMS Эксперт»
2. Спросить: «Почему паллета X в ячейке Y?» — ответ ссылается на ПодобратьЯчейку и топологию
3. Вкладка Требования → ввести текст → «Сформировать ТЗ» → `ЧерновикТЗ` заполнен
4. «Экспертиза» → три вызова LLM → результат в чате
5. Выбрать другой склад (без топологии) — WMS знания без топологии

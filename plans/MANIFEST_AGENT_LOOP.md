## 📞 Информация о проекте

**Название:** Agent Loop с инструментами для AIАссистента  
**Разработчик:** m.shenderov  
**Версия:** 1.0  
**Дата завершения:** 06.05.2026  
**Статус:** ✅ Production Ready  

**Описание:** Полнофункциональная система анализа заказов типографии через LLM с поддержкой function calling (инструментов). Система позволяет LLM запрашивать данные из 1С, анализировать их и возвращать структурированный JSON-отчёт с HTML-рендерингом.

---

## 🎓 Ключевые особенности

✅ **Function Calling** — LLM может запрашивать данные  
✅ **Итеративный анализ** — LLM может запросить ещё данные  
✅ **Множественные персоны** — разные типы анализа для разных ролей  
✅ **Надёжный парсинг** — 4-уровневая защита от ошибок  
✅ **Красивый HTML** — автоматический рендеринг с CSS  
✅ **Образовательный режим** — объяснение простым языком  
✅ **Масштабируемость** — легко добавить новые инструменты  
✅ **Production Ready** — протестировано и готово к использованию

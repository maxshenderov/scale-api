## 🐍 Параллельная подготовка Python-проекта

Пока вы разрабатываете 1С-модуль, можно подготовить Python-проект:

### Шаг 2.1: Создать конфигурационные файлы (Фаза 1.3-1.5)

**services/.env.example**
```
ANTHROPIC_API_KEY=sk-ant-...
OPENAI_API_KEY=sk-...
1C_API_URL=http://localhost:1541
LOG_LEVEL=INFO
```

**services/Dockerfile**
```dockerfile
FROM python:3.11-slim

WORKDIR /app

COPY requirements.txt .
RUN pip install --no-cache-dir -r requirements.txt

COPY . .

CMD ["uvicorn", "api.main:app", "--host", "0.0.0.0", "--port", "8000"]
```

**services/docker-compose.yml**
```yaml
version: '3.8'

services:
  ai-assistant:
    build: .
    ports:
      - "8000:8000"
    environment:
      - ANTHROPIC_API_KEY=${ANTHROPIC_API_KEY}
      - OPENAI_API_KEY=${OPENAI_API_KEY}
      - 1C_API_URL=${1C_API_URL}
    volumes:
      - ./:/app
```

### Шаг 2.2: Создать базовую структуру FastAPI (Фаза 2.1-2.5)

**services/api/main.py**
```python
from fastapi import FastAPI
from fastapi.middleware.cors import CORSMiddleware
import logging

app = FastAPI(title="AI Assistant for Printing Company")

# CORS для 1С
app.add_middleware(
    CORSMiddleware,
    allow_origins=["*"],
    allow_credentials=True,
    allow_methods=["*"],
    allow_headers=["*"],
)

# Логирование
logging.basicConfig(level=logging.INFO)
logger = logging.getLogger(__name__)

@app.get("/health")
async def health():
    return {"status": "ok"}

if __name__ == "__main__":
    import uvicorn
    uvicorn.run(app, host="0.0.0.0", port=8000)
```

## ❓ Часто задаваемые вопросы

**Q: С чего начать?**
A: Начните с создания 1С-модуля `Лико_АИАссистентДанные`. Это основа для всей системы.

**Q: Нужно ли создавать Python-проект сразу?**
A: Нет, можно разработать 1С-модуль отдельно, а потом интегрировать с Python. Но параллельная разработка ускорит процесс.

**Q: Какие реквизиты обязательны?**
A: Все реквизиты из плана. Если какого-то нет в ЗаказКлиента, добавьте как дополнительный реквизит.

**Q: Как тестировать 1С-модуль?**
A: Используйте консоль 1С (F9) и выполняйте функции вручную. Проверяйте результаты в отладчике.

**Q: Что делать, если JSON невалиден?**
A: Проверьте типы данных. Все числовые поля должны быть числами, строки — строками, даты — датами.

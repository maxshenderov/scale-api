# План реализации: Этап 0 (MVP) — Кнопка AI-Ассистент в 1С

**Версия:** 1.0  
**Статус:** Готов к разработке  
**Длительность:** 2–3 недели

---

## Обзор Этапа 0

**Цель:** Создать MVP, который анализирует существующий заказ в 1С и возвращает HTML-форму с технической и экономической оценкой.

**Входные данные:**
- JSON заказа из 1С (шапка + табличные части)
- PDF/JPG оригинал-макета (base64)

**Выходные данные:**
- HTML-форма с 4 блоками оценки (техническая, экономическая, анализ макета, чек-лист)

**Архитектура:**
```
1С (кнопка) → HTTP POST → FastAPI → LLM (Claude) → HTML → 1С (модальное окно)
```

---

## Компоненты для разработки

### На стороне 1С (BSL)

1. **Модуль `Лико_АИАссистентДанные` (серверный)**
   - Сбор данных заказа
   - Сериализация табличных частей
   - Отправка в FastAPI

2. **Модуль `Лико_АИАссистентКлиент` (клиентский)**
   - Обработка кнопок
   - Отображение результатов в модальном окне

3. **Расширение формы `Лико_ФормаДокумента` (ЗаказКлиента)**
   - Добавление кнопок "AI-Ассистент технолога" и "AI-Ассистент экономиста"

4. **HTTP-сервис `Лико_АИАссистентСервис` (опционально)**
   - REST-эндпоинты для вызова из внешних систем

### На стороне Python (FastAPI)

1. **`order_normalizer.py`**
   - Преобразование сырого JSON из 1С в нормализованный формат

2. **`pdf_processor.py`**
   - Парсинг PDF (извлечение текста и изображений)
   - Анализ макета с помощью Vision LLM

3. **`llm_client.py`**
   - Интеграция с Claude 3.5 Sonnet
   - Отправка промптов
   - Обработка ответов

4. **`html_generator.py`**
   - Генерация HTML-форм для отображения результатов

5. **`main.py` и `routes.py`**
   - FastAPI приложение
   - Эндпоинт `POST /api/v1/analyze`

6. **`requirements.txt`**
   - Зависимости Python

7. **`docker-compose.yml` и `Dockerfile`**
   - Контейнеризация

## Риски и митигация

| Риск | Вероятность | Влияние | Митигация |
|------|-------------|--------|----------|
| LLM даёт неправильный анализ | Средняя | Высокое | Валидация результатов, human-in-the-loop |
| PDF-парсер не распознаёт макет | Средняя | Среднее | Fallback на ручной ввод, логирование ошибок |
| 1С не может отправить HTTP-запрос | Низкая | Высокое | Тестирование на ранних этапах, документация |
| API ключи скомпрометированы | Низкая | Высокое | Использование .env, ограничение доступа |
| Timeout при анализе | Низкая | Среднее | Увеличение timeout, асинхронная обработка |

# ЭТАП 4: Разработка обработчика кнопки "Анализ заказа"

## Обзор этапа

На этом этапе мы создадим обработчик кнопки "Анализ заказа", который:
1. Проверяет, что заказ выбран
2. Вызывает функцию `ОтправитьЗапросАнализаЗаказа()` из Этапа 3
3. Отображает результат в поле `htmlЗаказ`
4. Обрабатывает ошибки и выводит сообщения пользователю

## Архитектура обработчика

```
Пользователь нажимает кнопку "Анализ заказа"
        ↓
АнализЗаказа(Команда) [обработчик кнопки]
        ↓
Проверка: заказ выбран?
        ↓ Да
ОтправитьЗапросАнализаЗаказа(Объект.Заказ, "Полный")
        ↓
Получение HTML-результата
        ↓
Объект.htmlЗаказ = РезультатHTML
        ↓
Отображение результата в поле htmlЗаказ
        ↓
Сообщение пользователю: "Анализ завершён"
```

## Полный код обработчика кнопки

Добавьте эту процедуру в модуль формы ТестLLM (в файл `1c/ERP/Обраб/ТестLLM/ТестLLM/Forms/Форма/Ext/Form/Module.bsl`):

```bsl
//+Лико m.shenderov 05.05.2026
// Обработчик кнопки "Анализ заказа"
// Отправляет заказ в LLM для анализа и отображает результат
Процедура АнализЗаказа(Команда)
    
    Попытка
        // Проверка 1: Заказ выбран?
        Если Объект.Заказ.Пусто() Тогда
            Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Пожалуйста, выберите заказ для анализа");
            Возврат;
        КонецЕсли;
        
        // Проверка 2: Заказ существует в базе?
        ДокументОбъект = Объект.Заказ.ПолучитьОбъект();
        Если ДокументОбъект = Неопределено Тогда
            Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Ошибка: заказ не найден в базе данных");
            Возврат;
        КонецЕсли;
        
        // Информирование пользователя о начале анализа
        Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Анализ заказа " + Объект.Заказ + " в процессе...");
        
        // Получение типа анализа (по умолчанию - полный)
        ТипАнализа = ПолучитьТипАнализаИзПараметров();
        
        // Вызов функции анализа
        РезультатHTML = ОтправитьЗапросАнализаЗаказа(Объект.Заказ, ТипАнализа);
        
        // Проверка результата
        Если ПустаяСтрока(РезультатHTML) Тогда
            Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Ошибка: не удалось получить результат анализа");
            Возврат;
        КонецЕсли;
        
        // Отображение результата в поле htmlЗаказ
        Объект.htmlЗаказ = РезультатHTML;
        
        // Информирование пользователя об успехе
        Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Анализ заказа " + Объект.Заказ + " завершён успешно");
        
    Исключение
        ОписаниеОшибки = ОписаниеОшибки();
        Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Ошибка при анализе заказа: " + ОписаниеОшибки);
    КонецПопытки;
    
КонецПроцедуры

//+Лико m.shenderov 05.05.2026
// Получает тип анализа из параметров сеанса или возвращает значение по умолчанию
Функция ПолучитьТипАнализаИзПараметров()
    
    // Проверяем, есть ли параметр сеанса для типа анализа
    Если ПараметрыСеанса.Свойство("Лико_ТипАнализаЗаказа") Тогда
        ТипАнализа = ПараметрыСеанса.Лико_ТипАнализаЗаказа;
        Если НЕ ПустаяСтрока(ТипАнализа) Тогда
            Возврат ТипАнализа;
        КонецЕсли;
    КонецЕсли;
    
    // Значение по умолчанию
    Возврат "Полный";
    
КонецФункции
```

```bsl
//+Лико m.shenderov 05.05.2026
// Расширенный обработчик кнопки "Анализ заказа" с выбором типа

// Показывает диалог выбора типа анализа
Функция ПоказатьДиалогВыбораТипаАнализа()
    
    СписокТипов = Новый СписокЗначений;
    СписокТипов.Добавить("Полный", "Полный анализ (технолог + экономист)");
    СписокТипов.Добавить("Технолог", "Анализ технолога");
    СписокТипов.Добавить("Экономист", "Анализ экономиста");
    
    ВыбранноеЗначение = Неопределено;
    
    Если СписокТипов.ВыбратьЭлемент(ВыбранноеЗначение, "Выберите тип анализа:") Тогда

    КонецЕсли;
    
    Возврат "";
    
КонецФункции
```

## Версия с кэшированием результатов

Если вы хотите кэшировать результаты анализа, чтобы не отправлять повторные запросы в LLM:

```bsl
//+Лико m.shenderov 05.05.2026
// Глобальный кэш результатов анализа
КэшРезультатовАнализа = Новый Соответствие;

//+Лико m.shenderov 05.05.2026
// Обработчик кнопки "Анализ заказа" с кэшированием
Процедура АнализЗаказа(Команда)
    
    Попытка
        // Проверка 1: Заказ выбран?
        Если Объект.Заказ.Пусто() Тогда
            Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Пожалуйста, выберите заказ для анализа");
            Возврат;
        КонецЕсли;
        
        // Проверка 2: Заказ существует в базе?
        ДокументОбъект = Объект.Заказ.ПолучитьОбъект();
        Если ДокументОбъект = Неопределено Тогда
            Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Ошибка: заказ не найден в базе данных");
            Возврат;
        КонецЕсли;
        
        ТипАнализа = ПолучитьТипАнализаИзПараметров();
        
        // Проверка кэша
        КлючКэша = Объект.Заказ + "_" + ТипАнализа;
        РезультатИзКэша = КэшРезультатовАнализа.Получить(КлючКэша);
        
        Если РезультатИзКэша <> Неопределено Тогда
            Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Анализ загружен из кэша");
            Объект.htmlЗаказ = РезультатИзКэша;
            Возврат;
        КонецЕсли;
        
        // Информирование пользователя о начале анализа
        Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Анализ заказа " + Объект.Заказ + " в процессе...");
        
        // Вызов функции анализа
        РезультатHTML = ОтправитьЗапросАнализаЗаказа(Объект.Заказ, ТипАнализа);
        
        // Проверка результата
        Если ПустаяСтрока(РезультатHTML) Тогда
            Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Ошибка: не удалось получить результат анализа");
            Возврат;
        КонецЕсли;
        
        // Сохранение в кэш
        КэшРезультатовАнализа.Вставить(КлючКэша, РезультатHTML);
        
        // Отображение результата в поле htmlЗаказ
        Объект.htmlЗаказ = РезультатHTML;
        
        // Информирование пользователя об успехе
        Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Анализ заказа " + Объект.Заказ + " завершён успешно");
        
    Исключение
        ОписаниеОшибки = ОписаниеОшибки();
        Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Ошибка при анализе заказа: " + ОписаниеОшибки);
    КонецПопытки;
    
КонецПроцедуры

//+Лико m.shenderov 05.05.2026
// Очистить кэш результатов анализа
Процедура ОчиститьКэшАнализа(Команда)
    КэшРезультатовАнализа.Очистить();
    Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Кэш результатов анализа очищен");
КонецПроцедуры
```

## Инструкции по добавлению кода

### Шаг 1: Откройте модуль формы ТестLLM

1. В 1С:Конфигураторе откройте **Обработки → ТестLLM → Форма → Модуль**
2. Перейдите в конец файла (после функций из Этапа 3)

### Шаг 2: Добавьте процедуру обработчика

1. Выберите одну из версий:
   - **Базовая версия** — простой обработчик без выбора типа
   - **Расширенная версия** — с диалогом выбора типа анализа
   - **Версия с кэшированием** — с сохранением результатов в памяти

2. Скопируйте выбранный код
3. Вставьте в конец модуля формы

### Шаг 3: Привяжите процедуру к кнопке

1. Откройте форму ТестLLM в дизайнере
2. Выберите кнопку "Анализ заказа"
3. В свойствах кнопки установите:
   - **Действие** → **АнализЗаказа**
   - **Представление** → **Кнопка**

### Шаг 4: Сохраните и скомпилируйте

1. Нажмите **Ctrl+S** для сохранения
2. Нажмите **F7** для компиляции конфигурации
3. Проверьте, что нет ошибок компиляции

## Тестирование обработчика

### Тест 1: Базовый тест

1. Откройте обработку ТестLLM
2. Выберите заказ в поле "Заказ" (например, ЛК006640049)
3. Нажмите кнопку "Анализ заказа"
4. Проверьте, что:
   - Появилось сообщение "Анализ заказа ... в процессе..."
   - В поле htmlЗаказ отобразился HTML-результат
   - Появилось сообщение "Анализ заказа ... завершён успешно"

### Тест 2: Тест без выбора заказа

1. Откройте обработку ТестLLM
2. Оставьте поле "Заказ" пустым
3. Нажмите кнопку "Анализ заказа"
4. Проверьте, что появилось сообщение об ошибке: "Пожалуйста, выберите заказ для анализа"

### Тест 3: Тест с расширенной версией

1. Откройте обработку ТестLLM
2. Выберите заказ
3. Нажмите кнопку "Анализ заказа"
4. Проверьте, что появился диалог выбора типа анализа
5. Выберите "Полный анализ"
6. Проверьте результат

### Тест 4: Тест кэширования

1. Откройте обработку ТестLLM
2. Выберите заказ
3. Нажмите кнопку "Анализ заказа"
4. Дождитесь результата
5. Нажмите кнопку "Анализ заказа" ещё раз
6. Проверьте, что появилось сообщение "Анализ загружен из кэша"

## Обработка ошибок

Обработчик обрабатывает следующие ошибки:

| Ошибка | Обработка |
|--------|-----------|
| Заказ не выбран | Сообщение: "Пожалуйста, выберите заказ для анализа" |
| Заказ не найден в БД | Сообщение: "Ошибка: заказ не найден в базе данных" |
| Не удалось получить результат | Сообщение: "Ошибка: не удалось получить результат анализа" |
| Исключение при выполнении | Сообщение: "Ошибка при анализе заказа: [описание]" |

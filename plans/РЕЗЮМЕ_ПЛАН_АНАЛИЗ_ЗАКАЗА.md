## 🎯 Что нужно сделать

Добавить в обработку **ТестLLM** функцию анализа заказа:

```
Пользователь выбирает заказ → Нажимает "Анализ заказа" → 
Система преобразует заказ в JSON → Отправляет в LLM → 
Отображает HTML-результат в поле htmlЗаказ
```

## 📊 Структура работ

### Этап 1: Подготовка (30 минут)
- Добавить реквизит `Заказ` (ссылка на ЗаказКлиента)
- Добавить реквизит `htmlЗаказ` (строка, неограниченная)
- Добавить кнопку "Анализ заказа" на форму
- Скомпилировать конфигурацию

### Этап 2: Функция преобразования JSON (1 час)
- Создать функцию `ПолучитьДанныеЗаказаДляАИ(ДокументСсылка)`
- Реализовать 7 вспомогательных функций для сбора данных:
  - Шапка заказа
  - Параметры этикетки
  - Данные производства
  - Операции печати (из регистра Лико_ЗаказЦвета)
  - Метрики (тираж, метраж)
  - Экономические данные
  - Данные качества
- Преобразовать структуру в JSON

### Этап 3: Функция отправки в LLM (45 минут)
- Создать функцию `ОтправитьЗапросАнализаЗаказа(ДокументСсылка, ТипАнализа)`
- Получить JSON заказа
- Сформировать промпт для анализа
- Отправить в LLM через существующую функцию `ОтправитьЗапросКLLM`
- Обработать ответ и вернуть HTML

### Этап 4: Обработчик кнопки (30 минут)
- Создать процедуру `АнализЗаказа(Команда)`
- Проверить выбор заказа
- Вызвать функцию анализа
- Отобразить результат в htmlЗаказ
- Обработать ошибки

### Этап 5: Тестирование (45 минут)
- Проверить формирование JSON
- Проверить отправку в LLM
- Проверить отображение HTML
- Проверить обработку ошибок
- Оптимизировать производительность

## 🔑 Ключевые компоненты

### 1. Реквизиты обработки ТестLLM

| Имя | Тип | Назначение |
|-----|-----|-----------|
| `Заказ` | DocumentRef.ЗаказКлиента | Выбор заказа для анализа |
| `htmlЗаказ` | Строка (неограниченная) | Результат анализа в HTML |

### 2. Функции преобразования

```
ПолучитьДанныеЗаказаДляАИ(ДокументСсылка)
├─ ПолучитьДанныеШапки(ДокументОбъект)
├─ ПолучитьДанныеЭтикетки(ДокументОбъект)
├─ ПолучитьДанныеПроизводства(ДокументОбъект)
├─ ПолучитьДанныеОперацийПечати(ДокументСсылка)
├─ ПолучитьДанныеМетрик(ДокументОбъект)
├─ ПолучитьДанныеЭкономики(ДокументОбъект)
├─ ПолучитьДанныеКачества(ДокументОбъект)
└─ Преобразовать в JSON
```

### 3. Функция отправки в LLM

```
ОтправитьЗапросАнализаЗаказа(ДокументСсылка, ТипАнализа)
├─ Получить JSON заказа
├─ Сформировать промпт
├─ Отправить в LLM (ОтправитьЗапросКLLM)
└─ Вернуть HTML-результат
```

### 4. Обработчик кнопки

```
АнализЗаказа(Команда)
├─ Проверить выбор заказа
├─ Вызвать ОтправитьЗапросАнализаЗаказа
├─ Отобразить результат в htmlЗаказ
└─ Обработать ошибки
```

## ⚠️ Потенциальные проблемы и решения

### Проблема 1: "Реквизит не найден"
**Причина**: Реквизит ЗаказКлиента не существует  
**Решение**: Проверьте имя реквизита в конфигурации, используйте правильное имя

### Проблема 2: "Регистр сведений не найден"
**Причина**: Регистр Лико_ЗаказЦвета не существует  
**Решение**: Используйте существующий регистр или табличную часть

### Проблема 3: JSON содержит null значения
**Причина**: Реквизит не заполнен  
**Решение**: Это нормально, null означает отсутствие значения

### Проблема 4: Ошибка при отправке в LLM
**Причина**: Неверный формат JSON или ошибка сети  
**Решение**: Проверьте JSON в консоли, убедитесь в наличии интернета

### Проблема 5: HTML не отображается
**Причина**: Поле htmlЗаказ не поддерживает HTML  
**Решение**: Используйте поле типа "HTML-документ" или "Текстовое поле"

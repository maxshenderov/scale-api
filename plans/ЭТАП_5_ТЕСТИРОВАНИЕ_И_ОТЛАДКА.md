## ТЕСТ 1: Формирование JSON

### Цель теста

Проверить, что функция `ПолучитьДанныеЗаказаДляАИ()` корректно преобразует данные заказа в JSON.

### Процедура тестирования

#### Шаг 1: Откройте консоль 1С

1. В 1С:Конфигураторе нажмите **Ctrl+Shift+F9** (или **Отладка → Консоль**)
2. Откроется окно консоли

#### Шаг 2: Выполните код для получения JSON

```bsl
// Получаем ссылку на тестовый заказ
ДокументСсылка = Справочники.ЗаказКлиента.НайтиПоНаименованию("ЛК006640049");

// Проверяем, что заказ найден
Если ДокументСсылка.Пусто() Тогда
    Сообщить("Ошибка: заказ ЛК006640049 не найден");
    Возврат;
КонецЕсли;

Сообщить("Заказ найден: " + ДокументСсылка);

// Получаем JSON
ДанныеJSON = ПолучитьДанныеЗаказаДляАИ(ДокументСсылка);

// Выводим JSON
Сообщить("JSON заказа:");
Сообщить(ДанныеJSON);
```

#### Шаг 3: Проверьте результат

Ожидаемый результат:
- JSON содержит 8 основных секций: `header`, `label`, `production`, `operations`, `metrics`, `economics`, `quality`
- Каждая секция содержит соответствующие данные
- JSON валиден (можно распарсить)

Пример структуры JSON:

```json
{
  "header": {
    "order_id": "ЛК006640049",
    "date": "2026-05-05",
    "client": "Клиент",
    "manager": "Менеджер",
    "status": "Проведён"
  },
  "label": {
    "name": "Этикетка",
    "size_mm": {"width": 100, "height": 50},
    "rapport": 10,
    "lanes": 4
  },
  "production": {
    "technology": "Флексо",
    "material": "Плёнка",
    "laminated": true
  },
  "operations": [
    {
      "number": 1,
      "name": "Печать",
      "type": "Флексо"
    }
  ],
  "metrics": {
    "circulation": 10000,
    "linear_meters": 500,
    "production_time": 8
  },
  "economics": {
    "price": 50000,
    "profitability": 25,
    "currency": "RUB"
  },
  "quality": {
    "spell_check": true,
    "barcode_check": true,
    "otk_control": true
  }
}
```

### Критерии успеха

- [ ] JSON успешно получен
- [ ] JSON содержит все 8 секций
- [ ] JSON валиден (можно распарсить)
- [ ] Все значения заполнены корректно
- [ ] Нет ошибок в консоли

### Отладка при ошибке

Если JSON не получен или содержит ошибки:

1. **Проверьте, что заказ существует:**
   ```bsl
   ДокументСсылка = Справочники.ЗаказКлиента.НайтиПоНаименованию("ЛК006640049");
   Сообщить(ДокументСсылка);
   ```

2. **Проверьте, что функция ПолучитьДанныеЗаказаДляАИ добавлена:**

3. **Проверьте логи ошибок:**
   - Откройте **Сервис → Журнал регистрации**
   - Найдите ошибки, связанные с функцией

## ТЕСТ 2: Отправка запроса в LLM

### Цель теста

Проверить, что функция `ОтправитьЗапросАнализаЗаказа()` корректно отправляет запрос в LLM и получает результат.

### Процедура тестирования

#### Шаг 1: Выполните код для отправки запроса

```bsl
// Получаем ссылку на тестовый заказ
ДокументСсылка = Справочники.ЗаказКлиента.НайтиПоНаименованию("ЛК006640049");

Если ДокументСсылка.Пусто() Тогда
    Сообщить("Ошибка: заказ не найден");
    Возврат;
КонецЕсли;

Сообщить("Начало анализа заказа...");

// Отправляем запрос в LLM
РезультатHTML = ОтправитьЗапросАнализаЗаказа(ДокументСсылка, "Полный");

// Выводим результат
Сообщить("Результат анализа:");
Сообщить(РезультатHTML);

// Проверяем, что результат содержит HTML
Если СтрНайти(РезультатHTML, "<html") > 0 Тогда
    Сообщить("✓ Результат содержит HTML");
Иначе
    Сообщить("✗ Результат не содержит HTML");
КонецЕсли;
```

#### Шаг 2: Проверьте результат

Ожидаемый результат:
- Функция возвращает HTML-строку
- HTML содержит теги `<html>`, `<body>`, `<h2>`, `<h3>` и т.д.
- HTML содержит анализ заказа (текст, таблицы, списки)
- Нет ошибок в консоли

### Критерии успеха

- [ ] Функция успешно выполнена
- [ ] Результат содержит HTML
- [ ] HTML содержит анализ заказа
- [ ] Время выполнения < 30 сек
- [ ] Нет ошибок в консоли

### Отладка при ошибке

Если запрос не отправлен или LLM не вернул результат:

1. **Проверьте, что функция ОтправитьЗапросКLLM работает:**
   ```bsl
   Промпт = "Привет, LLM!";
   РезультатLLM = ОтправитьЗапросКLLM(Промпт);
   Сообщить(РезультатLLM);
   ```

2. **Проверьте подключение к LLM:**
   - Откройте **Сервис → Параметры**
   - Проверьте URL LLM: `aichat-okil-sato.kartochka.tech`
   - Проверьте, что сервер доступен

3. **Проверьте логи ошибок:**
   - Откройте **Сервис → Журнал регистрации**
   - Найдите ошибки, связанные с LLM

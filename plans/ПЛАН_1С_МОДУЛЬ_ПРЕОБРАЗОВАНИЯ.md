# План разработки 1С-модуля преобразования ЗаказКлиента в JSON

## Обзор

Разработка серверного модуля `Лико_АИАссистентДанные` для преобразования данных заказа из 1С в нормализованный JSON для отправки в AI-сервис.

**Цель**: Создать функцию `ПолучитьДанныеЗаказаДляАИ(ДокументСсылка)`, которая:
1. Читает данные из ЗаказКлиента (шапка + табличные части)
2. Читает данные из ЗаказЦвета (операции печати)
3. Преобразует в нормализованный JSON структуру
4. Возвращает JSON готовый для отправки в Python-сервис

---

## Структура данных для преобразования

### Входные данные (из 1С)

**Источник 1: Документ ЗаказКлиента**
- Реквизиты шапки (Номер, Дата, Партнер, Организация и т.д.)
- Табличные части: Товары, Цвета, ВидыРабот, Производство, Секции

**Источник 2: Регистр сведений ЗаказЦвета**
- Строки операций печати с информацией о красках, материалах, параметрах

## Обзор проекта

Успешно разработана и внедрена система анализа заказов типографии с использованием LLM (Large Language Model). Система преобразует данные заказа в JSON, отправляет в LLM для анализа и отображает результат в виде HTML.

## Ключевые компоненты

### 1. JSON-структура заказа

```json
{
  "header": {
    "order_id": "ЛК006640049",
    "date": "2026-05-05",
    "client": "Клиент",
    "manager": "Менеджер",
    "status": "Проведён"
  },
  "label": {
    "name": "Этикетка",
    "size_mm": {"width": 100, "height": 50},
    "rapport": 10,
    "lanes": 4
  },
  "production": {
    "technology": "Флексо",
    "material": "Плёнка",
    "laminated": true
  },
  "operations": [
    {"number": 1, "name": "Печать", "type": "Флексо"}
  ],
  "metrics": {
    "circulation": 10000,
    "linear_meters": 500,
    "production_time": 8
  },
  "economics": {
    "price": 50000,
    "profitability": 25,
    "currency": "RUB"
  },
  "quality": {
    "spell_check": true,
    "barcode_check": true,
    "otk_control": true
  }
}
```

### 2. Типы анализа

- **Полный** — полный анализ (технолог + экономист)
- **Технолог** — анализ технолога
- **Экономист** — анализ экономиста

### 3. Обработка ошибок

Система обрабатывает следующие ошибки:
- Заказ не выбран
- Заказ не найден в БД
- Не удалось получить JSON
- LLM недоступен
- LLM вернул пустой результат
- Исключение при выполнении

## Использование

### Быстрый старт

1. Откройте обработку ТестLLM
2. Выберите заказ в поле "Заказ"
3. Нажмите кнопку "Анализ заказа"
4. Просмотрите результат анализа в поле `htmlЗаказ`

### Примеры использования

**Пример 1: Анализ заказа ЛК006640049**

```bsl
ДокументСсылка = Справочники.ЗаказКлиента.НайтиПоНаименованию("ЛК006640049");
РезультатHTML = ОтправитьЗапросАнализаЗаказа(ДокументСсылка, "Полный");
Сообщить(РезультатHTML);
```

**Пример 2: Получение JSON заказа**

```bsl
ДокументСсылка = Справочники.ЗаказКлиента.НайтиПоНаименованию("ЛК006640049");
ДанныеJSON = ПолучитьДанныеЗаказаДляАИ(ДокументСсылка);
Сообщить(ДанныеJSON);
```

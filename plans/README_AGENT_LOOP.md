# 🤖 AI Ассистент с Agent Loop и инструментами

## Быстрый старт

### Что это?
Система анализа заказов типографии через LLM с поддержкой **function calling** (инструментов). LLM может запрашивать данные из 1С, анализировать их и возвращать структурированный JSON-отчёт.

### Как это работает?

```
┌─────────────────────────────────────────────────────────────┐
│ Пользователь нажимает "Анализ заказа"                       │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ AgentLoop инициализируется с типом анализа (технолог/эконом)│
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ LLM получает системный промпт + описание инструментов       │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ LLM решает, какие инструменты нужны (get_order_header и т.д)│
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ 1С выполняет инструменты → возвращает JSON с данными        │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ LLM анализирует данные → может запросить ещё инструменты    │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ LLM формирует итоговый JSON-анализ                          │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ 1С парсит JSON → рендерит красивый HTML                     │
└────────────────────┬────────────────────────────────────────┘
                     │
                     ▼
┌─────────────────────────────────────────────────────────────┐
│ HTML отображается в форме (вердикт, риски, экономика)      │
└─────────────────────────────────────────────────────────────┘
```

## 📦 Что входит в коробку?

### 11 инструментов (tools)
1. `get_order_header` — шапка заказа
2. `get_label_params` — параметры этикетки
3. `get_production_flags` — флаги производства
4. `get_colors` — краски и цвета
5. `get_costs` — затраты
6. `get_production_params` — параметры производства
7. `get_metrics` — метрики (тираж, метраж, время)
8. `get_economics` — экономика (сумма, рентабельность)
9. `get_quality` — качество (проверки, образцы)
10. `get_order_items` — товары (номенклатура, количество)
11. `get_sections` — секции (полные параметры технологии)

### 4 типа анализа
- **technologist** — для технолога (риски, сложность, оптимизация)
- **economist** — для финансиста (рентабельность, затраты, цена)
- **full** — комплексный (технология + экономика + ресурсы)
- **educational** — для обучения (простым языком, без жаргона)

### HTML-рендеринг
Автоматически преобразует JSON в красивый HTML с:
- Вердиктом (accept/reject/conditional)
- Таблицей рисков
- Технологией печати
- Таймлайном производства
- Структурой затрат
- Контрольными точками качества


## 🐛 Если что-то не работает

### Ошибка: "Непредвиденный символ при чтении JSON"

**Решение:** Замените функцию `ИзвлечьJSONИзОтвета()` на исправленную версию.

Инструкции: [`ИСПРАВЛЕНИЕ_ПАРСИНГА_JSON.md`](ИСПРАВЛЕНИЕ_ПАРСИНГА_JSON.md)

### Ошибка: "Переменная не определена: Задачи"

**Решение:** Переименуйте локальную переменную на `ВсеЗадачи` в функции `ЗадачиАнализа()`.

### LLM не вызывает инструменты

**Проверьте:**
1. Провайдер поддерживает function calling (Claude, GPT-4o)
2. Инструменты правильно описаны в `ОписаниеИнструментов()`
3. Системный промпт содержит инструкцию использовать tools

## 📊 Примеры JSON-ответов

```json
    "summary": "Заказ принимается. Высокая сложность требует тщательной подготовки."
  }

```

```json
}
```

```json
    "cost_breakdown": {
      "material": 1284.14,
      "ink": 274.68,
```

## 🎯 Ключевые особенности

✅ **Function Calling** — LLM может запрашивать данные  
✅ **Итеративный анализ** — LLM может запросить ещё данные  
✅ **Множественные персоны** — разные типы анализа  
✅ **Надёжный парсинг** — 4-уровневая защита от ошибок  
✅ **Красивый HTML** — автоматический рендеринг  
✅ **Образовательный режим** — объяснение простым языком  

---

## 💡 Советы

1. **Для технолога** используйте `technologist` — LLM сосредоточится на рисках и сложности
2. **Для финансиста** используйте `economist` — LLM проанализирует рентабельность
3. **Для обучения** используйте `educational` — LLM объяснит без жаргона
4. **Для полного анализа** используйте `full` — LLM даст комплексную оценку

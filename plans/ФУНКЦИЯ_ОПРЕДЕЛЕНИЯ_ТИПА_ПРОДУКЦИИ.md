# Функция определения категории продукции для Qdrant

## Контекст
- **Тип заказа** (Термоусадка, СамоклеящаясяЭтикетка, Пакеты...) — уже есть в поле `ЗаказОбъект.Лико_ТипЗаказа`
- **Тип этикетки** (ЭТ, КЭ, Кльр...) — уже есть в поле `ЗаказОбъект.Лико_ТипЭтикетки`
- **Категория продукции** (Шампанское, Вина, Пиво, Шампунь, Масла...) — **вот что надо определить из наименования**

## Задача
Функция `ОпределитьКатегориюПродукцииДляQdrant(Наименование)` — только определяет категорию продукции.
Для типа заказа/этикетки используем реквизиты самого документа ЗаказКлиента.

## Категории продукции (из наименования)

### Алкогольные напитки
- `шампанское_игристые_вина` — Шампанское, Просекко, Асти
- `вина` — Вино, Мускат, Каберне, Мерло
- `пиво` — Пиво, Лагер, Але, Стаут
- `водка` — Водка
- `коньяк_бренди` — Коньяк, Бренди
- `ликеры` — Ликер
- `настойки` — Настойка
- `джин` — Джин
- `ром` — Ром
- `текила` — Текила
- `виски` — Виски

### Безалкогольные напитки
- `соки_нектары` — Сок, Нектар, Морс
- `вода` — Вода, Минеральная
- `газированные_напитки` — Газировка, Лимонад, Кола, Спрайт, Фанта
- `энергетики` — Энергетик
- `чай` — Чай
- `кофе` — Кофе

### Косметика и гигиена
- `шампунь` — Шампунь (**НЕ путать с шампанским!**)
- `кондиционер_для_волос` — Кондиционер
- `маска_для_волос` — Маска + волос
- `крем_косметический` — Крем для лица/рук/тела
- `лосьон` — Лосьон
- `скраб` — Скраб
- `дезодорант` — Дезодорант, Антиперспирант
- `парфюмерия` — Парфюм, Туалетная вода
- `мыло` — Мыло

### Бытовая химия
- `средства_для_стирки` — Стиральный порошок, стирка
- `средства_для_посуды` — Посуда, посудомоечная
- `средства_для_пола` — Пол, половая
- `средства_для_уборки` — Уборка, убиран

### Масла и автохимия
- `масла_автохимия` — Масло, Моторное, Трансмиссионное, SINTEC, MOBIL, SHELL, CASTROL, ZIC, Лукойл
- `антифриз` — Антифриз
- `тормозная_жидкость` — Тормозная
- `охлаждающая_жидкость` — Охлаждающая

### БАДы и лекарства
- `бады_лекарства` — БАД, Таблетки, Капсулы, Сироп, Витамины, CORDY, Иммунитет

### Продукты питания
- `молочные_продукты` — Молоко, Кефир, Сметана, Йогурт
- `сыры` — Сыр
- `мясные_продукты` — Мясо, Колбаса, Сосиски
- `соусы` — Соус, Кетчуп, Майонез
- `приправы_специи` — Приправы, Специи, Соль

### Строительные материалы
- `строительные_материалы` — Бетон, Цемент, Краска, Лак, Штукатурка, Плитка, Профиль, Пена, Утеплитель
- `клей` — Клей
- `герметик` — Герметик

### Прочее
- `прочее` — всё остальное

## Интеграция в payload

В [`СформироватьPayloadЗаказа`](1c/ERP/Обраб/AIАссистент/AIАссистент/Forms/Форма/Ext/Form/Module.bsl:3831) поле `inferred_product_type` должно заполняться так:

```bsl
// Тип заказа — из реквизита документа
ТипЗаказаСтр = НРег(СтрЗаменить(Строка(ЗаказОбъект.Лико_ТипЗаказа), " ", "_"));
Payload.Вставить("order_type", ТипЗаказаСтр);

// Тип этикетки — из реквизита документа
ТипЭтикеткиСтр = НРег(СтрЗаменить(Строка(ЗаказОбъект.Лико_ТипЭтикетки), " ", "_"));
Payload.Вставить("label_type", ТипЭтикеткиСтр);

// Категория продукции — из эвристики по наименованию
Payload.Вставить("product_category", ОпределитьКатегориюПродукцииДляQdrant(НазваниеЭтикетки));
```

Вместо одного поля `inferred_product_type` — три отдельных поля, каждое из правильного источника.

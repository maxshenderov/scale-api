Скан-Архив: общий журнал документов

Журнал предназначен для получения выборки документов, для которых возможно штрихкодирование печатных форм в СА.

В журнале есть возможность устанавливать отборы по:

  • Виду документа; 
  • Номеру документа;
  • Организауии;
  • Контрагенту;
  • Сумме документа;
  • Ответственному.

Есть гиперссылка для установки отбора по типам печатных форм.

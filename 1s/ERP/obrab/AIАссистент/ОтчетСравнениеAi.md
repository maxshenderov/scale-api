## 📡 Сервис и подключение (1С)

### Настройки подключения
```bsl
URLСервера = "aichat-okil-sato.kartochka.tech";
Порт       = 443;
ПутьКAPI   = "/api/v1/chat/completions";
КлючAPI    = "sk-***";
МодельID   = "anthropic/claude-haiku-4.5";
```

### Получение списка моделей
```bsl
Запрос = Новый HTTPЗапрос("/api/v1/models");
Запрос.Заголовки.Вставить("Authorization", "Bearer " + КлючAPI);
Запрос.Заголовки.Вставить("Content-Type", "application/json");
Ответ = Соединение.Получить(Запрос);

Если Ответ.КодСостояния = 200 Тогда
    ЧтениеJSON = Новый ЧтениеJSON();
    ЧтениеJSON.УстановитьСтроку(Ответ.ПолучитьТелоКакСтроку());
    Данные = ПрочитатьJSON(ЧтениеJSON);
    Для Каждого Модель Из Данные.data Цикл
        Сообщить("Модель: " + Модель.id);
    КонецЦикла;
КонецЕсли;
```

### Получение стоимости запроса
```bsl
Стоимость           = ДанныеОтвета.usage.cost;
СтоимостьПромпта    = ДанныеОтвета.usage.cost_details.upstream_inference_prompt_cost;
СтоимостьОтвета     = ДанныеОтвета.usage.cost_details.upstream_inference_completions_cost;
```

### Что такое Reasoning-токены
- Модель «думает вслух» перед ответом
- Токены тарифицируются, но пользователь их не видит
- **Полезно:** сложная математика, логика, анализ документов
- **Бесполезно:** простой чат, перевод, шаблонные ответы

### Способ 1 — Системный промпт
```
Ты аналитик типографии.

```bsl

### Способ 3 — JSON Schema (максимальная надёжность)
```bsl
РеспонсФормат = Новый Структура;

### Сравнение способов

| Способ | Надёжность | Сложность | Поддержка |

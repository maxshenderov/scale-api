# ОшибкиРазмещенияВАдрес — валидация размещения паллета (14 проверок)

## Сигнатура
```
Функция ОшибкиРазмещенияВАдрес(Ячейка, Высота, Ширина, Глубина, Вес) Экспорт
```
Возвращает **Массив строк** — список ошибок. Пустой массив = размещение допустимо.

---

## Правила размещения (основа всех проверок)

1. Если ширина паллета > 2/3 ширины секции → только 1 паллет в средний адрес (2)
2. Если ширина паллета > 1/3 ширины секции → 2 паллета в крайние адреса (1 и 3)
3. Если ширина паллета ≤ 1/3 ширины секции → 3 паллета во все адреса

---

## 14 проверок — полный список

### Проверки занятости и конфликтов (1-9)

| № | Проверка | Условие ошибки |
|----|----------|---------------|
| 1 | Адрес занят | В выбранном адресе уже есть паллет |
| 2 | Адрес1 конфликтует с Адрес2 | Адрес2 занят паллетом > 1/3 ширины секции |
| 3 | Адрес3 конфликтует с Адрес2 | Адрес2 занят паллетом > 1/3 ширины секции |
| 4 | Адрес2 конфликтует с Адрес1 | Адрес1 занят паллетом > 1/3 ширины секции |
| 5 | Адрес2 конфликтует с Адрес3 | Адрес3 занят паллетом > 1/3 ширины секции |
| 6 | Адрес2 недоступен (Адрес1 занят) | Размещаемый > 1/3 ширины + Адрес1 занят |
| 7 | Адрес2 недоступен (Адрес3 занят) | Размещаемый > 1/3 ширины + Адрес3 занят |
| 8 | Адрес1 не подходит | Размещаемый > 2/3 ширины секции |
| 9 | Адрес3 не подходит | Размещаемый > 2/3 ширины секции |

### Проверки габаритов секции (10-13)

| № | Проверка | Условие ошибки |
|----|----------|---------------|
| 10 | Ширина превышена | `Секция.Типоразмер.Ширина < Ширина` |
| 11 | Высота превышена | `Секция.Типоразмер.Высота < Высота` |
| 12 | Глубина превышена | `Секция.Типоразмер.Глубина < Глубина` |
| 13 | Вес превышен | `Секция.Типоразмер.Вес < (ВесВсехПаллет + Вес)` (если не безлимитная) |

### Проверки стеллажа (14)

| № | Проверка | Условие ошибки |
|----|----------|---------------|
| 14a | Мин ширина стеллажа | `Ширина < Стеллаж.МинШиринаПаллета` (если ≠ 0) |
| 14b | Макс ширина стеллажа | `Ширина > Стеллаж.МаксШиринаПаллета` (если ≠ 0) |
| 14c | Мин глубина стеллажа | `Глубина < Стеллаж.МинГлубинаПаллета` (если ≠ 0) |
| 14d | Макс глубина стеллажа | `Глубина > Стеллаж.МаксГлубинаПаллета` (если ≠ 0) |

### Дополнительно (вне основных проверок)

| Проверка | Условие |
|----------|---------|
| ЗапретРазмещения | Если у секции установлен — размещение запрещено сразу |

---

## Синхронизация с ПодобратьЯчейку

Все 14 проверок полностью синхронизированы между `ОшибкиРазмещенияВАдрес` (BSL) и `ПодобратьЯчейку` (WHERE запроса):

| Правило | ОшибкиРазмещения (BSL) | ПодобратьЯчейку (SQL WHERE) |
|---------|------------------------|---------------------------|
| ЗапретРазмещения | проверка 1 | `НЕ ЗапретРазмещения` |
| Глубина >= | проверка 12 | `Типоразмер.Глубина >= &Глубина` |
| Высота >= | проверка 11 | `Типоразмер.Высота >= &Высота` |
| Вес | проверка 13 | выбор с безлимитной |
| Стеллаж Мин/Макс | проверка 14 | 4 условия в WHERE |
| Ширина > 2/3 → все пусты | проверки 8,9 | WHERE условие |
| Ширина > 1/3 → Адрес2 пуст | проверки 2,3,6,7 | WHERE условие |
| Паллет2 > 1/3 блокирует | проверки 2,3 | `Типоразмер2.Ширина < W/3` |

**Ключевой паттерн**: [[СинхронизацияПодборВалидация]] — любые изменения должны вноситься в ОБЕ функции одновременно.

---

## Используемые объекты
- `Справочник.Лико_СкладскиеСекции` — секция, типоразмер, адреса, ЗапретРазмещения
- `Справочник.Лико_Стеллажи` — Мин/Макс ширина/глубина паллета
- `РегистрНакопления.Лико_ПаллетыВСекциях.ОстаткиПоАдресамСекции()` — текущие паллеты


## Исходный код

```bsl
Функция ОшибкиРазмещенияВАдрес(Ячейка,Высота,Ширина,Глубина,Вес) Экспорт 

	// У секции есть 3 адреса
	// В секцию можно устанавливать 1, 2 или 3 паллета
	// 1. Если ширина паллета больше 2/3 ширины секции, то в секцию можно установить только один паллет и только в средний (2) адрес
	// 2. Если ширина паллета больше 1/3 ширины секции, то в секцию можно установить 2 паллета в крайние адреса (1 и 3)
	// 3. Если ширина паллета меньше или равна 1/3 ширины секции, можно установить 3 паллета в три адреса

	
	Массив = Новый Массив();
	
	// Валидация входных параметров
	Если Не ЗначениеЗаполнено(Ячейка) Тогда
		Массив.Добавить("Ошибка: не указан адрес для размещения.");
		Возврат Массив;
	КонецЕсли;

	// Проверка признака ЗапретРазмещения секции
	Если Ячейка.Лико_Секция.ЗапретРазмещения Тогда
		Массив.Добавить("Ошибка: размещение в данной секции запрещено (установлен признак ЗапретРазмещения).");
		Возврат Массив;
	КонецЕсли;

	Секция = Ячейка.Лико_Секция;
	
			Структура = Новый Структура;
		Структура.Вставить("Высота", Высота);
		Структура.Вставить("Ширина", Ширина);
		Структура.Вставить("Глубина", Глубина);
		Структура.Вставить("Вес", Вес);
		
	// Получаем остатки паллетов по адресам секции
	Попытка
		СооАдресовСекции = РегистрыНакопления.Лико_ПаллетыВСекциях.ОстаткиПоАдресамСекции(Секция);
	Исключение
		Массив.Добавить("Ошибка: не удалось получить информацию об остатках паллетов в секции.");
		Возврат Массив;
	КонецПопытки;
	
	Адрес1 = СооАдресовСекции[Секция.Адрес1];
	Адрес2 = СооАдресовСекции[Секция.Адрес2];
	Адрес3 = СооАдресовСекции[Секция.Адрес3]; 
	
	// 
	ЭтоАдрес1 = Секция.Адрес1 = Ячейка;
	ЭтоАдрес2 = Секция.Адрес2 = Ячейка;
	ЭтоАдрес3 = Секция.Адрес3 = Ячейка;

	// 1.Проверка: Адрес уже занят
	Если ЗначениеЗаполнено(СооАдресовСекции[Ячейка]) Тогда 
		Массив.Добавить("Ошибка: выбранный адрес уже занят. Выберите другой адрес в секции.");
		//Возврат Массив;
	КонецЕсли;
	
	// 2.Проверка: Крайний адрес 1 конфликтует с занятым средним адресом
	Если ЭтоАдрес1 И ЗначениеЗаполнено(Адрес2) И Секция.Типоразмер.Ширина / 3 < Адрес2.Ширина Тогда
		Массив.Добавить("Ошибка: невозможно разместить паллет в адрес 1. В среднем адресе (2) уже установлен паллет большого размера (>1/3 ширины секции). Выберите адрес 3 или другую секцию.");
		//Возврат Массив;
	КонецЕсли; 
	
	// 3.Проверка: Крайний адрес 3 конфликтует с занятым средним адресом
	Если ЭтоАдрес3 И ЗначениеЗаполнено(Адрес2) И Секция.Типоразмер.Ширина / 3 < Адрес2.Ширина Тогда
		Массив.Добавить("Ошибка: невозможно разместить паллет в адрес 3. В среднем адресе (2) уже установлен паллет большого размера (>1/3 ширины секции). Выберите адрес 1 или другую секцию.");
		//Возврат Массив;
	КонецЕсли;

	// 4.Проверка: Средний адрес конфликтует с занятым крайним адресом 1
	Если ЭтоАдрес2 И ЗначениеЗаполнено(Адрес1) И Секция.Типоразмер.Ширина / 3 < Адрес1.Ширина Тогда
		Массив.Добавить("Ошибка: невозможно разместить паллет в средний адрес (2). В адресе 1 уже установлен паллет большого размера, что блокирует размещение в центре. Используйте адрес 3 или выберите другую секцию.");
		//Возврат Массив;
	КонецЕсли; 
	
	// 5.Проверка: Средний адрес конфликтует с занятым крайним адресом 3
	Если ЭтоАдрес2 И ЗначениеЗаполнено(Адрес3) И Секция.Типоразмер.Ширина / 3 < Адрес3.Ширина Тогда
		Массив.Добавить("Ошибка: невозможно разместить паллет в средний адрес (2). В адресе 3 уже установлен паллет большого размера, что блокирует размещение в центре. Используйте адрес 1 или выберите другую секцию.");
		//Возврат Массив;
	КонецЕсли;

	// 6.Проверка: Средний адрес не подходит для крупного паллета при занятом адресе 1
	Если ЭтоАдрес2 И ЗначениеЗаполнено(Адрес1) И Секция.Типоразмер.Ширина / 3 < Структура.Ширина Тогда
		Массив.Добавить("Ошибка: паллет слишком широк (>1/3 ширины секции) для размещения в среднем адресе (2), так как адрес 1 уже занят. Используйте адрес 3 или выберите другую секцию.");
		//Возврат Массив;
	КонецЕсли;
	
	// 7.Проверка: Средний адрес не подходит для крупного паллета при занятом адресе 3
	Если ЭтоАдрес2 И ЗначениеЗаполнено(Адрес3) И Секция.Типоразмер.Ширина / 3 < Структура.Ширина Тогда
		Массив.Добавить("Ошибка: паллет слишком широк (>1/3 ширины секции) для размещения в среднем адресе (2), так как адрес 3 уже занят. Используйте адрес 1 или выберите другую секцию.");
		//Возврат Массив;
	КонецЕсли; 
	
	// 8.Проверка: Крайний адрес 1 не подходит для крупного паллета
	Если ЭтоАдрес1 И Секция.Типоразмер.Ширина * 2 / 3 < Структура.Ширина Тогда
		Массив.Добавить("Ошибка: паллет слишком широк (>2/3 ширины секции) для размещения в адресе 1. Используйте средний адрес (2) или выберите другую секцию.");
		//Возврат Массив;
	КонецЕсли; 
	
	// 9.Проверка: Крайний адрес 3 не подходит для крупного паллета
	Если ЭтоАдрес3 И Секция.Типоразмер.Ширина * 2 / 3 < Структура.Ширина Тогда
		Массив.Добавить("Ошибка: паллет слишком широк (>2/3 ширины секции) для размещения в адресе 3. Используйте средний адрес (2) или выберите другую секцию.");
		//Возврат Массив;
	КонецЕсли;

	// 10.Проверка: Ширина паллета превышает ширину секции
	Если Секция.Типоразмер.Ширина < Структура.Ширина Тогда
		Массив.Добавить("Ошибка: ширина паллета превышает максимальную ширину секции. Паллет не может быть размещен в данной секции.");
		//Возврат Массив;
	КонецЕсли;

	// 11.Проверка: Высота паллета превышает высоту секции
	Если Секция.Типоразмер.Высота < Структура.Высота Тогда
		Массив.Добавить("Ошибка: высота паллета превышает максимальную высоту секции. Паллет не может быть размещен в данной секции.");
		//Возврат Массив;
	КонецЕсли;

	// 12.Проверка: Глубина паллета превышает глубину секции
	Если Секция.Типоразмер.Глубина < Структура.Глубина Тогда
		Массив.Добавить("Ошибка: глубина паллета превышает максимальную глубину секции. Паллет не может быть размещен в данной секции.");
		//Возврат Массив;
	КонецЕсли;
	
	// 13.Проверка: Общий вес превышает грузоподъемность секции
	ВесВсего = ?(ЗначениеЗаполнено(Адрес1), Адрес1.Вес, 0)
		+ ?(ЗначениеЗаполнено(Адрес2), Адрес2.Вес, 0)
		+ ?(ЗначениеЗаполнено(Адрес3), Адрес3.Вес, 0)
		+ Структура.Вес;

	Если Не Секция.Типоразмер.НеОграниченаПоГрузоподъемности
		И Секция.Типоразмер.Вес < ВесВсего Тогда
		Массив.Добавить("Ошибка: общий вес паллетов в секции превышает максимальную грузоподъемность секции.");
	КонецЕсли;

	// 14.Проверки габаритов по стеллажу (применяются только если значение ≠ 0)
	Стеллаж = Секция.Стеллаж;
	Если Стеллаж.МинШиринаПаллета <> 0 И Структура.Ширина < Стеллаж.МинШиринаПаллета Тогда
		Массив.Добавить("Ошибка: ширина паллета меньше минимально допустимой для стеллажа.");
	КонецЕсли;
	Если Стеллаж.МаксШиринаПаллета <> 0 И Структура.Ширина > Стеллаж.МаксШиринаПаллета Тогда
		Массив.Добавить("Ошибка: ширина паллета больше максимально допустимой для стеллажа.");
	КонецЕсли;
	Если Стеллаж.МинГлубинаПаллета <> 0 И Структура.Глубина < Стеллаж.МинГлубинаПаллета Тогда
		Массив.Добавить("Ошибка: глубина паллета меньше минимально допустимой для стеллажа.");
	КонецЕсли;
	Если Стеллаж.МаксГлубинаПаллета <> 0 И Структура.Глубина > Стеллаж.МаксГлубинаПаллета Тогда
		Массив.Добавить("Ошибка: глубина паллета больше максимально допустимой для стеллажа.");
	КонецЕсли;

	Возврат Массив;
КонецФункции
```

# ЗаполнитьВремяДоступаКСекциям — расчёт времени доступа

## Сигнатура
```
Процедура ЗаполнитьВремяДоступаКСекциям(Склад) Экспорт
```
Заполняет реквизиты `ВремяДоступа` для стеллажей и секций выбранного склада.

---

## Алгоритм расчёта

### 1. Время доступа стеллажа
```bsl
ВремяДоступаСтеллажа = Склад.Лико_ВремяСтеллажа * НомерСтроки
```
Где:
- `Склад.Лико_ВремяСтеллажа` — базовое время доступа к стеллажу (константа склада)
- `НомерСтроки` — порядковый номер стеллажа в списке (1, 2, 3...)

Стеллажи обрабатываются в порядке их следования в табличной части `Склад.Лико_Стеллажи`.

### 2. Время доступа секции
```bsl
СпрОбъект.ВремяДоступа = ВремяДоступаСтеллажа
    + (СпрОбъект.Место * Склад.Лико_ВремяМеста)
    + (СпрОбъект.Этаж * Склад.Лико_ВремяЭтажа)
```
Где:
- `Склад.Лико_ВремяМеста` — время на одно место (горизонтальное перемещение)
- `Склад.Лико_ВремяЭтажа` — время на один этаж (вертикальное перемещение)

### 3. Сортировка секций
Секции каждого стеллажа сортируются по `Код` (возрастание).

---

## Параметры склада (ключевые константы)

| Параметр | Назначение |
|----------|-----------|
| `Лико_ВремяСтеллажа` | Базовое время доступа к стеллажу |
| `Лико_ВремяМеста` | Время горизонтального перемещения на одно место |
| `Лико_ВремяЭтажа` | Время вертикального перемещения на один этаж |

---

## Влияние на ПодобратьЯчейку

`ВремяДоступа` используется в ORDER BY финального запроса `ПодобратьЯчейку`:

```sql
УПОРЯДОЧИТЬ ПО
    ...
    УровеньДоступа [УБЫВ / ASC],
    ВремяДоступа [УБЫВ / ASC]       -- ← этот реквизит
```

Направление зависит от `ОбратныйПорядокВремени`:
- `Ложь` (default): ASC — секции с быстрым доступом первыми
- `Истина`: УБЫВ — секции с медленным доступом первыми

---

## УровеньДоступа vs ВремяДоступа

| Поле | Как вычисляется | Где используется |
|------|----------------|-----------------|
| `УровеньДоступа` | `(Место-1)/3+1 <= КоличествоСекций/2` → 1 или 2 | В ORDER BY ПодобратьЯчейку (позиция 7) |
| `ВремяДоступа` | `ВремяСтеллажа + Место*ВремяМеста + Этаж*ВремяЭтажа` | В ORDER BY ПодобратьЯчейку (позиция 8) |

`УровеньДоступа` — грубая оценка (ближняя/дальняя половина стеллажа).
`ВремяДоступа` — точный расчёт в условных единицах времени.

## Исходный код (ManagerModule.bsl)

```bsl
Процедура ЗаполнитьВремяДоступаКСекциям(Склад) Экспорт 
	
	НомерСтроки=1;
	Для каждого Стеллаж Из Склад.Лико_Стеллажи Цикл 
		
		ВремяДоступаСтеллажа = Склад.Лико_ВремяСтеллажа*НомерСтроки;
		
		СпрОбъект = Стеллаж.Стеллаж.ПолучитьОбъект();
		СпрОбъект.ВремяДоступа=Склад.Лико_ВремяСтеллажа*НомерСтроки;
		СпрОбъект.Записать();
		
		Запрос = Новый Запрос;
		Запрос.Текст = 
		"ВЫБРАТЬ
		|	Лико_СкладскиеСекции.Ссылка КАК Ссылка,
		|	Лико_СкладскиеСекции.Код КАК Код
		|ИЗ
		|	Справочник.Лико_СкладскиеСекции КАК Лико_СкладскиеСекции
		|ГДЕ
		|	Лико_СкладскиеСекции.Стеллаж = &Стеллаж
		|
		|УПОРЯДОЧИТЬ ПО
		|	Код";
		Запрос.УстановитьПараметр("Стеллаж",Стеллаж.Стеллаж );
		РезультатЗапроса = Запрос.Выполнить();
		Выборка = РезультатЗапроса.Выбрать();
		Пока Выборка.Следующий() Цикл 
			 СпрОбъект= Выборка.Ссылка.ПолучитьОбъект();
			 
			СпрОбъект.ВремяДоступа= ВремяДоступаСтеллажа+(СпрОбъект.Место*Склад.Лико_ВремяМеста)+(СпрОбъект.Этаж*Склад.Лико_ВремяЭтажа);
		   СпрОбъект.Записать();
		КонецЦикла; 
		
		
	НомерСтроки=НомерСтроки+1;	
	КонецЦикла;
	
КонецПроцедуры
```

## Связанные объекты
- `Справочник.Склады` — реквизиты `Лико_ВремяСтеллажа`, `Лико_ВремяМеста`, `Лико_ВремяЭтажа`, ТЧ `Лико_Стеллажи`
- `Справочник.Лико_Стеллажи` — реквизит `ВремяДоступа`
- `Справочник.Лико_СкладскиеСекции` — реквизиты `ВремяДоступа`, `Место`, `Этаж`

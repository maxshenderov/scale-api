# /search-code — семантический поиск по кодовой базе

Поиск по индексированной кодовой базе проекта (1С BSL, XML, Python) через Qdrant (localhost:6333).

## Инструкция

Когда пользователь вызывает `/search-code <запрос>`, выполни:

```
python "d:\project\OKIL\mcp\qdrant-code-search\search.py" "<запрос>"
```

- Преобразуешь результат в читаемый вид
- Покажи файлы, строки и фрагменты кода с подсветкой синтаксиса
- Если скрипт вернул ошибку — проверь доступность Qdrant (`curl localhost:6333/health`) и RouterAI API

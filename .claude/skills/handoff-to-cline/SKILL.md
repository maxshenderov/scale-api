# Handoff to Cline

Передача задачи агенту Cline.

## Главное правило

**Ты делаешь структурированную выдержку из разговора.**

Не хронологию. Не «сначала было А, потом Б, потом В». Это мусор.

Ты фильтруешь:
- Всё устаревшее (ранние версии, отвергнутые идеи) → **в топку**
- Всё что уже сделано → **в топку**
- Промежуточные споры и недопонимания → **в топку**

Оставляешь только:
- **Текущая проблема** — что решаем прямо сейчас
- **Финальные решения** — к чему пришли (не как шли)
- **Актуальный контекст** — файлы, wiki, паттерны которые нужны
- **Конкретное действие** — что Cline должен сделать

Cline получает чистую картину, а не помойку из истории чата.

## Алгоритм

### Шаг 0: Структурированная выдержка

Из всего разговора извлеки только актуальное:

```
Текущая задача: [одно предложение — что надо сделать]
Актуальные решения: [только финальные, не промежуточные]
Ключевой контекст: [файлы, wiki, паттерны — только нужные]
```

Всё остальное не попадает в задачу.

### Шаг 1: Собери технический контекст

```
mcp__memory-bank-indexer__search_knowledge_base(query=<ключевые слова>, limit=5, type="all")
```

### Шаг 2: Определи куда писать

| TASKS.md | HANDOFF.md |
|---|---|
| 1 действие, 1 файл | несколько файлов/зависимостей |
| нет состояния | продолжить после паузы |

### Шаг 3: Запиши

**TASKS.md:**
```
### → cline | YYYY-MM-DD | !
Задача: [одно предложение]
Контекст: [сжатая выдержка]
Статус: new
```

**HANDOFF.md:**
```
### #ID | YYYY-MM-DD | started by claude | new

**Текущая задача:** [что сделать]

**Актуальные решения:**
- [финальное решение 1]
- [финальное решение 2]

**Технический контекст:**
- Wiki: [[Страница1]]
- Файлы: `path/file#L123`
```

### Шаг 4: Запиши в log.md

```markdown
## YYYY-MM-DD [claude] HANDOFF → cline | [суть]
```

# Scale API

HTTP-сервис для чтения показаний весов **СКУ I2121** (индикатор СКИ-12 / Yaohua) через M2M WiFi-UART модуль.

## Как это работает

```
Весы (RS-485) → M2M WiFi-модуль (TCP Server :8899) → Scale API (HTTP :8011) → 1С / curl
```

M2M модуль в режиме **Transparent** непрерывно шлёт данные весов в формате Yaohua (`wn00005.0kg`). Сервис подключается к модулю по TCP, читает одно показание и отдаёт его как JSON.

## Настройки M2M WiFi-модуля

Эти настройки задаются в самом модуле через веб-интерфейс. Сервис подключается к модулю используя переменные окружения из `.env`:

| Параметр модуля | Значение | Переменная в `.env` |
|---|---|---|
| IP | 192.168.12.147 | `SCALE_HOST` |
| Data Transfer Mode | Transparent (0) | — |
| 485 mode | ON | — |
| Baudrate | 9600, 8N1 | — |
| Network | Server, TCP, Port 8899 | `SCALE_PORT` |

**При смене IP модуля** — поменяй `SCALE_HOST` в `.env` и перезапусти:
```bash
docker compose restart
```

Веб-интерфейс модуля: `http://<SCALE_HOST>` (логин/пароль — см. наклейку на модуле).

## Endpoints

### `GET /health`

Проверка работоспособности сервиса.

```bash
curl http://localhost:8011/health
# → {"status": "ok"}
```

### `GET /api/weight`

Прочитать текущее показание весов.

```bash
curl http://localhost:8011/api/weight
```

Ответ (успех):
```json
{
  "ok": true,
  "value": 5.0,
  "unit": "kg",
  "stable": true,
  "mode": "n",
  "raw": "wn00005.0kg"
}
```

Ответ (нет данных / ошибка):
```json
{
  "ok": false,
  "value": null,
  "detail": "no reading"
}
```

Поля ответа:
- `value` — число, вес
- `unit` — единицы (`kg`)
- `stable` — `true` если вес стабилизировался, `false` если в движении
- `mode` — `"n"` (нетто) или `"g"` (брутто)
- `raw` — сырая строка от весов

## Подключение из 1С

```bsl
Соединение = Новый HTTPСоединение("<хост>", 8011);
Запрос = Новый HTTPЗапрос("/api/weight");
Ответ = Соединение.Получить(Запрос);

Если Ответ.КодСостояния = 200 Тогда
    Чтение = Новый ЧтениеJSON;
    Чтение.УстановитьСтроку(Ответ.ПолучитьТелоКакСтроку());
    Данные = ПрочитатьJSON(Чтение);

    Если Данные.ok Тогда
        Вес = Данные.value;      // Число
        Единицы = Данные.unit;   // "kg"
        Стабильно = Данные.stable; // Булево
        Режим = Данные.mode;     // "n" или "g"
    КонецЕсли;
КонецЕсли;
```

## Формат данных весов (Yaohua)

Строка вида `wn00005.0kg`:
- Символ 1: статус (`w` = stable, иначе unstable)
- Символ 2: режим (`n` = нетто, `g` = брутто)
- Символы 3-9: значение с плавающей точкой и ведущими нулями
- Последние 2: единицы (`kg`)

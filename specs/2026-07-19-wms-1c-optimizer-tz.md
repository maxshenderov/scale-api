Стеллаж — ряд секций. Ключевые реквизиты:

| Реквизит | Тип | Описание |
|---|---|---|
| `НомерСтеллажа` | Число | Номер стеллажа (1–9) |

| `МаксШиринаПаллета` | Число | Макс. ширина паллета (0 = без ограничения) |
| `МинГлубинаПаллета` | Число | Мин. глубина паллета (0 = без ограничения) |
| `МаксГлубинаПаллета` | Число | Макс. глубина паллета (0 = без ограничения) |

#### ТЧ `Этажи` (Лико_Стеллажи.Этажи)

Каждая строка — один этаж стеллажа:

| Реквизит | Тип | Описание |
|---|---|---|
| `НомерСтроки` | Число | Номер этажа (1, 2, 3...) |
| `Типоразмер` | Ссылка на `Лико_ТипоразмерыСкладскихСекций` | Габариты ячеек этого этажа |
| `Зазор` | Число, мм | Пространство над паллетом до балки — для манёвра вил |
| `ВысотаБалки` | Число, мм | Толщина горизонтальной балки стеллажа |
| `ВысотаОтПола` | Число, мм | Расстояние от пола до низа балки первого этажа |
| **`ВысотаОтПолаФиксирована`** | **Булево** | **Признак стоит только у одного этажа в стеллаже — всегда последнего (верхнего). Если Истина → высоту ЭТОГО этажа менять НЕЛЬЗЯ. Остальные этажи (включая первый) не фиксированы этим признаком.** |
| `ЗазорПоШирине` | Число, мм | Боковой зазор на один промежуток между паллетами и стойками |
| `МаксимальныйВесПодъёмаНаЭтаж` | Число, кг | Макс. вес который штабелёр поднимает на эту высоту |
| `МинимальнаяГлубинаНеОграничена` | Булево | Нет ограничения снизу по глубине паллета |
| `МаксимальнаяГлубинаНеОграничена` | Булево | Нет ограничения сверху по глубине паллета |

**Геометрия этажа по вертикали:**

```
Высота секции = Типоразмер.Высота + Зазор
Полная высота этажа = Высота секции + ВысотаБалки
Полезная высота для паллета = Типоразмер.Высота − Зазор

Балка ═══════════════ ← верх этажа
      │  Паллет      │ ← полезная высота
      │              │
──────├──────────────┤ ← низ секции (верх балки пред. этажа)
Балка ═══════════════
```

**Геометрическое ограничение при подборе высот:**

Пусть `ЭтажФикс` — этаж с `ВысотаОтПолаФиксирована = Истина` (всегда последний). Тогда:

```
ЦелеваяСумма = ЭтажФикс.ВысотаОтПола

ТекущаяСумма(Этажи 1..N-1) = Σ по всем этажам НИЖЕ ЭтажФикс:
    (Типоразмер.Высота + Зазор + ВысотаБалки)
```

Должно выполняться: **`ТекущаяСумма = ЦелеваяСумма` точно**, без запаса и без недостачи.

### 1.2 Справочник `Лико_СкладскиеСекции`

Секция — физический слот в стеллаже на конкретном этаже. Каждая секция содержит **ровно 3 адреса**.

| Реквизит | Тип | Описание |
|---|---|---|
| `Стеллаж` | Ссылка на `Лико_Стеллажи` | Родительский стеллаж |
| `Склад` | Ссылка на `Склады` | Склад |
| `Этаж` | Число | Номер этажа (1, 2, ...) |
| `Ряд` | Число | Позиция секции в ряду |
| `Место` | Число | Позиция первого адреса (Место, Место+1, Место+2) |
| `Типоразмер` | Ссылка на `Лико_ТипоразмерыСкладскихСекций` | Типоразмер секции |
| `Адрес1` | Ссылка на `СкладскиеЯчейки` | Первый адрес хранения |
| `Адрес2` | Ссылка на `СкладскиеЯчейки` | Второй (центральный) адрес |
| `Адрес3` | Ссылка на `СкладскиеЯчейки` | Третий адрес |
| `АдресЦентр` | Ссылка на `СкладскиеЯчейки` | = Адрес2 |
| `КоличествоАдресов` | Число | = 3 |
| `ЗапретРазмещения` | Булево | Ручная блокировка секции |
| `УровеньДоступа` | Число | 1 = ближняя половина стеллажа, 2 = дальняя |
| `ВремяДоступа` | Число | Время доступа к секции (сек) |

**Код секции:** `"Р{Ряд}-М({Место}-{Место+1}-{Место+2})-Э{Этаж}"` — например `Р501-М(01-02-03)-Э01`.

**Правила размещения паллет в секции по ширине:**

Пусть `W_s` = ширина секции (из типоразмера), `W_p` = ширина паллета.

| Условие | Категория | Сколько адресов занимает | Какие адреса |
|---|---|---|---|
| `W_p > 2/3 × W_s` | Широкий (wide) | 3 | Все: 1, 2, 3 |
| `W_s/3 < W_p ≤ 2/3 × W_s` | Средний (medium) | 2 | Адрес2 + один крайний (1 или 3) |
| `W_p ≤ W_s/3` | Узкий (narrow) | 1 | Любой из трёх |

**Формула монтажного зазора по ширине:**

```
Σ(ширин паллет в секции) + (N+1) × ЗазорПоШирине ≤ W_s
```

Где `N` = количество паллет в секции, `ЗазорПоШирине` берётся из `Этажи.ЗазорПоШирине` для этажа этой секции.

**Конфликты адресов (кто кого блокирует):**

- Адрес2 занят паллетом > W_s/3 → блокирует Адрес1 и Адрес3
- Адрес1 занят паллетом > W_s/3 → блокирует Адрес2
- Адрес3 занят паллетом > W_s/3 → блокирует Адрес2
- Новый паллет > W_s/3 не может встать в Адрес2 если Адрес1 или Адрес3 заняты

### 1.7 Регистры

#### `Лико_ПаллетыВСекциях` (регистр накопления, остатки)

Измерения: `Адрес` (СкладскиеЯчейки), `Паллет` (Лико_Паллеты2_0), `Секция` (Лико_СкладскиеСекции).
Ресурсы: `Количество`, `Заблокирован`.

Показывает **где стоит каждый паллет**. Остатки = 1 означает что паллет находится в этом адресе.

#### `Лико_ПараметрыПаллет` (регистр сведений, срез последних)

Измерение: `Паллет` (Лико_Паллеты2_0).
Ресурсы: `Типоразмер` (Лико_ТипоразмерыПаллет).

По `СрезПоследних` получаем габариты паллета: `Типоразмер.Высота`, `Типоразмер.Ширина`, `Типоразмер.Глубина`, `Типоразмер.Вес`.

### 1.8 Документ `Лико_ПеремещениеПаллета2_0`

Метод `СоздатьПеремещение(Паллет, Ячейка)` — создаёт и проводит документ перемещения паллета в указанную ячейку. Делает движения в `Лико_ПаллетыВСекциях` (расход со старого адреса, приход на новый).

### 1.9 Существующая функция валидации

```bsl
Функция ОшибкиРазмещенияПаллетаВАдрес(Ячейка, Паллет,
    Типоразмер = Неопределено, ПолныйОтвет = Ложь,
    ВиртуальноеСостояние = Неопределено) Экспорт
```

**18 проверок (накопление ошибок):**

| # | Проверка | Условие ошибки |
|---|---|---|
| 0 | Ячейка заполнена | Адрес уже занят (в реальности или в ВиртуальномСостоянии) |
| 1a | Секция заблокирована | `ЗапретРазмещения = Истина` |
| 2 | Крайний 1 заблокирован центром | Адрес2 занят паллетом > W/3 |
| 3 | Крайний 3 заблокирован центром | Адрес2 занят паллетом > W/3 |
| 4 | Центр заблокирован краем 1 | Адрес1 занят паллетом > W/3 |
| 5 | Центр заблокирован краем 3 | Адрес3 занят паллетом > W/3 |
| 6–7 | Центр недоступен | Новый паллет > W/3, край занят |
| 8–9 | Край не подходит | Новый паллет > W/2 |
| 10 | Переполнение ширины | `ШиринаПаллета > ШиринаСекции` |
| 11 | Переполнение высоты | `ВысотаПаллета > ВысотаСекции` |
| 12 | Переполнение глубины | `ГлубинаПаллета > ГлубинаСекции` |
| 13 | Переполнение веса | `Σ(вес паллет) > Грузоподъёмность` |
| 13a | Монтажный зазор | `ОстатокШирины − Ширина − 150..200 < 0` |
| 14a | Мин. ширина стеллажа | `ШиринаПаллета < МинШиринаПаллета` |
| 14b | Макс. ширина стеллажа | `ШиринаПаллета > МаксШиринаПаллета` |
| 14c–d | Ограничения глубины | Аналогично для глубины |
| 15 | Вес подъёма | `ВесПаллета > МаксимальныйВесПодъёмаНаЭтаж` |

**ВиртуальноеСостояние** — `Соответствие` где ключ = `Адрес` (СкладскиеЯчейки), значение = `ПаллетСсылка` (Лико_Паллеты2_0). Позволяет симулировать размещение паллет **без записи в регистры**. Функция при проверке занятости адреса сначала смотрит в ВиртуальноеСостояние, и только если там нет — в реальный регистр.

## 2. Функция 1: `ОптимальноеРазмещениеПаллет`

### Сигнатура

```bsl
Функция ОптимальноеРазмещениеПаллет(Склад, МассивПаллет, МаксПерестановок = 0) Экспорт
```

| Параметр | Тип | Описание |
|---|---|---|
| `Склад` | СправочникСсылка.Склады | Склад |
| `МассивПаллет` | Массив | Ссылки Лико_Паллеты2_0 |
| `МаксПерестановок` | Число | Макс. кол-во перестановок стоящих паллет (0 = не двигать) |

**Возврат:** `Структура`

```
Поля:
  Placements      — Массив структур {Паллет, Адрес, Секция, Стеллаж, Этаж}
  Rearrangements  — Массив структур {Паллет, ОткудаАдрес, КудаАдрес}
  Unplaced        — Массив структур {Паллет, Причина}
  Stats           — Структура {Всего, Размещено, Перестановок, ПлотностьДо, ПлотностьПосле}
```

### Алгоритм

Функция НЕ использует `ПодобратьЯчейку`. Вся логика размещения — своя, через прямой перебор секций и проверку `ОшибкиРазмещенияПаллетаВАдрес` с `ВиртуальнымСостоянием`.

```
ШАГ 1. Загрузить данные
  - Габариты всех паллет из партии: Лико_ПараметрыПаллет.СрезПоследних
  - Текущее состояние склада: все секции с адресами и паллетами
    (запрос к Лико_ПаллетыВСекциях + Лико_СкладскиеСекции)

ШАГ 2. Отсортировать партию по убыванию ширины (BFD — большие первыми)

ШАГ 3. Разбить на категории относительно ширины секции W_s:
  Wide:   W_p > 2W_s/3   — нужна пустая секция
  Medium: W_s/3 < W_p ≤ 2W_s/3 — нужен Адрес2 + крайний свободны
  Narrow: W_p ≤ W_s/3     — нужен 1 свободный адрес

ШАГ 4. Инициализировать ВиртуальноеСостояние
  = текущие остатки из Лико_ПаллетыВСекциях (все паллеты на складе)

ШАГ 5. ФАЗА 1 — Прямое размещение в свободные адреса
  Для каждого паллета (wide → medium → narrow):
    Для каждой секции подходящего этажа:
      Для каждого свободного адреса секции:
        Проверить ОшибкиРазмещенияПаллетаВАдрес(адрес, паллет, , , ВиртуальноеСостояние)
        Если вернула пустой массив → размещение подходит
    Если нашлась подходящая секция:
      Выбрать лучшую (best-fit по высоте: мин(ВысотаСекции − ВысотаПаллета))
      Записать размещение
      Обновить ВиртуальноеСостояние: добавить Адрес → Паллет
    Если нет → добавить паллет в ОчередьНаФазу2

ШАГ 6. ФАЗА 2 — Размещение с перестановками стоящих паллет
  Для каждого паллета из ОчередиНаФазу2:
    Если использовано перестановок >= МаксПерестановок → в Unplaced
    Для каждого этажа (снизу вверх):
      Для каждой секции этажа:
        Можно ли освободить адрес?
          Взять стоящий паллет P из этой секции
          Найти другой свободный адрес на этом же этаже
            (через ОшибкиРазмещения с ВиртуальнымСостоянием)
          Если нашли → временно переместить P туда
          Проверить: помещается ли новый паллет в освобождённый адрес
          Если да → записать перестановку P + размещение нового
          Если не помещается → вернуть P на место (откат)

ШАГ 7. Вернуть результат
```

## 3. Функция 2: `РеслотСклада`

### Сигнатура

```bsl
Функция РеслотСклада(Склад, МаксПеремещений) Экспорт
```

| Параметр | Тип | Описание |
|---|---|---|
| `Склад` | СправочникСсылка.Склады | Склад |
| `МаксПеремещений` | Число | Бюджет перемещений |

**Возврат:** `Структура`

```
Поля:
  Moves  — Массив структур {Паллет, ОткудаАдрес, КудаАдрес}
  Stats  — Структура {ИспользованоПеремещений, ОсвобожденоСекций, ПриростПлотности}
```

### Алгоритм

```
ШАГ 1. Найти частично занятые секции
  Секции где 0 < кол-во занятых адресов < 3

ШАГ 2. Построить кандидатов на объединение
  Для каждой пары частично занятых секций (A, B) в пределах одного этажа:
    canConsolidate(A, B):
      Для каждого адреса в A:
        Сколько свободных адресов?
      Для каждого паллета P в B:
        Можно ли P переместить в свободный адрес A?
        Проверить: ОшибкиРазмещенияПаллетаВАдрес(адрес_A, P, , , ВиртуальноеСостояние)
      Если ВСЕ паллеты из B можно переместить в A:
        → Добавить кандидата:
          Moves = [{P, from: адрес_B, to: адрес_A} для каждого P в B]
          Cost = кол-во паллетов в B
          Gain = 1 (секция B освобождается полностью)

ШАГ 3. Отсортировать кандидатов
  По эффективности = Gain / Cost (убывание)
  Одинаковая эффективность → сначала с меньшим Cost

ШАГ 4. Жадный отбор с бюджетом
  ИспользованоПеремещений = 0
  ЗанятыеПаллеты = [] // чтобы не двигать один паллет дважды
  
  Для каждого кандидата:
    Если ИспользованоПеремещений + Cost > МаксПеремещений → пропустить
    Если любой паллет из Moves уже в ЗанятыеПаллеты → пропустить
    Добавить Moves в план
    ИспользованоПеремещений += Cost
    Добавить все паллеты в ЗанятыеПаллеты

ШАГ 5. Вернуть результат
```

## 4. Функция 3: `ПодобратьВысотыЭтажей`

### Сигнатура

```bsl
Функция ПодобратьВысотыЭтажей(Стеллаж) Экспорт
```

| Параметр | Тип | Описание |
|---|---|---|
| `Стеллаж` | СправочникСсылка.Лико_Стеллажи | Стеллаж для анализа |

**Возврат:** `Структура`

```
Поля:
  Floors   — Массив структур:
    Этаж                              — Число
    ТекущийТипоразмер                 — Структура {id, Высота, Ширина, Глубина, Вес}
    РекомендуемыйТипоразмер           — Структура или Неопределено (если фиксирован)
    РекомендуемаяВысотаДоРаспределения — Число, мм (минимально достаточная до шага 2.f)
    ДобавкаМм                         — Число, мм (добавлено на шаге 2.f, 0 если не менялось)
    Паллетов                          — Число
    МаксВысотаПаллета                 — Число, мм
    ПотериМм                          — Число, мм
    ПотериПроцент                     — Число
    Фиксирован                        — Булево
    ПричинаФиксации                   — Строка или пусто

  Summary  — Структура:
    ВсегоПотерьМм                     — Число
    СреднийПроцентПотерь              — Число
    ОптимизируемыхЭтажей              — Число
    ЦелеваяСуммаВысот                 — Число, мм (= ВысотаОтПола зафиксированного этажа)
    ФактическаяСуммаПослеПодбора      — Число, мм
    Совпадение                        — Булево
    ОстатокРасхожденияМм              — Число, мм
```

### Алгоритм (двухпроходный с геометрическим ограничением)

```
ШАГ 1. Получить этажи стеллажа
  Этажи = Стеллаж.Этажи
  ВсегоЭтажей = Этажи.Количество()

ШАГ 2. Для каждого этажа — статистика и фиксация:

  a. Собрать паллеты на этом этаже
     Запрос к Лико_ПаллетыВСекциях.Остатки:
       WHERE Секция.Стеллаж = Стеллаж AND Секция.Этаж = НомерЭтажа
     Для каждого паллета получить габариты из Лико_ПараметрыПаллет.СрезПоследних

  b. Статистика высот паллет:
     Если паллеты есть:
       maxH = МАКС(Высота паллета)
       p90  = 90-й перцентиль высот
     Если паллетов нет: maxH = 0, p90 = 0

  c. Потери:
     ТекущаяВысота = Этаж.Типоразмер.Высота
     ПотериМм = ТекущаяВысота - maxH
     ПотериПроцент = ПотериМм / ТекущаяВысота * 100

  d. Проверка фиксации (исправлено):
     Если Этаж.ВысотаОтПолаФиксирована = Истина Тогда
       Фиксирован = Истина
       Причина = "ВысотаОтПолаФиксирована"
       // Рекомендации не считаем, высоту не трогаем
     Иначе
       Фиксирован = Ложь
       // Участвует в подборе минимально достаточной высоты (шаг 3)
       // и в распределении избытка (шаг 5)
     КонецЕсли;

ШАГ 3. ПРОХОД 1 — минимально достаточные высоты

  Для каждого НЕфиксированного этажа подобрать МИНИМАЛЬНО ДОСТАТОЧНЫЙ типоразмер:
    Каталог = Лико_ТипоразмерыСкладскихСекций
    Подходящие = отфильтровать где:
      Высота >= p90 (или maxH если паллетов мало)
      Ширина = ТекущаяШирина
      Глубина >= ТекущаяГлубина
      Вес >= ТекущийВес ИЛИ НеОграниченаПоГрузоподъемности
    РекомендуемыйТипоразмер = мин(Подходящие, по Высоте)
    РекомендуемаяВысотаДоРаспределения = РекомендуемыйТипоразмер.Высота

ШАГ 4. ПРОВЕРКА ГЕОМЕТРИЧЕСКОГО ОГРАНИЧЕНИЯ

  ЭтажФикс = этаж где ВысотаОтПолаФиксирована = Истина
  ЦелеваяСумма = ЭтажФикс.ВысотаОтПола

  МинСумма = Σ(РекомендуемаяВысотаДоРаспределения + Зазор + ВысотаБалки)
              по всем нефиксированным этажам ниже ЭтажФикс
            + Σ(ТекущийТипоразмер.Высота + Зазор + ВысотаБалки)
              по фиксированным этажам ниже ЭтажФикс

  Избыток = ЦелеваяСумма − МинСумма

  Если Избыток < 0 Тогда
    → ОШИБКА по стеллажу:
      "Невозможно подобрать высоты: минимально необходимая сумма
       превышает ВысотаОтПола зафиксированного этажа"
    (не пытаться сжать ниже минимально достаточного — паллеты не влезут)

  Если Избыток = 0 Тогда
    → идеальное совпадение, переход к шагу 6 (Сводка)

  Если Избыток > 0 Тогда
    → переход к шагу 5 (распределение избытка)

ШАГ 5. ПРОХОД 2 — распределение избытка

  a) Весь избыток отдаётся ОДНОМУ этажу-получателю среди нефиксированных
     этажей ниже ЭтажФикс — тому, у кого запас максимален:

       ЭтажПолучатель = аргмакс(РекомендуемаяВысотаДоРаспределения − maxH)

     (этаж, где минимально достаточная высота больше всего «с запасом»
     относительно фактической загрузки — добавка туда наименее рискованна).

     При равенстве запаса у нескольких этажей — выбрать нижний по номеру
     (ближе к полу), для детерминированности результата при повторном запуске.

     Все остальные нефиксированные этажи получают ровно
     РекомендуемаяВысотаДоРаспределения без изменений (ДобавкаМм = 0).

  b) К минимально достаточному типоразмеру ЭтажаПолучателя подобрать из
     каталога Лико_ТипоразмерыСкладскихСекций типоразмер с:

       НоваяВысота = РекомендуемаяВысотаДоРаспределения(ЭтажПолучатель) + Избыток

     — ближайший ДОСТУПНЫЙ типоразмер с Шириной=Текущей, Глубиной>=Текущей,
     Высота >= НоваяВысота.

  c) Если точное совпадение суммы физически недостижимо (шаг каталога 100 мм,
     требуемая точность до мм) → в Summary.ОстатокРасхожденияМм записать разницу,
     Summary.Совпадение = Ложь. Не блокировать расчёт.

ШАГ 6. Собрать сводку и вернуть результат
```

### Ограничения

- `ВысотаОтПолаФиксирована` проверяется **только на самом этаже** (без специальной логики «первый/последний»)
- Ширина секции не меняется (сохраняется топология)
- Глубина и грузоподъёмность не уменьшаются
- Типоразмеры — только из существующего каталога `Лико_ТипоразмерыСкладскихСекций`
- **Ни одному этажу не назначается высота меньше минимально достаточной (p90/maxH), даже ради точного совпадения суммы**

## 6. Критерии приёмки

- [ ] `ОптимальноеРазмещениеПаллет`: N паллет за 1 вызов, перестановки ≤ лимита
- [ ] `РеслотСклада`: освобождает M секций за ≤ K ходов, эффективность > 0
- [ ] `ПодобратьВысотыЭтажей`: не меняет фиксированные, подбирает из каталога, ПотериПроцент рассчитан корректно
- [ ] **Сумма высот всех нефиксированных этажей ниже зафиксированного + высоты фиксированных = `ВысотаОтПола` зафиксированного этажа точно (если каталог позволяет); иначе — предупреждение в Summary с величиной расхождения**
- [ ] **Ни одному этажу не назначается высота меньше минимально достаточной (p90/maxH), даже ради точного совпадения суммы**
- [ ] **Если минимально достаточная сумма превышает целевую — функция возвращает ошибку по стеллажу**
- [ ] **Признак `ВысотаОтПолаФиксирована` проверяется только на самом этаже (без логики «первый/последний»)**
- [ ] **Весь избыток (если требуется) отдаётся ОДНОМУ этажу — с максимальным запасом (РекомендуемаяВысотаДоРаспределения − maxH); при равенстве — нижнему по номеру; остальные этажи получают ровно минимально достаточный типоразмер**
- [ ] Все используют `ОшибкиРазмещенияПаллетаВАдрес` + `ВиртуальноеСостояние`
- [ ] `ПодобратьЯчейку` **не используется**
- [ ] Чистые функции — без записи в регистры, результат возвращается как структура

## 1. Что уже есть

### 1.1 Метаданные

`Лико_Стеллажи` — стеллажи с ТЧ `Этажи` (параметры этажа) и ТЧ `ЗоныПриемкиОтгрузки`.

`Лико_СкладскиеСекции` — секции стеллажа, каждая имеет `Адрес1`, `Адрес2`, `Адрес3` (3 адреса).

Правила размещения по ширине паллета (`W_p`) относительно ширины секции (`W_s`):

| Ширина паллета | Занимает адресов |
|---|---|
| `W_p > 2/3 × W_s` | 3 (вся секция) |
| `W_s/3 < W_p ≤ 2/3 × W_s` | 2 (Адрес2 + крайний) |
| `W_p ≤ W_s/3` | 1 |

Формула зазора: `Σ ширин + (N+1) × ЗазорПоШирине ≤ W_s`

### 1.2 ТЧ Этажи (ключевые поля)

| Поле | Назначение |
|---|---|
| `Типоразмер` | Высота×Ширина×Глубина×Грузоподъёмность секций этажа |
| `ЗазорПоШирине` | Боковой зазор, мм |
| `МаксимальныйВесПодъёмаНаЭтаж` | Макс. вес на этой высоте, кг |
| `ВысотаОтПолаФиксирована` | Если Истина → **первый и последний этажи нельзя менять** при подборе высот |
| `Зазор`, `ВысотаБалки`, `ВысотаОтПола` | Геометрия (spec §1) |

### 1.3 Существующие функции

```bsl
// Поиск адреса для ОДНОГО паллета (13 приоритетов)
Функция ПодобратьЯчейку(Склад, Высота, Ширина, Глубина, Вес,
    ОбратныйПорядокВремени = Ложь, Все = Ложь) Экспорт

// Валидация размещения (18 проверок)
// ВиртуальноеСостояние — Соответствие(Адрес → ПаллетСсылка) для симуляции
Функция ОшибкиРазмещенияПаллетаВАдрес(Ячейка, Паллет,
    Типоразмер = Неопределено, ПолныйОтвет = Ложь,
    ВиртуальноеСостояние = Неопределено) Экспорт
```

### 1.4 Регистры и документы

- `Лико_ПаллетыВСекциях.Остатки` — текущее размещение паллет
- `Лико_ПараметрыПаллет.СрезПоследних` — габариты паллет
- `Лико_ПеремещениеПаллета2_0.СоздатьПеремещение(Паллет, Ячейка)` — перемещение

## 2. Функция 1: ОптимальноеРазмещениеПаллет

### Назначение

Разместить партию паллет, при необходимости **переставляя уже стоящие** для уплотнения.

### Сигнатура

```bsl
Функция ОптимальноеРазмещениеПаллет(Склад, МассивПаллет, МаксПерестановок = 0) Экспорт
```

**Параметры:**
- `Склад` — ссылка на склад
- `МассивПаллет` — массив ссылок `Лико_Паллеты2_0`
- `МаксПерестановок` — число (0 = только заполнение пустых мест)

**Возврат:** `Структура { Placements, Rearrangements, Unplaced, Stats }`

### Алгоритм

```
1. ЗАГРУЗИТЬ габариты всех паллет из Лико_ПараметрыПаллет.СрезПоследних
2. ОТСОРТИРОВАТЬ партию по убыванию ширины (BFD)
3. ИНИЦИАЛИЗИРОВАТЬ ВиртуальноеСостояние = текущие остатки из регистра

4. ФАЗА 1 — Прямое размещение:
   Для каждого паллета (wide→medium→narrow):
     Кандидаты = ПодобратьЯчейку(,,,,,Все=Истина)
     Отфильтровать: ОшибкиРазмещения(,,,ВиртуальноеСостояние) = []
     Если есть → разместить в лучшего, обновить ВиртуальноеСостояние
     Если нет → в очередь на Фазу 2

5. ФАЗА 2 — С перестановками (для неразмещённых):
   Для каждого паллета из очереди:
     Если использовано >= МаксПерестановок → в Unplaced
     
     Для каждого этажа снизу вверх:
       Найти секцию S где можно освободить адрес:
         - Взять стоящий паллет P из S
         - Найти для P другой свободный адрес на этом же этаже
           (через ОшибкиРазмещения с ВиртуальнымСостоянием)
         - Проверить что новый паллет помещается в освобождённый адрес
         - Если да → записать перестановку + размещение

6. ВЕРНУТЬ результат
```

### Структура результата

```
Placements:    Массив [{Pallet, Address, Section, Rack, Floor}]
Rearrangements: Массив [{Pallet, FromAddress, ToAddress}]
Unplaced:      Массив [{Pallet, Reason}]
Stats:         Структура {Total, Placed, RearrangementsUsed,
                         DensityBefore, DensityAfter}
```

## 3. Функция 2: РеслотСклада

### Назначение

Найти план перемещений для уплотнения: освободить максимум секций за ≤ N ходов.

### Сигнатура

```bsl
Функция РеслотСклада(Склад, МаксПеремещений) Экспорт
```

**Возврат:** `Структура { Moves, Stats }`

### Алгоритм

```
1. НАЙТИ все секции где 0 < занятых_адресов < 3

2. ПОСТРОИТЬ кандидатов:
   Для каждой пары секций (A, B):
     Проверить что все паллеты из B можно переместить в A
     (через ОшибкиРазмещения с учётом категорий, зазоров, веса, высоты)
     Если да → кандидат {
       Moves: [{Pallet, FromAddress, ToAddress}],
       Cost: кол-во паллет в B,
       Gain: 1 (секция B освобождается)
     }

3. ОТСОРТИРОВАТЬ по эффективности (Gain / Cost) по убыванию

4. ОТОБРАТЬ жадным алгоритмом:
   Пока usedMoves + Cost <= МаксПеремещений И паллет не участвует дважды:
     Добавить в план, usedMoves += Cost

5. ВЕРНУТЬ {Moves, Stats: {MovesUsed, SectionsFreed, DensityGain}}
```

## 4. Функция 3: ПодобратьВысотыЭтажей

### Назначение

Для стеллажа подобрать оптимальные типоразмеры этажей под фактическую номенклатуру.

### Сигнатура

```bsl
Функция ПодобратьВысотыЭтажей(Стеллаж) Экспорт
```

**Возврат:** `Структура { Floors, Summary }`

### Алгоритм

```
1. ДЛЯ КАЖДОГО ЭТАЖА стеллажа:

   a. СОБРАТЬ все паллеты на этом этаже (из Лико_ПаллетыВСекциях)
      ВысотыПаллет = габариты из Лико_ПараметрыПаллет

   b. ВЫЧИСЛИТЬ:
      maxH = Макс(ВысотыПаллет)
      p90  = 90-й перцентиль ВысотыПаллет
      wasted = ТекущийТипоразмер.Высота - maxH
      wasted% = wasted / ТекущийТипоразмер.Высота * 100

   c. ПРОВЕРИТЬ фиксацию:
      Если (этаж = 1 И ВысотаОтПолаФиксирована) ИЛИ этаж = последний:
        → фиксирован, рекомендации нет

   d. ПОДОБРАТЬ типоразмер (для нефиксированных):
      Из каталога Лико_ТипоразмерыСкладскихСекций найти где:
        Высота >= p90
        Ширина = ТекущаяШирина
        Глубина >= ТекущаяГлубина
        Вес >= ТекущийВес
      Взять с минимальной достаточной высотой

2. ВЕРНУТЬ [{Floor, CurrentTypeSize, RecommendedTypeSize,
            PalletsCount, MaxPalletHeight, WastedMm, WastedPercent, Fixed}]
```

### Ограничения

- Первый этаж + последний — **не меняются** (если `ВысотаОтПолаФиксирована`)
- Ширина секции не меняется (топология)
- Глубина и грузоподъёмность не уменьшаются
- Типоразмеры — только из существующего каталога

## 6. Критерии приёмки

- [ ] `ОптимальноеРазмещениеПаллет`: N паллет за вызов, перестановки ≤ лимита
- [ ] `РеслотСклада`: освобождает секции за ≤ N ходов
- [ ] `ПодобратьВысотыЭтажей`: не меняет фиксированные этажи, подбирает из каталога
- [ ] Все используют `ПодобратьЯчейку` + `ОшибкиРазмещения` + `ВиртуальноеСостояние`
- [ ] **Чистые функции** — только симуляция, без записи в регистры. Результат возвращается как структура.

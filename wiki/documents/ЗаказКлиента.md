# ЗаказКлиента (кастомные формы)

> Центральный документ системы Лико. Кастомная форма `Лико_ФормаДокумента` (~6600+ строк) — главный интерфейс работы с заказом: расчёт тиражей, параметры печати/вырубки, цвета, работы, отгрузки, создание повторов, интеграция с AI.

## Кастомные формы

В документе 19 форм, из них кастомные (Лико_):

| Форма | Назначение |
|---|---|
| `Лико_ФормаДокумента` | **Главная форма** — полный интерфейс заказа |
| `Лико_ФормаСписка` | Список заказов с кастомными колонками |
| `Лико_ФормаСпискаЗакрытияОтгрузки` | Список для закрытия отгрузки |
| `Лико_МастерЗаполненияПоПрокату` | Мастер заполнения параметров по прокату |
| `Лико_РедактированиеПараметровСекции` | Редактирование параметров секции |
| `Лико_ФормаВыбораДокументаОтгрузки` | Выбор документа отгрузки |
| `Лико_ФормаВыбораТипаЭтикетки` | Выбор типа этикетки |
| `Лико_ФормаДокумента_ЗаказОснастки` | Форма для заказа оснастки |
| `Лико_ФормаДокументаЦветаРаботы` | Форма цветов и работ |
| `Лико_ФормаЗаявкиНаЦветоделение` | Форма заявки на цветоделение |

## Ключевые возможности Лико_ФормаДокумента

### Расчёт тиражей и метража
- `РассчитатьЗаказНаСервере()` — полный пересчёт заказа
- `РассчитатьТиражНаСервере()` — расчёт тиража из погонного метража
- `РассчитатьМетражНаСервере()` — расчёт метража из количества
- `РасчитатьТиражМетраж()` — Client-метод расчёта тиража и метража

### Работа с параметрами печати/вырубки
- `ЗаполнитьПараметрыШтампа()` — автозаполнение параметров из оснастки (штамп вырубной, тиснения)
- `ПараметрыШтампаПриИзменении()` — обработка изменений параметров
- `ПроверитьЗаполнениеПараметровШтампа()` — проверка корректности
- `ПроставитьВидВырубки()` — установка вида вырубки с пересчётом параметров
- Группы процедур `ВыделениеЦветом*` — цветовая индикация заполнения параметров
- `ИзменитьДоступностьОбъектаДляВидаВырубки()` — управление видимостью полей

### Цвета и работы
- `ЦветаРаботы()` — инициализация структуры цветов и работ
- `УтверждениеЦветов()` — логика утверждения цветов
- `ПроверкаЗаполненияЦветовРабот()`, `ПроверитьЗаполнениеРабот()` — валидация
- `СоздатьФорму()` — создание новой формы из строки цвета
- `СоздатьНовуюФорму()` — создание формы с подбором

### Отгрузки и затраты
- `ЗаполнитьОтгрузкиНаСервере()` — заполнение ТЧ отгрузок из регистров
- `РассчитатьНормативыПоОтгрузкеНаСервере()` — расчёт нормативов
- `ЗаполнитьЗатратыНаСервере()` — заполнение затрат
- `ОбновитьИтогиОтгрузки()` — обновление итогов по отгрузкам

### Отправка в работу
- `НаправитьВРаботу()` — сложная логика отправки: проверки, блокировки, письма
- `НаправитьВРаботуНаСервере()` — серверная часть отправки
- `Утвердить()`, `УтвердитьЗаказ()` — утверждение заказа
- `ПроверкаЗаполненияЗаказаНаСервере()` — комплексная проверка перед отправкой

### Повторы и копирование
- `СоздатьПовторЗаказа()` — создание повтора заказа с отслеживанием различий
- `СоздатьПовторЗаказаНаСервере()` — серверная логика создания повтора
- `ПолучитьСписокОтличийПланФакт()` — анализ план/факт для повтора

### Интеграции
- `ВыгрузкаВТабаш()` — выгрузка заказа в Табаш (внешняя база)
- `ВыгрузкаВТабашПоПрокатам()` — выгрузка с разбивкой по прокатам
- `DFMСервер.СтартDFM()` — запуск подсистемы DFM
- `ОбработатьШтрихкоды()` — обработка сканированных штрихкодов

### Оснастка
- `СоздатьЗаказНаОснастку()` — создание связанного заказа на оснастку
- `ПроверитьНаличиеОснастки()` — проверка наличия оснастки
- `СоздатьЗаявкуНаОснастку()` — создание заявки на оснастку

### Прочее
- `ПриСозданииНаСервере()` — инициализация формы: параметры отборов для динамических списков, DFM, кнопка «Бога» для редактирования параметров штампов, скрытие команд в подменю ЕЩЁ
- `ДобавитьУсловноеОформление()` — настройка условного оформления ТЧ
- `ПередЗаписью()` — валидация и обработка перед записью (GTIN, термоусадка, ставки НДС)
- `ПоказатьИзмененияНаСервере()` — отслеживание изменений реквизитов
- `ОтправитьПисьмо()` — отправка email-уведомлений

## Статусы задач

```
new → wip ↔ paused → review → done
```

| Статус | Значение | Кто может взять |
|--------|----------|-----------------|
| `new` | Задача создана, никто не начал | **Любой** |
| `wip` | В работе | Тот кто начал |
| `paused` | Приостановлен, можно перехватить | **Любой** |
| `review` | Готово, жду проверки вторым агентом | Второй агент |
| `done` | Завершено | — |

**Ключевое:** `paused` = «забирай». `new` = «никто не начал, бери смело».

## Формат задачи в HANDOFF.md

```markdown
### #20260603-001 | 2026-06-03 | started by cline | wip

**Задача:** Добавить процедуру РасчетСтоимости

**Контекст:**
- Wiki: [[Лико_ОбщегоНазначенияСервер]]
- Файлы: `1s/ERP/.../Module.bsl#L10950` (добавлено тело процедуры)
- Следующий: `1s/ERP/.../Forms/Лико_ФормаДокумента/Form.xml#L342` (добавить команду)
- Паттерн: `СоздатьКоманду()` в [[Лико_ПрограммноеСозданиеДокументовСправочников]]
- Зависимости: [[Лико_СебестоимостьЗаказов]], [[Лико_ЗатратыПоЗаказу]]

**Последнее:** Написал тело процедуры, протестировал на 3 заказах
**Блокировка:** `Module.bsl` (cline, до 15:00)

**История:**
- 14:00 (cline) начал — написал тело процедуры
- 14:30 → приостановил (paused), нужна команда в форме
```

### Правила заполнения контекста

- **Файлы** — с номерами строк если известны: `Module.bsl#L10950`
- **Следующий** — конкретный файл и место: `Form.xml#L342`
- **Паттерн** — ссылка на wiki-страницу с примером кода
- **Блокировка** — мягкий маркер «я здесь, не наступи» (файл + агент + время)
- **История** — для сложных задач, где контекст меняется

## Как перехватить задачу

1. В HANDOFF.md найди задачу со статусом `paused` или `new`
2. Пометь себя: `Статус: wip (cline)`, `Блокировка: файл (cline)`
3. Прочитай **Контекст** — там всё: где остановился предыдущий агент
4. Начни со **Следующий** — там конкретный файл и строка
5. При паузе/завершении — обнови HANDOFF.md

## Как передавать задачи Claude Code

Пользователь говорит просто **«Передай Claude»** (или «Передай Claude задачу») — **без описания задачи**. Ты сам извлекаешь задачу из текущего контекста разговора.

### Алгоритм

#### Шаг 1: Извлеки суть из разговора

Посмотри на весь текущий контекст: что обсуждалось, какие решения приняты, над чем работали, что не получилось, что нужно сделать дальше.

**Напиши в задачу:**
1. **Что обсуждали** — краткое содержание разговора
2. **Какие решения приняты** — к чему пришли
3. **Почему** — логика, аргументы, контекст
4. **Что конкретно сделать** — действие для Claude

#### Шаг 2: Определи сложность

| Простая → TASKS.md | Сложная → HANDOFF.md |
|---|---|
| 1 действие | много действий/файлов |
| нет состояния | продолжить после паузы |
| не нужен код | нужны строки/файлы/паттерны |

#### Шаг 3: Запиши задачу

**Простая (TASKS.md):**
```markdown
### → claude | YYYY-MM-DD | !
Задача: [что сделать — одно предложение]
Контекст: [суть обсуждения, почему, какие решения приняты]
Статус: new
```

**Сложная (HANDOFF.md):**
```markdown
### #ID | YYYY-MM-DD | started by cline | new

**Контекст обсуждения:**
[о чём говорили, какие решения приняты, логика рассуждений]

**Задача:** [что конкретно сделать]

**Технический контекст:**
- Wiki: [[Страница1]], [[Страница2]]
- Файлы: `path/file#L123`
- Паттерны: ...
```

#### Шаг 4: Запиши в log.md

```markdown
## YYYY-MM-DD (Cline) HANDOFF → claude | [суть]
```

### Важно
Claude Code не видел наш разговор. Твоя задача — передать ему **суть обсуждения и ход мыслей**, а не просто список дел. Он должен понять ПОЧЕМУ и ЗАЧЕМ, а не только ЧТО.

## Конфликты при параллельной работе

1. **Не редактируй файл с блокировкой** другого агента
2. **Если нужен заблокированный файл** — поставь задачу/вопрос в HANDOFF.md
3. **Один BSL-файл = один агент** (параллельная запись = потеря данных)
4. **Wiki-страницы** — Git merge справится с непересекающимися изменениями
5. **Если оба правят одну wiki-страницу** — приоритет у последнего ingest

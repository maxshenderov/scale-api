# Синхронизация Подбор + Валидация

> Когда одна функция подбирает место (WHERE в запросе), а другая валидирует размещение — они должны реализовывать **одни и те же правила**. Иначе подбор вернёт место, которое валидация потом отклонит.

## Когда использовать

Паттерн применим когда в системе есть:
- **Подбор** — функция, которая ищет подходящее место (складская ячейка, рабочий центр, исполнитель)
- **Валидация** — функция, которая проверяет корректность конкретного выбора

Обе функции должны реализовать одни и те же правила — иначе подбор вернёт вариант, который валидация отклонит, и наоборот.

## Антипаттерн (было до 2026-05-27)

```bsl
// ОшибкиРазмещенияВАдрес — 14 проверок
Функция ОшибкиРазмещенияВАдрес(Ячейка, Высота, Ширина, Глубина, Вес)
    // проверка: ширина > 2/3 → только адрес 2
    // проверка: ширина > 1/3 → адреса 1 или 3
    // проверка: соседи не блокируют адрес 2
    // ... 14 проверок
КонецФункции

// ПодобратьЯчейку — запрос БЕЗ этих фильтров!
Функция ПодобратьЯчейку(Склад, Высота, Ширина, Глубина, Вес)
    // ГДЕ
    //   (Паллет1 = Пустая ИЛИ Паллет2 = Пустая ИЛИ Паллет3 = Пустая)
    //   -- нет проверки ширины паллета!
    // ВЫБРАТЬ
    //   ...  -- нет поля "Адрес"
    Пока Выборка.Следующий() Цикл
        Результат = Выборка.Адрес;  // ← перезаписывает — берёт последнюю (дальнюю)
    КонецЦикла;
КонецФункции
```

**Результат:** подбор вернул секцию с занятыми адресами 1 и 3 для паллета > 2/3, и адрес "не определён" (нет поля).

## Правильный паттерн

```bsl
// 1. ОшибкиРазмещенияВАдрес — правила 1/3 и 2/3
// Правило: ширина > 2/3 → только один паллет в средний адрес
Если Ширина > Секция.Типоразмер.Ширина * 2 / 3 Тогда
    // только адрес 2, остальные пусты
КонецЕсли;

// Правило: ширина > 1/3 → только крайние адреса
Если Ширина > Секция.Типоразмер.Ширина / 3 Тогда
    // адрес 1 или 3, адрес 2 пустой
КонецЕсли;

// 2. ПодобратьЯчейку — ТО ЖЕ САМОЕ в WHERE и SELECT
ВЫБРАТЬ ПЕРВЫЕ 1
    // ...
    ВЫБОР
        КОГДА &Ширина > Типоразмер.Ширина * 2 / 3
            ТОГДА Адрес2
        КОГДА &Ширина > Типоразмер.Ширина / 3
            ТОГДА ВЫБОР
                КОГДА Паллет1 = ПустаяСсылка ТОГДА Адрес1
                ИНАЧЕ Адрес3
            КОНЕЦ
        ИНАЧЕ ВЫБОР
            КОГДА Паллет1 = ПустаяСсылка ТОГДА Адрес1
            КОГДА Паллет2 = ПустаяСсылка
                И Типоразмер1.Ширина <= Типоразмер.Ширина / 3
                И (Паллет3 = ПустаяСсылка
                   ИЛИ Типоразмер3.Ширина <= Типоразмер.Ширина / 3)
                ТОГДА Адрес2
            КОГДА Паллет3 = ПустаяСсылка ТОГДА Адрес3
            ИНАЧЕ Адрес1
        КОНЕЦ
    КОНЕЦ КАК Адрес
ГДЕ
    // Фильтр 1: ширина > 2/3 → все адреса пусты
    И ВЫБОР
        КОГДА &Ширина > Типоразмер.Ширина * 2 / 3
            ТОГДА Паллет1 = Пустая И Паллет2 = Пустая И Паллет3 = Пустая
        КОГДА &Ширина > Типоразмер.Ширина / 3
            ТОГДА Паллет2 = Пустая И (Паллет1 = Пустая ИЛИ Паллет3 = Пустая)
        ИНАЧЕ ИСТИНА
    КОНЕЦ

// 3. ПЕРВЫЕ 1 — взять ближайшую по сортировке
Пока Выборка.Следующий() Цикл
    Результат = Выборка.Адрес;
    Прервать;  // или ПЕРВЫЕ 1 в SELECT
КонецЦикла;
```

## Таблица синхронизации

| Правило | Валидация (BSL) | Подбор (SQL WHERE) |
|---|---|---|
| Ширина > 2/3 → один паллет в центре | `Если Ширина > * 2 / 3 Тогда` | `Паллет1=Пустая И Паллет2=Пустая И Паллет3=Пустая` |
| Ширина > 1/3 → крайние адреса | `Если Ширина > / 3 Тогда` | `Паллет2=Пустая И (Паллет1=Пустая ИЛИ Паллет3=Пустая)` |
| Соседи не блокируют адрес 2 | `Типоразмер1.Ширина <= / 3` | `Типоразмер1.Ширина <= Типоразмер.Ширина / 3` |
| Адрес уже занят | `ЗначениеЗаполнено(Соо[Ячейка])` | `Паллет1/2/3 = ПустаяСсылка` в SELECT |
| Монтажный зазор (1 паллет в секции → +150мм, 2 паллета → +200мм) | Проверка 13a: `ОстатокШиринаСекции - Структура.Ширина - ТребуемыйЗазор < 0` | Финальный ГДЕ над `ВТ_ИТОГ`: `КоличествоПаллетВСекции=1 → ОстатокШирина-&Ширина-150>=0`, `=2 → -200>=0` |
| Запрет размещения на секции | Проверка 1a: `Секция.ЗапретРазмещения` | `НЕ Лико_СкладскиеСекции.ЗапретРазмещения` в ВТСекции.ГДЕ |

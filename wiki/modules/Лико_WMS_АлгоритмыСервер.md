# Лико_WMS_АлгоритмыСервер

> Общий модуль с алгоритмами оптимизации размещения паллет на складе.

## Что делает

Содержит алгоритмы локальной оптимизации заполнения складских секций паллетами. Решает задачу bin packing для одной секции: из списка доступных паллет разных типоразмеров выбирает оптимальную комбинацию, которая максимально плотно заполняет секцию.

**Ключевая функция:**
- `ОптимальноеЗаполнениеСекции(Секция, ТаблицаТипов, ЗазорМежду = 50)` — оптимальное заполнение одной секции

**Файл:** `output/Liko_WMS_OptimalSectionFill.bsl`

## Алгоритм

Используется **жадный алгоритм с look-ahead** (не простой жадный):

1. **Фильтрация** — отбрасывает паллеты которые физически не влезают (высота/ширина/вес/узкопроходность)
2. **Look-ahead симуляция** — для каждого подходящего типоразмера СИМУЛИРУЕТ: "а что если я поставлю ЭТОТ паллет, сколько ещё влезет после него?"
3. **Гомогенное заполнение** — предпочитает ОДИНАКОВЫЕ паллеты (3×900 лучше чем 1×1200 + 1×800)
4. **Выбор лучшего** — выбирает тип с максимальным скором: `количество_паллет × 1000 + утилизация_ширины × 100`

### Пример работы

Секция 2700мм, паллеты: 1200мм (5шт), 900мм (10шт), 800мм (15шт)

**Вариант А (наивный):** 
- 1×1200 → остаток 1450мм → ещё 1×1200 → остаток 200мм → ничего не влезет
- **Итого:** 2 паллеты (2400мм чистой ширины)

**Вариант Б (с look-ahead):**
- 1×900 → остаток 1750мм → ещё 1×900 → остаток 800мм → ещё 1×800
- **Итого:** 3 паллеты (2600мм чистой ширины) ✓ **ЛУЧШЕ**

## Ключевые функции

### ОптимальноеЗаполнениеСекции()

```bsl
Функция ОптимальноеЗаполнениеСекции(Секция, ТаблицаТипов, ЗазорМежду = 50) Экспорт
```

**Параметры:**
- `Секция` — СправочникСсылка.Лико_СкладскиеСекции или Структура с полями:
  - Ширина, Высота, Глубина (мм)
  - МаксВес (кг), МаксПаллет (обычно 3)
  - УзкийПроход (Булево), МаксШиринаПаллетыУП (мм)
- `ТаблицаТипов` — ТаблицаЗначений с колонками:
  - Ширина, Высота, Глубина, Вес
  - Количество — сколько паллет этого типа доступно
  - Ссылка — ID паллета (для возврата)
- `ЗазорМежду` — зазор между паллетами (по умолчанию 50мм)

**Формула зазоров:** N паллет занимают (N+1) зазоров
- Пример: 3 паллеты → |50| паллет1 |50| паллет2 |50| паллет3 |50|

**Возвращает:** Массив структур
```bsl
[
  {ИндексТипа: 0, Количество: 2},
  {ИндексТипа: 2, Количество: 1}
]
```

### ЖадноеЗаполнениеСLookAhead()

Внутренняя функция — основной цикл алгоритма:
1. Проходит по свободным слотам (обычно 3)
2. Для каждого слота выбирает лучший паллет через симуляцию
3. Обновляет остатки ширины/веса/количества

### ВыбратьЛучшийДляОстатка()

Внутренняя функция — look-ahead симуляция:
1. Для КАЖДОГО кандидата симулирует жадное заполнение остатка
2. На первой итерации берёт исходный кандидат
3. На следующих пытается взять ТОТ ЖЕ тип (гомогенность)
4. Если тот же тип не влезает — берёт самый широкий
5. Считает скор: `количество × 1000 + утилизация × 100`
6. Возвращает кандидат с лучшим скором

### НайтиСамыйШирокий()

Утилита — находит самый широкий паллет в массиве кандидатов.

Endpoint: `POST /api/pack_section`

## Применение

1. **Последовательное размещение:**
   - 1С подбирает секцию для первого паллета ([[Лико_ПодобратьЯчейку]])
   - Если секция новая (пустая) — запускается `ОптимальноеЗаполнениеСекции()`
   - Берётся не следующий паллет по списку, а оптимальная комбинация для этой секции
   - После заполнения секции — берётся следующий паллет и процесс повторяется

2. **Преимущества:**
   - Плотное заполнение (3 паллеты вместо 2)
   - Однородное размещение (проще искать, меньше путаницы)
   - Учёт всех ограничений (высота, вес, узкопроходность)

## Пример использования

```bsl
// В модуле Лико_WMS_Сервер
Функция РазместитьПаллетыОптимально(СписокПаллет, Склад) Экспорт
    
    Для Каждого Паллет Из СписокПаллет Цикл
        
        // Подобрать секцию для первого паллета
        Секция = Лико_СкладскиеСекции.ПодобратьЯчейку(Паллет);
        
        Если НЕ СекцияЗанята(Секция) Тогда
            
            // Секция пустая → оптимизируем заполнение
            ТаблицаТипов = ПостроитьТаблицуТипов(ОставшиесяПаллеты);
            
            Результат = Лико_WMS_АлгоритмыСервер.ОптимальноеЗаполнениеСекции(
                Секция, 
                ТаблицаТипов, 
                50  // Зазор 50мм
            );
            
            // Разместить выбранные паллеты
            Для Каждого Выбор Из Результат Цикл
                СтрокаТипа = ТаблицаТипов[Выбор.ИндексТипа];
                Для Сч = 1 По Выбор.Количество Цикл
                    РазместитьПаллетВСекцию(СтрокаТипа.Ссылка, Секция);
                КонецЦикла;
            КонецЦикла;
            
        Иначе
            // Секция занята → просто размещаем текущий паллет
            РазместитьПаллетВСекцию(Паллет, Секция);
        КонецЕсли;
        
    КонецЦикла;
    
КонецФункции
```

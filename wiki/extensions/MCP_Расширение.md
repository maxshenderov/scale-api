# MCP Расширение

> MCP-сервер внутри 1С: доступ к данным конфигурации через Model Context Protocol (JSON-RPC 2.0).

Репозиторий: https://github.com/vladimir-kharin/1c_mcp
Автор: Харин Владимир (С) 2025.

## Что расширяет

Расширение добавляет в конфигурацию 1С полноценный MCP-сервер (Model Context Protocol),
реализованный как HTTP-сервис. Сервер принимает JSON-RPC 2.0 запросы и предоставляет
стандартные MCP-методы: инструменты (tools), ресурсы (resources) и промпты (prompts).
Протокол: MCP Streamable HTTP, версия протокола `2025-03-26`.

## Архитектура

```
HTTP-запрос (JSON-RPC 2.0)
  -> mcp_APIBackend (HTTPService) — принимает запросы, маршрутизация методов
    -> mcp_КонтейнерыПовтИсп — кешируемые таблицы инструментов/ресурсов/промптов
    -> mcp_Метаданные — создание таблиц, схем параметров, сбор из контейнеров
    -> mcp_Выполнение — вызов инструментов, чтение ресурсов, получение промптов
    -> mcp_Содержимое — формирование MCP-структур (text, image, blob, prompt message)
    -> Обработки-контейнеры — реализация конкретных инструментов/ресурсов/промптов
```

Контейнеры регистрируются через подсистемы:
- `mcp_MCPСервер.mcp_КонтейнерыИнструментов` — обработки с инструментами
- `mcp_MCPСервер.mcp_КонтейнерыРесурсов` — обработки с ресурсами
- `mcp_MCPСервер.mcp_КонтейнерыПромптов` — обработки с промптами

## Новые объекты

### Общие модули
- `mcp_Выполнение` — движок выполнения: вызов инструментов, чтение ресурсов, получение промптов
- `mcp_КонтейнерыПовтИсп` — кешируемые таблицы инструментов/ресурсов/промптов (повторное использование)
- `mcp_Метаданные` — создание таблиц и схем параметров, сбор контейнеров, JSON-схемы
- `mcp_ОбщегоНазначения` — утилиты: JSON-парсинг (из контекста LLM), разбор URL, нормализация ключей
- `mcp_Содержимое` — фабрика MCP-структур: text, image, blob, prompt message

### HTTP-сервисы
- `mcp_APIBackend` — HTTP API: эндпоинты `/rpc`, `/mcp`, `/health`, JSON-RPC-маршрутизация

### Обработки (контейнеры инструментов)
- `mcp_ИнструментДанныеОКонфигурации` — три инструмента:
  - `list_metadata_objects` — список объектов метаданных с фильтрацией
  - `get_metadata_structure` — структура конкретного объекта (реквизиты, ТЧ, измерения, ресурсы)
  - `execute_bsl` — выполнение произвольного BSL-кода на сервере 1С
- `mcp_РесурсОписаниеСинтаксисаВстроенногоЯзыка` — ресурс с синтаксисом встроенного языка 1С
- `mcp_УправлениеСервером` — управление MCP-сервером

### Роли
- `mcp_ОсновнаяРоль`

### Подсистемы
- `mcp_MCPСервер` — корневая подсистема, содержит:
  - `mcp_КонтейнерыИнструментов`
  - `mcp_КонтейнерыРесурсов`
  - `mcp_КонтейнерыПромптов`

## MCP-методы (JSON-RPC)

| Метод | Назначение |
|---|---|
| `initialize` | Handshake: версия протокола, возможности сервера, serverInfo |
| `tools/list` | Список доступных инструментов с inputSchema |
| `tools/call` | Вызов инструмента с аргументами |
| `resources/list` | Список доступных ресурсов |
| `resources/read` | Чтение содержимого ресурса по URI |
| `prompts/list` | Список доступных промптов |
| `prompts/get` | Получение сообщений промпта с аргументами |

## Контракт контейнера

Обработка-контейнер должна реализовать экспортные методы (для инструментов — обязательно, для ресурсов/промптов — опционально):
- `ДобавитьИнструменты(ТаблицаИнструментов)` — заполняет таблицу инструментами
- `ВыполнитьИнструмент(ИмяИнструмента, Аргументы)` — выполняет инструмент
- `ДобавитьРесурсы(ТаблицаРесурсов)` — заполняет таблицу ресурсами
- `ПрочитатьРесурс(Адрес)` — возвращает содержимое ресурса
- `ДобавитьПромпты(ТаблицаПромптов)` — заполняет таблицу промптами
- `ПолучитьПромпт(ИмяПромпта, Параметры)` — возвращает сообщения промпта

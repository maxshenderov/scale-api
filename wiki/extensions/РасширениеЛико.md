# Расширение Лико

> Главное расширение конфигурации `УправлениеПредприятием` для типографии Лико. Добавляет все кастомные объекты с префиксом `Лико_`, переопределяет поведение базовых справочников и документов.

## Что расширяет

Базовая конфигурация: **УправлениеПредприятием** (ERP).

Расширение находится в `1s/ERP/extensions/liko/` и содержит:
- Управляемый модуль приложения (`ManagedApplicationModule`) — подписка на `ПриНачалеРаботыСистемы`.
- **35+ общих модулей** с префиксом `Лико_`.
- **HTTP-сервис `Liko_Rest`** — REST API для веб-портала и мобильных клиентов (70+ endpoints).
- **40+ общих форм**, команд, отчётов.
- Расширения **базовых справочников** (Номенклатура, Склады, СкладскиеЯчейки, ДоговорыКонтрагентов, Сотрудники и др.).
- Расширения **базовых документов** (формы ЗаказКлиента, печать и т.д.).

## Основные изменения

### ManagedApplicationModule
- `Лико_ПриНачалеРаботыСистемы()` — при старте системы вызывает `Лико_СерверВзаимодействияСервер.ПроверкаВозможностиИспользованияСистемыВзаимодействия()` (для веб-сокетов и HTTP-сервисов).

### Общие модули (ключевые)
- `Лико_ОбщегоНазначенияСервер` — центральный модуль (~10900 строк): общие процедуры, работа с данными, экспорт.
- `Лико_Дополнительно` / `Лико_ДополнительноКлиент` / `Лико_ДополнительноКлиентСервер` — сообщения, проверки, сервисные функции.
- `Лико_Склады` / `Лико_СкладыКлиент` / `Лико_СкладыВызовСервера` — складская логика.
- `Лико_Планирование` / `ПланированиеСервер` — планирование производства.
- `Лико_ТиражМетраж` — расчёт тиражей и метражей.
- `Лико_Диадок` — интеграция с ЭДО Диадок.
- `Лико_HTTP_Сервер` — HTTP-инфраструктура (токены, ответы).
- `Лико_WMS_Сервер` — WMS REST API для веб-приложения оптимизации склада (10 ProcName).
- `Лико_СерверВзаимодействияСервер` / `Лико_СерверВзаимодействияКлиент` — веб-сокеты.
- `WebSocketКлиент` / `WebSocketСервер` — WebSocket-коммуникация.
- `SDK_Telegram` — интеграция с Telegram.
- `Лико_АсинхронныеПроцедуры` — фоновые/асинхронные задания.
- `Лико_QdrantИндексация` — формирование данных для Qdrant.
- `DFMСервер` / `DFMКлиент` — интеграция с DFM (система дизайна/флексо).
- `СА_ПроцедурыСканАрхиваСервер` — работа со скан-архивом.
- `МенеджерОборудованияКлиент` / `МенеджерОборудованияВызовСервера` — интеграция с оборудованием (TouchPad, принтеры).
- `РасчетСебестоимостиПостатейныеЗатраты` — калькуляция себестоимости.
- `УстановкаЦенСервер` — ценообразование.
- Переопределяемые модули: `ВариантыОтчетовПереопределяемый`, `УправлениеПечатьюПереопределяемый`, `МодификацияКонфигурацииПереопределяемый`.

### Расширение базовых справочников
- **Номенклатура** — ObjectModule, ManagerModule, форма выбора.
- **СкладскиеЯчейки** — ObjectModule, ManagerModule, форма списка.
- **Склады** — форма выбора.
- **ДоговорыКонтрагентов** — ObjectModule.
- **Сотрудники** — ManagerModule.
- **УпаковкиЕдиницыИзмерения** — ObjectModule, ManagerModule, форма выбора.
- **СерииНоменклатуры** — ObjectModule.
- **ФизическиеЛица** — ObjectModule.
- **БанковскиеСчетаКонтрагентов** — ManagerModule.
- **СоглашенияСКлиентами** — ObjectModule.
- **РабочиеЦентры** — форма выбора, форма списка, структура РЦ.
- **ЦеновыеГруппы** — ObjectModule.

### Общие формы
- `Лико_ФормаАвторизацииСклада` — авторизация на складе.
- `Лико_ФормаПодбораСерии` / `Лико_ФормаПодбораНоменклатуры` — подбор серий/номенклатуры.
- `Лико_ФормаВыбораСЗ` / `Лико_ФормаВыбораАдреса` — выбор складских зон/адресов.
- `Лико_QR_code` — генерация и сканирование QR-кодов.
- `Лико_РасчетДлиныРолика` — калькулятор длины ролика.
- `Лико_ФормаВопроса` — диалог вопроса.
- `ОтправкаСообщения` — отправка сообщений пользователям.
- `ПечатьДокументов` — кастомизированная печать.

- `Лико_ПравилаСписанияНоменклатурыПодЗаказ` — правила автосписания.
- `Лико_ФормулыПантонов` — формулы смешивания красок Pantone.
- `Лико_Формы` — форма подбора.
- `Лико_ОтображениеРабочихЦентров` — отображение РЦ.
- `Лико_ПараметрыРасчетаРаскрояМатериалов` — параметры раскроя.

- `Лико_ВерсииНоменклатуры` — версионирование номенклатуры.
- `ЯССМ_Нарезки`, `ЯССМ_ОбъектыНоменклатуры` — объекты ЯССМ (ярусная система складских мест).

### Общие команды
- `Лико_ТоварыВЯчейках` — отчёт по товарам в ячейках.
- `ПанельОтчетовЛико_Склад` — панель складских отчётов.
- `Лико_АнализЗакупок` — анализ закупок.
- `Лико_ЗакрытиеЗаказаПоставщика` — закрытие заказа поставщику.
- `Лико_ПриложениеКВБЗ` — приложение к внутреннему бухгалтерскому заказу.
- `Лико_ЗаявкаСГИ` — заявка на склад готовой продукции.

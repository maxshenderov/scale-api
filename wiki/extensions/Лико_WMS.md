# Лико_WMS_Сервер

> Общий модуль (Server) в расширении Лико — WMS REST API для веб-приложения оптимизации размещения паллет на складе. 10 экспортных функций-ProcName, вызываемых через HTTP-сервис Liko_Rest.

## Что делает

Предоставляет REST API для внешнего веб-приложения (Python FastAPI + Svelte):
- Топология склада (стеллажи, этажи, типоразмеры)
- Текущая занятость секций и паллеты на полу
- Подбор ячеек и валидация размещения
- Пакетное планирование размещения (greedy)
- Создание документов перемещения паллет
- Экспорт/импорт снимков склада для автономной работы
- Генерация синтетических данных для отладки

## Ключевые процедуры

- `WMS_CheckConnection(ПараметрыPOST)` — ping/pong, проверка доступности API.
- `WMS_GetWarehouses(ПараметрыPOST)` — список складов где есть стеллажи.
- `WMS_GetRacks(ПараметрыPOST)` — полная топология стеллажей с этажами и типоразмерами.
- `WMS_GetOccupancy(ПараметрыPOST)` — занятость всех секций: какие паллеты в каких адресах.
- `WMS_GetFloor(ПараметрыPOST)` — паллеты в зонах приёмки/отгрузки.
- `WMS_FindCell(ПараметрыPOST)` — обёртка над `ПодобратьЯчейкуПоПаллету(Все=Истина)`, возвращает всех кандидатов.
- `WMS_PlacePallets(ПараметрыPOST)` — greedy планировщик пакетного размещения.
- `WMS_ValidatePlacement(ПараметрыPOST)` — обёртка `ОшибкиРазмещенияПаллетаВАдрес()`.
- `WMS_MovePallet(ПараметрыPOST)` — создание документа `Лико_ПеремещениеПаллета2_0`.
- `WMS_ExportSnapshot(ПараметрыPOST)` — полный снимок склада (топология + занятость + пол).
- `WMS_GenerateMockData(ПараметрыPOST)` — генератор синтетического склада для отладки.

### Внутренние хелперы

- `HttpВернутьОшибку_WMS(Код, Сообщение)` — единый контракт ошибок `{ ok: false, error: { code, message } }`.
- `СсылкаПоСтрокеGUID(СтрокаGUID, ИмяМетаданных)` — поиск ссылки по строковому GUID.
- `ЦветСтеллажа(НомерСтеллажа)` — фиксированная палитра из 9 цветов для стеллажей 1-9.
- `СобратьАдрес(Ячейка, Паллет, Типоразмер)` — структура адреса с паллетом или null.
- `ЗанятостьАдреса(Паллет)` — 1 если паллет заполнен, иначе 0.
- `СобратьТопологиюСклада(СкладСсылка)` — возвращает `{ Склад, Стеллажи }`.
- `СобратьЗанятостьСекций(СкладСсылка)` — возвращает `{ Секции, Сводка }`.
- `СобратьПаллетыНаПолу(СкладСсылка)` — возвращает `{ Паллеты }`.
- `МожетРазместить(Состояние, Паллет, ЦелевоеКоличество)` — проверка физических ограничений.
- `СоздатьРазмещение(Паллет, Состояние, FillLevel)` — запись размещения.
- `ОбновитьСостояние(Состояние, Паллет)` — симуляция размещения.

## Диспетчеризация

Функции вызываются через существующий HTTP-сервис `Liko_Rest`:
```
POST /hs/Liko_Rest  { "ProcName": "WMS_GetRacks", "warehouse": "guid" }
```

Механизм: `Liko_Rest.Post()` -> `ВызовМетода()` -> `Вычислить("WMS_GetRacks(Параметры)")`.

## Единый контракт ошибок

Все функции возвращают HTTP 200:
```json
// Успех:   { "ok": true, ... }
// Ошибка:  { "ok": false, "error": { "code": "...", "message": "..." } }
```

## Используемые модули

- `Лико_HTTP_Сервер` — `Ответ()`, `СтруктураВJSON()`.
- `Лико_СкладскиеСекции` — `ПодобратьЯчейку()`, `ПодобратьЯчейкуПоПаллету()`, `ОшибкиРазмещенияПаллетаВАдрес()`.

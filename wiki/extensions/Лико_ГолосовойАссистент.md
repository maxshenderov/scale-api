# Лико_ГолосовойАссистент

> Внешняя обработка 1С (`obrab/`): AI-ассистент с кнопкой «Спросить AI», инструментами для LLM и отображением ответов в ПолеHTML. Фаза 2.

## Что делает

Отправляет контекст формы (тип ассистента, инструменты, system_prompt) в Python-сервис `telegram_voice` (порт 8004), опрашивает `/latest` каждую секунду и отображает ответы LLM в ПолеHTML.

Поддерживает три типа ассистента:
- **Склад** — 3 инструмента: get_cell_sections, find_cell_for_placement, explain_cell_choice
- **Заказы** — без инструментов, информационный
- **General** — универсальный

## Форма

- `АссистентDisplayHTML` (ПолеHTML) — встроенный JS: опрос `/latest` раз в секунду, отправка контекста при нажатии кнопки
- `СпроситьАссистентаButton` — кнопка «Спросить AI» на командной панели
- `ТипАссистента` (Строка) — тип ассистента: "Склад" / "Заказы" / "General"
- `ЧатIDАссистента` (Число) — Telegram chat ID для привязки сессии
- `АссистентSessionID` (Строка) — UUID сессии

## Ключевые процедуры (Module.bsl)

- `ПриСозданииНаСервере()` — динамически создаёт реквизиты, кнопку, ПолеHTML с JS
- `СпроситьАссистента(Команда)` — клиент: собирает контекст → строит HTML с CTX в JS → страница отправляет POST /context
- `ПодготовитьКонтекстНаСервере()` — собирает JSON: session_id, chat_id, tools, system_prompt
- `ПолучитьКонтекстАссистента(ТипАссистента)` — возвращает system_prompt + tools для типа
- `ИнструментыСклада()` — 3 инструмента (function calling): get_cell_sections, find_cell_for_placement, explain_cell_choice
- `ПостроитьHTMLДляФормы(КонтекстJSON)` — генерирует HTML с JS: var CTX = '...' или null; sendCtx() при загрузке; pollLatest() каждую секунду
- `ПостроитьHTMLСКонтекстомНаСервере()` — обёртка над ПостроитьHTMLДляФормы()

## Поток данных

```
1. Открытие формы → HTML с CTX=null → только опрос /latest
2. Кнопка «Спросить AI» → сбор контекста → новый HTML с CTX=<JSON> → JS сразу POST /context
3. Telegram голосовое → STT → поиск сессии по chat_id → LLM с инструментами → ответ в _latest
4. JS опрашивает /latest каждую секунду → ответ отображается в ПолеHTML
```

## Особенности реализации

- **Никаких скрытых div и плейсхолдеров**: контекст вставляется прямо в JS-переменную `CTX` внутри `<script>`, и `sendCtx()` вызывается сразу при загрузке HTML
- **HTTP вместо WebSocket**: 1С опрашивает `/latest` через `XMLHttpRequest` + `setInterval` (1 сек)
- **Контекст пересобирается при каждом нажатии**: свежие данные формы каждый раз
- **Экранирование кавычек**: `СтрЗаменить(json, "'", "\'")` для безопасной вставки в JS

## Используемые модули

Не зависит от WebSocketСервер/WebSocketКлиент. Использует нативный механизм ПолеHTML + встроенный JS XMLHttpRequest.

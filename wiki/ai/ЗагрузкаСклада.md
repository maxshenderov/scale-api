# ЗагрузкаСклада

> Визуализация поперечного сечения стеллажа склада с пропорциональным отображением паллет, секций, ячеек и зон приёмки/отгрузки в HTML-поле формы.

## Что делает

Обработка отображает интерактивную HTML-визуализацию стеллажа:

1. **Карта стеллажей** — динамические кнопки для каждого стеллажа с цветовой индикацией загрузки (зелёный <50%, синий 50-89%, оранжевый 90-99%, красный 100%).
2. **Поперечное сечение** — покрашенное в масштабе изображение этажей, секций и ячеек стеллажа.
3. **Паллеты** — пропорциональные прямоугольники с номером, габаритами (ГxШxВ), статусом (занят/резерв), цветом.
4. **Свободное пространство** — расчёт расстояния от краёв паллета до границ секции в мм.
5. **Зоны приёмки/отгрузки** — отдельный ряд блоков с паллетами, привязанными к адресам хранения зоны.
6. **Навигация** — двойной клик по паллету/ячейке/зоне открывает карточку объекта через `zagsklad://` протокол.

## Ключевые процедуры

### Управление стеллажами
- `ЗаполнитьГруппуСтеллажейНаСервере()` — запрашивает `Справочник.Лико_Стеллажи` по выбранному складу, вычисляет процент загрузки каждого, создаёт динамические кнопки с цветом.
- `ВыбратьСтеллаж(Команда)` — обработчик клика по кнопке стеллажа: парсит `КодПолный` из имени элемента, вызывает `РендерЗагрузкиСтеллажаНаСервере()`.
- `НайтиСтеллажПоКодуНаСервере(КодПолный)` — поиск стеллажа по `КодПолный`.
- `УдалитьДинамическиеЭлементы()` — очистка ранее созданных кнопок и декораций.

### Расчёт загрузки
- `ПолучитьПроцентЗагрузкиСтеллажа(СтеллажСсылка)` — считает общее количество адресов через `Лико_СкладскиеСекции.КоличествоАдресов`, затем через `РегистрНакопления.Лико_ПаллетыВСекциях.Остатки` находит занятые адреса. Возвращает `Мин(занято/всего * 100, 100)`.
- `ЦветЗагрузкиПроцент(ПроцентЗагрузки)` — маппинг процента на цвет: зелёный/синий/оранжевый/красный.
- `ЦветСтеллажаИзДопНастроек(ДопНастройкиХранилище)` — извлекает кастомный цвет из `ДопНастройки` стеллажа (хранилище -> структура -> `ЦветСтеллажа`).

### Рендеринг HTML
- `РендерЗагрузкиСтеллажаНаСервере(СтеллажСсылка, ПроцентЗагрузки)` — главная процедура (~650 строк HTML-генерации):
  1. Данные стеллажа (наименование, код).
  2. Этажи из `СтеллажОбъект.Этажи` с кэшированием типоразмеров.
  3. Секции из `Лико_СкладскиеСекции` с группировкой по этажам (сортировка: этаж DESC, место ASC).
  4. Паллеты из `РегистрНакопления.Лико_ПаллетыВСекциях.Остатки` (включая заблокированные/зарезервированные).
  5. Типоразмеры паллет из `РегистрСведений.Лико_ПараметрыПаллет.СрезПоследних`.
  6. HTML: масштабируемый контейнер, сетка секций с ячейками, паллеты с абсолютным позиционированием, двойной клик -> `openItem()`.
  7. Зоны приёмки/отгрузки из `ЗоныПриемкиОтгрузки` с пакетным запросом остатков.
  8. Легенда, правила размещения.

### Навигация
- `htmlПриНажатии(Элемент, ДанныеСобытия, СтандартнаяОбработка)` — обрабатывает `zagsklad://type/guid` из кликов в HTML, открывает форму объекта (`ФормаОбъекта` для паллет/ячеек).
- `ПолучитьСсылкуПоГУИД(ТипОбъекта, ГУИДСтрока)` — конвертирует GUID-строку в ссылку (`Лико_Паллеты2_0` для "pallet", `СкладскиеЯчейки` для "cell").

### Вспомогательные
- `ЦветВHex(Цвет)` — конвертирует 1С-цвет в CSS `#RRGGBB`.
- `ФорматЧислоHTML(Число)` — форматирует число с точкой как разделителем дробной части для CSS.

### Масштаб
- Коэффициент `МасштабМм = 0.05` (1мм = 0.05px, стеллаж 2000мм -> 100px на экране).
- В HTML встроен JavaScript-слайдер масштаба (20-300%).

## Используемые объекты
- `Справочник.Лико_Стеллажи` — стеллажи с этажами и зонами.
- `Справочник.Лико_СкладскиеСекции` — секции с адресами (Адрес1/2/3).
- `Справочник.Лико_Паллеты2_0` — паллеты.
- `Справочник.Лико_ТипоразмерыПаллет` — габариты паллет.
- `РегистрНакопления.Лико_ПаллетыВСекциях` — остатки паллет в секциях.
- `РегистрСведений.Лико_ПараметрыПаллет` — параметры паллет (типоразмер).

# Handoff — Общий трекер задач

> Любой агент (Claude Code / Cline) читает, берёт, обновляет, перехватывает.
> Статусы: `new` → `wip` ↔ `paused` → `review` → `done`

---

## Статусы

| Статус | Значение | Кто может взять |
|--------|----------|-----------------|
| `new` | Задача создана, никто не начал | **Любой** |
| `wip` | В работе | Тот кто начал |
| `paused` | Приостановлен, можно перехватить | **Любой** |
| `review` | Готово, жду проверки вторым агентом | Второй агент |
| `done` | Завершено | — |

**Ключевое:** `paused` = «забирай». `new` = «никто не начал, бери смело».

---

## Формат задачи

```markdown
### #ID | ДАТА | started by АГЕНТ | СТАТУС

**Задача:** Краткое описание

**Контекст:**
- Wiki: [[Страница1]], [[Страница2]]
- Файлы: `path/to/file.bsl#L10950` (что уже изменено)
- Следующий: `path/to/next.xml` (куда идти дальше, строка N)
- Паттерн: `ИмяПроцедуры()` в [[Модуль]]
- Зависимости: [[Регистр1]], [[Справочник2]]

**Последнее:** что сделано последним
**Блокировка:** `файл` (агент, до HH:MM)

**История:**
- ДД.ММ ГГ:ГГ (Агент) — действие
```

### Правила заполнения контекста

- **Файлы** — с номерами строк если известны: `Module.bsl#L10950`
- **Следующий** — конкретный файл и место: `Form.xml#L342`
- **Паттерн** — ссылка на wiki-страницу с примером кода
- **Блокировка** — мягкий маркер «я здесь, не наступи» (файл + агент + время)
- **История** — для сложных задач, где контекст меняется

### Как обновлять контекст

- **Уровень 1 — wip (продолжаю):** обновляю только «Последнее» и «Историю». Коротко.
- **Уровень 2 — paused (приостановил):** пишу развёрнуто: что сделано, где остановился, какой файл и строка следующие. Это точка перехвата.
- **Уровень 3 — review (завершил часть):** пишу «Следующий: [агент] — [действие]». Второй агент видит и делает.

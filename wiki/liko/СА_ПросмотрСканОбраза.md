# СА_ПросмотрСканОбраза

> Обработка просмотра скан-образов документов — BSL-код формы практически весь закомментирован.

## Что делает / Доработки
Расширяет типовую обработку просмотра скан-образов. В текущем состоянии:
- Основной BSL модуль формы содержит только закомментированный код поиска связанных документов
- Функциональность просмотра сканов реализована через XML-метаданные формы (не в BSL)
- Закомментирована логика `НайтиСвязанныеДокументыНаСервереПоРеализации` — поиск счетов-фактур по реализации

## Ключевые процедуры
- `Лико_НайтиСвязанныеДокументыНаСервере()` — закомментировано: поиск связанных документов по заказу клиента и реализации
- `Лико_НайтиСвязанныеДокументыНаСервереПоРеализации()` — закомментировано: запрос `СчетФактураВыданный` по основанию

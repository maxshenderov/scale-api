# ЛикоОстаткиТоваров

> Отчет по остаткам товаров (аналог типового) с подстановкой коэффициентов упаковки, веса и объема. Имеет несколько вариантов форм отчета.

## Что делает

Расширяет типовой отчет «Остатки товаров». Код идентичен `Лико_ТоварыВЯчейках`:
- Регистрирует `ПриСозданииНаСервере` для установки отборов по командам
- В `ПриКомпоновкеРезультата` подменяет макросы упаковки/веса/объема в СКД
- Включает отбор по сегменту номенклатуры
- Автоматически подставляет единицы измерения из констант

## Ключевые процедуры

- `ОпределитьНастройкиФормы()` — регистрирует обработчик `ПриСозданииНаСервере`
- `ПриСозданииНаСервере()` — установка отбора по параметру команды (ячейка/номенклатура/область хранения/складская группа)
- `ПриКомпоновкеРезультата()` — подстановка `&ТекстЗапросаКоэффициентУпаковки`, `&ТекстЗапросаОбъем`, `&ТекстЗапросаВес` через `Справочники.УпаковкиЕдиницыИзмерения`
- `УстановитьЗаголовкиПолей()` — замена плейсхолдеров `%ЕдиницаВеса%` / `%ЕдиницаОбъема%` на значения констант `ЕдиницаИзмеренияВеса` / `ЕдиницаИзмеренияОбъема`

## Формы отчета

Имеет множество вариантов форм: `ФормаОтчета`, `ФормаНастроекОтчета`, `ФормаОтчета1`..`ФормаОтчета5` (включая подварианты `4_0`, `4_1`).

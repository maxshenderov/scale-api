# Лико_Прайс

> Документ прайс-листа на готовую продукцию. При проведении записывает цены в регистры сведений Лико_ПрайсыГП и Лико_ЦеныГП. Поддерживает два режима: прайс на конкретную номенклатуру и прайс на размерную сетку (ширина x высота этикетки).

## Что делает

Фиксирует цены на продукцию с привязкой к типу этикетки, количеству и валюте. В зависимости от реквизита `ТипГПДляПрайса` запись ведется либо по конкретной продукции, либо по размерным параметрам (Ширина/Высота). Две табличные части: `НоменклатураПрайса` (для прайсов по списку номенклатуры) и `Товары` (для прайсов по конкретным позициям).

## Ключевые процедуры

### ObjectModule

- `ОбработкаПроведения()` -- формирует движения по регистрам:
  - `Лико_ПрайсыГП` -- факт наличия прайса для продукции (связь Продукция-Прайс)
  - `Лико_ЦеныГП` -- детальные цены: продукция или размеры, тип этикетки, количество, цена, валюта

### Форма выбора

- `ПриОткрытииНаСервере()` / `ПриСозданииНаСервере()` -- динамическая настройка отбора по ширине и высоте для подбора соответствующей номенклатуры.

## Режимы прайса

Перечисление `Лико_ТипыГПДляПрайса`:
- `РазмерыЭтикетки` -- прайс по габаритам (Ширина x Высота), без привязки к конкретной номенклатуре
- Другие значения -- прайс по конкретной продукции

## Используемые модули

Стандартная процедура проведения без внешних модулей.

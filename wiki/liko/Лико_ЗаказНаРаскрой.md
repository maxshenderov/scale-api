# Лико_ЗаказНаРаскрой

> Заказ на раскрой (продольную резку) материала. Рассчитывает плановое время выполнения на основе параметров правил раскроя. Создаёт и управляет номенклатурой незавершённого производства. Движения в регистре `Лико_РаскройМатериаловПланФакт`.

## Что делает

- Два вида операций: Раскрой и Активация (через `ВидыРаботСотрудников`)
- Рассчитывает время резки по формуле с параметрами правила (`Лико_ПараметрыРасчетаРаскрояМатериалов`):
  ПЗВ + КоличествоУпаковок/Скорость + ВремяСъёма/средняяДлинаРолика + ВремяРолика + ВремяЮмбы + ВремяНастройкиНожей
- Автоматически создаёт номенклатуру незавершённого производства при необходимости
- Создаётся из ЗаказКлиента (через `СоздатьПоЗаказуКлиента`)
- При проведении: приход в регистр `Лико_РаскройМатериаловПланФакт`

## Ключевые процедуры (ObjectModule)

- `ПередЗаписью()` — рассчитывает время выполнения (ВремяВыполненияПлан, ВремяРаботыПлан, ВремяНастройкиПлан), норматив резки
- `ОбработкаПроведения()` — формирует движение прихода в `Лико_РаскройМатериаловПланФакт`
- `ИнициализироватьДокумент()` — заполняет начальные реквизиты (Дата, Ответственный, Автор)
- `ПолучитьРаскройСтрокой()` — формирует строковое представление раскроя (Нарезка-КоличествоРоликов)
- `ОбработкаПроверкиЗаполнения()` — исключает НоменклатураВыпуск для не-Активации

## Ключевые процедуры (ManagerModule)

- `СоздатьПоЗаказуКлиента(ЗаказКлиента, РабочийЦентр, Метраж)` — создаёт/находит и заполняет заказ на раскрой
- `ЗаполнитьСтруктуруПоЗаказуКлиента()` — формирует структуру параметров из регистра `Лико_ПараметрыПроизводстваЗаказа`
- `ПолучитьНоменклатуруПолуфабриката(ЗаказКлиента)` — ищет или создаёт номенклатуру НЗП с характеристикой
- `ПолучитьДанныеЗаказуКлиента(ЗаказКлиента)` — получает данные резки из `Лико_ПараметрыПроизводстваЗаказа`
- `РасчитатьВремяВыполнения()` — расчёт времени по формуле правила
- `ПолучитьСтатистикуПоНарезке(Организация, Номенклатура, КолМес)` — статистика расхода/остатка/потребности по нарезкам за N месяцев
- `ПЗВ()`, `ПЗВПереворот()`, `СредняяДлинаРоика()`, `ФорматироватьЧислоКакВремя()` — вспомогательные

# Лико_ЗакрытиеМесяца

> Регламентный документ закрытия месяца. Списывает материальные ценности в эксплуатации (спецоснастку), у которых истекла дата завершения эксплуатации.

## Что делает

- При проведении формирует бухгалтерские движения по кредиту счетов `Хозрасчетный`
- Анализирует остатки по счету `МатериальныеЦенностиВЭксплуатации` (субсчет `СпецоснасткаВЭксплуатацииВспомогательный`)
- Списывает позиции, у которых `ДатаЗавершенияЭксплуатации` < дата документа (начало месяца)
- Для спецоснастки не заполняет субконто `РаботникиОрганизаций`

## Ключевые процедуры

- `ОбработкаПроведения(Отказ, Режим)` — единственная процедура: запрос остатков по бухгалтерскому регистру, формирование кредитовых движений

## Реквизиты

- `Организация` — фильтр по организации
- `Дата` — на начало месяца от этой даты проверяется истечение эксплуатации

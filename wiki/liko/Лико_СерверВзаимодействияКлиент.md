# Лико_СерверВзаимодействияКлиент

> Клиентский модуль системы взаимодействия — подключение и отключение мобильных устройств через СистемуВзаимодействия 1С.

## Что делает
Управляет подключением мобильных устройств к 1С через типовую СистемуВзаимодействия: регистрирует обсуждение с ключом `ERP_mobile`, подключает обработчик новых сообщений, обрабатывает отключение. Используется для мобильных приложений (сканеры, ТСД), которые обмениваются сообщениями с 1С.

## Ключевые процедуры
- `ПодключениеМобильныхУстройств()` — проверяет регистрацию ИБ в СистемеВзаимодействия, создаёт обсуждение через Лико_СерверВзаимодействияСервер.СоздатьОбсуждение(), запускает обработчик новых сообщений
- `ОтключениеМобильныхУстройств()` — отключает обработчик сообщений для обсуждения ERP_mobile

## Используется в
- Формы, работающие с мобильными устройствами (ТСД, сканеры)
- При начале сеанса для подключения мобильного обмена

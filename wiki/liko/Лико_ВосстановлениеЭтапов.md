# Лико_ВосстановлениеЭтапов

> Обработка-обёртка для восстановления этапов производственного распоряжения из интерфейса.

## Что делает

Вызывает серверную процедуру `Лико_ОбщегоНазначенияСервер.ВосстановлениеЭтапов()` для переданного распоряжения. Вся логика восстановления этапов находится в общем модуле — обработка нужна только для вызова из UI (команда на форме).

## Ключевые процедуры

- `ВосстановитьЭтапы(Команда)` — клиентский обработчик команды, получает `Объект.Распоряжение` и вызывает сервер.
- `ВосстановитьЭтапыНаСервере(Распоряжение)` — серверный метод, делегирует в `Лико_ОбщегоНазначенияСервер.ВосстановлениеЭтапов(Распоряжение)`.

# Лико_WMS_Сервер

> REST API для WMS — управление складскими операциями, размещение и поиск паллет.

## Что делает

Общий модуль 1С, экспортирующий 10 ProcName-функций для веб-приложения WMS:
- Управление складами и топологией (стеллажи, этажи, секции)
- Поиск мест размещения паллет на основе 13 правил приоритизации
- Получение текущей занятости адресов
- Перемещение паллет между ячейками
- Health-check для веб-приложения

## Ключевые процедуры

- `WMS_CheckConnection()` — проверка доступности, версия, timestamp
- `WMS_GetWarehouses()` — список складов с WMS-заданиями
- `WMS_GetRacks()` — полная топология стеллажей (статичная, кэшируется)
- `WMS_GetOccupancy()` — текущее состояние всех секций (какие паллеты где стоят)
- `WMS_GetFloor()` — паллеты в зонах приёмки/отгрузки и на полу
- `WMS_FindCell()` — обёртка над `ПодобратьЯчейку` (все варианты мест)
- `WMS_ValidatePlacement()` — проверка возможности размещения паллета в ячейке
- `WMS_MovePallet()` — одиночное перемещение паллета
- `WMS_ExportSnapshot()` — полный снимок состояния склада для синхронизации
- `WMS_ExecutePlacements()` — пакетное выполнение плана размещения (массив placement-ов)

## Вспомогательные процедуры

- `HttpВернутьОшибку_WMS()` — единообразный формат ошибок
- `СсылкаПоСтрокеGUID()` — резолв GUID → ссылка на справочник
- `ЦветСтеллажа()` — фиксированная палитра цветов для визуализации
- `СобратьАдрес()` — формирование структуры адреса с паллетом
- `ЗанятостьАдреса()` — бинарный флаг (паллет есть / нет)
- `СобратьТопологиюСклада()` — построение дерева стеллажей → этажи → типоразмеры
- `СобратьЗанятостьСекций()` — запрос всех адресов и паллет в них
- `СобратьПаллетыНаПолу()` — поиск паллет в зонах без привязки к стеллажам

## Связь с ЗаказКлиента

Модуль не связан с ЗаказКлиента напрямую — это инфраструктурный сервис для управления физическим складом.

## Используемые модули

- [[Лико_HTTP_Сервер]] — HTTP-утилиты, JSON, сериализация
- `Справочники.Лико_Стеллажи` — топология
- `Справочники.Лико_СкладскиеСекции` — ячейки, приоритизация поиска
- `Справочники.Лико_Паллеты2_0` — справочник паллет
- `РегистрСведений.Лико_ПараметрыПаллет` — габариты паллет
- `РегистрНакопления.Лико_ПаллетыВСекциях` — текущее размещение

## Интеграция

Вызывается из [[Liko_Rest]] как `ProcName` по схеме `POST /wms/{procName}`.

Ответы — JSON с единообразной структурой:
```json
{ "ok": true, "data": {...} }
{ "ok": false, "error": { "code": "...", "message": "..." } }
```

# ЛикоЗаказИнфо

> Обработка-помощник: показывает детальную информацию по заказу для конкретного рабочего центра — цвета, виды работ, параметры штампа, расчётные метражи и время.

## Что делает
Открывается из формы заказа или из интерфейса планирования. Отображает состав заказа в разрезе выбранного рабочего центра и номера варианта:
- Цвета (из ТЧ `ЗаказКлиента.Цвета`) с типом краски, процентом заливки, грамматурой
- Виды работ (из ТЧ `ЗаказКлиента.ВидыРабот`) с машинами, оснасткой, клеем
- Этикетки (из ТЧ `ЗаказКлиента.Товары`) с количеством и номенклатурой
- Параметры штампа (из `СпецификацииНоменклатуры.ПараметрыШтампа`): Z, шаг печати, длина/ширина этикетки
- Расчётные параметры из регистра `Лико_ПараметрыПроизводстваЗаказа`: метры на настройку, метры на брак, время печати, скорость

## Ключевые процедуры
- `ПриСозданииНаСервере()` — принимает параметры `РабочийЦентр` и `Заказ`, получает данные через `ДанныеПоРЦ()`, заполняет цвета/работы/этикетки/параметры штампа
- `ДанныеПоРЦ(РабочийЦентр, Заказ)` — запрос к `Лико_ПараметрыПроизводстваЗаказа` + `ПооперационноеРасписание2_2`, возвращает ТЗ с номером заказа, контрагентом, датами, временем изготовления
- `ПоказатьЦветаРаботы()` — три запроса: цвета, виды работ с машинами, этикетки и параметры штампа
- `ЗаполнитьРасчетныеПараметры()` — заполняет Z, шаг печати, оснастку, нарезку, метры/время из `Лико_ПараметрыПроизводстваЗаказа`
- `НомерВариантаПриИзменении()` — при смене варианта перезаполняет цвета и расчётные параметры

## Связь с ЗаказКлиента
Использует ТЧ `ЗаказКлиента.Цвета`, `ЗаказКлиента.ВидыРабот`, `ЗаказКлиента.Товары`. Читает `СпецификацииНоменклатуры.ПараметрыШтампа`. Основной источник расчётных данных — регистр `Лико_ПараметрыПроизводстваЗаказа`.

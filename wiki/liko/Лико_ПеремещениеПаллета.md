# Лико_ПеремещениеПаллета

> Перемещение товаров на паллетах между ячейками и складами ГП. Автоматически создает цепочку типовых документов складского учета.

## Что делает

Основной документ для перемещения паллет с ГП между ячейками (внутри одного склада) или между складами. При проведении:

1. Формирует движения по регистру `Лико_АдресноеХранение` (приход/расход по ячейкам).
2. Добавляет записи в `Лико_ЭтапыЗаказа` (СкладГП / Растарка).
3. Отражает движения в `Лико_ПланированиеУпаковки`.
4. Создаёт типовые документы:
   - **В пределах одного склада:** `ОтборРазмещениеТоваров` (Перемещение)
   - **Между складами:** `ПеремещениеТоваров` + `РасходныйОрдер` (если ордерная схема) + `ОтборРазмещениеТоваров` (отбор) + `ПриходныйОрдер` + `ОтборРазмещениеТоваров` (размещение)

## Табличные части

- `Содержимое` -- серии товаров на паллете
- `ЗаказыНаРастарку` -- строки для планирования растарки (исходные и НЕисходные)

## Реквизиты

- `Паллет` -- перемещаемый паллет
- `ЯчейкаОтправитель`, `СкладОтправитель` -- откуда
- `ЯчейкаПолучатель`, `СкладПолучатель` -- куда
- `ПричинаРастарки` -- причина, если ячейка-получатель = ячейка растарки
- `Площадка`, `Организация`, `Подразделение` -- орг. реквизиты

## Ключевые процедуры

- `ПередЗаписью()` -- множество проверок: запрет будущих дат, контроль типов складов (только ГП), запрет перемещения между складами ответственного хранения, проверка причины растарки, запрет смены паллета
- `ОбработкаПроведения()` -- движения по Лико_АдресноеХранение и Лико_ЭтапыЗаказа, вызов `СоздатьТиповыеДокументы()`
- `ПаллетПриИзменении()` -- авто-заполнение `Содержимое` из текущего положения паллета
- `ЗаполнитьТаблицуРастарки()` -- группировка содержимого по характеристикам для растарки
- `ПроверитьПоАдресномуХранению()` -- сверка содержимого документа с регистром Лико_АдресноеХранение
- `СоздатьТиповыеДокументы()` -- полная цепочка складских документов

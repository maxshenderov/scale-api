# ЯССМ_ОбъектыНоменклатуры

> Справочник объектов номенклатуры в подсистеме ЯССМ. Связывает номенклатуру с номером поставки и партнером. Автонумерация поставок, синхронизация партнера из резерва серий.

## Что делает / Доработки
- **Учет объектов номенклатуры** — каждая запись привязана к номенклатуре и имеет уникальный номер поставки.
- **Расширение `ObjectModule`**: переопределена функция `ОпределитьПоследнийНомерПоставкиДляНоменклатуры()` — возвращает максимальный номер поставки для данной номенклатуры (или 0 для первого объекта).
- **Расширение `ManagerModule`**: переопределена процедура `УстановитьПартнера()` — синхронизирует реквизит `Партнер` объектов номенклатуры из регистра `Лико_РезервСерий`. Если в резерве серий есть партнер, он проставляется в объекте номенклатуры (запись через обмен `ОбменДанными.Загрузка = Истина`).
- **Расширение формы элемента**: подключена подсистема `РаботаСФайлами` — к объекту можно прикреплять файлы прямо из формы элемента.

## Ключевые процедуры
- `Лико_ОпределитьПоследнийНомерПоставкиДляНоменклатуры(Номенклатура)` — &Вместо штатной, запрос к справочнику для поиска максимального номера поставки
- `Лико_УстановитьПартнера(ОбъектыНоменклатуры)` — &Вместо штатной, синхронизация партнера из регистра `Лико_РезервСерий`

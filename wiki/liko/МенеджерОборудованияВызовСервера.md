# МенеджерОборудованияВызовСервера

> Переопределение поиска рабочих мест: особая логика для компьютера `rd-sklad` — сброс MAC-адреса.

## Что делает
Расширяет типовую функцию `НайтиРабочиеМестаПоИдентификатору` (аннотация `&Вместо`). Добавляет специальную обработку для компьютера `rd-sklad`: при совпадении имени компьютера очищает MAC-адрес, чтобы поиск рабочего места шёл только по имени. Также исключает `rd-sklad` из поиска рабочих мест по одному только имени компьютера (приоритет 4).

## Ключевые процедуры
- `Лико_НайтиРабочиеМестаПоИдентификатору(ИдентификаторКлиента, ИмяКомпьютера, MACАдрес)` — переопределение типовой функции. Если ИмяКомпьютера = `"rd-sklad"`, обнуляет MAC-адрес и исключает из поиска только по имени.

## Используется в
- Определение рабочего места при входе пользователя (менеджер оборудования)
- Терминал склада на `rd-sklad`

# Лико_ВозвратТоваров

> Возврат товаров -- при проведении автоматически создаёт документ `ПрочееОприходованиеТоваров` с фильтрацией серий по остаткам.

## Что делает
Расширяет типовой документ возврата товаров. При проведении автоматически создаёт/редактирует `ПрочееОприходованиеТоваров` для возврата на склад. Фильтрует серии -- удаляет позиции, у которых нет остатков по бухгалтерскому учёту.

## Ключевые процедуры

### ObjectModule
- `Лико_Лико_СоздатьРедактироватьПрочееОприходование()` -- `&Вместо`. При проведении находит или создаёт `ПрочееОприходованиеТоваров`, очищает товары, заполняет из табличной части возврата (только позиции с остатками серий), записывает и проводит. Использует `Лико_ОбщегоНазначенияСервер.НайтиДокумент()`.

### ManagerModule
- `Лико_ОстаткиСерийПоБух()` -- `&Вместо`. Запрашивает остатки серий в регистре `ТоварыНаСкладах` по массиву серий -- возвращает список серий с остатками.
- `Лико_ЗарегистрироватьУчетныеМеханизмы()` -- регистрирует механизм `Лико_Склад`.

## Связь с ЗаказКлиента
Возврат товаров может быть связан с конкретным заказом клиента через типовой реквизит `ЗаказПокупателя`.

## Табличные части
- **Товары** -- возвращаемые позиции (номенклатура, серия, количество, цена)

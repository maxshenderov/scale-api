# Лико_ОткрытьТиповуюФормуОбъекта

> Общая команда: открывает типовую (не кастомную) форму документа для переданного объекта.

## Что делает

Проверяет тип переданного параметра (`ПараметрКоманды`). Для `ДокументСсылка.ЗаказКлиента` открывает типовую форму `Документ.ЗаказКлиента.Форма.ФормаДокумента` (в отличие от [[Лико_ФормаСписка]] — кастомной формы).

## Ключевые процедуры

- `ОбработкаКоманды()` — проверка типа ссылки, открытие типовой формы с параметром `Ключ`

## Связи [[...]]

- [[ЗаказКлиента]] — типовой документ, для которого открывается форма
- [[Лико_ФормаСписка]] — кастомная форма списка ЗаказКлиента

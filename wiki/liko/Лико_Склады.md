# Лико_Склады

> Центральный модуль складских операций: остатки по ячейкам, параметры проведения Лико_-документов, закрытие заказов поставщикам, графики оплаты.

## Что делает
Серверный модуль, обеспечивающий складскую логику Лико. Содержит запрос остатков по регистру ТоварыВЯчейках с поддержкой фильтра по видам номенклатуры (из параметров рабочего места). Предоставляет единую точку настройки параметров проведения для всех Лико_-документов — добавляет кастомные регистры накопления в зависимости от типа документа. Управляет закрытием заказов поставщикам: проверяет остатки, делает сторно-движения, обновляет состояния. Заполняет этапы графика оплаты в документах.

## Ключевые процедуры
- `ОстаткиПоСкладу(РабочийЦентрЯчейкаМассив, НаДату, СписокВидовНОменклатуры)` — запрос остатков ТоварыВЯчейках по ячейкам с фильтром. Принимает РабочийЦентр, СкладскуюЯчейку или Массив.
- `ПолучитьФильтрПоВидамНоменклатуры()` — получает настройки фильтра по видам номенклатуры из параметров рабочего места.
- `ПараметрыДляПроведенияДокумента(Документ, Свойства)` — формирует список подчинённых регистров для проведения Лико_-документов. Обрабатывает: Лико_БланкЭтапа, Лико_ПодготовкаМатериалов, ЭтапПроизводства2_2, ПриобретениеТоваровУслуг, Лико_ПередачаТоваров, ЛикоРаспределениеРасходовПоЭтапам, Лико_ВыполненныеРаботы, ВозвратТоваровПоставщику и др.
- `ОтразитьДвижения(ТаблицыДляДвижений, Движения, Отказ)` — отражает движения по всем Лико_-регистрам через ПроведениеДокументов.
- `ТекстыЗапросовКонтрольДатыЗапретаПоТаблицеИзменений(Запрос)` — заглушка для механизма контроля даты запрета.
- `ТекстыЗапросовСторнирования(МетаданныеДокумента)` — заглушка для механизма сторнирования.
- `ЗакрытьЗаказНаСервере(ЗаказПоставщику)` — закрывает заказ поставщику: сторнирует ТоварыКПоступлению и ЗаказыПоставщикам, обновляет СостоянияЗаказовПоставщикам.
- `ПопыткаЗакрытияЗаказаПоставщику(ЗаказПоставщику)` — проверяет остатки КОформлению и закрывает заказ, если все оформлено.
- `ЗаполнитьЭтапыГрафикаОплаты(ДокументОбъект, Заказ, Сумма, ВариантОплаты)` — добавляет этап графика оплаты (КредитПослеОтгрузки, 100%).
- `ПроверитьСостояниеЗаказаПоставщику(Заказы)` — проверяет выполнение заказов поставщикам (план/факт), переводит в состояние ОжидаетсяОплатаПослеПоступления если остаток < 7%.
- `ЗаписатьСправочникВРежимеОбмена(МассивОбъектов)` — записывает справочники с флагом ОбменДанными.Загрузка.

## Используется в
- Проведение всех Лико_-документов
- Закрытие заказов поставщикам
- Формирование остатков по складам/ячейкам

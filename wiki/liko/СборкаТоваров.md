# СборкаТоваров

> Типовой документ сборки/разборки товаров. Доработка — исключение регистров контроля для складов типа СИМ.

## Что делает / Доработки
- **Сборка и разборка товаров** — стандартная ERP-операция изменения состава номенклатуры.
- **Расширение `ObjectModule`**: при проведении документа для складов с типом `Лико_ТипСклада.СИМ` из списка контролируемых регистров исключаются `ТоварыКОтгрузке`, `ТоварыНаСкладах`, `СвободныеОстатки`. Это нужно чтобы документы сборки не блокировались контролем остатков на складах СИМ (склад исходных материалов).

## Ключевые процедуры
- `Лико_СформироватьСписокРегистровДляКонтроля()` — &После штатной процедуры, корректирует массив регистров для контроля проведения, удаляя из него регистры товарных остатков для складов СИМ.

# РеализацияТоваровУслуг (типовой, доработан)

> Исключение регистра СвободныеОстатки из контроля для складов СИМ (аналогично РасходныйОрдерНаТовары).

## Доработки

- **`Лико_СформироватьСписокРегистровДляКонтроля`** (`&После("СформироватьСписокРегистровДляКонтроля")`) -- для складов с типом `СИМ` удаляет регистр `СвободныеОстатки` из массива контролируемых регистров. Отключает проверку свободных остатков при проведении реализации для складов СИМ.

## Ключевые процедуры

- `Лико_СформироватьСписокРегистровДляКонтроля()` -- исключение СвободныеОстатки для складов СИМ.

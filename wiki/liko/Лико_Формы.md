# Лико_Формы

> Справочник печатных форм (клише, пластин) — хранит информацию о каждой форме: к какому заказу относится, на каком рабочем центре, с какой краской, параметры полимера. Форма подбора использует историю движений форм для фильтрации по расположению.

## Что хранит

Учет печатных форм на всех этапах жизненного цикла: создание, привязка к заказу, перемещение между рабочими центрами, списание или утилизация.

**Реквизиты:**
- `ЗаказТех`, `Заказ`, `ЗаказПоРельсе` (Документ.ЗаказКлиента) — привязка к заказам
- `Контрагент` (Справочник.Контрагенты) — контрагент заказа
- `Организация` (Справочник.Организации) — организация
- `Площадка` (Справочник.Лико_Площадки) — площадка
- `ВидПечати` (Перечисление.Лико_ВидыПечати) — флексо, офсет, глубокая и т.д.
- `ТипКраски` (Справочник.ЦеновыеГруппы) — тип краски
- `Название` (Справочник.Лико_Пантоны/Строка) — название цвета
- `ТипЦвета` (Справочник.Лико_ТипыЦвета) — тип цвета (C, M, Y, K, Pmc и т.д.)
- `ВидСекции` (Справочник.Лико_ВидыСекций) — вид секции
- `Номенклатура` (Справочник.Номенклатура) — связанная номенклатура
- `РабочийЦентр` (Справочник.РабочиеЦентры) — текущий РЦ
- `ФормаСписана` (Булево) — признак списания
- `ДействияСФормой` (Перечисление.Лико_ДействияСФормой) — Хранить / Утилизировать
- `Пересвет` (Булево) — признак пересвета
- Параметры полимера: `ВидПолимера`, `ТолщинаПолимера`, `ДистортФлексо`
- `Грамматура`, `ПроцентЗаливки`, `ШагПечати`, `Ширина`, `Длина`, `Сплошная` (Булево)
- `ТрафаретнаяСетка` (Справочник.Лико_ТрафаретныеСетки)
- `УголПоворотаРастра` (Справочник.Лико_УглыПоворотаРастра)
- `КодЛинкс` (Строка)

**Табличная часть «Этикетки»:**
- `Номенклатура` (Справочник.Номенклатура) — этикетки, использующие эту форму

## Ключевые процедуры

- `Лико_ПриСозданииНаСервереПеред()` (ФормаПодбора, сервер) — формирует сложный запрос для формы подбора. Основной источник: `РегистрСведений.Лико_ИсторияДвиженийФорм.СрезПоследних`. Поддерживает отборы:
  - По коду формы (`КодФормыОтбор`, с ПОДОБНО)
  - По номенклатуре этикеток (`НоменклатураОтбор`)
  - По контрагенту (`КонтрагентОтбор`)
  - По расположению (РЦ или конверт)
  - По заказу клиента (`ЕстьЗаказКлиента`)
  - По виду печати, организации
  - Приоритетность: формы с кодом, заданным в `КодФормыОтборДляПриоритета`, поднимаются выше
  - JOIN с историей в конвертах (для фильтра по расположению в конверте)
  - Вычисляемое поле `Выбрана` — отмечены ли формы в списке

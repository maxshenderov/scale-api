# Liko_WebService

> Веб-сервис для получения свойств пользователей ИБ через HTTP (REST API).

## Что делает
Предоставляет HTTP-эндпоинты для получения информации о пользователях информационной базы: сопоставление имени пользователя с его свойствами (ПользовательОС), а также GUID ссылки. Поддерживает вывод в JSON (основной) и XDTO форматах. Пространство имён: `http://okil-sato.ru`.

## Ключевые процедуры
- `ПолучитьСвойстваПользователяИБ()` — возвращает XDTO-таблицу GridUserProporties со свойствами пользователей (UserID, UserOS). Фильтр по конкретному UserID опционален.
- `GetUserPropertiesHttp()` — HTTP-вариант: запрашивает всех пользователей, формирует JSON-массив с Name, Ref, UserOS, Guid и возвращает HTTPСервисОтвет(200) с Content-type: application/json.

## Используется в
- HTTP-сервисы 1С для интеграции с внешними системами
- REST API контура okil-sato.ru

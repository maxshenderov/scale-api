# ПланированиеСервер

> Серверные процедуры управления планом работ БЭ (Лико_ПланРаботБЭ): формирование операций, ранжирование, отображение.

## Что делает
Модуль отвечает за серверную логику работы с планом производственных операций резки (БЭ).
Формирует операции в регистре Лико_ПланРаботБЭ, ранжирует заказы по приоритету внутри рабочих центров,
рассчитывает даты начала/окончания, время выполнения и остатки.
Генерирует табличные массивы для отображения плана на управляемой форме и поддерживает асинхронную отправку через WebSocket.

## Ключевые процедуры
- `СформироватьОперацию()` — создаёт операцию для заказа в плане: записывает в регистр и ранжирует
- `ЗаписатьВПлан()` — записывает заказ в регистр Лико_ПланРаботБЭ с транзакционной сменой статуса
- `РанжироватьЗаказыПоПриоритету()` — пересчитывает приоритеты заказов внутри рабочих центров, рассчитывает даты начала/окончания, учитывает начало первого проката печати
- `СформироватьМассивТЗСервер()` — формирует массив структур (рабочий центр -> ТаблицаЗначений) для формы плана
- `РендерЭлементовСервер()` — динамически создаёт элементы формы (таблицы) для отображения плана, настраивает drag-and-drop
- `ЕстьЗаказыВПлане()` / `ЕстьЗаказыВПланеСервер()` — проверяет наличие заказов в плане по массиву ссылок
- `РЦНайтиПоНомеруСервер()` — ищет рабочий центр по порядковому номеру
- `ПроверкаИзмененияПланаСервер()` — сравнивает текущий план с переданным массивом структур через хеш (CRC32)
- `ПолучитьХешОбъекта()` — сериализует объект в XML и вычисляет CRC32 хеш
- `СформироватьМассивТЗСерверАсинх()` — асинхронная версия: ранжирует, формирует ТЗ и отправляет через WebSocket
- `ФорматироватьЧислоКакВремя()` — конвертирует десятичное число в формат ЧЧ.ММ
- `УдалитьПодчиненыеЭлеметы()` — рекурсивно удаляет подчинённые элементы формы
- `СформироватьОперацию140323()` и `РанжироватьЗаказыПоПриоритету140323()` — старые версии (14.03.2023) без связи с ПооперационноеРасписание2_2

## Используется в
- Форма плана БЭ (управляемая форма)
- Интеграция с WebSocket для real-time обновления плана

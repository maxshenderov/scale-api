# Лико_ЗаявкаНаДизайн

> Заявка на дизайн этикетки. Заполняется из ЗаказКлиента. ManagerModule генерирует текст скрипта дизайна (15-строчный формат) с параметрами этикетки, штампа, намотки для передачи во внешние дизайнерские системы.

## Что делает

- Заполняется из ЗаказКлиента: ВидЗаказа, Комментарий, Партнер, Организация, Менеджер, Площадка; копирует Товары
- При создании не из заказа: заполняет организацию по доп. реквизиту пользователя

## Ключевые процедуры

- `ОбработкаЗаполнения()` — из Структуры (ЗаказКлиента) или инициализация по текущему пользователю

## Ключевые процедуры (ManagerModule)

- `СформироватьТекстДляСкриптаДизайн120120(ДокЗаявкаНаДизайн, Номенклатура, НомерСтроки, Спецификация, Отказ)` — формирует 11-строчный текст (артикул, контрагент, менеджер, дизайнер, размер этикетки, штамп, способ наклейки, намотка)
- `Лико_СформироватьТекстДляСкриптаДизайн(ДокЗаявкаНаДизайн, Номенклатура, НомерСтроки, Спецификация, НомерВарианта, Отказ)` — расширенная версия с 15 строками (+ Z, ОсновнойМатериал, Наименование этикетки)
- `СформироватьТекстДляСкриптаДизайн(...)` — ещё одна версия с GTIN из ЧестныйЗнак
- Все функции запрашивают `Лико_ПараметрыШтампа` и поля из ЗаказКлиента / Лико_Спецификации (размеры, ручьи, Z, нарезка)
- `ЕстьГруппаДоступа(ГруппаДоступа, Пользователь)` — проверка членства пользователя в группе доступа

## Формат скрипта дизайна

15 строк: Артикул монтажа, Контрагент, Ответственный, Дизайнер, Размер этикетки, Штамп, Способ наклейки (0-3), Макс. диаметр, Внутр. диаметр, Направление намотки, Кол-во этикеток в ролике, Организация, Z, Основной материал, Этикетка

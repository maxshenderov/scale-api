# ДоговорыКонтрагентов

> Расширение справочника договоров — BSL-код полностью закомментирован (заглушка).

## Что делает / Доработки
Модуль объекта справочника (8684 байта) содержит полностью закомментированное переопределение `ПередЗаписью` (через `&ИзменениеИКонтроль`). Логика включала:
- Проверку `ОбновлениеИнформационнойБазы.ПроверитьОбъектОбработан`
- Автозаполнение `НаименованиеДляПечати`
- Определение `ХозяйственнаяОперация` по типу договора
- Изменение признака согласованности
- Установку допустимой суммы задолженности
- Очистку филиалов для нецентрализованных
- Взаиморасчеты: `ВзаиморасчетыСервер.ПередЗаписью`
- Удаление графика исполнения при снятии флага
- Подготовку данных для синхронизации ключей
- Заполнение назначения и НДС
- Вставка Маковеевой А.Ю. (31.10.2025): проверка заполненности `СтавкаНДС`

В текущем состоянии весь код в комментариях, модуль не активен.

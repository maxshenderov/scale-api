# РаботаСФайлами

> Обработка работы с присоединенными файлами — добавляет поле «Тип файла» (BRC) для номенклатуры и партнеров.

## Что делает / Доработки
Расширяет форму присоединенных файлов. Для справочников `НоменклатураПрисоединенныеФайлы` и `ПартнерыПрисоединенныеФайлы` добавляет:
- Колонку «Тип файла» (`Лико_ТипФайла`) в список
- Кнопку для выбора типа файла из справочника `Лико_ТипыФайлов` (для партнеров — заголовок «Указать тип файла»)

## Ключевые процедуры
- `Лико_ПриСозданииНаСервереПосле()` — добавляет поле `Лико_ТипФайла` в список для `НоменклатураПрисоединенныеФайлы` или `ПартнерыПрисоединенныеФайлы`
- `Лико_BRCПосле()` — открывает форму выбора из справочника `Лико_ТипыФайлов`
- `Лико_BRCЗавершение()` — сохраняет выбранный тип файла через серверный вызов
- `ИзменитьЛикоТипФайла(Ссылка, ТипФайла)` — устанавливает `Лико_Тип` объекту справочника

# Лико_СтоимостьДоставки

> Оборотный регистр накопления: распределяет стоимость доставки по товарам реализации пропорционально их весу.

## Что хранит

Движения по документам реализации и отгрузки — стоимость доставки, разнесенная на каждую строку товара. Расчет идет через вес номенклатуры: общая стоимость доставки делится на общий вес, затем умножается на вес каждой строки.

## Измерения

| Измерение | Тип | Описание |
|---|---|---|
| Склад | Справочник.Склады | Склад отгрузки |
| Заказ | Документ.ЗаказКлиента | Заказ клиента |
| Номенклатура | Справочник.Номенклатура | Номенклатура |
| Характеристика | Справочник.ХарактеристикиНоменклатуры | Характеристика |
| Серия | Справочник.СерииНоменклатуры | Серия |

## Ресурсы

| Ресурс | Тип | Описание |
|---|---|---|
| Количество | Число | Количество |
| Сумма | Число | Сумма доставки |
| СуммаРегл | Число | Сумма доставки в регл. учете (= Сумма * Курс) |

## Регистраторы

`Документ.ОтгрузкаТоваровСХранения`, `Документ.РеализацияТоваровУслуг`, `Документ.Лико_ЗаявкаНаТранспортировку`

## Ключевые процедуры

- `Лико_РассчитатьСтоимостьДоставки(Объект)` — рассчитывает стоимость доставки для каждой строки ТЧ `Товары` документа реализации:
  1. Вычисляет общую стоимость доставки в евро (через курс валюты управленческого учета)
  2. Вычисляет общий вес коробок через `Лико_РассчитатьОбщийВесКоробок`
  3. Стоимость доставки за 1 кг = общая стоимость в евро / общий вес
  4. Запросом умножает `Количество * ВесУпаковки * СтоимостьЗаКг` для каждой строки
  5. Заполняет реквизит `Лико_СтоимостьДоставки` в строках товаров

- `Лико_РассчитатьОбщийВесКоробок(Объект)` — вычисляет суммарный вес упаковок всех товаров через `УпаковкиЕдиницыИзмерения.ТекстЗапросаВесУпаковки`.

- `Лико_СформироватьДвиженияПоРНЛико_СтоимостьДоставки(Отказ, ОбъектСсылка, ВызовИзОбработкиПроведения)` — формирует движения регистра:
  - При вызове из проведения: очищает движения и заполняет заново
  - При вызове извне: работает через создание набора записей по ссылке
  - Поддерживает документы `РеализацияТоваровУслуг` и `ОтгрузкаТоваровСХранения`
  - Группирует по Заказ, Номенклатура, Характеристика, Склад, суммируя количество и стоимость

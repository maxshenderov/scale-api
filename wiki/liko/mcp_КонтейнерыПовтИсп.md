# mcp_КонтейнерыПовтИсп

> MCP-модуль: кешируемые таблицы инструментов, ресурсов и промптов (повторное использование).

## Что делает

Предоставляет три функции — `Инструменты()`, `Ресурсы()`, `Промпты()` — каждая из которых:
1. Создает пустую таблицу через `mcp_Метаданные`
2. Заполняет её через `mcp_Метаданные.ЗаполнитьТаблицу*()`, который обходит все обработки-контейнеры из соответствующих подсистем

Результат кешируется в рамках одного сеанса через механизм повторного использования модуля 1С.
Это позволяет не обходить контейнеры при каждом запросе — таблицы строятся один раз.

## Ключевые процедуры

- `Инструменты()` — возвращает `ТаблицаЗначений` с колонками: `ИмяОбработкиКонтейнера`, `Имя`, `Описание`, `СхемаПараметров`.
- `Ресурсы()` — возвращает `ТаблицаЗначений` с колонками: `ИмяОбработкиКонтейнера`, `Адрес`, `Имя`, `Описание`.
- `Промпты()` — возвращает `ТаблицаЗначений` с колонками: `ИмяОбработкиКонтейнера`, `Имя`, `Описание`, `Параметры`.

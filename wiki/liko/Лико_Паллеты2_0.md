# Лико_Паллеты2_0

> Справочник паллет версии 2.0 — расширенное управление паллетами с привязкой к типоразмерам, учётом остатков серий в ячейках и автоматическим созданием.

## Что хранит

- Обновлённая версия [[Лико_Паллеты]] с дополнительной логикой работы с типоразмерами и сериями
- Тип паллета (опционально, задаётся при создании через `НовыйПаллет()`)
- Связь с регистром сведений `Лико_ПараметрыПаллет` (типоразмер: высота, ширина, глубина, вес)

## Ключевые процедуры

### ManagerModule

- `ШтрихКод(ПаллетСсылка)` — генерирует штрихкод паллета: "8" + вид информации "02" + код (10 знаков) + контрольная сумма
- `ШтрихКодСтрокой(ПаллетСсылка)` — то же с разделителями-пробелами для читаемости
- `СерииНаПаллете(Паллет, Дата)` — запрос к регистру `Лико_ТоварыНаПаллетах.Остатки`, возвращает массив серий номенклатуры на паллете
- `ПолучитьОстаткиТоваровПоСериямВЯчейках(ДанныеТоваров, ДатаДокумента)` — универсальная функция: принимает ТаблицуЗначений / Массив / Структуру с сериями, запрашивает `ТоварыВЯчейках.Остатки`, возвращает таблицу остатков (Номенклатура, Характеристика, Упаковка, Серия, Ячейка, ВНаличииОстаток, КоличествоКПеремещению)
- `ПроверитьНаличиеОстатков(ТаблицаОстатков, ДанныеТоваров)` — проверяет, все ли серии из документа имеют остатки в ячейках; возвращает структуру с флагом `ОстаткиДостаточны`, списком строк без остатков и текстами причин
- `ТипоразмерПаллета(Паллет)` — получает параметры типоразмера (Высота, Ширина, Глубина, Вес) из регистра `Лико_ПараметрыПаллет.СрезПоследних`
- `НовыйПаллет(ТипПаллета)` — создаёт и записывает новый элемент справочника с указанным типом (автор: m.shenderov 08.04.2026)

### Вспомогательные функции-адаптеры

- `ПреобразоватьДанныеТоваровВТаблицу(ДанныеТоваров)` — адаптер: преобразует ТаблицуЗначений / Массив / Структуру в унифицированную таблицу с колонками Серия, НомерСтроки
- `ПреобразоватьМассивВТаблицу(Массив, Таблица)` — массив серий в таблицу
- `ПреобразоватьСтруктуруВТаблицу(Структура, Таблица)` — структура с ключами "Серия"/"Серии" в таблицу
- `ФорматироватьСтрокуОшибки(НомерСтроки, Номенклатура, ...)` — форматирование сообщения об ошибке для строки с указанием ячейки
- `ФорматироватьСтрокуОшибкиПоСерии(НомерСтроки, Номенклатура, ...)` — форматирование сообщения об ошибке по серии (без конкретной ячейки)

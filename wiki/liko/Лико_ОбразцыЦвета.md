# Лико_ОбразцыЦвета

> Перечисление — типы образцов цвета, используемые при цветоделении и согласовании цвета в заказах.

## Тип объекта
**Перечисление** (`Enum`).

## Значения перечисления
| Значение | Назначение |
|---|---|
| **ВнешнийОбразец** | Образец цвета, предоставленный клиентом (внешний образец) |
| **ЦветоПроба** | Цветопроба — пробный оттиск для согласования цвета |
| **БезОбразца** | Печать без образца цвета |
| **ПредыдущийТираж** | Образец цвета из предыдущего тиража |
| **ЭтикеткаВОМ** | Этикетка в ОМ (образец-мастер) |
| **КаталогПантонов** | Цвет по каталогу Pantone |
| **ЭтикеткаВКнигеОбразцов** | Этикетка из книги образцов |

## Ключевые процедуры

### ManagerModule — `ОбработкаПолученияДанныхВыбора()`
Переопределяет стандартный список выбора значений перечисления. Вместо стандартного поведения возвращает фиксированный список значений в нужном порядке:
`ВнешнийОбразец` -> `ЦветоПроба` -> `БезОбразца` -> `ПредыдущийТираж` -> `ЭтикеткаВОМ` -> `КаталогПантонов` -> `ЭтикеткаВКнигеОбразцов`

Это гарантирует, что при выборе в формах значения отображаются в логическом порядке: от внешнего образца через различные варианты согласования к печати без образца.

## Связь с ЗаказКлиента
Используется в процессе цветоделения при определении способа согласования цвета для каждого заказа. Тип образца влияет на технологию допечатной подготовки и может влиять на стоимость.

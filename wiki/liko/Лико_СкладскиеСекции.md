# Лико_СкладскиеСекции

> Складские секции стеллажей — ключевой элемент топологии склада. Каждая секция содержит 3 адреса (ячейки) для размещения до 3 паллет.

## Что хранит
- **Стеллаж** — ссылка на родительский стеллаж
- **Склад** — склад размещения
- **Этаж** — номер этажа в стеллаже
- **Ряд, Место, Места** — позиционирование (ряд + 3 места: Место, Место+1, Место+2)
- **Типоразмер** — ссылка на `Лико_ТипоразмерыСкладскихСекций` (габариты и грузоподъемность)
- **Адрес1, Адрес2, Адрес3** — три адреса хранения (ссылки на `СкладскиеЯчейки`)
- **АдресЦентр** = Адрес2
- **КоличествоАдресов** = 3
- **ВремяДоступа** — время доступа к секции (используется при оптимизации подбора)
- **УровеньДоступа** — число (2 знака): назначаемый вручную приоритет доступа. 1 = ближняя половина стеллажа (приоритет), 2 = дальняя половина. В коде `ПодобратьЯчейку` вычисляется динамически из позиции секции `(Место - 1) / 3 + 1 <= КоличествоСекций / 2`, но реквизит позволяет задать вручную
- **ЗапретРазмещения** — булево: ручная блокировка секции для исключения из автоматического подбора (ремонт, блокировка ячейки)

## Модуль объекта: `ПередЗаписью`
Автогенерация кода и наименования по шаблону:
- `Код` = `"Р{Ряд}-М({Место}-{Место+1}-{Место+2})-Э{Этаж}"`
- `Наименование` = `"Р{Ряд}-М({Места})-Э{Этаж}"`

## Модуль менеджера: ключевые процедуры

### `ПодобратьЯчейку(Склад, Высота, Ширина, Глубина, Вес, ОбратныйПорядокВремени)`
Интеллектуальный подбор оптимальной складской ячейки для паллета. Возвращает **один адрес** (`ПЕРВЫЕ 1` в финальном SELECT — ближайший по сортировке).

**Алгоритм:**
1. Фильтрует секции по складу и типоразмеру (глубина, вес, высота)
2. Определяет уровень доступа (ближняя/дальняя половина стеллажа)
3. Собирает остатки паллет по трем адресам каждой секции из регистра `Лико_ПаллетыВСекциях`
4. Вычисляет остатки ширины, веса, высоты
5. Сортирует по приоритетам: уровень доступа, неограниченная грузоподъемность, остаток высоты, остаток ширины, остаток веса, время доступа
6. Возвращает `ПЕРВЫЕ 1` — ближайшую подходящую ячейку

**Вычисляемое поле `Адрес`** — определяет конкретный адрес размещения по ширине паллета:
```sql
ВЫБОР
    КОГДА &Ширина > Типоразмер.Ширина * 2 / 3
        ТОГДА Адрес2                          -- только средний
    КОГДА &Ширина > Типоразмер.Ширина / 3
        ТОГДА ВЫБОР                           -- только крайние
            КОГДА Паллет1 = ПустаяСсылка ТОГДА Адрес1
            ИНАЧЕ Адрес3
        КОНЕЦ
    ИНАЧЕ ВЫБОР                               -- первый свободный
        КОГДА Паллет1 = ПустаяСсылка ТОГДА Адрес1
        КОГДА Паллет2 = ПустаяСсылка
            И Типоразмер1.Ширина <= Типоразмер.Ширина / 3
            И (Паллет3 = ПустаяСсылка
               ИЛИ Типоразмер3.Ширина <= Типоразмер.Ширина / 3)
            ТОГДА Адрес2
        КОГДА Паллет3 = ПустаяСсылка ТОГДА Адрес3
        ИНАЧЕ Адрес1
    КОНЕЦ
КОНЕЦ КАК Адрес
```

**WHERE-фильтры** (синхронизированы с `ОшибкиРазмещенияВАдрес`):
- Хоть один адрес свободен
- Остаток ширины > 0
- Вес не превышен (если не безлимитная)
- Паллет2, если занят, не блокирует крайние (его ширина < 1/3 секции)
- Если `&Ширина > 2/3` — все три адреса пусты
- Если `&Ширина > 1/3` — Паллет2 пустой И (Паллет1 пустой ИЛИ Паллет3 пустой)

### `ПодобратьЯчейкуПоПаллету(Склад, Паллет, Типоразмер, УровеньДоступа)`
Обертка над `ПодобратьЯчейку` — извлекает габариты из типоразмера паллета.

### `ОшибкиРазмещенияПаллетаВАдрес(Ячейка, Паллет)`
Валидация размещения паллета в конкретный адрес. Проверяет 14 правил:
- Занятость адреса
- Конфликты с соседними адресами (ширина > 1/3 или > 2/3 секции)
- Превышение габаритов секции (ширина, высота, глубина)
- Превышение общей грузоподъемности секции
- Признак `ЗапретРазмещения` секции
- Габариты стеллажа (Мин/Макс ширина и глубина из `Лико_Стеллажи`)

### `ДобавлениеИзменениеСекций(Стеллаж)`
Пакетное создание/обновление секций для стеллажа — по этажам и количеству секций.

### Служебные
- `Секция(Стеллаж, Этаж, Код)` — поиск секции по стеллажу, этажу и коду
- `ЗаписатьСекциюВАдрес(Секция)` — запись ссылки на секцию в каждый из 3 адресов
- `АдресХранения(Ряд, Место, Этаж)` — поиск ячейки по коду `"Р{Ряд}М{Место}Э{Этаж}"`
- `КодСекции(Ряд, Место, Этаж)` — генерация кода секции

## Правила размещения паллет в секции
- Секция имеет 3 адреса, можно разместить 1, 2 или 3 паллета
- Если ширина паллета > **2/3** ширины секции — только в средний адрес (2)
- Если ширина паллета > 1/3 ширины секции — в крайние адреса (1, 3), но не в средний
- Если ширина <= 1/3 — можно разместить 3 паллета
- **ЗапретРазмещения**: если у секции установлен признак `ЗапретРазмещения = Истина` — размещение запрещено во все адреса
- **Габариты стеллажа**: проверяются `МинШиринаПаллета`, `МаксШиринаПаллета`, `МинГлубинаПаллета`, `МаксГлубинаПаллета` из справочника `Лико_Стеллажи` (применяются только если значение ≠ 0)

## ОшибкиРазмещенияВАдрес(Ячейка, Высота, Ширина, Глубина, Вес)
Валидация размещения паллета в конкретный адрес. Проверяет 14 правил:
1. Занятость адреса
2. Конфликты с соседними адресами (ширина > 1/3 или > 2/3 секции)
3. Превышение габаритов секции (ширина, высота, глубина)
4. Превышение общей грузоподъемности секции
5. **Признак `ЗапретРазмещения`** — если установлен, размещение запрещено во все адреса
6. **Габариты стеллажа** — проверка Мин/Макс ширина и глубина из связанного стеллажа

## Синхронизация `ПодобратьЯчейку` и `ОшибкиРазмещенияВАдрес`

**Все 14 проверок синхронизированы** — функции гарантируют одинаковое поведение:

| Правило | ОшибкиРазмещенияВАдрес | ПодобратьЯчейку WHERE |
|---|---|---|
| ЗапретРазмещения | проверка | строка `НЕ ЗапретРазмещения` |
| Глубина >= | проверка | `Типоразмер.Глубина >= &Глубина` |
| Высота >= | проверка | `Типоразмер.Высота >= &Высота` |
| Вес (если не безлимитная) | проверка | `Вес >= &Вес` + фильтр остатка |
| Габариты стеллажа | проверки | `Мин/Макс Ширина/Глубина` |
| Паллет2 > 1/3 блокирует крайние | проверки 2, 3 | `Типоразмер2.Ширина < Типоразмер.Ширина / 3` |
| **Ширина > 2/3 → все адреса пусты** | правило 1 | `Паллет1=Пустая И Паллет2=Пустая И Паллет3=Пустая` |
| **Ширина > 1/3 → Паллет2 пустой** | правило 2 | `Паллет2=Пустая И (Паллет1=Пустая ИЛИ Паллет3=Пустая)` |
| Адрес уже занят | проверка 1 | `Паллет1/2/3 = ПустаяСсылка` в вычислении адреса |
| Соседи не блокируют адрес 2 | проверки 4, 5 | `Типоразмер1/3.Ширина <= Типоразмер.Ширина / 3` |

**Изменения 2026-05-27:**
1. **Добавлено `ПЕРВЫЕ 1`** — функция возвращает ближайшую ячейку (раньше брала последнюю = самую дальнюю)
2. **Добавлено вычисляемое поле `Адрес`** — определяет конкретный адрес по правилам 1/3 и 2/3
3. **Добавлены WHERE-фильтры** для синхронизации с ОшибкиРазмещенияВАдрес:
   - Паллет > 2/3: все 3 адреса пусты
   - Паллет > 1/3: Паллет2 пустой И (Паллет1 пустой ИЛИ Паллет3 пустой)
   - Проверка соседей при выборе адрес 2 для паллета ≤ 1/3

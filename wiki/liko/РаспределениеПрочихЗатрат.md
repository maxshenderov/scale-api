# РаспределениеПрочихЗатрат

> Типовой документ распределения прочих затрат. Доработка ManagerModule — переопределение формирования документа с поддержкой налогового учета.

## Что делает / Доработки
- **Распределение прочих затрат** по трем видам учета: управленческий, регламентированный, налоговый.
- **Расширение `ManagerModule`**: переопределена функция `СформироватьДокумент()` — добавлен вид учета «НалоговыйУчет» (НЕ УТ, локализация). Логика: для каждого вида учета подбирается или создается документ, заполняется, проводится. При ошибках фиксируется состояние и описание ошибки.
- Поддерживается перезапись предыдущего документа (отмена проведения старого перед записью нового).

## Ключевые процедуры
- `Лико_СформироватьДокумент(ПараметрыЗаполнения)` — &Вместо штатной, обрабатывает три вида учета (Упр, Регл, Нал), подбирает/создает документы, проводит их, возвращает параметры состояния.

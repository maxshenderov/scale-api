# Лико_ОтображениеРабочихЦентров

> Справочник настроек отображения рабочих центров — конфигурирует внешний вид таблиц РЦ в обработке планирования производства (колонки, группировка, ширина, доступ).

## Что хранит

Настройки визуализации для каждого набора рабочих центров: какие колонки показывать, их ширину, группировку по дням, фильтры по площадке и этапам планирования.

**Реквизиты:**
- `ГруппироватьПоДням` (Булево) — группировка строк по дням
- `КоличествоРЦПоГоризонтали` (Число) — сколько РЦ выводить в строку по горизонтали
- `КоличествоСтрокВТаблицеРЦ` (Число) — число строк в таблице РЦ
- `ШиринаТаблицыСвободных` (Число) — ширина таблицы свободных РЦ
- `ВидЭтаповПланирования` (Справочник.Лико_ВидыЭтаповПроизводства) — фильтр по этапам
- `ТолькоСвоиПоУмолчанию` (Булево) — показывать только свои РЦ
- `НомерПрокатаПоУмолчанию` (Число) — номер проката по умолчанию
- `Площадка` (Справочник.Лико_Площадки) — площадка
- `НеПоказыватьВОбработкеПланирования` (Булево)
- `КомандыКолористов` (Булево) — режим для команд колористов

**Табличные части:**
- **РабочиеЦентры** — список РЦ: `РабочийЦентр` (Справочник.РабочиеЦентры)
- **ОтображениеКолонокРЦ** — колонки занятых РЦ: `ИмяКолонки`, `Заголовок`, `Ширина`, `ФорматнаяСтрока`
- **ОтображениеКолонокСвободные** — колонки свободных РЦ: + `ПорядокСортировки`, `СортироватьПоУбыванию`, `ТолькоДляСортировки`
- **ОтображениеКолонокСнятые** — колонки снятых РЦ: `ИмяКолонки`, `Заголовок`, `Ширина`
- **Доступ** — ограничение доступа: `Пользователь` (Справочник.Пользователи)

## Ключевые процедуры

Модуль объекта пуст — настройки используются декларативно через обработку планирования.

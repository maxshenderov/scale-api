# Лико_ЗабраковкаОснастки

> Документ выбраковки оснастки. Создаётся на основании заявки на ремонт рабочих центров. Управляет признаком К2 у объектов номенклатуры.

## Что делает

- Заполняется из `ТС_ЗаявкаНаРемонтРабочихЦентров`
- При проведении: записывает признак `Категория2` в `ЯССМ_ОбъектНоменклатуры` по сериям из ТЧ `Товары`
- При отмене проведения: сбрасывает `Категория2` в `Ложь`
- Валидирует заполнение реквизитов `Дефект`, `Решение`, `Серия` в каждой строке товаров
- Отслеживает изменение решения и сбрасывает `ПисьмоПоРешениюОтправлено`
- Работает с сериями: есть `ПараметрыУказанияСерий`, `ТекстЗапросаЗаполненияСтатусовУказанияСерий` (адресное хранение, ордерная схема)

## Ключевые процедуры

- `ОбработкаЗаполнения()` — заполняет реквизиты из `ТС_ЗаявкаНаРемонтРабочихЦентров` (СотрудникОбнаружившийБрак, ЗаказКлиента, Организация, РабочийЦентр)
- `ОбработкаПроведения()` — вызывает `ЗаписатьК2ВОбъектНоменклатуры()`
- `ЗаписатьК2ВОбъектНоменклатуры(Отмена)` — для каждой строки Товары записывает `Категория2` в объект номенклатуры серии
- `ПередЗаписью()` — проверяет заполнение Дефект/Решение/Серия; отслеживает изменение решения для сброса флага отправки письма
- `ПараметрыУказанияСерий(Объект)` — настройка указания серий для ордерной схемы (складской документ)
- `ТекстЗапросаЗаполненияСтатусовУказанияСерий()` — формирует запрос статусов серий с учётом политик учёта

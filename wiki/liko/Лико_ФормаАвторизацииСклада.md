# Лико_ФормаАвторизацииСклада

> Общая форма авторизации складского оператора. Сканирование штрихкода сотрудника открывает форму документа.

## Что делает

При открытии ждет сканирования штрихкода. Распознает ШК типа `ШК_Сотрудника` через `Лико_ДополнительноКлиент.ОбработатьШтрихКодНеТовара()`.

После успешной авторизации:
- Устанавливает глобальную переменную `ГлЛико_Оператор`
- Отправляет оповещение `АвторизацияОператора`
- Открывает форму документа (имя из параметра `ИмяДокумента`, ключ из `Ключ`)

Поддерживает также ручную авторизацию по F2/F3 — вызывает `Справочники.Лико_РабочиеМеста.ПолучитьСвойство("СотрудникПоF2"/"СотрудникПоF3")`.

## Параметры формы

- `ИмяДокумента` — имя документа для открытия после авторизации
- `Ключ` — ссылка на документ

## Ключевые процедуры

- `ПриСозданииНаСервере()` — сохраняет `ИмяДокумента` и `Ключ` из параметров, настраивает подключаемое оборудование
- `ПриОткрытии()` — инициализирует `ГлЛико_Оператор`, запускает сканер
- `ОбработатьШтрихкоды()` — ищет ШК сотрудника, авторизует и открывает форму
- `ОткрытьФормуДокумента()` — закрывает форму авторизации и открывает `Документ.<ИмяДокумента>.Форма.ФормаДокумента`
- `СотрудникПоF2()` / `СотрудникПоF3()` — ручная авторизация по горячим клавишам
- `СотрудникПоF2НаСервере()` / `СотрудникПоF3НаСервере()` — получают сотрудника из свойств рабочего места
- `ОбработкаОповещения()` — слушает `АвторизацияОператора` и `ScanData`

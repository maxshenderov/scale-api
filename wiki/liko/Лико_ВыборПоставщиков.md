# Лико_ВыборПоставщиков

> Документ-заглушка для подсистемы выбора поставщиков. Не содержит собственной логики проведения -- только стандартные обработчики печати, отчётов и версионирования.

## Что делает

Документ создан как каркас для будущей реализации функционала выбора поставщиков. На данный момент не имеет ObjectModule.bsl (нет собственной логики проведения). ManagerModule содержит только стандартные процедуры-заглушки.

## Ключевые процедуры

- `ДобавитьКомандыПечати()` -- пустая заглушка
- `Печать()` -- пустая заглушка
- `ДобавитьКомандыОтчетов()` -- пустая заглушка (закомментирован вызов СтруктураПодчиненности)
- `ПриОпределенииНастроекВерсионированияОбъектов()` -- пустая заглушка

## Связь с ЗаказКлиента

Прямой связи на уровне кода нет. Предположительно будет использоваться для сравнения и выбора поставщиков материалов по заказам.

## Связи

Нет активных связей -- документ-заглушка.

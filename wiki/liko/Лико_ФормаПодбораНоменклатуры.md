# Лико_ФормаПодбораНоменклатуры

> Общая форма подбора номенклатуры с условным оформлением для характеристик, серий и единиц измерения.

## Что делает / Доработки
Расширяет типовую форму подбора номенклатуры. Главное дополнение — настройка **условного оформления** (conditional formatting) для трех типов полей:
- **Характеристики номенклатуры** — если не используются, поле затеняется с текстом «<характеристики не используются>»
- **Серии номенклатуры** — несколько вариантов оформления в зависимости от статуса указания серий и типа номенклатуры (товар/тара/услуга)
- **Единицы измерения** — скрываются, если заполнена упаковка

## Ключевые процедуры
- `УстановитьУсловноеОформление()` — вызывает настройку для характеристик и серий
- `УстановитьУсловноеОформлениеХарактеристикНоменклатуры()` — настройка для поля характеристики
- `УстановитьУсловноеОформлениеСерийНоменклатуры()` — сложная логика: «для товаров», «серия не указывается», «серия указывается отдельно», «серия указывается в ТЧ Товары»
- `УстановитьУсловноеОформлениеЕдиницИзмерения()` — скрывает поле единиц измерения при заполненной упаковке

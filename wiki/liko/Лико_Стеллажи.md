# Лико_Стеллажи

> Справочник стеллажей склада. Управляет топологией склада: создает ячейки, секции и зоны приемки/отгрузки.

## Что хранит
- **Склад** — привязка к складу
- **Код** — автонумерация (числовой, длина 5)
- **КодПолный** — полный код ряда
- **КодДоп** — дополнительный код ряда
- **КаталогСкладскихЯчеек** — корневая папка ячеек в иерархии `СкладскиеЯчейки`
- **КоличествоСекций** — количество секций в стеллаже
- **КоличествоЯчеекВСекции** — количество ячеек в одной секции
- **КоличествоЗонПриемкиОтгрузки** — количество зон на полу
- **Этажи** — табличная часть: этажи стеллажа (НомерСтроки, Типоразмер)
- **ЗоныПриемкиОтгрузки** — табличная часть: адреса зон приемки/отгрузки (АдресХранения)
- **ДопНастройки** — дополнительные настройки (в т.ч. ЦветСтеллажа)

## Модуль менеджера

### `ДобавлениеИзменениеТопологииСклада(Стеллаж)`
Основная процедура — создает/обновляет всю топологию склада для стеллажа одной операцией:
1. `СоздатьТопологиюЯчеек` — создает иерархию: Ряд -> Места -> Этажи -> Ячейки
2. `СоздатьТопологиюСекций` — делегирует в `Лико_СкладскиеСекции.ДобавлениеИзменениеСекций()`
3. `СоздатьТопологиюЗоныПриемкиИОтгрузки` — создает зоны на полу (ПОЛ -> адреса)

Все три операции выполняются в транзакции.

### `ЦветаСтелажей(Склад)`
Возвращает `Соответствие` Стеллаж -> ЦветСтеллажа для визуализации склада. Извлекает цвет из `ДопНастройки` каждого стеллажа.

### Служебные процедуры (создание топологии ячеек)
- `СоздатьПолучитьРяд(Параметры)` — создает/находит группу ячеек «Ряд №X»
- `ОбработатьМеста(Ряд, Параметры)` — обходит все места ряда
- `ОбработатьЭтажи(Параметры, Место, Ряд)` — обходит этажи для каждого места
- `СоздатьРедактироватьМесто()` / `СоздатьРедактироватьЭтаж()` / `СоздатьРедактироватьЯчейку()` — создание/обновление элементов иерархии `СкладскиеЯчейки`
- `ПолучитьКодПоРодителю()` — генерация кода ячейки из полного наименования УПП

Все элементы создаются с заполнением полей УПП (`Лико_КодУПП`, `Лико_ИдУПП`, `Лико_ПолноеНаименованиеУПП`) для обмена данными.

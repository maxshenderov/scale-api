# Лико_ФормаВыбораАдреса

> Общая форма — диалог выбора адреса из контактной информации владельца (контрагента, партнера и т.п.).

## Что делает

Форма отображает список контактной информации владельца, фильтруя только виды КИ, содержащие "Адрес" в наименовании. Для каждого адреса добавляется кнопка "Выбрать". При выборе адреса форма возвращает структуру с полями `Представление`, `ЗначенияПолей`, `Комментарий`. При закрытии с модификацией — сохраняет изменения контактной информации в объекте владельца.

Использует стандартную подсистему `УправлениеКонтактнойИнформацией` для отображения и редактирования.

## Ключевые процедуры

- `ПриСозданииНаСервере()` — получает владельца КИ из параметра `Объект`, фильтрует виды КИ (только адреса), инициализирует подсистему `УправлениеКонтактнойИнформацией`
- `ЗаполнитьИсключаемыеВидыКИ()` — возвращает массив всех видов КИ, кроме тех, что содержат "Адрес" в наименовании
- `КомандаВыбратьАдрес()` — формирует результат выбора из `КонтактнаяИнформацияОписаниеДополнительныхРеквизитов` и закрывает форму
- `ПриЗакрытииНаСервере()` — сохраняет изменения КИ в объекте владельца (с проверкой прав)
- `Подключаемый_*` — стандартные обработчики подсистемы контактной информации

# Лико_ПодборНоменклатуры

> Расширенная форма выбора номенклатуры для склада — с остатками по ячейкам, объектам номенклатуры и штрихкодами.

## Что делает

Форма выбора номенклатуры (`ФормаВыбора` для справочника Номенклатура), расширенная складской функциональностью:
- Показывает остатки товаров из регистров `ТоварыВЯчейках` и `ЯССМ_ОбъектыНоменклатуры`.
- Фильтры: Код, Артикул, ЦеноваяГруппа, Нарезка, Втулка.
- Режим «ТолькоОстатки» — скрывает номенклатуру с нулевым остатком.
- Обработка штрихкодов (складское сканирование).
- Подбор серий (открытие формы серий).
- Выбор значения номенклатуры с учётом складских параметров.

Формирует сложный запрос к остаткам, учитывающий параметры склада, помещения, характеристики, серии.

## Ключевые процедуры

- `ТекстЗапросаОстатковНоменклатуры()` — формирует основной текст запроса остатков из `ТоварыВЯчейках` и `ЯССМ_ОбъектыНоменклатуры` с фильтрами по складу, помещению, характеристике, сериям.
- `ОбработатьШтрихкоды()` — обрабатывает ввод штрихкодов для поиска и подбора номенклатуры.
- `ВыбратьЗначениеНоменклатуры()` — выполняет выбор значения номенклатуры с передачей выбранного значения в форму-владелец.
- `УстановитьВидимость()` — управляет видимостью элементов формы в зависимости от контекста (склад, помещение).

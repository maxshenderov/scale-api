# Лико_ВводОстатковПоСкладу

> Документ ввода начальных остатков товаров на складе. Используется при внедрении системы для переноса складских остатков из исторической учётной системы.

## Что делает

Вводит начальные остатки товаров в ячейках склада. При проведении записывает движения с видом Приход в регистр ТоварыВЯчейках. Также содержит процедуру ТекстОтраженияВРеглУчете для формирования проводок в регламентированном учёте по нескольким счетам и разделам.

## Ключевые процедуры

- `ОбработкаПроведения()` -- основное проведение: запись приходных движений в ТоварыВЯчейках
- `ТекстОтраженияВРеглУчете()` -- формирование запроса для отражения в бухгалтерском учёте с разделами:
  - ОстаткиСобственныхТоваров
  - ОстаткиСобственныхТоваровНаПроизводстве
  - Расчёты с поставщиками/покупателями
  - Кассы и кредиты

## Связь с ЗаказКлиента

Не привязан напрямую к конкретному заказу. Используется для инициализации общих складских остатков системы.

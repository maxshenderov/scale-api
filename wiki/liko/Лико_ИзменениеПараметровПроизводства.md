# Лико_ИзменениеПараметровПроизводства

> Документ фиксации изменений параметров производства по заказу — подтверждает изменения и проставляет дату утверждения.

## Что делает

Служебный документ для протоколирования изменений производственных параметров. Имеет состояния (`Состояние` — перечисление `Лико_СостоянияДокументаИзменениеПараметровПроизводства`). При подтверждении автоматически проставляется `ДатаУтверждения`. При копировании очищаются дата утверждения, состояние и автор.

Объектный модуль минимален — основной код в форме документа.

## Ключевые процедуры

- `ПередЗаписью()` — если Состояние = «Подтверждено» и дата не заполнена, проставляет `ДатаУтверждения = ТекущаяДата()`. Если состояние не «Подтверждено», очищает дату утверждения.
- `ПриКопировании()` — очищает `ДатаУтверждения`, `Состояние`, `Автор`.

# Лико_Дополнительно

> Серверный модуль дополнительных утилит — доп. реквизиты, поиск организаций, расчёт веса коробки.

## Что делает

Вспомогательные серверные функции общего назначения. Не зависит от бизнес-документов, работает как чистая утилита.

## Ключевые процедуры

- `ПолучитьИмяДопРеквизита(ИмяПредопределенногоЗначения, ЛеваяЧастьИмени)` — возвращает имя формы динамического дополнительного реквизита по предопределённому значению
- `РассчитатьВесКоробки(Номенклатура, КоличествоВУпаковке, КоробокВКомплекте, Заказ)` — рассчитывает вес коробки по плотности, зависящей от типа заказа:
  - Термоусадка → 65 г/м²
  - ВплавляемаяЭтикетка → 350 г/м²
  - Остальные → 120 г/м²
- `НайтиОбработкиРабочегоМестаДляОткрытияПриНачалеРаботыСистемы()` — поиск обработок для автозапуска по рабочему месту пользователя
- `ОбработатьШтрихКодНеТовараСервер(Штрихкод)` — обработка нетоварных штрихкодов (серверная часть)

## Связь с ЗаказКлиента

Определяет плотность материала по [[ЗаказКлиента]].Лико_ТипЗаказа для расчёта веса.

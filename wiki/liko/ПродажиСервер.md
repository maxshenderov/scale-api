# ПродажиСервер

> Типовой общий модуль БСП «Продажи (сервер)». Упоминается в контексте локализации документов переработки.

## Что делает

Типовой серверный модуль подсистемы «Продажи» — содержит процедуры для работы с документами продаж, отгрузки, реализации.

## Доработки Лико

Модуль упоминается в связях [[ПередачаСырьяПереработчикуЛокализация]] — локализация использует процедуры модуля `ПродажиСервер` для переопределения временной таблицы товаров при суммировании из `ВидыЗапасов`.

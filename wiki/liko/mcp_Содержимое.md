# mcp_Содержимое

> MCP-модуль: фабрика MCP-структур — text, image, blob, prompt message.

## Что делает

Предоставляет функции для создания типизированных структур содержимого, соответствующих
спецификации Model Context Protocol. Каждая функция формирует `Структура` с полями,
ожидаемыми MCP-клиентом.

## Ключевые процедуры

- `ТекстовоеСодержимое(Текст)` — создает структуру `{type: "text", text: ...}`. Базовый тип содержимого для ответов инструментов.
- `ТекстовоеСодержимоеРесурса(Текст, MimeТип)` — аналогично, но с полем `mimeType`. Используется для ресурсов, где важен MIME-тип.
- `ИзображениеСодержимое(Данные, MimeТип)` — создает структуру `{type: "image", data: base64, mimeType}`. Принимает данные как строку base64 или `ДвоичныеДанные`.
- `ДвоичноеСодержимое(Данные, MimeТип)` — создает структуру `{type: "blob", blob: base64, mimeType}`. Для бинарных ресурсов.
- `СообщениеПромпта(Роль, Текст)` — создает структуру сообщения для промптов: `{role: "user"|"assistant"|"system", content: {type: "text", text: ...}}`.

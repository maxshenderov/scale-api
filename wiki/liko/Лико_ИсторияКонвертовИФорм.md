# Лико_ИсторияКонвертовИФорм

> Отчет по истории движения форм в конвертах и их связи с заказами. Автор: m.shenderov (30.03.2018).

## Что делает

Формирует табличный документ (ландшафтная ориентация) на основе макета с областями: `Заголовок`, `Раздел`, `Строка`. 
Выводит историю движений форм из регистра `Лико_ИсторияДвиженийФорм` с группировками по коду формы (первые 7 символов), номенклатуре и комментарию.

Отчет ищет формы четырьмя способами (объединение через `ОБЪЕДИНИТЬ ВСЕ`):
1. **По конверту** — формы, которые были в указанном конверте (справочник `Лико_Конверты`)
2. **По заказу приема** — формы, привязанные к заказу через `ЗаказКлиента.Формы` (по номеру заказа)
3. **По заказу операции** — формы, у которых `ЗаказПокупателя.НомерБезПрефикса` совпадает
4. **По коду формы** — поиск по `Лико_Формы.Код` (первые 7 символов)

## Параметры отчета

- `Организация` — фильтр по организации
- `НомерЗаказа` — число, 0 = без фильтра
- `Конверт` — ссылка на справочник `Лико_Конверты`, пустая ссылка = без фильтра

## Ключевые процедуры

- `СформироватьОтчет()` (сервер) — основной метод: выполняет запрос с 4 секциями UNION ALL, группирует результат по `КодФормы7` -> `Номенклатура` -> `Комментарий`, выводит в табличный документ через области макета
- `СформироватьОтчет1()` (клиент) — команда формы, вызывает `СформироватьОтчет()`

## Используемые объекты

- Регистр сведений `Лико_ИсторияДвиженийФорм`
- Справочник `Лико_Формы`
- Справочник `Лико_Конверты`
- Документ `ЗаказКлиента.Формы` (табличная часть)

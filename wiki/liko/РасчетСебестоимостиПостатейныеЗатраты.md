# РасчетСебестоимостиПостатейныеЗатраты

> Переопределение базы распределения расходов на заказы клиента в расчёте себестоимости.

## Что делает
Модуль заменяет типовой текст запроса `ТекстЗапросаБазаРаспределенияРасходовНаЗаказы` через аннотацию `&ИзменениеИКонтроль`. Добавляет поддержку заказов давальца (`ЗаказДавальца2_5`) в расчёт себестоимости — типовой запрос работает только с `ЗаказКлиента`, а в Лико есть заказы давальца, которые тоже требуют распределения постатейных расходов. Меняет алиасы таблиц с `Заказ` на `Лико_Заказ` для исключения конфликтов с типовым кодом. Также добавляет `Организация` в индексацию временных таблиц.

Доработка помечена комментарием `//++ НЕ УТКА` и добавляет UNION ALL с выборкой из `ЗаказДавальца2_5.Продукция` для отбора заказов давальца в аналитику расходов.

## Ключевые процедуры
- `Лико_ТекстЗапросаБазаРаспределенияРасходовНаЗаказы()` — возвращает модифицированный текст запроса (использует макросы `#Удаление`/`#Вставка` типового механизма)

## Используется в
- Регламентное задание расчёта себестоимости
- Закрытие месяца

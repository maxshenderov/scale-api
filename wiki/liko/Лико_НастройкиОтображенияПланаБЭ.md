# Лико_НастройкиОтображенияПланаБЭ

> Справочник настроек отображения колонок плана бюджетирования/экономики (БЭ). Хранит конфигурацию видимости и ширины полей для форм плана.

## Что хранит
- Наименование — ссылка на стандартный справочник НастройкиОтображенияПлана
- ПоляТаблицы — табличная часть с настройками каждого поля:
  - Имя, Заголовок, Ширина, Видимость, Шаблон
  - СайтВидимость, СайтВидимостьРасшифровка

## Ключевые процедуры
- `ПолучитьМассивНастроек(Настройка)` — экспортная функция менеджера. Возвращает массив структур с параметрами каждого поля таблицы (Имя, Заголовок, Ширина, Видимость, Шаблон, СайтВидимость, СайтВидимостьРасшифровка). По умолчанию используется основная настройка `Справочники.НастройкиОтображенияПлана.Основная`.

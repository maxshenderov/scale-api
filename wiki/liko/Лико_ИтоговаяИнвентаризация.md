# Лико_ИтоговаяИнвентаризация

> Отчётный документ — агрегирует данные пересчётов за период по складу для итоговой сверки инвентаризации.

## Что делает

Документ-отчёт без ObjectModule (нет серверного кода объекта). Вся логика — в форме документа (`ЗаполнитьДокументНаСервере()`). Собирает данные для итоговой инвентаризации склада за период:

1. **ТоварыИвентаризаций** — все строки из проведённых ПересчетТоваров по складу за период (статусы: ВнесениеРезультатов, Выполнено), исключая скрытые инвентаризации и контроль приёмки.
2. **ПересчетыТоваров** — сводка по документам пересчёта с признаком наличия расхождений.
3. **ПустыеЯчейки** — ячейки, которые были пусты на начало и на конец периода, а также ячейки без товаров в иерархии пересчитываемых групп.
4. **ЯчейкиБезПересчета** — ячейки СИМ, не попавшие ни в один пересчёт.
5. **ТоварыПриходСписание** — движения прихода/списания за период (Лико_ПередачаТоваров по причине «СписаниеНедостачИнвентаризации» и Лико_ВозвратТоваров по причине «ПриходИзлишкаИнвентаризации»).

## Ключевые процедуры (форма)

- `ЗаполнитьДокументНаСервере()` — основной алгоритм: собирает все пять ТЧ через серию сложных запросов по регистру `ТоварыВЯчейках`, справочнику `СкладскиеЯчейки`, документам `ПересчетТоваров`, `Лико_ПередачаТоваров`, `Лико_ВозвратТоваров`.

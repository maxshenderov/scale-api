# Лико_ПроведениеДокументов

> Модуль управления проведением документов — контроль регистров и механизмов учёта Лико.

## Что делает

Переопределяет стандартную логику проведения документов ERP для Лико. Добавляет контроль складского регистра и отключает ненужные ордерные механизмы.

## Ключевые процедуры

- `ПараметрыДляПроведенияДокумента(Документ, Отказ, РежимПроведения, СтруктураПараметров)` — добавляет регистр `ТоварыВЯчейках` в список контрольных регистров для складских документов Лико (если документ работает со складом Лико)
- `УчетныеМеханизмыДокумента(Документ, МассивМеханизмов)` — убирает механизмы `Обеспечение` и `АдресныйСклад` когда установлен флаг `Лико_НеНужныДвиженияОрдерныхСкладов` на документе

## Связь с ЗаказКлиента

Влияет на проведение документов связанных с [[ЗаказКлиента]]:
- Складские документы (приходы/расходы) получают дополнительный контроль ячеек
- Ордерные склады Лико получают упрощённое проведение без механизмов Обеспечения

## Паттерн использования

```bsl
// В обработчиках событий проведения документов (подписка)
Лико_ПроведениеДокументов.ПараметрыДляПроведенияДокумента(Источник, Отказ, РежимПроведения, СтруктураПараметров);
```

# ВнутреннееПотребление (типовой, доработан)

> Доработки Лико: передача в эксплуатацию с автоподбором серий по FIFO, блокировка старой операции «Передача в производство», управление статусами и сериями.

## Доработки

- **Блокировка операции «Передача в производство»** — при выборе `ПередачаВПроизводство` запись запрещена (сообщение пользователю: использовать форму «Производство — Получение и возврат материалов»).
- **Автостатус для передачи в эксплуатацию** — если операция `ПередачаВЭксплуатацию` и статус не заполнен, автоматически устанавливается `Принято`.
- **Автоподбор серий по FIFO** — для операции `ПередачаВЭксплуатацию` с видом `ПередачаВЭксплуатацию`: очистка серий, затем запрос к `ТоварыНаСкладах.Остатки` на момент документа, подбор серий по минимальной дате (FIFO), пока не набрано нужное количество.
- **Очистка резервов при удалении проведения** — вызов `Лико_Дополнительно.ОчиститьРегистрРезервыТоваровОрганизацийПоРегистратору()`.
- **Расчет роликов (Намотка/Втулка/КолРоликов)** — для строк с характеристикой, имеющей нарезку `ЯССМ_Нарезка`, вычисляется количество роликов и общее количество через размер нарезки и намотку.

## Ключевые процедуры

- `Лико_ПередЗаписью()` (вместо `ПередЗаписью`) — основная процедура, содержит всю логику: блокировка операции, подбор серий FIFO, установка статусов, расчет роликов. Выполняется при любом режиме записи.
- `Лико_ОбработкаУдаленияПроведения()` (после `ОбработкаУдаленияПроведения`) — очистка регистра резервов товаров организаций по регистратору.

# Лико_ЗаказОснастки

> Заказ на изготовление/перезаказ оснастки (штампы, контрматрицы, кондуктора). Заполняется из ЗаказКлиента по секциям/цветам. Ведёт регистр `Лико_ЗаказыНаОснастку`. Создаёт внутренние заказы на производство оснастки (полуфабрикаты).

## Что делает

- Табличная часть `Оснастка` — строки заказа оснастки (Номенклатура, Количество, Заказ, Менеджер, Статус)
- Табличная часть `Этикетки` — привязка этикеток к строкам оснастки (по КлючСтроки)
- При проведении:
  - Создаёт записи в регистре `Лико_ЗаказыНаОснастку` (новые строки)
  - Обновляет существующие записи при изменении Менеджер/Заказ/Номенклатура
  - Заполняет пустые Партнер/Менеджер/Заказ в `Лико_ПараметрыШтампа`
- При подтверждении (Статус = Подтвержден) отправляет письмо ответственному за оснастку
- `СоздатьЗаказНаполуфабрикат()` — создаёт внутренний ЗаказКлиента (тип Полуфабрикат) на производство оснастки
  - Для контрматриц: статус «ГотовКГравировке», этап гравировального участка
  - Для остального: статус «ВключенВПлан»
- `НаправитьВРаботу()` — вызывает `Лико_Планирование.НаправитьВРаботуЗаказОснастки()`
- `ОснасткаСоздатьСообщение()` — отправляет HTML-сообщение через макет о статусе заказа

## Ключевые процедуры

- `ОбработкаЗаполнения()` — заполняет Оснастку из Цветов ЗаказКлиента: виды работ, параметры штампов, нарезки, Z, ручьи. Ищет контрматрицы/кондуктора по артикулу
- `ОбработкаПроведения()` — синхронизация с регистром `Лико_ЗаказыНаОснастку` + заполнение `Лико_ПараметрыШтампа` + письмо ответственному
- `СоздатьЗаказНаполуфабрикат(Организация, Площадка, ЗаказКлиента, Партнер, Регион, Номенклатура, Количество)` — создаёт внутренний заказ на оснастку с гравировальным РЦ
- `ПолучитьРабочийЦентрГравировальныйУчасток(Площадка)` — находит первый неудалённый РЦ гравировки на площадке
- `ТекстЗапросаОснасткаНаЗаказ(ТекстЗапроса)` — формирует запрос оснастки с учётом внутреннего производства (гравировальный участок)

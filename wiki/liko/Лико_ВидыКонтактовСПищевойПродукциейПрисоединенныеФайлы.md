# Лико_ВидыКонтактовСПищевойПродукциейПрисоединенныеФайлы

> Служебный справочник-хранилище присоединенных файлов (изображений) для справочника Лико_ВидыКонтактовСПищевойПродукцией.

## Что хранит

Присоединенные файлы (изображения) привязанные к элементам справочника видов контактов с пищевой продукцией. Файлы добавляются через механизм `РаботаСФайлами`.

## Ключевые процедуры

Модуль менеджера:
- `РеквизитыРедактируемыеВГрупповойОбработке()` — возвращает реквизиты доступные для группового редактирования (делегирует в `РаботаСФайлами`)
- `ПриЗаполненииОграниченияДоступа(Ограничение)` — настраивает RLS через владельца файла: чтение и изменение разрешены если разрешены для `ВладелецФайла`

Модуль объекта пуст — стандартное поведение подсистемы `РаботаСФайлами`.

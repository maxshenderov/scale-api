# Лико_НастройкиФормыУчетаТрафаретныйУчасток

> Справочник настроек формы учёта для трафаретного участка. Конфигурирует отображение команд и операций в интерфейсе трафаретной печати.

## Что хранит
- Тип — тип строки настройки: "Команда" или вид операции
- НастройкиФормы — табличная часть:
  - Наименование — для команд: "Добавить", "КВыдаче", "Списание", "Выдать", "Приемка", "Снятие"; для операций: ссылка на справочник Лико_Работы
  - КомандаОперации — операция для не-команд: "КВыдаче", "Списание", "Выдать", "Приемка", "Снятие"
  - ТипСетки — ценовая группа, содержащая "Сетка" в наименовании

## Ключевые процедуры
### ФормаЭлемента
- `НастройкиФормыНаименованиеНачалоВыбора()` — заполняет список выбора в зависимости от типа: для "Команда" подставляет стандартные команды (Добавить, КВыдаче, Списание, Выдать, Приемка, Снятие), для операций — список из справочника Лико_Работы.
- `НастройкиФормыКомандаОперацииНачалоВыбора()` — для не-команд подставляет список операций (КВыдаче, Списание, Выдать, Приемка, Снятие).
- `ТипСеткиНачалоВыбора()` — отбирает ценовые группы с "Сетка" в наименовании.
- `ПолучитьСписок()` — серверная функция, запрашивает ценовые группы по маске "%Сетка%".

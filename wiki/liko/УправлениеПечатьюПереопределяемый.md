# УправлениеПечатьюПереопределяемый

> Регистрация Лико_-документов в списке объектов с командами печати.

## Что делает
Модуль расширяет типовой список объектов, для которых доступны команды печати, через аннотацию `&После`. Добавляет пять Лико_-документов в перечень объектов подсистемы «Управление печатью», чтобы для них можно было настраивать печатные формы через типовой механизм БСП.

## Ключевые процедуры
- `Лико_ПриОпределенииОбъектовСКомандамиПечати()` — добавляет документы `Лико_ПодготовкаМатериалов`, `Лико_ЗаказНаРаскрой`, `Лико_УстановкаВидаНастроечногоМатериала`, `Лико_ЗаявкаНаИзготовлениеФорм`, `Лико_ФормированиеПаллета2_0` в список объектов с печатными командами

## Используется в
- Подсистема «Управление печатью» (БСП)
- Настройка печатных форм для Лико_-документов

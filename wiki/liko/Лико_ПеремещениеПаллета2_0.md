# Лико_ПеремещениеПаллета2_0

> Перемещение паллета версии 2.0 -- использует новую систему паллет (`Лико_Паллеты2_0`). Формирует движения по типовому регистру `ТоварыВЯчейках` и своему `Лико_ПаллетыВСекциях`.

## Что делает

В отличие от первой версии, работает напрямую с `ТоварыВЯчейках` (типовой регистр) вместо `Лико_АдресноеХранение`. Проводит паллет целиком:

1. **Проверки:** заполнение полей, последовательность проведения (запрет заднего числа при наличии более поздних документов с теми же сериями).
2. **Подготовка:** получает серии на паллете через `Справочники.Лико_Паллеты2_0.СерииНаПаллете()`, проверяет остатки.
3. **Движения:**
   - `ТоварыВЯчейках`: расход из старой ячейки + приход в новую (для каждой серии)
   - `Лико_ПаллетыВСекциях`: списание из предыдущей секции + приход в новую секцию
4. **При отмене проведения:** проверяет наличие зависимых документов с теми же сериями, проведенных позже.

## Реквизиты

- `Паллет` -- перемещаемый паллет (справочник Лико_Паллеты2_0)
- `АдресХранения` -- новый адрес (ячейка), из него выводятся `Склад`, `Площадка`, `Организация`

## Ключевые процедуры

- `ВыполнитьПроверкиПередПроведением()` -- валидация полей, проверка последовательности в неоперативном режиме
- `ПодготовитьДанныеДляПроведения()` -- получение серий и проверка остатков через API Лико_Паллеты2_0
- `СформироватьДвиженияДокумента()` -- движения по ТоварыВЯчейках и Лико_ПаллетыВСекциях (только если адрес изменился)
- `ПроверитьИзменениеАдресаПаллета()` -- сравнение текущего адреса с новым
- `ПроверитьПроведениеЗаднимЧислом()` -- поиск более поздних документов с теми же сериями, вывод подробной инструкции пользователю
- `ПроверитьНаличиеЗависимыхДокументов()` -- проверка при отмене проведения
- `СообщитьОбОшибке()` -- вывод через `СообщениеПользователю`

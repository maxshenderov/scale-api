# Лико_ВводОстатковЗатратДляОтгрузки

> Документ ввода начальных остатков затрат для последующей отгрузки. Используется при старте системы для переноса исторических данных о затратах по заказам.

## Что делает

Переносит остатки затрат из исторической системы в регистры накопления. При проведении записывает движения в два регистра: Лико_ЗатратыПоЗаказу (оборотный) и Лико_ЗатратыПоЗаказуДляОтгрузки (остатки с видом движения Приход).

Табличная часть "Затраты" содержит поля: ЗаказКлиента, РабочийЦентр, Затрата, СтатьяЗатрат, НомерПроката, ВидРабот, НомерРаботы, ВидНастроечногоМатериала, Количество, Сумма, КоличествоПМ.

## Ключевые процедуры

- `ОбработкаПроведения()` -- запросом выбирает строки ТЧ "Затраты", создаёт наборы записей для регистров Лико_ЗатратыПоЗаказу и Лико_ЗатратыПоЗаказуДляОтгрузки (с ВидДвижения.Приход), заполняет все измерения

## Связь с ЗаказКлиента

Каждая строка документа ссылается на конкретный ЗаказКлиента. Затраты переносятся в разрезе заказа, что позволяет системе корректно рассчитывать себестоимость и отгрузку.

# Лико_ОбменМеждуЕРП

> План обмена — настройка и выполнение синхронизации данных между узлами распределённой информационной базы (РИБ) нескольких экземпляров 1С:ERP.

## Тип объекта
**План обмена** (`ExchangePlan`) для распределённой информационной базы (РИБ).

## Что делает
Обеспечивает двусторонний обмен данными между главным и подчинёнными узлами 1С:ERP в распределённой информационной базе. При получении данных автоматически обрабатывает входящие объекты, пересчитывает зависящие регистры и отправляет изменённые данные обратно.

## Реквизиты
- **РегистрироватьИзменения** (`Булево`) — флаг регистрации изменений для автообмена

## Ключевые процедуры (ObjectModule)

### `ПриПолученииДанныхОтПодчиненного()`
Основной обработчик входящих данных от подчинённого узла. При получении объектов:
1. **Партионный учёт** — накапливает данные для перерасчёта себестоимости
2. **Взаиморасчёты с клиентами/поставщиками** — создаёт задания к распределению расчётов
3. **Книга покупок/продаж** — формирует задания для записей книги покупок/продаж
4. **Реестр документов** — отражает документы в реестре
5. **Файлы** — обрабатывает присоединённые файлы

### `ПриПолученииДанныхОтГлавного()`
Обработчик данных от главного узла. Отражает документы в реестре и обрабатывает файлы.

### `ПриОтправкеДанныхГлавному()`
При отправке партий товаров организаций в главный узел переопределяет набор записей — удаляет не первичные записи (оставляет только первичное поступление).

### `ПриПолученииДанныхФайла()`
Переопределяет стандартную загрузку для специальных объектов:
- **СегментыНоменклатуры, СегментыПартнеров** и др. справочники с регламентными заданиями — маппит идентификаторы регламентных заданий на локальные
- **НастройкиАдресныхСкладов** — восстанавливает регламентные задания расчёта прогноза и создания заданий на отбор
- **КонтактыВзаимодействий** — накапливает для последующей очистки дублей
- **ПредметыПапкиВзаимодействий** — объединяет массивы предметов и папок
- **ЗаказКлиента, ЗаявкаНаВозвратТоваровОтКлиента** — накапливает заказы для отражения состояния

### `ПослеЗагрузкиДанных()`
Выполняет пост-обработку после полной загрузки:
1. Замена дублей ключей аналитики (учёта номенклатуры, по партнёрам, партий, видов запасов)
2. Обновление устаревших видов запасов с остатками
3. Отражение состояния заказов клиентов
4. Отражение документов в реестре
5. Перерасчёт себестоимости по накопленным данным
6. Создание заданий к распределению расчётов с клиентами и поставщиками
7. Очистка дублей справочника **СтроковыеКонтактыВзаимодействий** (пометка на удаление + замена ссылок)
8. Перерасчёт состояния контактов/предметов/папок взаимодействий
9. Формирование заданий книги покупок/продаж
10. Удаление заданий к закрытию месяца и списанию ТМЦ в эксплуатации в подчинённом узле

### `ПередЗаписью()`
При записи объекта плана обмена (не в режиме загрузки) проверяет необходимость выполнения `ПослеЗагрузкиДанных()`.

## Ключевые процедуры (ManagerModule)

### `ПриПолученииНастроек()`
Настройки плана обмена по умолчанию:
- Предупреждать о несоответствии версий правил обмена
- Не используется в модели сервиса
- Включён алгоритм получения описания варианта настройки

### `ПриПолученииОписанияВариантаНастройки()`
Формирует описание варианта настройки обмена:
- Комплект правил: `https://releases.1c.ru/project/EnterpriseERP20`
- Шаблоны: `\1c\Enterprise20`
- Форма создания начального образа: `ОбщаяФорма.СозданиеНачальногоОбразаСФайлами`
- Используются все доступные транспорты сообщений обмена
- Заголовок помощника: «Настройка распределенной информационной базы»

### `ВариантыНастройкиРасписания()`
Возвращает 3 варианта расписания автообмена:
1. **Каждые 15 минут** (Пн–Пт)
2. **Каждый час с 8:00 до 20:00** (ежедневно)
3. **Каждую ночь в 2:00** (Пн–Пт, кроме Сб–Вс)

## Формы
- **ФормаУзла** — форма карточки узла РИБ. При создании пропускает инициализацию для автотестов. При закрытии оповещает другие формы событием `ЗакрытаФормаУзлаПланаОбмена`.
- **ПодробнаяИнформация** — форма с HTML-макетом «ПодробнаяИнформация», отображающая справку о синхронизации данных в РИБ.

# Лико_Псевдонимы

> Псевдонимы для групп материалов — автонумеруемые записи с привязкой к ГруппаМатериала.

## Что хранит
Справочник псевдонимов/алиасов для групп материалов. Каждая запись принадлежит конкретной `ГруппаМатериала` и получает автоматический номер в рамках группы.

Неиерархический справочник. Код не используется (длина 0), автонумерация отключена. Наименование до 100 символов. Контроль уникальности отключён.

**Реквизиты:** ГруппаМатериала, Номер.

Наименование формируется автоматически: `ГруппаМатериала.Наименование + " " + Номер`.

## Ключевые процедуры

### ObjectModule
- `ПередЗаписью()` -- при создании нового элемента: запрос максимального Номера в рамках ГруппаМатериала, инкремент, формирование Наименования

ManagerModule отсутствует.

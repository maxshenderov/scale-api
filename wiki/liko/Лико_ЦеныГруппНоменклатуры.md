# Лико_ЦеныГруппНоменклатуры

> Регистр сведений (периодический) — хранение цен для ценовых групп номенклатуры с разбивкой по типам цен, площадкам и дополнительными параметрами себестоимости.

## Тип регистра
**Периодический** (`Periodical`). Цены привязаны к дате записи.

## Измерения
- **ТипЦен** (`EnumRef.Лико_ТипЦен`) — тип цены (ОсновнаяЕвро, ЦенаПоставщика, Табаш, ТабашФакт)
- **ЦеноваяГруппа** (составной тип: `CatalogRef.Лико_ПараметрыРасчетаНормативов`, `CatalogRef.Номенклатура`, `CatalogRef.ЦеновыеГруппы`) — ценовая группа, может быть как справочником ценовых групп, так и конкретной номенклатурой или параметрами расчёта нормативов
- **Площадка** (`CatalogRef.Организации`) — производственная площадка

## Ресурсы
- **Валюта** (`CatalogRef.Валюты`) — валюта цены
- **Цена** (`Число`) — значение цены
- **ЕдиницаИзмерения** (`CatalogRef.УпаковкиЕдиницыИзмерения`) — единица измерения цены
- **Наценка** (`Число`) — процент наценки
- **ПотериНаРезке** (`Число`) — процент потерь на резке
- **СкладскиеРасходы** (`Число`) — складские расходы
- **Экосбор** (`Число`) — экологический сбор

## Реквизиты
- **Код** (`Строка`) — код записи
- **Ответственный** (`CatalogRef.Пользователи`) — пользователь, создавший запись
- **Основание** (составной тип: `DocumentRef.Лико_УстановкаСтоимостиЦеновыхГрупп`, `DocumentRef.ПриходныйОрдерНаТовары`) — документ-основание цены
- **АвтоРасчетЦены** (`Булево`) — признак автоматического расчёта цены

## Ключевые процедуры

### RecordSetModule — `ПередЗаписью()`
При каждой записи набора автоматически заполняет реквизит **Ответственный** текущим пользователем сеанса для всех строк набора.

### ФормаСписка — `ПриСозданииНаСервере()`
При открытии формы списка с параметром **ЦеноваяГруппа** автоматически устанавливает отбор динамического списка по этой ценовой группе.

### Команда — `ОбработкаКоманды()`
Открывает форму списка регистра с предустановленным отбором по ценовой группе, переданной как параметр команды.

## Связь с ЗаказКлиента
Цены из этого регистра используются при расчёте стоимости заказа. Тип цен определяет, по какой методике рассчитывается цена (основная в евро, цена поставщика или специальные типы Табаш/ТабашФакт). Разбивка по площадкам позволяет иметь разные цены для разных производственных площадок. Дополнительные ресурсы (наценка, потери на резке, складские расходы, экосбор) участвуют в расчёте полной себестоимости заказа.

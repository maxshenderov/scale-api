# Лико_ФормаПодбораСерии

> Общая форма подбора серий номенклатуры по остаткам на складе.

## Что делает / Доработки
Форма выбора серий для конкретной номенклатуры/характеристики на указанном складе. Принимает параметры:
- `Номенклатура`, `Характеристика`, `Склад` — обязательные
- `ТолькоОстатки` — флаг фильтрации только по остаткам

Возвращает массив структур с полями `Серия`, `АдресХранения`, `Количество` для выбранных строк.

## Ключевые процедуры
- `ПриСозданииНаСервере()` — устанавливает параметры динамического списка `СерииСписок` (номенклатура, характеристика, склад)
- `ВыбратьЗначениеНоменклатуры()` — собирает выделенные серии в массив структур и закрывает форму
- `СерииСписокВыбор()` — обрабатывает двойной клик как выбор значения

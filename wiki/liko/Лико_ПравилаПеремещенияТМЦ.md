# Лико_ПравилаПеремещенияТМЦ

> Правила складского перемещения ТМЦ: стратегии ФИФО/ЛИФО, блокировки и контроля выдачи по заявкам.

## Что хранит
Иерархический справочник (группы + элементы). Группа -- контейнер для набора правил по связке `ВидНоменклатуры + Организация`. Элементы -- отдельные правила с приоритетом, настройками СКД и стратегией перемещения.

**Основные реквизиты:** ВидНоменклатуры, Организация, Приоритет, СложнаяНастройка, ОтборНастройки (ХранилищеЗначения для СКД), Выключить.

Дополнительные реквизиты формируют простое условие (без СКД) -- проверка наличия/отсутствия свойств номенклатуры.

**Перечисления-связки:**
- `Лико_СтратегииПеремещенияТМЦ` -- стратегия (ФИФО, ЛИФО, Заблокировать)
- `Лико_ДействияПоПравилуПеремещенияТМЦ` -- действие (ЗаполнитьПоПравилу, Проверить, КонтрольВыдачиПоЗаявке, ЗаблокироватьНеПоправилу)

## Ключевые процедуры

### ObjectModule
- `ПередЗаписью()` -- автоформирование наименования из контекста; автонумерация приоритета; сбор описания из доп. реквизитов
- `ПриЗаписи()` -- двойная запись (первая для получения ссылки), затем вызов `СохранитьНастройкуПравил()`
- `ПриКопировании()` -- копирует ОтборНастройки из объекта-оригинала
- `ОбработкаПроверкиЗаполнения()` -- исключает Организацию из проверки заполнения

### ManagerModule
- `ОпределитьПравило(Номенклатура, Документ)` -- определяет правило для одной номенклатуры по СКД-пакету запросов
- `ОпределитьПравилаДляТоваров(Товары, Документ)` -- пакетное определение правил для всей ТЧ товаров (префиксная замена параметров)
- `СохранитьНастройкуПравил(ВидНоменклатуры, Организация)` -- перестраивает кэш настроек для группы: формирует единый пакетный запрос из всех СКД-настроек элементов группы, сохраняет в реквизит `НастройкаПравил` группы
- `ПолучитьПриоритетМакс()` / `ПереместитьПоПриоритету()` -- управление приоритетом с атомарным swap'ом
- `ВыполнитьПроверку(ДокументОбъект, Отказ)` -- главная точка входа: вызывает стратегии проверки и заполнения
- `ВыполнитьПроверкуЗаявкиНаСклад()` -- проверка для `Лико_ЗаявкаНаСклад` (стратегии блокировки и заполнения)
- `ВыполнитьПроверкуПередачиТоваров()` -- проверка для `Лико_ПередачаТоваров` (стратегии блокировки и контроля выдачи)
- `СтратегияЗаблокировать()` -- блокировка перемещения номенклатуры (сообщение с полем)
- `СтратегияЗаполнитьПоПравилу()` -- автозаполнение ТЧ товаров по правилу (ФИФО/ЛИФО) из регистра `ТоварыВЯчейках.Остатки`
- `СтратегияКонтроляВыдачиПоЗаявке()` -- проверка что товары из передачи есть в заявке-основании
- `СтратегияПроверитьПравило()` -- проверка FIFO/LIFO: сравнение дат формирования объектов номенклатуры в документе с остатками
- `ОпределеитьМетодДвиженияМеждуСкладами()` -- вычисляет ФИФО/ЛИФО по иерархии складов (отправитель vs получатель)
- `СтартСистемы()` -- проверка даты начала учёта правил (`Лико_ПредопределенныеЗначения.ДатаНачалаУчетаПравилПеремещенияТМЦ`)

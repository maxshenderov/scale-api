# Лико_ЗаписьОбъектов

> Регистр сведений — очередь асинхронной обработки объектов 1С. Позволяет регистрировать объекты (документы, справочники) для последующей пакетной обработки: проведения, пересчета параметров выпуска, загрузки.

## Что хранит

- **Измерения:** Ссылка (ЛюбаяСсылка), ИмяОперации, Параметр
- **Ресурсы:** Потоки (число потоков), Порядок, УидФЗ (уникальный идентификатор фонового задания), Ошибка (текст ошибки)
- Периодичность: по секундам, независимый

## Ключевые процедуры

- `ПараметрПроведение()` — возвращает `"Проведение"`
- `ПараметрЗагрузка()` — возвращает `"Загрузка"`
- `ПараметрДляПересчета()` — возвращает `"ДляПересчета"`
- `ПараметрЗапись()` — возвращает `"Запись"`
- `ДобавитьВОчередь(МассивСсылок, ИмяОперации, Параметр, Потоки)` — добавляет объекты в очередь. Каждая ссылка — отдельная запись. Потоки по умолчанию = 1.
- `ВыполнитьОперацииИзОчереди()` — читает все записи, группирует по ИмяОперации, разбивает на партии (Количество/Потоки), для каждой партии запускает фоновое задание через `Лико_АсинхронныеПроцедуры`. Записывает УидФЗ в записи.
- `ПроведениеВыполнить(МассивСсылок, ИмяОперации, Параметр)` — перепроводит документы: получает объект, вызывает `Записать(Проведение)`, удаляет запись из очереди. При ошибке — записывает `ОписаниеОшибки()`.
- `ДляПересчетаВыполнить(МассивСсылок, ИмяОперации, Параметр)` — пересчитывает параметры выпуска через `Лико_Планирование.ЗаполнениеПараметровВыпуска()`, удаляет запись. При ошибке — сохраняет описание ошибки.
- `ПолучитьИмяМетода(Параметр)` — формирует имя метода фонового задания: `Лико_АсинхронныеПроцедуры.<Параметр>Выполнить`

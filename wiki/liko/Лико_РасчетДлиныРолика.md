# Лико_РасчетДлиныРолика

> Общая форма для расчета длины ролика материала по начальному/конечному диаметру и толщине. Поддерживает ввод через сканер штрихкода.

## Что делает

Рассчитывает длину намотанного материала по формуле спирали Архимеда:
`L = Pi * (2*r0*h + hs*h2s) / s_1000 / 1000`

где `r0` — начальный радиус, `h = r - r0` — разница радиусов, `s_1000` — толщина в мм / 1000.

При сканировании штрихкода объекта номенклатуры (`ЯССМ_ОбъектыНоменклатуры`) автоматически подставляет номенклатуру и начальный диаметр (из реквизита `Втулка.РазмерНаружногоДиаметра`).

Толщина материала берется из реквизита `Лико_ТолщинаМатериала` номенклатуры или вида номенклатуры.

## Параметры формы

- `Номенклатура` — выбранный материал
- `РедактироватьТолщину` — разрешить ручной ввод толщины (принудительно Истина, m.shenderov 26.03.2018)
- `ВозвращатьЗначение` — флаг возврата результата
- `НачальныйДиаметр` — предустановленный начальный диаметр
- `РежимБезРедактированияМетров` — блокирует поля номенклатуры и длины

## Ключевые процедуры

- `РассчитатьДлинуРолика()` — формула расчета; возвращает 0 при нулевой толщине, нулевом начальном диаметре или если конечный < начального
- `ПолучитьТолщинуМатериала()` (сервер без контекста) — `Номенклатура.Лико_ТолщинаМатериала` -> `ВидНоменклатуры.Лико_ТолщинаМатериала`
- `РазмерНаружногоДиаметра()` (сервер без контекста) — запрос к `ЯССМ_ОбъектыНоменклатуры.Втулка.РазмерНаружногоДиаметра`
- `ОбработатьШтрихкоды()` — распознает ШК через `Лико_ДополнительноКлиент.ОбработатьШтрихКодНеТовара()`, фильтрует по видам `ШК_ОбъектаНоменклатуры_Короткий` / `ШК_ОбъектаНоменклатуры`
- `ОбработатьШКНоменклатуры()` — устанавливает `Номенклатура` и `НачальныйДиаметр`
- `УправлениеЭлементамиФормы()` — валидация (сообщения о незаполненных полях)
- `ОК()` — закрывает форму, возвращая `Структура.ДлинаРолика`

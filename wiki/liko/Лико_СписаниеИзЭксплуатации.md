# Лико_СписаниеИзЭксплуатации

> Документ-распоряжение на списание ТМЦ из эксплуатации. При проведении создает и записывает типовой документ `ВнутреннееПотребление` с хозяйственной операцией "Передача в эксплуатацию" и фиксирует связь в регистре `Лико_СвязиСТиповымиДокументами`.

## Что делает

Выступает как управляющий документ для операций с ТМЦ в эксплуатации:
- При проведении находит или создает документ `ВнутреннееПотребление` (операция "Передача в эксплуатацию")
- Заполняет его данными: организация, подразделение, склад, помещение, МОЛ
- Связывает распоряжение с типовым документом через регистр `Лико_СвязиСТиповымиДокументами`

Содержит также закомментированный код процедуры `СписатьИзЭксплуатации()` -- логика создания документа `СписаниеИзЭксплуатации` на основе оборотов регистра `ТМЦВЭксплуатации` (не используется).

## Ключевые процедуры

### ObjectModule

- `ОбработкаЗаполнения()` -- инициализация реквизитов шапки через `Лико_ОбщегоНазначенияСервер.РеквизитыШапки()` и установка даты/ответственного.
- `ОбработкаПроведения()` -- вызывает `ПередатьВЭксплуатацию()`.
- `ПередатьВЭксплуатацию()` -- основная логика:
  1. Находит/создает `ВнутреннееПотребление` через `НайтиДокументПередачаВЭксплуатацию()`
  2. Заполняет дату (конец предыдущего месяца), организацию, подразделение, склад
  3. Устанавливает хоз. операцию "ПередачаВЭксплуатацию", вид операции из перечисления `Лико_ВидыОпераций_Списание`
  4. Записывает документ, при ошибке -- сообщение через `Лико_ДополнительноКлиентСервер`
  5. Пишет связь в регистр `Лико_СвязиСТиповымиДокументами`
- `НайтиДокументПередачаВЭксплуатацию()` -- ищет существующий `ВнутреннееПотребление` по ссылке на распоряжение. Если не найден -- создает новый.
- `НайтиДокументСписанияИзЭксплуатации()` -- аналогичный поиск для `СписаниеИзЭксплуатации` (используется только в закомментированной логике).
- `СписатьИзЭксплуатации()` -- закомментирован, выбирал остатки ТМЦ в эксплуатации за период и формировал документ `СписаниеИзЭксплуатации`.

### Форма документа

- `ПриСозданииНаСервере()` -- установка ссылки для отображения типовых документов, заполнение автора.
- `МесяцПриИзменении()` -- автокоррекция даты на конец месяца.

## Используемые модули

- `Лико_ОбщегоНазначенияСервер` -- заполнение реквизитов шапки
- `Лико_ДополнительноКлиентСервер` -- сообщения об ошибках

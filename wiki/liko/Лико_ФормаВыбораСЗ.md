# Лико_ФормаВыбораСЗ

> Общая форма выбора значений из СпискаЗначений с возможностью предварительной отметки элементов.

## Что делает / Доработки
Универсальная форма выбора из СпискаЗначений (СЗ). Принимает параметры:
- `СписокЗначений` — список для выбора
- `СписокЗначенийОтметка` — элементы, которые должны быть отмечены при открытии
- `Заголовок`, `Ширина`, `Высота` — настройки отображения

При нажатии ОК возвращает новый `СписокЗначений` с отмеченными элементами.

## Ключевые процедуры
- `Ок(Команда)` — собирает отмеченные значения в `СписокЗначений` и закрывает форму с результатом
- `Отмена(Команда)` — закрывает форму без результата
- `ПриСозданииНаСервере()` — заполняет таблицу значений из параметров, устанавливает отметки и размеры формы

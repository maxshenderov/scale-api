# Лико_ПрочиеЗатраты

> Документ фиксирует прочие (косвенные) затраты и распределяет их по заказам клиентов пропорционально выручке за выбранный период.

## Что делает

При проведении вызывает `Лико_Планирование.РаспределениеПрочихЗатратПоЗаказам()` для расчетного распределения. Форма документа содержит механизм `ЗаполнитьПоВыручке` -- сложный запрос к регистру `ВыручкаИСебестоимостьПродаж`, который сопоставляет строки затрат с фактической выручкой по заказам, рабочим центрам, партнерам, менеджерам и площадкам, вычисляя пропорциональную долю затрат для каждого заказа.

## Ключевые процедуры

### ObjectModule

- `ОбработкаПроведения()` -- делегирует в `Лико_Планирование.РаспределениеПрочихЗатратПоЗаказам(ссылка, Отказ)`.

### ManagerModule

Стандартные процедуры печати, отчетов и версионирования -- все с пустым телом.

### Форма документа

- `ЗаполнитьПоВыручкеНаСервере()` -- основной алгоритм распределения:
  1. Запрос к оборотному регистру `ВыручкаИСебестоимостьПродаж` за период документа
  2. Соединение со строками затрат из ТЧ `ЗатратыКРаспределению` с гибкими условиями: Партнер, Менеджер, Площадка, РабочийЦентр, Заказ (каждое поле может быть пустым -- тогда условие ИСТИНА, т.е. без фильтрации)
  3. Расчет доли каждой строки затрат пропорционально доле выручки заказа в общей выручке
  4. Загрузка результата в ТЧ `Затраты`
- `ПриСозданииНаСервере()` -- инициализация подключаемых команд.

## ТЧ документа

- `ЗатратыКРаспределению` -- исходные статьи затрат с аналитикой (Партнер, Менеджер, Площадка, РабочийЦентр, Заказ)
- `Затраты` -- результат распределения после заполнения по выручке

## Используемые модули

- `Лико_Планирование` -- распределение прочих затрат по заказам
- `ПодключаемыеКоманды` -- стандартная подсистема

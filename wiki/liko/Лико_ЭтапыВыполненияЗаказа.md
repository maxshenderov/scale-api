# Лико_ЭтапыВыполненияЗаказа

> Справочник этапов выполнения заказа. Классификатор статусов и этапов жизненного цикла производственного заказа.

## Что делает

Определяет этапы через которые проходит заказ клиента: от создания до отгрузки. Каждый этап имеет настраиваемые флаги для отслеживания, количественного учёта и позиционирования.

## Реквизиты

| Реквизит | Тип | Описание |
|---|---|---|
| КоличественныйПоказатель | Булево | Этап имеет количественный показатель |
| ДоПечати | Булево | Этап выполняется до печати |
| СтатусЗаказаID | Число | ID связанного статуса заказа |
| IDМеста | Число | ID позиции/места |
| Отслеживание | Булево | Требуется отслеживание этапа |

## Использование

Этапы используются при создании полуфабрикатов (дочерних заказов) через `Лико_СоздатьЗаказНаполуфабрикат()` в ManagerModule документа [[ЗаказКлиента]]. Определяют какие этапы нужны для оснастки и гравировки.

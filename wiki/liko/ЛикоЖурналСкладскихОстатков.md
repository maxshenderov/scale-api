# ЛикоЖурналСкладскихОстатков

> Журнал движений товаров по складу — показывает обороты регистра `ТоварыВЯчейках` с фильтрацией по номенклатуре, партии, нарезке, втулке, складу и заказу.

## Что делает
Отображает историю складских операций в выбранном периоде. Фильтры: дата начала/окончания, номенклатура, номер поставки, нарезка, втулка, рабочий центр (ячейка), организация, заказ клиента. Поддерживает сканер штрихкодов для быстрого поиска по ШК объекта номенклатуры или адреса.

Формирует два списка:
1. **Список** — строки движений (приход/расход) по регистру `ТоварыВЯчейках.Обороты`
2. **СписокПартии** — партии объектов номенклатуры (при включённом фильтре по номеру поставки)

## Ключевые процедуры
- `СформироватьНаСервере()` — основной запрос к `ТоварыВЯчейках.Обороты` с разбором вида операции через `ВЫБОР КОГДА` (Поступление, Закрытие заказа, Передача, Возврат, Расход, Пересчет, Перемещение). Связывает с `ЯССМ_ОбъектыНоменклатуры` для нарезки/втулки/номера поставки
- `СформироватьПартииСервер()` — отдельный запрос для отображения партий из `ЯССМ_ОбъектыНоменклатуры` и `Лико_ПартииПроизводства`
- `СписокВыбор()` — при выборе строки открывает документ-регистратор
- `ОбработатьШтрихкоды()` — обработка ШК: по ШК объекта номенклатуры заполняет фильтры и переформировывает список
- `ПриСозданииНаСервере()` — устанавливает период (начало/конец года), заполняет реквизиты шапки через `Лико_ОбщегоНазначенияСервер.РеквизитыШапки()`

## Используемые модули
- `Лико_ДополнительноКлиент` — обработка штрихкодов не-товара
- `Лико_Дополнительно` — получение значений реквизитов объектов
- `Лико_ОбщегоНазначенияСервер` — реквизиты шапки

# ЛикоРаспределениеРасходовПоЭтапам

> Документ распределения расходов по этапам производства. Создаёт документы `ВнутреннееПотребление` для списания материалов и распределяет оснастку со склада.

## Что делает

Основной документ закрытия месяца для распределения материалов и оснастки:
- При проведении создаёт/редактирует документ `ВнутреннееПотребление` (списание товаров по требованию) с заполнением статей расходов из номенклатуры или предопределённых значений.
- При проведении вызывает `ПроведениеДокументов.ОбработкаПроведенияДокумента` и формирует набор записей распределения.
- В форме: при ручном запуске «Распределить оснастку» загружает остатки со склада оснастки в ТЧ `ОбщийРасходМатериалов` и `ТаблицаРаспределения` с учётом FIFO-серий и сдвига периода.
- ManagerModule заполняет параметры инициализации для движений: период, склад, получатель, складская операция.

## Ключевые процедуры

- `Лико_СоздатьРедактироватьСписание(РежимЗаписи, Отказ)` (вместо `СоздатьРедактироватьСписание`, ObjectModule) — создаёт/находит документ `ВнутреннееПотребление`, заполняет реквизиты (Организация, Подразделение, Склад, Дата = конец месяца), сворачивает ТЧ по номенклатуре, устанавливает `ХозяйственнаяОперация = СписаниеТоваровПоТребованию`, заполняет статью расходов из `Лико_СтатьяРасходов` номенклатуры или `Лико_МастерНастройкиСтатьиРасходаДляНоменклатуры`. Проводит документ, ошибка отменяет транзакцию.
- `Лико_ОбработкаПроведения(Отказ, РежимПроведения)` (вместо `ОбработкаПроведения`) — вызывает `ПроведениеДокументов.ОбработкаПроведенияДокумента(ЭтотОбъект, Отказ)` и `СозатьНаборЗаписейРаспределения(Отказ)`.
- `Лико_РаспределитьОснастку()` (вместо `РаспределитьОснастку`, форма) — для `ВидРаспределения = РаспределениеОснастки`. Два варианта запроса: для ордерной схемы склада (с проверкой организации через серии) и без ордерной. Загружает остатки в ТЧ. Автор: m.shenderov, 28.06.2018.
- `Лико_ЗаполнитьПараметрыИнициализации(Запрос, ДокументОбъект)` (вместо `ЗаполнитьПараметрыИнициализации`, ManagerModule) — читает реквизиты документа (Дата→Период, Склад, Получатель) и устанавливает их как параметры запроса для движений.

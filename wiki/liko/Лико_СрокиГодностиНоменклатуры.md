# Лико_СрокиГодностиНоменклатуры

> Регистр сведений: сроки годности (в днях) номенклатуры в разрезе площадок. Периодический, используется для контроля годности при складских операциях.

## Что хранит
Для каждой комбинации Площадка + Номенклатура хранится срок годности в днях. Используется СрезПоследних для получения актуального срока на дату.

## Измерения
- **Площадка** — производственная площадка/склад
- **Номенклатура** — элемент справочника Номенклатура
- **СрокГодности** — срок годности в днях (ресурс?)

## Ключевые процедуры
- `Контролировать(Площадка, Номенклатура, Дата)` — возвращает срок годности (число) для одной позиции номенклатуры на указанной площадке и дате. Использует СрезПоследних.
- `СрокГодностиНоменклатуры(Площадка, Номенклатура, Дата)` — возвращает Соответствие (Номенклатура -> СрокГодности) для списка номенклатуры. Для номенклатуры без записи возвращает 0.

# ТС_Инструкции

> Справочник инструкций и тестов подсистемы ТОиР (техническое обслуживание и ремонт). Доработка — загрузка файлов инструкций в скан-архив, просмотр PDF и изображений, поддержка Google Forms тестов.

## Что делает / Доработки
- **Хранение инструкций и тестов** для операторов рабочих центров. Каждый элемент имеет тип: `Инструкция` или `Тест` (перечисление `ТС_ТипыИнструкцийИТестов`).
- **Расширение формы элемента** (`ФормаЭлементаУПР`):
  - **Загрузка файла инструкции**: при добавлении файла он копируется в каталог скан-архива инструкций (`СА_Настройки.КаталогСканАрхиваИнструкций`). Путь формируется как `[Код]_[Наименование].[Расширение]`.
  - **Автонумерация кода**: при записи без кода вызывается `УстановитьНовыйКод()`.
  - **Проверка заполнения**: перед записью обязательно должен быть указан путь к файлу.
- **Расширение формы просмотра** (`ФормаПросмотраУпрТС`):
  - **Просмотр PDF**: через внешний HTTP-просмотрщик PDF.
  - **Просмотр изображений**: через `Новый Картинка()` с помещением во временное хранилище.
  - **Просмотр Google Forms тестов**: для типа `Тест` формируется URL с параметрами теста, открывается в HTML-поле формы.
  - **Разворот на весь экран** через `Лико_ДополнительноКлиент.РазвернутьОкноФормыНаВесьЭкран()`.
- **Расширение формы выбора** (`ФормаВыбораУпрТС`): закомментированная логика проверки непрочитанных инструкций через регистр `ТС_ЖурналОзнакомленияСИнструкциями`.

## Ключевые процедуры
- `Лико_ДбавитьФайлПосле(Команда)` — на клиенте, выбор файла и просмотр для типа Инструкция
- `Лико_ПередЗаписьюВместо(Отказ, ПараметрыЗаписи)` — копирование файла в архив + автонумерация
- `Лико_ПолучитьКорневойАдресНаСервере()` — путь к каталогу скан-архива из `СА_Настройки`
- `Лико_ПросмотрКартинки()` — просмотр PDF/изображений/Google Forms тестов
- `Лико_РазвернутьОкноФормыНаВесьЭкранКлиент()` — разворот на весь экран

# Лико_КонтрольСроковГодностиНоменклатуры

> Регламентный документ — устанавливает сроки годности, административные сроки и сроки уведомления по номенклатуре в разрезе площадок.

## Что делает

Управление сроками годности номенклатуры. Документ содержит две табличные части:
- **Площадки** — перечень площадок, для которых действуют сроки.
- **Товары** — список номенклатуры с полями: `СрокГодности`, `СрокГодностиАдминистративный`, `СрокУведомления`.

При проведении формирует движения по регистру сведений `Лико_СрокиГодностиНоменклатуры`. Для каждого товара и каждой площадки создаётся запись с индивидуальными сроками (если указаны в строке) или общими (из шапки документа).

## Ключевые процедуры

- `ОбработкаПроведения()` — для каждой пары Площадка x Товар создаёт запись в `Лико_СрокиГодностиНоменклатуры`. Если срок в строке = 0, берёт значение из шапки документа.

### ManagerModule

- `РассылкаВыполнена()` — обработчик события рассылки: находит последний проведённый документ по рассылке, определяет площадки и вызывает отметку уведомлений (`ОтметитьУведомлениеУОбъектовНоменклатуры`).
- `ОтметитьУведомлениеУОбъектовНоменклатуры()` — для номенклатуры, у которой прошёл срок уведомления, проставляет реквизит `УведомлениеОтправлено` на объектах номенклатуры (`ЯССМ_ОбъектНоменклатуры`).
- `НеотмеченныеОбъекты()` — сложный запрос: по регистру `Лико_СрокиГодностиНоменклатуры` и остаткам `ТоварыВЯчейках` находит объекты номенклатуры, у которых `ДатаУведомления <= ТекущаяДата` и `УведомлениеОтправлено` не заполнено.

# СА_УправлениеСканАрхивом

> Расширение типовой обработки сканированного архива (СканАрхив). Добавляет Лико-специфичную логику: замена СчетФактурыВыданный на Реализацию, навигация по разделам, проверка организаций.

## Что делает
Расширяет типовую обработку `СА_УправлениеСканАрхивом` с использованием `&Вместо`:

### ObjectModule (Ext/ObjectModule.bsl)
Закомментированный код, который ранее переопределял `НайтиДокументПоЗначениюШтрихКода` с расширенным списком менеджеров объектов для поиска документов по ШК (Реализация, Приобретение, Сверка, СчетФактура, ЗаказКлиента, ТранспортнаяНакладная и др.).

### Form Module (ФормаУправляемая)
- `Лико_ЭтоСчетФактура()` — `&Вместо("ЭтоСчетФактура")`, проверяет принадлежность организации к Ликофлекс/ИксПак/Авантаж
- `Лико_ОбработатьВыборРаздела()` — `&Вместо("ОбработатьВыборРаздела")`, подсветка активного раздела оранжевым, очистка сеансов при переходе в ЖурналСеансов
- `Лико_ЗаменитьСчетФактуруНаРеализацию()` — замена СчетФактурыВыданный на документ-основание (Реализацию) во всех образах
- `ЗаменитьСчетФактуруВыданный()` — для каждого образа, где объект = СчетФактураВыданный, заменяет ссылку на `ДокументОснование`

## Ключевые процедуры
- `Лико_ЭтоСчетФактура(Док)` — проверка: документ это СчетФактураВыданный, не корректировочный, организация из списка
- `ЗаменитьСчетФактуруВыданный()` — обход `Объект.Образы`, замена ссылок СчетФактура -> Реализация
- `Лико_ОбработатьВыборРаздела()` — стилизация разделов + логика обновления сеансов

## Используемые модули
- `Лико_Дополнительно` — значение реквизита объекта
- `СА_ПроцедурыСканАрхиваКлиент` — прикрепление серии к последнему

# Лико_СкладыКлиент

> Клиентские складские операции: заполнение упаковки по характеристике, открытие форм номенклатуры и серий, отчёт по остаткам.

## Что делает
Клиентский модуль для работы со складскими формами. При изменении характеристики в табличной части автоматически заполняет упаковку через нарезку. Предоставляет обработчики клика по серии и объекту номенклатуры с открытием соответствующих форм. Позволяет открыть отчёт по остаткам товаров (ЛикоОстаткиТоваров) с настроенными отборами по номенклатуре и нарезке.

## Ключевые процедуры
- `ЗаполнениеУпаковкиПоХарактеристики(Форма, Элемент)` — при изменении Характеристики получает нарезку и заполняет Упаковку.
- `ПоказатьФормуОбъектаНоменклатуры(Элемент, ВыбраннаяСтрока, Поле, СтандартнаяОбработка, Имя)` — открывает форму элемента ЯССМ_ОбъектыНоменклатуры или СерииНоменклатуры по клику.
- `ОткрытьОтчетПоОстаткам(ТекСтр)` — открывает отчёт ЛикоОстаткиТоваров с отборами по Номенклатуре и Нарезке из текущей строки.

## Используется в
- Формы с табличной частью Товары (подбор упаковки)
- Складские отчёты

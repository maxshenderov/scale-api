# ПорядокОтраженияНаСчетахУчета

> Типовой регистр сведений (непериодический, независимый) — настройка счетов учёта для статей доходов/расходов. Расширение добавляет проверку прав на изменение счетов.

## Тип регистра
**Непериодический** (`Nonperiodical`), **Независимый** (`Independent`). Типовой регистр конфигурации, расширенный доработкой Лико.

## Измерения
- **Организация** (`CatalogRef.Организации`) — организация (мастер-измерение)
- **АналитикаУчета** (`ОпределяемыйТип.НастройкаСчетовУчетаАналитикаУчета`) — аналитика учёта
- **МестоУчета** (`ОпределяемыйТип.НастройкаСчетовУчетаМестоУчета`) — место учёта
- **ВидСчета** (`EnumRef.ВидыСчетовРеглУчета`) — вид счёта (денежные средства и др.)
- **Долгосрочный** (`Булево`) — признак долгосрочности

## Ресурсы
- **СчетУчета** (`ChartOfAccountsRef.Хозрасчетный`) — счёт учёта
- **Субконто** (`ChartOfCharacteristicTypesRef.СтатьиРасходов` / `СтатьиДоходов`) — субконто
- **ОтноситсяКМалоценнымТМЦ** (`Булево`) — признак малоценных ТМЦ

## Ключевые процедуры (из расширения)

### RecordSetModule — `&После("ПередЗаписью")`
```bsl
Процедура Лико_ПередЗаписью(Отказ, Замещение)  // --> Маковеева А.Ю. 04.05.2023
    ЕстьПравоИзмененияСчетовВСтатьях = РольДоступна("Лико_ИзменениеСчетаУчетаВСтатьяхДоходовИРасходов")
        Или РольДоступна("ПолныеПрава");
    Для Каждого Стр Из ЭтотОбъект Цикл
        Если НЕ (ЕстьПравоИзмененияСчетовВСтатьях
            Или Стр.ВидСчета = Перечисления.ВидыСчетовРеглУчета.ДенежныеСредства
            Или ТипЗнч(Стр.АналитикаУчета) = Тип("ПланВидовХарактеристикСсылка.СтатьиРасходов")
                И Стр.АналитикаУчета.ВариантРаспределенияРасходовРегл = Перечисления.ВариантыРаспределенияРасходов.НаРасходыБудущихПериодов) Тогда
            Отказ = Истина;
        КонецЕсли;
    КонецЦикла;
КонецПроцедуры
```

**Логика**: ограничивает изменение счетов учёта для статей доходов/расходов. Разрешено:
- Пользователям с ролью `Лико_ИзменениеСчетаУчетаВСтатьяхДоходовИРасходов` или `ПолныеПрава`
- Для денежных средств (`ВидыСчетовРеглУчета.ДенежныеСредства`)
- Для расходов будущих периодов

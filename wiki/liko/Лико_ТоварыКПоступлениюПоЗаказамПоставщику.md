# Лико_ТоварыКПоступлениюПоЗаказамПоставщику

> Регистр накопления остатков: отслеживает ожидаемое поступление товаров по заказам поставщикам (обычные заказы, НЕ предзаказы).

## Что хранит

Остатки товаров к поступлению: документ `ЗаказПоставщику` формирует Приход (сколько заказано), документы `ПриходныйОрдерНаТовары` и `ПриобретениеТоваровУслуг` формируют Расход (сколько фактически поступило). Остаток = сколько еще ожидается к поступлению.

## Регистраторы

`Документ.ПриобретениеТоваровУслуг`, `Документ.ЗаказПоставщику`, `Документ.ПриходныйОрдерНаТовары`

## Ключевые процедуры

- `Проведение(ДокументОбъект)` / `СформироватьДвижения(ДокументСсылка)` — стандартные обработчики проведения через `ПолучитьДвиженияПоДокументу`.

- `ПолучитьДвиженияПоДокументу(Ссылка, Движения)` — диспетчер, вызывает три частных процедуры:
  - `ПолучитьДвиженияПоДокументуЗаказПоставщику` — Приход, сумма Количество по ТЧ `Товары`, фильтр `Лико_Предзаказ = ЛОЖЬ`
  - `ПолучитьДвиженияПоДокументуПриходныйОрдер` — Расход, сумма Количество по ТЧ `Товары`, фильтр: распоряжение — ЗаказПоставщику И НЕ предзаказ
  - `ПолучитьДвиженияПоДокументПриобретениеТоваровИУслуг` — Расход, сумма Количество по ТЧ `Товары`, фильтр: склад без ордерной схемы

- `ПроверкаНаОшибки(Движения, Документ)` — если движения не сформированы, выбрасывает исключение.

## Отличие от Предзаказов

Этот регистр — для **обычных** заказов поставщику (`Лико_Предзаказ = ЛОЖЬ`). Для предзаказов используется отдельный регистр [[Лико_ТоварыКПоступлениюПоПредзаказамПоставщику]].

# ЗакрытиеЗаказов

> Отчет «Закрытие заказов» — полностью переопределяет стандартную компоновку, строит табличный документ вручную через `ПроцессорКомпоновкиДанных`.

## Что делает

Отключает стандартную обработку (`СтандартнаяОбработка = Ложь`), очищает документ результата и вручную выполняет полный цикл компоновки:
1. Получает настройки из `КомпоновщикНастроек`
2. Выполняет макет через `КомпоновщикМакетаКомпоновкиДанных`
3. Инициализирует `ПроцессорКомпоновкиДанных`
4. Выводит результат через `ПроцессорВыводаРезультатаКомпоновкиДанныхВТабличныйДокумент`

Выполняется в привилегированном режиме.

## Ключевые процедуры

- `ПриКомпоновкеРезультата()` — единственная процедура. Отключает стандартную обработку, очищает результат, вручную проходит весь цикл: Макет -> Процессор компоновки -> Процессор вывода -> Табличный документ.

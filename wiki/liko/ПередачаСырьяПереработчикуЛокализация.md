# ПередачаСырьяПереработчикуЛокализация

> Переопределение временной таблицы товаров: суммирование из ТЧ `ВидыЗапасов` вместо `Товары` для `ПередачаСырьяПереработчику`.

## Что делает
Расширяет типовую процедуру `ПоместитьВременнуюТаблицуТоваров` (аннотация `&Вместо`). Для документа `ПередачаСырьяПереработчику` заменяет источник данных: вместо табличной части `Товары` использует `ВидыЗапасов` с группировкой по ссылке, номенклатуре, характеристике, серии, упаковке и НомерГТД. Суммирует `ЗалоговаяСтоимость` как СуммаБезНДС (вместо типового расчёта через СуммыДокументовВВалютахУчета).

## Ключевые процедуры
- `Лико_ПоместитьВременнуюТаблицуТоваров(МенеджерВременныхТаблиц, ПараметрыЗаполнения)` — формирует временную таблицу товаров из `ПередачаСырьяПереработчику.ВидыЗапасов` с группировкой и суммированием. Использует `ЗалоговаяСтоимость` как базу для суммы без НДС.

## Используется в
- Печатные формы документа ПередачаСырьяПереработчику

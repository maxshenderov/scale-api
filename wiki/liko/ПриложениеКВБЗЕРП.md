# ПриложениеКВБЗЕРП

> Внешняя печатная форма «Приложение к внутреннему бланку заказа» для документа `ЗаказКлиента`. Генерирует подробный производственный лист с цветами, видами работ, перемоткой, параметрами штампа и штрихкодом.

## Что делает
Печатная форма (вид `ПечатнаяФорма`), подключается к `Документ.ЗаказКлиента`. Формирует 2 листа:
- **Лист 1** — шапка с параметрами заказа, таблица видов работ, таблица цветов (до 16 строк), таблица перемотки, подвал с метрами на настройку/брак по прокатам
- **Лист 2** — краткая информация + штрихкод заказа

Особая логика для типа заказа «Термоусадка»: отдельные макеты областей, коэффициент перемотки, максимальный диаметр рулона, параметры ТУ (ширина рукава, перфорация, поперечная резка).

Для `Indigo` (цифровая печать): расчёт длины печати через раппорт, площади печати, количества этикеток в раппорте.

## Ключевые процедуры/функции
- `ПечатьПриложениеВБЗ()` — основной метод, возвращает табличный документ. Собирает данные заказа, заполняет макет, выводит цвета/виды работ/перемотку/подвал
- `Печать(МассивОбъектовНазначения, ...)` — экспортная процедура для команд печати
- `ПолучитьТабДокЦвета()` — формирует таблицу цветов (до 16) с типом краски, процентом заливки, цветоделением
- `ПолучитьТабДокПеремотка(Заказ)` — таблица перемотки с картинками направлений намотки
- `ВыборкаПеремотка()` — запрос к `ЗаказКлиента.Товары`, группировка по диаметру/направлению/кромке
- `ПолучитьКоэффициентПеремотки()` — расчёт коэффициента по ручьям, диаметру, способу наклейки, ценовой группе
- `СведенияОВнешнейОбработке()` — регистрация как `ПечатнаяФорма` для `Документ.ЗаказКлиента`

## Связь с ЗаказКлиента
Печатается из документа `ЗаказКлиента`. Использует ТЧ `Товары`, `ВидыРабот`, `Цвета`. Читает `Лико_ПараметрыПроизводстваЗаказа` для метров на настройку/брак.

# Лико_ДополнительноКлиент

> Клиентский модуль дополнительных утилит — управление окнами, штрихкоды, запуск форм.

## Что делает

Клиентская часть утилитарного модуля. Управляет окнами форм, штрихкодами и автозапуском обработок при старте системы.

## Ключевые процедуры

- `ОбработатьШтрихКодНеТовара(Штрихкод)` — делегирует обработку на сервер через [[Лико_Дополнительно]]
- `ОткрытьДругуюФормуОбработки(ФормаВладелец, ИмяДругойФормы, ...)` — открывает форму в контексте той же обработки (строит путь по имени формы-владельца)
- `ОткрытьОбработкуПриНачалеРаботыСистемы()` — открывает обработки рабочего места при старте 1С (только тонкий клиент)
- `ДобавитьВЗаголовокСистемыИмяБазы()` — добавляет имя базы к заголовку окна системы
- `УстановитьРежимОсновногоОкна()` — устанавливает режим основного окна по настройкам рабочего места
- `РазвернутьОкноФормыНаВесьЭкран()` — разворачивает форму через WScript.Shell SendKeys (% → UP→UP→ENTER)
- `ВосстановитьОкноФормы()` — восстанавливает окно (SendKeys `%+R`)
- `ПочиститьШтрихкодыОтЗапрещенныхСимволов(МассивШтрихкодов)` — удаляет символ(29) из строк штрихкодов (GS — Group Separator)

## Особенности

- `РазвернутьОкноФормыНаВесьЭкран()` использует COM-объект `WScript.Shell` — работает только на Windows-клиенте
- Обходной путь для оборудования: перед открытием формы с `РазвернутьОкноФормыНаВесьЭкран` нужно отключить scanner (keyboard emulation) через `МенеджерОборудованияКлиентПереопределяемый`, иначе первые нажатия клавиш путаются со штрихкодом

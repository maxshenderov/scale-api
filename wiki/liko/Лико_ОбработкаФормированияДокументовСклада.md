# Лико_ОбработкаФормированияДокументовСклада

> Форма РасходногоОрдераНаТовары — управление статусами, отбором, упаковкой и отгрузкой товаров со склада.

## Что делает

Основная форма документа `РасходныйОрдерНаТовары` (~2178 строк). Управляет полным циклом складской отгрузки:

- **Статусная модель**: КОтбору -> Подготовлено -> КПроверке -> Проверен -> КОтгрузке -> Отгружен.
- **Две табличные части**: `ТоварыПоРаспоряжениям` (план отгрузки по распоряжениям) и `ОтгружаемыеТовары` (фактически отгружаемое).
- **Заполнение по распоряжениям**: автоматическое заполнение `ОтгружаемыеТовары` из `ТоварыПоРаспоряжениям` с разбивкой по упаковкам.
- **Заполнение по отобранным товарам**: при смене статуса заполняет фактически отобранные товары из складских документов отбора.
- **Штрихкодирование**: сканирование штрихкодов номенклатуры, серий, упаковочных листов.
- **Упаковочные листы**: создание, навигация по уровням (товар -> коробка -> палета), упаковка/распаковка.
- **Серии**: подбор серий (включая FEFO), указание серий для отгружаемых товаров.
- **Проверка/исправление количества**: открытие форм проверки упаковки и корректировки количества.
- **Перенос строк**: перенос выбранных строк в новый или существующий расходный ордер.
- **Адресное хранение**: поддержка адресного склада (помещения, ячейки).
- **Задание на перевозку**: привязка к заданию на перевозку, управление порядком доставки.
- **Сортировка**: сортировка строк по возрастанию/убыванию выбранной колонки.

## Ключевые процедуры

- `ПриСозданииНаСервере()` — инициализация формы, настройка оборудования, условное оформление, статусы серий.
- `ПриОткрытии()` — подключение сканера штрихкодов, кеширование статуса, запуск обработчика ожидания.
- `СтатусПриИзменении(Элемент)` — клиентский обработчик смены статуса с проверкой возможности изменения.
- `СтатусПриИзмененииСервер()` — серверная логика: заполнение по отобранным товарам, обновление даты отгрузки, доступность.
- `ЗаполнитьПоРаспоряжениям()` — заполнение `ОтгружаемыеТовары` из `ТоварыПоРаспоряжениям`, разбивка по упаковкам, заполнение серий по FEFO.
- `ЗаполнитьПоОтобраннымТоварам()` — заполнение фактически отобранных товаров из документов отбора.
- `ОбработатьШтрихкоды()` — обработка отсканированных штрихкодов.
- `Упаковать()` / `Распаковать()` — управление упаковочными листами.
- `РазбитьСправочноПоУпаковкам()` — разбивка строк по упаковкам номенклатуры.
- `ПроверитьКоличество()` / `ИсправитьКоличество()` — проверка и исправление количества через отдельные формы.
- `ПеренестиВНовыйОрдер()` / `ПеренестиВСуществующийОрдер()` — перенос строк между расходными ордерами.
- `ЗаполнитьСерииПоFEFO()` — автоматическое заполнение серий по принципу FEFO.
- `УказатьСерии()` — ручное указание серий для выбранной строки.
- `ПерезаполнитьОтгружаемымиТоварами()` — перезаполнение табличной части.

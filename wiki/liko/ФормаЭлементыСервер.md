# ФормаЭлементыСервер

> Серверные утилиты для динамического создания таблиц на управляемых формах.

## Что делает
Модуль предоставляет инструменты для программного создания элементов форм типа «ТаблицаФормы» на управляемых формах. Позволяет динамически создавать реквизиты формы (ТаблицаЗначений с колонками), строить табличный элемент формы с полями ввода для каждой колонки, а также задавать свойства «заглушки» для выравнивания таблиц в ряд. Используется модулем [[ПланированиеСервер]] для рендеринга плана работ.

## Ключевые процедуры
- `СоздатьРеквизитФормыТЗ()` — создаёт реквизит формы типа ТаблицаЗначений с колонками по структуре переданной ТЗ; удаляет старый реквизит при необходимости и присваивает значение
- `СоздатьЭлементФормыТаблица()` — удаляет существующий элемент таблицы и создаёт новый с колонками-полями для каждой колонки ТЗ
- `ПолучитьЭлементФормыТаблица()` — то же, что и СоздатьЭлементФормыТаблица, но возвращает созданный элемент
- `УстановитьСвойстваДляТаблицыЗаглушка()` — для таблиц с именем начинающимся на «Заглушка» скрывает шапку, подвал, заголовки и закрашивает фон цветом рамки

## Используется в
- [[ПланированиеСервер]] — рендеринг таблиц плана БЭ
- Все формы с динамическим построением таблиц

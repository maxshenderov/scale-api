# Лико_АвтоРасчетЦенЦГ

> Регистр сведений (периодический, посекундный) — управление флагом автоматического расчёта цен для ценовых групп по организациям.

## Тип регистра
**Периодический** (`Second`), **Независимый** (`Independent`). Периодичность — посекундная, что позволяет точно отслеживать моменты включения/выключения авторасчёта.

## Измерения
- **Организация** (`CatalogRef.Организации`) — организация (главный фильтр)
- **ЦеноваяГруппа** (`CatalogRef.ЦеновыеГруппы`) — ценовая группа (главный фильтр)

## Ресурсы
- **АвтоРасчет** (`Булево`) — признак автоматического расчёта цены для данной организации и ценовой группы

## Ключевые процедуры (из расширения)

### ManagerModule — `&Вместо("Установить")`
```bsl
Процедура Лико_Установить(ЦеноваяГруппа, Знач Период, АвтоРасчет)
```
Для каждой организации из списка `ОрганизацииАвтоРасчета()`:
- Проверяет через `Установлен()`, не совпадает ли текущее значение
- Если значение отличается — создаёт набор записей с отбором по Организация, ЦеноваяГруппа, Период
- Записывает новое значение `АвтоРасчет` с привилегированным режимом

Используется регистром [[Лико_СтоимостьЦеновыхГрупп]] для фильтрации ценовых групп с авторасчётом при поступлении товаров.

# Лико_ПараметрыПечатиКлиентаДляУпаковки

> Справочник параметров печати, задаваемых клиентом для конкретного вида упаковки. Привязывает партнёра к параметрам печати упаковки.

## Что хранит

- Партнер (контрагент) — клиент, для которого настраиваются параметры
- Наименование — автоформируемое (подтягивается из наименования партнёра)
- Параметры печати для упаковки (цветность, секции, покрытия, и т.п.)

## Ключевые процедуры

### ФормаЭлемента
- `ПартнерПриИзменении(Элемент)` — при выборе партнёра автоматически заполняет Наименование через `Лико_Дополнительно.ЗначениеРеквизитаОбъекта(Партнер, "Наименование")`

## Связи

- [[Лико_Дополнительно]] — используется для получения реквизита партнёра
- Справочник `Партнеры` (типовой) — клиенты
- [[Лико_ПараметрыРасчетаНормативов]] — смежный справочник нормативов печати

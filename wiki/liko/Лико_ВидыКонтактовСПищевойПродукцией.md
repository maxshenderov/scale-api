# Лико_ВидыКонтактовСПищевойПродукцией

> Справочник видов контакта упаковки с пищевой продукцией. Классификатор для маркировки безопасности пищевой упаковки.

## Что хранит

Классификацию контакта упаковки с пищевыми продуктами: прямой, непрямой, без контакта.

**Предопределенные значения:**
- `ПрямойКонтакт` — Прямой контакт
- `НепрямойКонтакт` — Непрямой контакт
- `НетКонтакта` — Без контакта
- `НетКонтактаСКонтролемСрокаГодности` — Без контакта (с контролем срока годности)

Каждый элемент имеет реквизит `ФайлКартинки` — присоединенное изображение-иллюстрация вида контакта.

## Ключевые процедуры

Формы справочника реализуют работу с изображениями:
- Добавление, просмотр, редактирование, очистка изображения
- Выбор изображения из присоединенных файлов
- `СписокПриАктивизацииСтроки()` — загрузка навигационной ссылки на изображение при выборе строки списка
- `ПриСозданииЧтенииНаСервере()` — восстановление ссылки на изображение при открытии

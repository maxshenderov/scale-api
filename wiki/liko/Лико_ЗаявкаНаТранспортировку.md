# Лико_ЗаявкаНаТранспортировку

> Главный документ склада готовой продукции — собирает коробки по сериям/паллетам для отгрузки и автоматически генерирует цепочку типовых документов (реализации, ТН, перемещения, ордера).

## Что делает

Ключевой документ складской логистики. Формируется на основании заявок на отгрузку (`Лико_ЗаявкаНаОтгрузку`). Оператор подбирает конкретные коробки (серии, паллеты) со стеллажей. При проведении в статусе «Закрыт» автоматически создаёт цепочку типовых документов:

- `ОтборРазмещениеТоваров` (перемещение по адресному складу)
- `РеализацияТоваровУслуг` (продажа клиенту)
- `ТранспортнаяНакладная`
- `СчетФактураВыданный`
- `ПеремещениеТоваров`
- `Лико_ПередачаТоваровМеждуОрганизациями`
- `АктВыполненныхРабот`
- `ПриемкаТоваровНаХранение` / `ОтгрузкаТоваровСХранения`

Также: движения по адресному хранению (`Лико_АдресноеХранение`), записи в `Лико_ЭтапыЗаказа` (этап «Отгрузка»), движения по `Лико_СтоимостьДоставки` и `Лико_ЗатратыПоЗаказу`.

## Ключевые процедуры

- `ОбработкаПроведения()` — основная логика: адресное хранение, движения по заявкам на отгрузку, этапы заказа, стоимость доставки, создание типовых документов.
- `СоздатьТиповыеДокументы()` — оркестратор создания всей цепочки: помечает старые на удаление, создаёт перемещения, реализации, счета-фактуры, ТН и т.д.
- `СоздатьДокументРеализацияТоваровУслуг()` — создаёт/перезаполняет реализацию: подбирает договор, привязывает оплаты.
- `СоздатьДокументТраспортнаяНакладная()` — создаёт/обновляет транспортную накладную с данными перевозчика.
- `СоздатьДокументОтборРазмещениеТоваров()` — создаёт ордер на перемещение по адресному складу.
- `СформироватьТаблицуСерий()` — сопоставляет товары без серий с фактическими сериями на складе.
- `СформироватьТаблицуДляСозданияРеализаций()` — группирует данные для создания реализаций (по контрагентам, валютам, складам).
- `ПриКопировании()` — сбрасывает Статус, грузоотправителя, диспетчера, ШК.
- `СоздатьШтрихкод()` — генерирует ШК документа.
- `ПересчитатьПодобранноеКоличество()` — пересчитывает количество из серий.
- `РассчитатьСтоимостьДоставки()` / `РассчитатьОбщийВесКоробок()` — расчёт стоимости и веса.

### ManagerModule

- `РассчитатьВесКоробокДляТаблицыСерий()` — вычисляет суммарный вес коробок по переданной таблице серий.

# Лико_ЗадачаОтделуРазработки

> Задача для отдела разработки. Интеграция с внешней системой СУП (SMP) через HTTP. Отправляет задачу в формате JSON по API при нажатии кнопки «Отправить в СУП».

## Что делает

- Не содержит серверных модулей (ObjectModule/ManagerModule пустые)
- Вся логика в форме документа (`ФормаДокумента`)
- Кнопка «ОтправитьВСУП» отправляет JSON с реквизитами задачи во внешнюю систему
- Требует полные права для отправки
- Аутентификация через HTTP-соединение с параметрами из справочника `HTTPСервисы.SMP`
- API endpoint: `CreateTaskFromErp`

## Ключевые процедуры (форма)

- `ОтправитьВСУП()` — клиентская: проверяет модифицированность/запись, вызывает серверную
- `ОтправитьВСУПНаСервере()` — формирует JSON (UnId, Дата, Наименование, Автор, АвторПочта, Цель, ОписаниеПроцесса, ТЗ, Представление), отправляет HTTP POST, выводит ответ
- `ПолучитьПочтуПользователя(Пользователь)` — запрос к контактной информации пользователя

## Реквизиты

- `Наименование`, `Автор`, `Цель`, `ОписаниеПроцесса`, `ТЗ` — основные поля задачи

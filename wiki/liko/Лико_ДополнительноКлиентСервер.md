# Лико_ДополнительноКлиентСервер

> Общий клиент-серверный код — стандартное сообщение пользователю и проверка ролей.

## Что делает

Минимальный, но критичный модуль. Содержит функции, вызываемые и с клиента, и с сервера. Это главный способ вывода сообщений пользователю во всех Лико_-модулях.

## Ключевые процедуры

- `СообщитьДляКлиента(ТекстСообщения, СтатусСообщения="")` — универсальный вывод сообщений:
  - На клиенте: `СообщитьПользователю()`
  - На сервере: `ОбщегоНазначения.СообщитьПользователю()` или накапливает в БэкграундЗадаче
  - Статусы: Предупреждение, Ошибка, Информация (маппинг на `СтатусСообщения`)
- `КонкретнаяРольДоступна(ИмяРоли, Пользователь)` — проверка роли через SQL-запрос по группам доступа:
  - Поддерживает проверку для произвольного пользователя (не только текущего)
  - Запрос идёт через РС `ГруппыДоступаПользователей` и `ГруппыДоступа`

## Паттерн использования

```bsl
// Стандартная обработка ошибок в Лико_-модулях
Попытка
    // ... логика ...
Исключение
    Лико_ДополнительноКлиентСервер.СообщитьДляКлиента(
        "Ошибка: " + ОписаниеОшибки(), "Ошибка");
КонецПопытки;
```

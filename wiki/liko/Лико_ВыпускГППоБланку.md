# Лико_ВыпускГППоБланку

> Регистр сведений, фиксирующий выпуск готовой продукции по бланку этапа. Заполняется автоматически при закрытии бланка со статусом «Перемотка».

## Что хранит

- **Измерения:** Период, Регистратор (Лико_БланкЭтапа), Серия, ОбъектНоменклатуры
- **Ресурсы:** ЗаказКлиента, КоличествоВРолике, КоличествоРучьев, Количество, ЗакрытиеБланка
- Периодичность: по секундам, подчинение регистратору

## Ключевые процедуры

- `Записать(Регистратор)` — экспортная процедура, вызывает `ЗаписатьПоЗакрытиюБланка()`. Точка входа извне.
- `ЗаписатьПоЗакрытиюБланка(РегистраторОбъект)` — проверяет тип регистратора (`Лико_БланкЭтапа`) и статус выпуска (`Перемотка`). Если условия выполнены, формирует ТЗ из товаров бланка (серия, объект номенклатуры, заказ клиента, количество = шт * ручьи) и вызывает `СформироватьНаборЗаписей()`.
- `СформироватьНаборЗаписей(РегистраторОбъект, ТЗ)` — создает набор записей, заполняет из ТЗ, записывает.

## Связь с ЗаказКлиента

Выпуск ГП привязан к `ЗаказКлиента` через серию товара в бланке этапа. Количество рассчитывается как `КоличествоШт * КоличествоРучьев`.

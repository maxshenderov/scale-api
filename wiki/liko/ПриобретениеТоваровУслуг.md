# ПриобретениеТоваровУслуг (типовой, доработан)

> Подбор по приходным ордерам, расчет нарезки (погонные метры), учет курса валют для Лико. m.shenderov 2017-2023, Маковеева А.Ю. 2022-2023.

## Доработки

- **Подбор по приходным ордерам** -- кнопка `ЛикоПодборПоПриходныиОрдерам` и выбор `Лико_ПриходныйОрдер` в строке ТЧ работают через обработку `Лико_ЗаполнениеТЧПТУ`. После подбора строки с совпадающим ордером обновляются, новые добавляются с ценой из существующих строк.
- **Расчет нарезки** -- при изменении характеристики вычисляется `КоличествоПМ` (погонные метры) = `Количество / (Нарезка / 1000)`. Процедуры: `ОбновитьЗависимыеРеквизитыФормыПоЗаказу`, `ЗаполнитьСлужебныеРеквизитыПоНоменклатуре`, `ОбновитьНарезкуТовара`.
- **Курс валюты** -- `Лико_НадписьВалютыНажатиеЗавершение` сохраняет `Лико_Курс` из результата закрытия формы валюты (Маковеева А.Ю. 23.05.2022).
- **Условное оформление** -- строки с заполненным `Лико_ПриходныйОрдер` подсвечиваются зеленым (205, 255, 205).

## Ключевые процедуры

- `Лико_ЛикоПодборПоПриходныиОрдерамВместо(Команда)` -- подбор по ордерам (клиент).
- `Лико_ЗаполнитьПоОрдерамПослеЗавершение(ФормаРезультат, ФормаПараметры)` -- обработка результата подбора (клиент).
- `ОбновитьНарезкуТовара()` -- пересчет погонных метров для всех строк (сервер).
- `ПолучитьНарезкуСервер(Характеристика)` -- получение нарезки из `ЯССМ_Нарезка.Размер` (сервер).
- `Лико_ТоварыВыборПосле(Элемент, ВыбраннаяСтрока, Поле, СтандартнаяОбработка)` -- выбор приходного ордера (клиент).
- `Лико_НадписьВалютыНажатиеЗавершение(РезультатЗакрытия, ДополнительныеПараметры)` -- сохранение Лико_Курс (клиент).

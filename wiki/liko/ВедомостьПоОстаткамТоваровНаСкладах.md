# ВедомостьПоОстаткамТоваровНаСкладах

> Отчет «Ведомость по остаткам товаров на складах» — расширение с несколькими вариантами форм отчета.

## Что делает / Доработки
Расширяет типовой отчет ведомости по остаткам. Содержит несколько вариантов форм отчета (ФормаОтчета, ФормаОтчета1..5, ФормаОтчета4_0, ФормаОтчета4_1) — каждая с собственным BSL-модулем. Основной модуль (167902 байта) содержит полную логику инициализации компоновщика настроек, обработку расшифровок, сохранение ключа текущего варианта, параметры открытия формы.

## Ключевые процедуры (основная форма)
- `ПриСозданииНаСервере()` — инициализация компоновщика, определение режима расшифровки, загрузка ключа варианта, сохранение параметров формы
- Переменные: `ОбработчикПослеФормированияНаКлиенте`, `ВыполнятьЗамеры`, `ФормированиеПриОткрытии`

## Формы
- `ФормаОтчета` — основная (167902 байта)
- `ФормаОтчета1` .. `ФормаОтчета5` — варианты
- `ФормаОтчета4_0`, `ФормаОтчета4_1` — подварианты

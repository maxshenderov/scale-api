# Лико_СвойстваМатериала

> Классификатор свойств материалов — используется для маркировки и описания свойств номенклатуры.

## Что хранит
Простой справочник-классификатор. Содержит перечень свойств (признаков), которые можно назначить материалам/номенклатуре.

## Ключевые процедуры
- Модуль объекта пуст — вся логика стандартная, события не переопределены.
- Есть форма элемента с расширением (`ФормаЭлемента/Ext/Form/Module.bsl`).

## Связи
Скорее всего используется через регистры сведений для хранения значений свойств номенклатуры.

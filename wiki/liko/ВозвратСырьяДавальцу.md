# ВозвратСырьяДавальцу (типовой, доработан)

> Доработка Лико: очистка списка регистров для контроля при проведении (оставляет массив пустым).

## Доработки

- **Снятие контроля регистров** — при формировании списка регистров для контроля (после `СформироватьСписокРегистровДляКонтроля`) массив регистров очищается. Это отключает штатный контроль остатков при проведении.

## Ключевые процедуры

- `Лико_СформироватьСписокРегистровДляКонтроля()` (после `СформироватьСписокРегистровДляКонтроля`) — очищает `ДополнительныеСвойства.ДляПроведения.РегистрыДляКонтроля`, подменяя его пустым массивом.

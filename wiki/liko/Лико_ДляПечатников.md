# Лико_ДляПечатников

> Обработка — рабочее место печатника: печать нормативов, технологических карт для разных машин, заявка на склад, корректировка цветов.

## Что делает

Обработка предоставляет интерфейс для печатников производственных участков. По номеру заказа (7 символов) находит документ через `Лико_Дополнительно.НайтиДокументПоНомеру7Символов` и позволяет:

- Печатать нормативы
- Печатать технологические карты: Rotomec, DRENT, FLEXO, MPS (+ универсальная)
- Открыть форму корректировки цветов (`Лико_ФормаДокументаЦветаРаботы`)
- Открыть заявку на склад (`Лико_ЗаявкаНаСклад`)
- Интегрирована с WebSocket для приема QR-кодов

При создании на сервере настраивает принтер по умолчанию из `Лико_РабочиеМеста`.

## Ключевые процедуры

- `ПолучитьЗаказ()` — находит документ `ЗаказКлиента` по номеру (7 символов) через `Лико_Дополнительно.НайтиДокументПоНомеру7Символов`
- `ПолучитьВнешнююОбработку()` — загружает внешнюю печатную форму по наименованию из справочника `ДополнительныеОтчетыИОбработки`
- `ВызватьДопПФНаСервере()` — подключает внешнюю обработку и вызывает `ПечатьВнешнейПечатнойФормы`
- `ВывестиФормуПечати()` — выводит результат печати через `УправлениеПечатьюКлиент`
- `ПечатьНормативов()` — открывает форму внешней обработки "Нормативы"
- `ПечатьТехнологическойКарты()` — печатает универсальную техкарту
- `ПечатьТехнологическойКартыRotomec()` — техкарта для машины Rotomec
- `ПечатьТехнологическойКартыDrent()` — техкарта для машины DRENT
- `ТехнологическиеКартыFlexo()` — техкарта для FLEXO
- `ТехнологическиеКартыMps()` — техкарта для MPS
- `КорректировкаЦветов()` — открывает форму `Лико_ФормаДокументаЦветаРаботы` с флагом `КорректировкаЦветов`
- `ЗаявкаНаСклад()` — открывает документ `Лико_ЗаявкаНаСклад`
- `ПриСозданииНаСервере()` — инициализирует настройки принтера и WebSocket
- `ПолучитьОператора()` — получает текущего оператора из `Лико_РабочиеМеста.СотрудникПоF2`
- `ПриОткрытии()` — сохраняет оператора в `ГлЛико_Оператор`

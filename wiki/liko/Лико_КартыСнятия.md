# Лико_КартыСнятия

> Регистр накопления (обороты) — учёт брака и перерасхода материалов по заказам (карты снятия).

## Тип регистра
**Обороты** (`Turnovers`). Движения делаются документами-регистраторами, регистр накапливает обороты для анализа брака.

## Измерения
- **ЗаказКлиента** (`DocumentRef.ЗаказКлиента`) — заказ, по которому зафиксирован брак
- **НомерКарты** (`Строка(30)`) — номер карты снятия
- **Печатник** (`CatalogRef.Сотрудники`) — печатник, допустивший брак
- **РабочийЦентр** (`CatalogRef.РабочиеЦентры`) — рабочий центр, где произошёл брак
- **Материал** (`CatalogRef.Номенклатура`) — материал, по которому перерасход
- **ДатаРаботы** (`Дата`) — дата, когда выполнялась работа
- **Смена** (`Число(10,0)`) — номер смены
- **Нарезка** (`CatalogRef.ЯССМ_Нарезки`) — нарезка

## Ресурсы
- **КвадратныйМетражФакт** (`Число(15,2)`) — фактический квадратный метраж брака

## Реквизиты
- **Технолог** (`CatalogRef.Сотрудники`) — технолог
- **Причина** (`CatalogRef.Лико_ПричиныСнятия`) — причина брака/снятия
- **Заключение** (`Строка(300)`) — заключение по браку
- **Примечание** (`Строка(200)`) — примечание

## Ключевые процедуры (из расширения)

### RecordSetModule — `&Вместо("ПередЗаписью")`
```bsl
Процедура Лико_ПередЗаписью(Отказ, Замещение)
    ПродолжитьВызов(Отказ, Замещение);
КонецПроцедуры
```
Заглушка — просто продолжает вызов типового обработчика. Основная логика в типовом модуле регистра.

## Связь с ЗаказКлиента
Ключевое измерение — `ЗаказКлиента`. Регистр используется для анализа брака/перерасхода в разрезе заказов, рабочих центров, печатников и материалов.

# Лико_Цветоделение

> Регистр сведений (непериодический, подчинённый регистратору) — учёт данных цветоделения по заказам: цветоделители, корректоры, количество цветов по технологиям печати.

## Тип регистра
**Непериодический** (`Nonperiodical`), **Подчинённый регистратору** (`RecorderSubordinate`). Каждая запись привязана к документу-регистратору.

## Измерения
- **Заказ** (`DocumentRef.ЗаказКлиента`) — заказ клиента (главный фильтр)
- **Идентификатор** (`UUID`) — уникальный идентификатор записи цветоделения
- **ПредыдущийИдентификатор** (`UUID`) — идентификатор предыдущей версии (при переделке)

## Ресурсы (исполнители)
- **Цветоделитель** (`CatalogRef.Пользователи`) — основной цветоделитель
- **Корректор1** (`CatalogRef.Пользователи`) — первый корректор
- **Корректор2** (`CatalogRef.Пользователи`) — второй корректор
- **ЦветоделительПлан** (`CatalogRef.Пользователи`) — плановый цветоделитель
- **ПредыдущийЦветоделитель** (`CatalogRef.Пользователи`) — предыдущий цветоделитель (при переделке)

## Ресурсы (количества цветов по технологиям)
- **КоличествоНаименований** (`Число(10,0)`) — количество наименований в заказе
- **КоличествоЦветовОфсет** (`Число(10,0)`) — количество цветов офсетной печати
- **КоличествоЦветовФлексо** (`Число(10,0)`) — количество цветов флексопечати
- **КоличествоЦветовВысокая** (`Число(10,0)`) — количество цветов высокой печати
- **КоличествоЦветовГлубокая** (`Число(10,0)`) — количество цветов глубокой печати
- **КоличествоЦветовИндиго** (`Число(10,0)`) — количество цветов цифровой печати (indigo)
- **КоличествоЦветовТрафарет** (`Число(10,0)`) — количество цветов трафаретной печати

## Ресурсы (отделка)
- **КоличествоКонгревов** (`Число(10,0)`) — количество конгревных тиснений
- **КоличествоТиснений** (`Число(10,0)`) — общее количество тиснений
- **ТиснениеНФ** (`Число(10,0)`) — тиснение НФ
- **ТиснениеГалакси** (`Число(10,0)`) — тиснение Галакси
- **ТиснениеГолография** (`Число(10,0)`) — тиснение голография

## Ресурсы (даты и версии)
- **ДатаЦветоделения** (`ДатаВремя`) — дата выполнения цветоделения
- **ДатаКорректировки1** (`ДатаВремя`) — дата первой корректировки
- **ДатаКорректировки2** (`ДатаВремя`) — дата второй корректировки
- **ДатаЗаявки** (`ДатаВремя`) — дата подачи заявки на цветоделение
- **Версия** (`Число(10,0)`) — версия цветоделения

## Ресурсы (коэффициенты и переделки)
- **Коэффициент** (`Число(10,2)`) — коэффициент сложности
- **КоэффициентКорректора** (`Число(10,2)`) — коэффициент корректора
- **Переделка** (`Число(10,0)`) — количество переделок
- **КоррекцияЦветоделения** (`Число(10,0)`) — количество коррекций
- **ПричинаВозвратаНаПовторноеЦветоделение** (`CatalogRef.Лико_ПричиныВозвратаНаПовторноеЦветоделение`) — причина возврата

## Реквизиты
- **Комментарий** (`Строка(300)`) — комментарий

## Ключевые процедуры (из расширения)

### ФормаСписка — `Лико_ПриСозданииНаСервереВместо` (закомментирован)

Формирует сложный динамический список цветоделений со следующими данными:
1. **ВТ_ЗаказыВПлане** — заказы в плане производства (из `ПооперационноеРасписание2_2`, прокат №1, не выполнено)
2. **втНомерСтроки** — преобразование НомераСтроки (1-11) в строку для отображения
3. **Основной запрос** — сбор всех данных: Заказ, Заказчик, Менеджер, РабочийЦентр, ВидЗаказа, ТипЗаказа, даты, исполнители, признак Цифровой (indigo), Срочный, Этап (из `Лико_ЭтапыЗаказа`), Номер (Заказ + номер строки)
4. Поддерживает фильтрацию по параметру `Заказ` через динамический список

## Связь с ЗаказКлиента
Один из ключевых производственных регистров. Каждый заказ клиента проходит этап цветоделения, где фиксируются:
- Кто делал цветоделение и корректировки
- Сколько цветов по каждой технологии печати
- Количество тиснений и конгревов
- Версии и переделки

Данные используются для планирования загрузки цветоделителей и расчёта стоимости допечатной подготовки.

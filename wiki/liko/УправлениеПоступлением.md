# УправлениеПоступлением

> Обработка рабочего места приемки товаров — самая крупная доработка формы с авторизацией операторов, фильтрацией по организации и быстрым отбором заказов.

## Что делает / Доработки
Расширяет типовую обработку «Управление поступлением» (рабочее место склада для приемки). Ключевые доработки:
- **Авторизация операторов**: кнопки F2/F3 — быстрый выбор сотрудника из справочника `Лико_РабочиеМеста` с оповещением `АвторизацияОператора`
- **Фильтр по организации**: в запрос добавлен отбор `Лико_Организация` из помещения, плюс фильтрация по типам документов (ЗаказПоставщику, ЗаказПереработчику, ЗаказДавальца)
- **Быстрый отбор заказов**: через хранилище системных настроек сохраняется/загружается `БыстрыйОтборЗаказовПоставщику`
- **Собственный запрос распоряжений**: `ТекстЗапросаРаспоряженияНаПоступление()` — полный переопределенный запрос с временными таблицами, анализом остатков регистра `ЗаказыПоставщикам` и `ТоварыКПоступлению`
- **Фильтр по незакрытым заказам**: через `СостоянияЗаказовПоставщикам`, отсечение заказов старше года
- **Переопределение `ЗаполнитьРаспоряженияНаПоступление`** через `&Вместо` с добавлением колонок Организация и Менеджер
- **Состояния поступления**: полная логика с мерными типами единиц и допустимыми отклонениями

## Ключевые процедуры
- `СотрудникПоF2(Команда)` / `СотрудникПоF3(Команда)` — быстрый вход оператора
- `Лико_ОбработкаОповещенияПосле()` — обработка `АвторизацияОператора` и данных со сканера штрихкодов
- `Лико_ПриСозданииНаСервереПосле()` — инициализация `РабочееМесто` из параметров сеанса
- `Лико_ЗаполнитьРаспоряженияНаПоступление()` — `&Вместо` типовой процедуры с расширенной логикой
- `Лико_ЗаполнитьРаспоряженияНаПоступление241220()` — предыдущая версия заполнения (декабрь 2020)
- `ТекстЗапросаРаспоряженияНаПоступление()` — полный текст запроса (1200 строк) для быстрого отбора заказов
- `Лико_БыстрыйОтборЗаказовПоставщикуПриИзмененииПосле()` — перезаполняет распоряжения при изменении флажка

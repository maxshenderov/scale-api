# Лико_СпособыПодготовкиМакета

> Классификатор способов подготовки макета (prepress) — определяет каким способом готовится макет к печати на конкретном рабочем центре.

## Что хранит
- **Код** = `"{КодТехнологии}{НомерСпособа}"` — автогенерация при записи
- **ТехнологияПечати** — ссылка на технологию печати
- **НомерСпособа** — порядковый номер способа в рамках технологии
- **РабочиеЦентры** — табличная часть: привязка способа к конкретным рабочим центрам
- **ВидыСекций** — табличная часть: привязка к видам секций заказа (позволяет фильтровать по цветовым секциям)

## Модуль объекта: `ПередЗаписью`
```bsl
Код = СтрШаблон("%1%2", СокрЛп(ТехнологияПечати.КодТехнологии), НомерСпособа);
```

## Модуль менеджера: `ПолучитьКодТехнологии(ЗаказКлиента)`
Определяет код способа подготовки макета для конкретного заказа клиента. Алгоритм:
1. Если у заказа не заполнена `НоменклатураDFM` — возвращает пустую строку
2. Фильтрует способы по `РабочийЦентр` заказа
3. Для каждого способа проверяет пересечение `ВидыСекций` способа и `ВидыСекций` из табличной части `Цвета` заказа
4. Приоритет: способ с наибольшим количеством совпадающих видов секций
5. Если совпадений нет — выбирает способ без привязки к видам секций

## Связь с ЗаказКлиента
Способ подготовки макета определяется на основе `РабочийЦентр` и табличной части `Цвета.ВидСекции` заказа. Код способа используется для маршрутизации заказа в производстве.

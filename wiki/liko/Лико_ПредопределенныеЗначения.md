# Лико_ПредопределенныеЗначения

> Центральный справочник предопределённых значений Лико. Хранит настраиваемые параметры системы: любой тип значения через составной реквизит `ЗначениеПараметра`.

## Что делает

Справочник используется как реестр конфигурационных констант и параметров, специфичных для Лико. В отличие от типовых констант 1С, позволяет хранить значения любых типов (составной тип реквизита `ЗначениеПараметра`) и менять их без изменения конфигурации.

Шаблон использования в коде:
```bsl
Значение = ПредопределенноеЗначение("Лико_ПредопределенныеЗначения.ИмяПараметра").ЗначениеПараметра;
```

## Реквизиты

| Реквизит | Тип | Описание |
|---|---|---|
| ЗначениеПараметра | Составной тип (100+ типов) | Значение параметра — может быть ссылкой на справочник, документ, перечисление, строку, число и т.д. |

Составной тип включает все основные справочники и перечисления конфигурации, что позволяет использовать один справочник для хранения любых настроек.

## Ключевые процедуры

Сам справочник не содержит бизнес-логики в модулях. Его значение — в предопределённых элементах, на которые ссылается код через `ПредопределенноеЗначение()`.

# Лико_ДефектыМатериалов

> Справочник видов дефектов материалов — классификатор брака сырья в производстве.

## Что хранит

Перечень типов дефектов материалов с возможностью ручной сортировки (кнопки Вверх/Вниз).

## Ключевые процедуры

Форма `ФормаВыбораИнфопад`:
- `СписокПриАктивизацииЯчейки()` — при клике на `Наименование` закрывает форму выбора и возвращает текущую строку
- `СписокКнопкаВНиз(Команда)` / `СписокКнопкаВверх(Команда)` — перемещение элемента в списке (ручная сортировка по коду)
- `СписокКнопкаВНизНаСервере(Ссылка)` — запрос следующего по коду элемента
- `СписокКнопкаВверхНаСервере(Ссылка)` — запрос предыдущего по коду элемента

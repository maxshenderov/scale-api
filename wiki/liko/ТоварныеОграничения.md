# ТоварныеОграничения

> Типовой регистр сведений (непериодический, независимый) — настройка товарных ограничений: страховой запас, min/max, нормы потребления. Расширение добавляет контроль прав и заполнение полей при создании.

## Тип регистра
**Непериодический** (`Nonperiodical`), **Независимый** (`Independent`). Типовой регистр конфигурации, расширен доработкой Лико.

## Измерения
- **Склад** (`CatalogRef.Склады`) — склад (мастер-измерение)
- **Номенклатура** (`CatalogRef.Номенклатура`) — номенклатура (мастер-измерение, только Товар и МногооборотнаяТара)
- **Характеристика** (`CatalogRef.ХарактеристикиНоменклатуры`) — характеристика номенклатуры (связь по Номенклатуре)
- **ГруппировкаТоварныхОграничений** (`CatalogRef.ГруппировкиТоварныхОграничений`) — группировка

## Ресурсы
- **СтраховоеКоличествоЗапаса** (`Число(15,3)`) — страховой запас
- **МинимальноеКоличествоЗапаса** (`Число(15,3)`) — минимальный запас
- **МаксимальноеКоличествоЗапаса** (`Число(15,3)`) — максимальный запас
- **НормаПотребления** (`Число(15,3)`) — норма потребления в день
- **МетодОбеспеченияПотребностей** (`EnumRef.МетодыОбеспеченияПотребностей`) — метод обеспечения (обязательное)
- **УпаковкаЗаказа** (`CatalogRef.УпаковкиЕдиницыИзмерения`) — упаковка заказа
- **ОбеспечениеЗаказовПриПоддержанииЗапаса** (`EnumRef.ОбеспечениеЗаказовПриПоддержанииЗапаса`) — обеспечение заказов
- **СреднедневноеПотребление** (`Число(15,3)`) — среднедневное потребление
- **СреднееОтклонениеПотребления** (`Число(15,3)`) — среднее отклонение потребления

## Реквизиты
- **РеквизитДопУпорядочивания** (`Число(5,0)`) — порядок применения для цеховых кладовых
- **ДатаРасчетаРекомендаций** (`Дата`) — дата последнего расчёта рекомендаций
- **ЭтоДействующийПараметр** (`Булево`) — признак действующего параметра
- **ЕстьРекомендацияПоИзменению** (`Булево`) — есть рекомендация по изменению
- **ЭтоГруппировка** (`Булево`) — признак группировки

## Ключевые процедуры (из расширения)

### ФормаЗаписи — `Лико_ПриСозданииНаСервереПосле`
```bsl
Процедура Лико_ПриСозданииНаСервереПосле(Отказ, СтандартнаяОбработка)
    Если РольДоступна("Лико_УстановкаТоварныхОграничений") Тогда
        ТолькоПросмотр = Ложь;
    КонецЕсли;
    Если Не ЗначениеЗаполнено(Параметры.Ключ) Тогда
        // Заполнение из ЗначенияЗаполнения:
        // ЭтоДействующийПараметр, ОбеспечениеЗаказовПриПоддержанииЗапаса, МетодОбеспеченияПотребностей
    КонецЕсли;
КонецПроцедуры
```

**Логика**:
1. Проверяет роль `Лико_УстановкаТоварныхОграничений` — если есть, разрешает редактирование
2. При создании новой записи (Ключ не заполнен) — копирует значения из `Параметры.ЗначенияЗаполнения`:
   - `ЭтоДействующийПараметр`
   - `ОбеспечениеЗаказовПриПоддержанииЗапаса`
   - `МетодОбеспеченияПотребностей`

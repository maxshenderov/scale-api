# Лико_ПодготовкаЗаказов

> Обработка формирования текста запроса для планирования подготовки заказов по производственному расписанию.

## Что делает

Формирует текст запроса к регистру `ПооперационноеРасписание2_2` с присоединением `ЗаказКлиента` и `Лико_ПодготовленныеМатериалы`. Используется для планирования — какие заказы и в каком объёме нужно подготовить, с учётом уже подготовленных материалов.

## Ключевые процедуры

- `ФормированиеТекстаЗапроса()` — генерирует BSL-текст запроса, который собирает данные из `ПооперационноеРасписание2_2` (выходные изделия по этапам), соединяет с `ЗаказКлиента` (для получения контекста заказа) и `Лико_ПодготовленныеМатериалы` (для учёта уже подготовленного).

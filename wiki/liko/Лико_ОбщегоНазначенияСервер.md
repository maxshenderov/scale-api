# Лико_ОбщегоНазначенияСервер

> Главный серверный утилитарный модуль (~10900 строк) — ядро кастомной логики Лико.

## Что делает

Центральный модуль всей кастомной логики. Содержит заполнение реквизитов документов, работу с заказами, интеграцию с производством. Почти все серверные процедуры Лико_ вызывают его.

## Ключевые процедуры

- `ЗаполнениеРеквизитовШапки(Документ, СтандартнаяОбработка)` — заполняет шапку заказа при создании (организация, подразделение, склад, рабочее место из параметров сеанса)
- `РеквизитыШапки(Документ)` — возвращает структуру реквизитов шапки для передачи между процедурами
- `ПолучитьСтруктуруДляЗаполненияТиповыхДокументов(ЗаказСсылка)` — формирует структуру для программного создания типовых документов на основе заказа

## Зависимости

- `ПараметрыСеанса.ТекущийПользователь` — текущий пользователь
- `ПараметрыСеанса.Лико_РабочееМесто` — рабочее место (рабочий центр)
- [[Лико_Дополнительно]], [[Лико_ДополнительноКлиентСервер]], [[Лико_Планирование]]
- [[Лико_ПрограммноеСозданиеДокументовСправочников]] — вызывает стандартизированно

## Связь с ЗаказКлиента

Основная точка входа в Лико-логику при работе с [[ЗаказКлиента]]:
- Вызывается из обработчиков событий формы `Лико_ФормаДокумента`
- Заполняет реквизиты шапки при открытии нового заказа

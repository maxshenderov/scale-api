# mcp_ИнструментДанныеОКонфигурации

> MCP-обработка (контейнер инструментов): три инструмента для работы с метаданными конфигурации 1С и выполнения BSL-кода.

## Что делает

Обработка-контейнер, регистрируемая в подсистеме `mcp_MCPСервер.mcp_КонтейнерыИнструментов`.
Реализует контракт контейнера: `ДобавитьИнструменты()` и `ВыполнитьИнструмент()`.

Предоставляет три инструмента:
1. `list_metadata_objects` — получение списка объектов метаданных
2. `get_metadata_structure` — получение структуры конкретного объекта метаданных
3. `execute_bsl` — выполнение произвольного BSL-кода на сервере 1С

## Ключевые процедуры

- `ДобавитьИнструменты(Инструменты)` — регистрирует все три инструмента с JSON-схемами параметров.

### list_metadata_objects
- Параметры: `metaType` (обязательный, enum из ~40 типов), `nameMask` (подстрока в имени/синониме), `maxItems` (лимит, по умолчанию 100).
- Возвращает список строк вида `"ПолноеИмя (Синоним)"`, разделенных переводом строки.

### get_metadata_structure
- Параметры: `metaType` (обязательный), `name` (точное имя, без учета регистра).
- Делегирует в `ObjectModule.ОписаниеСтруктурыОбъектаМетаданных()`.
- Для регистров выводит: заголовок, стандартные реквизиты, измерения, ресурсы.
- Для остальных: заголовок, стандартные реквизиты, реквизиты, владельцы (для подчиненных справочников), табличные части.
- Для перечислений — показывает до 10 значений.

### execute_bsl
- Универсальный инструмент удаленного выполнения BSL-кода.
- Параметры: `code` (обязательный), `params` (JSON-object -> MCP_Params), `transaction` (по умолчанию Истина), `commit` (по умолчанию Ложь — безопасно), `resultExpression` (альтернатива MCP_Result), `returnJson` (формат ответа).
- Контекст выполнения: доступны переменные `MCP_Params` (Структура) и `MCP_Result` (присвоить для возврата).
- При `transaction=Истина, commit=Ложь` изменения откатываются — безопасный режим по умолчанию.
- Умеет сериализовать в JSON: примитивы, массивы, структуры, соответствия, таблицы значений, даты (ISO).
- ПРЕДУПРЕЖДЕНИЕ БЕЗОПАСНОСТИ: инструмент по сути является удаленным выполнением кода. Рекомендуется использовать отдельного пользователя с минимальными правами.

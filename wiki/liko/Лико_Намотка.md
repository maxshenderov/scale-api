# Лико_Намотка

> Справочник намоток (рулонов) — хранит изображения/картинки, привязанные к элементам намотки.

## Что хранит
- ФайлКартинки — ссылка на присоединённый файл из справочника Лико_НамоткаПрисоединенныеФайлы
- АдресКартинки — навигационная ссылка для отображения изображения на форме
- ДанныеФайлаКартинки — временные данные файла до записи

## Ключевые процедуры
### ФормаЭлемента
- `ДобавитьИзображениеНаКлиенте()` — диалог выбора файла изображения. Если объект не записан — загружает во временное хранилище, иначе — через подсистему РаботаСФайлами.
- `ВыбратьКартинкуИзПрисоединенныхФайлов()` — открывает форму присоединённых файлов для выбора существующего изображения.
- `ОбработкаОповещения()` — при событии "Запись_Файл" обновляет ссылку на файл и навигационную ссылку картинки.
- `ПослеЗаписиНаСервере()` — создаёт присоединённый файл из временных данных и записывает объект повторно.
- `ПросмотретьИзображение()` / `ОчиститьИзображение()` / `ИзменитьИзображение()` — управление картинкой из формы.
- `НавигационнаяСсылкаКартинки(ФайлКартинки, ИдентификаторФормы)` — получает навигационную ссылку на двоичные данные файла через РаботаСФайлами.

### ФормаСписка
- `СписокПриАктивизацииСтроки()` — при выборе строки в списке подгружает картинку для предпросмотра.
- `ФайлКартинкиНажатие()` — открывает присоединённый файл для просмотра.

# ОтчетПереработчика (типовой, доработан)

> Автозаполнение ДоляСтоимости по количеству продукции. m.shenderov 07.11.2023.

## Доработки

- **`Лико_ПередЗаписью`** (`&Перед("ПередЗаписью")`) -- перед записью для каждой строки табличной части `Продукция` заполняет `ДоляСтоимости = Количество`. Это обеспечивает пропорциональное распределение стоимости по количеству без ручного ввода.

## Ключевые процедуры

- `Лико_ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)` -- заполнение ДоляСтоимости в цикле по Продукция.

# Лико_Отгрузки

> Регистр сведений (периодический, регистратор ЗаказКлиента): связка заказа с отгрузками — стоимость, себестоимость, доход, метраж и время.

## Что делает

Фиксирует каждую отгрузку по заказу клиента с полным набором финансовых и производственных показателей. Позволяет отследить историю отгрузок по одному заказу (один заказ может отгружаться несколькими документами).

Регистратор — `Документ.ЗаказКлиента`. Каждая запись идентифицируется по тройке: заказ + документ отгрузки + ключ строки (UUID).

## Измерения

| Измерение | Тип | Описание |
|---|---|---|
| Заказ | Документ.ЗаказКлиента | Заказ клиента |
| Отгрузка | Документ.ОтчетДавальцу, Документ.ПеремещениеТоваров, Документ.РеализацияТоваровУслуг | Документ отгрузки (составной тип) |
| КлючСтроки | УникальныйИдентификатор | UUID строки отгрузки |

## Связь с ЗаказКлиента

Регистратор — `ЗаказКлиента`. Записи создаются при проведении документов отгрузки (РеализацияТоваровУслуг, ОтчетДавальцу, ПеремещениеТоваров).

Один заказ может иметь множество записей — по одной на каждый документ отгрузки. Первая отгрузка помечается флагом `ПерваяОтгрузка`.

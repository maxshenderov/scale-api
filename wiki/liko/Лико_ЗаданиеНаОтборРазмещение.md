# Лико_ЗаданиеНаОтборРазмещение

> Складское задание на отбор/размещение паллет. Управляет перемещением паллет между адресами хранения. Работает в связке с Лико_ЗаявкаНаСклад, Лико_ФормированиеПаллета2_0, Лико_ПеремещениеПаллета2_0.

## Что делает

- Создаётся для отбора, размещения или перемещения паллеты
- Определяет тип задания (`Лико_ТипыСкладскихЗаданий`) по наличию секций в адресах: Перемещение / Размещение / Отбор
- Статусная модель: `Новое` -> `ВТранзите` (если есть транзитный адрес) -> `Выполнено` (если заполнен АдресКудаФакт) -> `Отменено`
- При проведении отменяет старые задания с тем же паллетом
- Формирует движения в регистре `Лико_ПаллетыВСекциях`

## Ключевые процедуры (ObjectModule)

- `ПередЗаписью()` — определяет ТипЗадания, устанавливает Статус (Новое/ВТранзите/Выполнено), заполняет Площадка/Организация/Склад из адреса
- `ОбработкаПроведения()` — отменяет старые задания с тем же паллетом, вызывает `СформироватьДвиженияПаллетыВСекциях()`
- `СформироватьДвиженияПаллетыВСекциях()` — приход в регистр `Лико_ПаллетыВСекциях` с признаком блокировки
- `ПриКопировании()` — сбрасывает ключевые реквизиты

## Ключевые процедуры (ManagerModule)

- `СоздатьЗадание(ДокументОснование, Паллет, АдресОткуда, АдресКуда)` — создаёт и проводит новое задание. Автоматически ищет паллет и подбирает ячейку
- `СоздатьЗаданияПоЗаявке(ЗаявкаНаСклад)` — группирует товары по адресам хранения, для каждого создаёт уникальное задание на площадку отгрузки
- `СоздатьЗаданиеПоФормированию(ФормированиеПаллета)` — создаёт задание размещения для сформированного паллета
- `ИзменитьЗаданиеПоПеремещению(ПеремещениеПаллета)` — обновляет существующее задание (транзитный адрес / фактический адрес)
- `ОтменитьСтарыеЗадания(Паллет, ЗаданиеСсылка)` — отменяет все проведённые задания с тем же паллетом (кроме указанного)
- `ПаллетВЗадании(Паллет)` — проверяет, есть ли паллет в активных заданиях
- `НайтиПаллетПоАдресу(Адрес)` — ищет паллет по остаткам в `Лико_ПаллетыВСекциях`
- `ЭтоТранзитныйАдрес(Адрес)` — проверяет принадлежность адреса к зонам приёмки/отгрузки стеллажей

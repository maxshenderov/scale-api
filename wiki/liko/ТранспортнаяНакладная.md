# ТранспортнаяНакладная

> Типовой документ транспортной накладной. Доработка ManagerModule — расширенный подбор документов-оснований с учетом Лико_ПередачаТоваров.

## Что делает / Доработки
- **Оформление транспортной накладной** на основании документов отгрузки/перемещения товаров.
- **Расширение `ManagerModule`**: переопределена функция `Лико_ПолучитьТолькоДокументыОснованияСТоварамиУд()` — добавлен документ `Лико_ПередачаТоваров` в список источников для заполнения временной таблицы товаров. Это нужно потому что в Лико используется собственная передача товаров, и транспортная накладная должна уметь подбирать товары из этого документа.
- Функция фильтрует входящий массив распоряжений: оставляет только те, где есть номенклатура типа «Товар» или «МногооборотнаяТара». Для распоряжений без товаров выводит сообщение об ошибке.

## Ключевые процедуры
- `Лико_ПолучитьТолькоДокументыОснованияСТоварамиУд(МассивВсехРаспоряжений, Отказ)` — &Вместо штатной, собирает товары из расширенного набора документов-источников (РеализацияТоваровУслуг, ВозвратТоваровПоставщику, КорректировкаРеализации, ПеремещениеТоваров, ОтгрузкаТоваровСХранения, ПередачаСырьяПереработчику, ПередачаДавальцу, ВозвратСырьяДавальцу + **Лико_ПередачаТоваров**).

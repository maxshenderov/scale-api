# Лико_Перемотка

> Справочник спецификаций перемотки рулонного материала. Хранит параметры направления, диаметров, резки и кромки для операций перемотки.

## Что хранит

- Направление перемотки (ссылка на справочник направлений)
- Внутренний диаметр рулона
- Максимальный диаметр рулона
- Количество этикеток в ролике
- Флаги: ПродольнаяРезка, ПоперечнаяРезка
- Кромка
- Наименование (автоформируемое): конкатенация Направление + диаметры + кол-во этикеток + признаки резки + кромка

## Ключевые процедуры

### ObjectModule
- `ПередЗаписью(Отказ)` — автоформирует наименование из полей: Направление, ВнутреннийДиаметр, МаксимальныйДиаметрРулона, КоличествоЭтикетокВРолике, ПродольнаяРезка, ПоперечнаяРезка, Кромка

### ФормаВыбора
- `ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)` — настраивает отборы по Партнеру, Номенклатуре и Городу в зависимости от переданных параметров

## Связи с ЗаказКлиента

Используется при расчёте нормативов перемотки для заказов на этикетку.

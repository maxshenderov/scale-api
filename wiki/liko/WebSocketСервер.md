# WebSocketСервер

> Серверный модуль подсистемы WebSocket — инициализация соединений, токены авторизации, HTTP-коммуникация с interconnection-сервером.

## Что делает
Обеспечивает полную серверную инфраструктуру WebSocket: инициализацию на формах (добавление реквизитов и элемента ПолеHTMLДокумента), получение JWT-токенов, формирование QR-кодов, HTTP-запросы к interconnection-серверу (int.okil.ru / int-dev.okil.ru), отправку сообщений через API. Поддерживает два режима: infopad (инфопады) и barcode-scanner (сканирование).

## Ключевые процедуры
- `Settings()` — возвращает настройки подключения (продакшн): username, password, WebSocketURL, domain, API endpoints
- `SettingsTest()` — возвращает настройки для тестового контура (int-dev.okil.ru)
- `Инициализация()` — основная процедура: добавляет реквизиты формы (WebSocketURL, WebSocketSubject, WebSocketUUID, FormGUID и др.), создаёт элемент ПолеHTMLДокумента, настраивает attach-files
- `ПолучитьКодРабочегоМеста()` — формирует код рабочего места из параметров сеанса
- `ОтправитьСообщение()` — отправляет сообщение через API (talk_uuid + content) с Bearer-токеном
- `ПолучитьToken()` — получает JWT-токен через API signin (логин/пароль)
- `СтруктураВJSON()` — сериализует структуру 1С в JSON
- `HttpRequest()` — универсальный HTTP POST-запрос с заголовками
- `ПолучитьОтветJSON()` — парсит HTTP-ответ как JSON
- `Url()` — формирует URL с query-параметрами
- `ЭтоИнфопад()` — проверяет, является ли рабочее место инфопадом

## Используется в
- Все формы, где нужен WebSocket (через вызов Инициализация() в ПриСозданииНаСервере)

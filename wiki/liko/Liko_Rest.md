# Liko_Rest

> HTTP-сервис REST API для веб-портала Лико и мобильных клиентов. Более 70 эндпоинтов: пользователи, складские остатки, продажи, отгрузки, производство, планирование, печать отчётов, TouchPad, WebSocket-задачи.

## Что делает

Единая точка входа для внешних систем через HTTP:

1. **GET** — заглушка (возвращает пустой ответ).
2. **POST** — принимает JSON с обязательным полем `ProcName`, делегирует вызов в функцию с соответствующим именем.
3. **Debug-режим** — при `Debug=1` пишет тело запроса в журнал регистрации.

Все ответы — JSON (таблица значений или структура через `HttpВернутьТзКакJSON` / `HttpВернутьСтруктуруКакJSON`).

## Ключевые группы эндпоинтов

### Пользователи и доступ
- `Users` — список пользователей 1С с email, GUID, UserOS.
- `UserAccess` — проверка доступа пользователя к сайту (свойство `Лико_ДоступКСайту`).
- `GetToken` — выдача токена через `Лико_HTTP_Сервер.GetToken()`.
- `SectionsAccess` — доступ к разделам сайта (Показатели, ПланированиеРЦ, СостояниеМашин, ОстаткиСГП, Продажи, Отгрузки, Отчеты).
- `ReportAccess` — список доступных отчётов для пользователя.
- `Access` — общая проверка доступа.

### Площадки и партнёры
- `ProdSiteList` — список площадок (организаций), доступных пользователю.
- `PartnersList` / `PartnersList071220` — список партнёров.
- `BusinessRegionsList` — список бизнес-регионов.

### Складские остатки (WRP / WRP2)
- `WRP` — остатки готовой продукции (СГП) с группировкой по периоду (0-1-2-3 мес), складу, номенклатуре. Использует `РегистрНакопления.ТоварыНаСкладах` + `ТоварыВЯчейках` для фильтрации растарки.
- `WRP2` — расширенная версия остатков с доп. аналитиками.
- `WRM` — остатки материалов на складе.
- `WRMDetail` / `WRMDetailПлощадка` — детализация остатков материалов.

### Продажи
- `SalesUpd2` / `SalesUpd2_Old` — данные продаж с агрегацией.
- `SalesDetail` — детализация продаж.
- `SalesDailyAverage` — среднедневные продажи.
- `SalesManagers` / `SalesManagersMonth` — продажи по менеджерам.
- `SalesStatistics` — статистика продаж.

### Отгрузки
- `Shipments` — данные отгрузок.
- `ShipmentsPlan` — план отгрузок.
- `ShipmentsDailyAverage` — среднедневные отгрузки.

### Производство
- `Production` — данные производства.
- `ProductionDetail` — детализация производства.
- `Production2` — перерасходы производства.
- `Production2Detail` — детализация перерасходов.
- `ProductionDailyAverage` — среднедневное производство.
- `ProductionStatistics` — статистика производства.

### Финансы
- `SettlementsWithClients` — расчёты с клиентами.
- `SettlementsWithClientsDetail` — детализация расчётов с клиентами.
- `SettlementsWithProviders` — расчёты с поставщиками.
- `SettlementsWithProvidersDetail` — детализация расчётов с поставщиками.
- `ExchangeDifferences` / `ExchangeDifferencesDetail` — курсовые разницы.
- `MoneyDailyAverage` — среднедневные денежные показатели.
- `ProfitabilityReport` — отчёт по рентабельности.

### Планирование и отчёты
- `PlanWorkCenters` / `PlanWorkCenters210921` — план рабочих центров.
- `TableWorkCenters` — таблица рабочих центров.
- `PrintReport` / `PrintReportSKD` — печать отчётов (СКД).
- `ZPTable` — зарплатная таблица.

### Заказы и документы
- `OrdersSuppliers` — заказы поставщикам.
- `SearchClientOrder` — поиск заказа клиента по номеру.
- `TrackedOrders` — отслеживаемые заказы.
- `StagesControl` — контроль этапов заказа.
- `CancelStagesControl` — отмена контроля этапов.
- `OrderStages` / `OrderStagesInfo` / `StagesОrder` — информация по этапам заказа.
- `GetDocsPackets` / `GetDocsPacketInfo` / `GetDocsPacketsStates` / `SetDocsPacketState` — работа с пакетами документов.

### Номенклатура и продукция
- `GetProductByArticle` — поиск номенклатуры по артикулу.
- `CreateProduct` / `CreateProduct030221` — создание номенклатуры.
- `GetOM` — получение оригинал-макетов.
- `CuttingPlan` — план раскроя.

### WebSocket и задачи
- `WssSC` — WebSocket-запрос (Server-Client).
- `WssSСRequest` — WebSocket-запрос.
- `WssSСMobyleClient` — WebSocket мобильный клиент.
- `WssZakazMaterialClose` — закрытие заказа материала через WebSocket.
- `WssTask` — WebSocket-задача.

### Файлы и вложения
- `AttachFiles` / `AttachFilesOld` — прикрепление файлов.
- `UpdateAppFileInfo` — обновление информации о файле.
- `ПолучитьДвоичныеДанныеОригиналМакета` — получение бинарных данных оригинал-макета.
- `QueryFree` — свободный запрос.

### TouchPad (производственное оборудование)
- `TouchPad_GetState` — получить состояние TouchPad.
- `TouchPad_SetColor` / `TouchPad_SetColor301023` — установка цвета.
- `TouchPad_GetWorkplaceParams` — параметры рабочего места.
- `TouchPad_WriteОffMaterials` — списание материалов.
- `TouchPad_MovingМaterials` — перемещение материалов.

### Статусы и контроль
- `StatusWorkCenters` — состояние рабочих центров.
- `CheckingAvailabilityMaterialsOrder` — проверка доступности материалов для заказа.
- `exchange_changeStatus` — смена статуса обмена.
- `ListOverspendingMaps` — список карт перерасходов.
- `NewOverspendingMap` / `CreateOverspendingMap` — создание карт перерасходов.

### Каталоги
- `GetCatalogItemsByProps` — получение элементов справочника по свойствам.

## Вспомогательные функции
- `ВызовМетода(Метод, Параметры)` — диспетчер вызова методов через `Выполнить()`.
- `HttpВернутьТзКакJSON(ТЗ)` — конвертирует таблицу значений в JSON-строку.
- `HttpВернутьСтруктуруКакJSON(Структура)` — конвертирует структуру в JSON.
- `HttpВернутьОшибку(КодОшибки, Сообщение)` — возвращает HTTP-ошибку с JSON.
- `ПроверитьОбязательныеПараметры(Структура, ПараметрыОднойСтрокой)` — валидация обязательных полей.
- `ПолучитьПользователя(UserOS)` — поиск пользователя 1С по UserOS.
- `ПолучитьСписокРолей(Пользователь)` — роли пользователя.
- `ПолучитьДоступныеОтчеты(Пользователь)` — варианты отчётов, доступные пользователю.
- `ПолучитьДоступныеРазделы(Пользователь)` — доступные разделы.
- `НайтиДокумент(ДокументИмя, Номер, Дата)` — поиск документа.
- `ПолучитьТабличныйДокументВариантаОтчета()` — формирование табличного документа варианта отчёта.

## Используемые модули
- `Лико_HTTP_Сервер` — токены, ответы, `СтруктураВJSON`.
- `Лико_СерверВзаимодействияСервер` — WebSocket.
- `УправлениеСвойствами` — свойства пользователей.
- `Пользователи.СвойстваПользователяИБ()` — получение UserOS.

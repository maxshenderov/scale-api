# Лико_ТипыЗаказов

> Перечисление типов заказов клиента. Определяет логику расчёта метража и обработки бланков этапов в зависимости от типа продукции.

## Значения

Перечисление используется в [[ЗаказКлиента]] для ветвления бизнес-логики:

- **Термоусадка** — делит метраж на количество ручьёв при расчёте
- **СамоклеящаясяЭтикетка** — берёт чистые метры без деления на ручьи

## Где используется

- [[ЗаказКлиента]] — `расш_СформироватьСоответствиеЗасчитанныхЭтикетокПоПотреблениюСледующегоПроката()`: ветвление по типу заказа
- [[Лико_ТиражМетраж]] — расчёт тиража и метража
- [[Лико_БланкЭтапа]] — учёт бланков по этапам

# Лико_РабочиеМеста

> Привязка рабочих мест: пользователь + имя компьютера -> свойства и доп. реквизиты рабочего места.

## Что хранит
Иерархический справочник для идентификации рабочих мест. Каждое рабочее место определяется связкой `Пользователь + ИмяКомпьютера`. Хранит настройки печати и другие свойства рабочего места через доп. реквизиты.

**Реквизиты:** Пользователь, ИмяКомпьютера, ПечататьДокументыПриРаботеНаТСД, ПечатьСразуНаПринтер.

Используется в параметре сеанса `Лико_РабочееМесто.ИмяКомпьютера`.

## Ключевые процедуры

### ObjectModule
- `ПередЗаписью()` -- автоформирование Код и Наименование из Пользователь + ИмяКомпьютера
- `ПроверкаЗаполнения()` -- требует заполнения хотя бы одного из: ИмяКомпьютера или Пользователь; проверка согласованности ТСД-печати (если ПечататьДокументыПриРаботеНаТСД, то ПечатьСразуНаПринтер тоже должно быть Истина)
- `ПриКопировании()` -- сбрасывает Наименование, ИмяКомпьютера, Пользователь

### ManagerModule
- `ПолучитьСвойство(ИмяСвойства, ЗначениеПоУмолчанию, Пользователь, ИмяКомпьютера)` -- поиск рабочего места с тройным приоритетом:
  1. Точное совпадение: `ИмяКомпьютера + Пользователь`
  2. Только `Пользователь` (ИмяКомпьютера пустое)
  3. Только `ИмяКомпьютера` (Пользователь пустой)
  
  Возвращает значение стандартного реквизита (Код, Наименование, любой реквизит метаданных) или доп. свойства по заголовку.

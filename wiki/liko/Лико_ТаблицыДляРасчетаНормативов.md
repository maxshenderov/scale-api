# Лико_ТаблицыДляРасчетаНормативов

> Справочник многомерных таблиц для расчета производственных нормативов — связывает показатели (виды работ, типы материалов, типы заказов) с числовыми значениями по вариантам расчета, включая таблицу цветов.

## Что хранит

Многомерные таблицы, где строки — комбинации показателей (Показатель + Показатель2), а значения — числовые нормативы, с разбивкой по рабочим центрам и вариантам расчета. Отдельная таблица для нормативов по количеству цветов.

**Реквизиты:**
- `Комментарий` (Строка)

**Табличная часть «РабочиеЦентры»:**
- `РабочийЦентр` (составной тип: Справочник.РабочиеЦентры, Перечисление.Лико_ТипыМатериалов, Перечисление.Лико_ТипыОперацийПеремотки, Справочник.ВидыРабочихЦентров, Строка)
- `НомерВарианта` (Число)

**Табличная часть «ТаблицаПоказателей»:**
- `Показатель` (составной тип: Справочник.Лико_ПараметрыРасчетаНормативов, Справочник.ВидыРаботСотрудников, Перечисление.Лико_ТипыМатериалов, Перечисление.Лико_ТипыЗаказов, Справочник.Лико_ВидыСекций, Число, Строка)
- `Показатель2` — второй разрез показателя
- `ЗначениеПоказателя`, `ЗначениеПоказателя2` (Число)
- `НомерВарианта` (Число) — привязка к варианту
- `ВариантРасчета` (Число) — номер варианта расчета
- `ОднократноеЗначение` (Булево) — значение применяется один раз (не умножается)
- `Комментарий` (Строка)

**Табличная часть «ТаблицаЦветов»:**
- `КоличествоЦветов` (Число) — количество цветов (красок)
- `ЗначениеПоказателя` (Число) — норматив для данного количества цветов
- `НомерВарианта`, `ВариантРасчета` (Число)
- `Комментарий` (Строка)

**Табличная часть «ВариантыРасчета»:**
- `ВариантРасчета` (Число) — список доступных вариантов

## Ключевые процедуры

- `Лико_СкопироватьВариант()` (ФормаЭлемента, клиент) — копирует строки из одного варианта расчета в другой. Проверяет модифицированность формы, предлагает записать. Поддерживает копирование как ТаблицыПоказателей, так и ТаблицыЦветов (определяется по имени команды). Запрашивает номер исходного варианта и номер копии через `ВвестиЧисло()`. Вызывает серверный метод `СкопироватьВариантНаСервере()`

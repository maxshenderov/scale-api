# Лико_МастерНастройкиСтатьиРасходаДляНоменклатуры

> Справочник правил сопоставления статей расходов видам номенклатуры. Определяет, по какой статье расходов списывать конкретную номенклатуру.

## Что хранит
- СтатьяРасхода — ссылка на план видов характеристик СтатьиРасходов
- ВидНоменклатуры — вид номенклатуры, к которому применяется правило
- Организация — организация, для которой действует правило
- СложнаяНастройка — флаг: используется ли отбор через СКД (схема компоновки данных)
- ОтборНастройки — хранилище настроек СКД для сложной фильтрации
- Приоритет — порядок применения правил (чем меньше, тем выше приоритет)
- Выключить — флаг отключения правила
- ДополнительныеРеквизиты — простые условия: свойства номенклатуры с флагом Исключить

## Ключевые процедуры
### ObjectModule
- `ПередЗаписью()` — автозаполнение наименования как `СтатьяРасхода - ВидНоменклатуры`, автонумерация приоритета. Для простых настроек генерирует описание из дополнительных реквизитов.

### ManagerModule
- `ОпределитьСтатьюРасходов(Номенклатура, ДокументРасхода)` — находит подходящую статью расхода для номенклатуры: перебирает правила по приоритету, для простых сверяет доп. реквизиты, для сложных выполняет СКД-отбор.
- `ОпределитьПравило(Номенклатура, ДокументРасхода)` — то же, но возвращает ссылку на правило, а не статью.
- `ИспользоватьПравилоСКД(Выборка, Номенклатура, ДокументРасхода)` — выполняет СКД-отбор из макета "ОтборПоУсловию" для сложных настроек. Возвращает Истина, если номенклатура проходит фильтр.
- `ПолучитьПриоритетМакс(ВидНоменклатуры)` — возвращает максимальный приоритет для вида номенклатуры (для автонумерации новых правил).
- `ПереместитьПоПриоритету(Ссылка, Шаг)` — меняет приоритеты двух правил местами (сдвиг вверх/вниз в списке). Использует транзакцию.
- `ПолучитьПравилоПоПриоритету(ВидНоменклатуры, Приоритет)` — находит правило с конкретным приоритетом.

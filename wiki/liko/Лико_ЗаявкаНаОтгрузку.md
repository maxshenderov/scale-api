# Лико_ЗаявкаНаОтгрузку

> Документ формирования заявки на отгрузку готовой продукции клиенту — связывает ЗаказКлиента с процессом отгрузки, контролирует валюты, отсрочки, цены, склады и типы отгрузки.

## Что делает

Центральный документ логистики сбыта. Создаётся на основании ЗаказаКлиента. Управляет полным процессом отгрузки: от формирования строк по заказам до контроля согласованности валют, договоров, адресов доставки и взаимодействия со складом через связанные документы (Лико_ЗаявкаНаТранспортировку). Проводит движения по регистрам `Лико_ПараметрыОтрузки` и `Лико_ЗаявкиНаОтгрузку`.

Основная логика сосредоточена в `ПередЗаписью` (500+ строк валидаций) и `ОбработкаПроведения` (формирование движений).

## Ключевые процедуры

- `ОбработкаПроведения()` — формирует движения по регистрам `Лико_ПараметрыОтрузки` (параметры) и `Лико_ЗаявкиНаОтгрузку` (приход); вызывает `ЕстьЗаявкаНаОтгрузку()` для синхронизации флага на заказе.
- `ПередЗаписью()` — комплексная валидация (500+ строк): проверка валют соглашений, отсрочек платежей, соответствия характеристики и заказа, уникальности адреса доставки, типа отгрузки vs типа склада, нулевых цен, блокировка закрытых заявок, запрет проведения задним числом/после 17:00.
- `ОбработкаУдаленияПроведения()` — очищает движения и синхронизирует флаг `ЕстьЗаявкаНаОтгрузку` на заказах.
- `ОбработкаПроверкиЗаполнения()` — удаляет из проверки обязательные поля для услуг (ЗаказКлиента, ВалютаЦены, ОтгрузкаВРублях).

### ManagerModule

- `ПолучитьТекстЗапросаДляДереваОстатки()` — формирует текст запроса для дерева остатков (адресное хранение через `ТоварыВЯчейках` или безадресное через `ТоварыНаСкладах`).
- `ПолучитьТекстЗапросаДляДереваЗаказы()` — запрос для дерева заказов с ценами, НДС, адресами доставки.
- `НайтиИлиСоздатьХарактеристикуДляУслуги()` — находит или автоматически создаёт характеристику номенклатуры для услуги в привязке к заказу.
- `ЕстьЗаявкаНаОтгрузку()` — синхронизирует флаг `ЕстьЗаявкаНаОтгрузку` на документах ЗаказКлиента (сверка регистра с реквизитом).

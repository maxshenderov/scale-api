# ФормаЭлементыКлиентСервер

> Клиент-серверные утилиты для работы с формами. Разбиение строки в массив подстрок.

## Что делает
Модуль содержит функцию `РазложитьСтрокуВМассивПодстрок` — аналог типовой `СтроковыеФункцииКлиентСервер.РазложитьСтрокуВМассивПодстрок`, скопированный в расширение. Разбивает строку по разделителю произвольной длины с возможностью пропуска пустых строк и сокращения непечатаемых символов. Для разделителя-запятой без пустых строк и с сокращением непечатаемых символов использует платформенную `СтрРазделить` для оптимизации.

## Ключевые процедуры
- `РазложитьСтрокуВМассивПодстрок()` — разбивает строку в массив по разделителю с опциями пропуска пустых строк и сокращения непечатаемых символов

## Используется в
- Клиент-серверные операции с формами, где требуется парсинг строк

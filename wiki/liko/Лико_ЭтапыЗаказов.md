# Лико_ЭтапыЗаказов

> CommonCommand — запускает внешнюю обработку "Этапы заказов" из предопределенных значений.

## Что делает

Команда получает внешнюю обработку через предопределенное значение `ВнешняяОбработкаЭтапыЗаказов` из справочника `Лико_ПредопределенныеЗначения`, подключает её через `ДополнительныеОтчетыИОбработкиВызовСервера` и открывает форму обработки. Если предопределенное значение не заполнено, выводит сообщение об ошибке.

## Ключевые процедуры

- `ОбработкаКоманды()` — получает внешнюю обработку, подключает её и открывает форму `ВнешняяОбработка.<Имя>.Форма`.
- `ПолучитьВнешнююОбработку()` (сервер) — извлекает ссылку на обработку из `Лико_ПредопределенныеЗначения.ВнешняяОбработкаЭтапыЗаказов`.

# ПриходныйОрдерНаТовары (типовой, доработан)

> Самый насыщенный доработками типовой документ: BRC-входной контроль, авторизация склада, подбор серий через ОбъектыНоменклатуры, резервирование под клиента, автопечать ордера, бухгалтерский учет. m.shenderov 2017-2023.

## Доработки

- **BRC -- Входной контроль** -- полная подсистема контроля качества при приемке: критерии для упаковки (динамические реквизиты `BRC*`), параметры входного контроля (`Лико_ПараметрыВходногоКонтроля`), решение о приемке, подпись документа. Учитывает `Лико_ВидКонтактаСПищевойПродукцией`. Критерии подгружаются из справочника `Лико_КритерииВходногоКонтроля`. При изменении флажков в таблице BRC -- изменения синхронно записываются в `ЯССМ_ОбъектНоменклатуры`.
- **Авторизация склада** -- при открытии формы проверяется `ГлЛико_Оператор`; если не заполнен, открывается `Лико_ФормаАвторизацииСклада` (блокирует интерфейс). Автор документа и рабочее место заполняются автоматически.
- **Подбор серий для СИМ** -- `&Вместо("ОткрытьПодборСерий")` для складов СИМ открывает обработку `Лико_СозданиеОбъектовНоменклатурыГрупповое` вместо стандартного подбора. Подбор преобразует ОбъектыНоменклатуры в строки ТЧ.
- **Автопечать ордера** -- после проведения (если включено в настройках рабочего места) автоматически открывается печатная форма "Приходный ордер на товары".
- **Резервирование под клиента** -- кнопка `ЗарезервироватьПодКлиента` собирает уникальные серии из ТЧ и открывает форму `Лико_УстановкаРезерваМатериалов`.
- **Бухгалтерский учет** -- управление через флаг `Лико_ОтражатьВБухгалтерскомУчете`. При включении заполняется таблица `Лико_ЦеныНоменклатуры` (свертка по номенклатуре).
- **Интеркампани** -- определение и управление через `Лико_Интеркампани`, `Лико_РаспоряжениеИнтеркампани`.
- **Товары в пути** -- для складов типа `ТоварыВПути` добавляются колонки `Лико_Цена`, `Лико_Сумма`, `Лико_ВалютаТоваровВПути`.
- **Автоподбор договора** -- `Лико_ДоговорАвтоПодборВместо` подбирает договоры по контрагенту из распоряжения.

## Ключевые процедуры

- `Лико_ПриСозданииНаСервереПосле(Отказ, СтандартнаяОбработка)` -- основная инициализация формы: BRC, видимость, интеркампани (сервер).
- `Лико_ПриОткрытииПеред(Отказ)` -- авторизация склада, заполнение автора и рабочего места (клиент).
- `Лико_ОткрытьПодборСерий(Текст, ТекущиеДанные)` -- замена стандартного подбора серий для СИМ (клиент).
- `Лико_ПодборСерийЗавершение(РезультатФорма, ПараметрыФорма)` -- обработка результата подбора ОбъектовНоменклатуры (клиент).
- `СформироватьТаблицуУпаковокBRC()` -- динамическое создание колонок BRC в ТЧ (сервер).
- `ЗаполнитьКритерииДляВходногоКонтроля()` -- синхронизация критериев с видом контакта (сервер).
- `Лико_ПослеЗаписиПосле(ПараметрыЗаписи)` -- автопечать ордера, обновление BRC (клиент).
- `Лико_ЗарезервироватьПодКлиентаПосле(Команда)` -- асинхронная процедура резервирования (клиент).
- `Лико_ПодписатьДокументПосле(Команда)` -- подпись BRC с проверкой заполнения решений (клиент).

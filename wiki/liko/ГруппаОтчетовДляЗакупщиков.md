# ГруппаОтчетовДляЗакупщиков

> Отчетная группа для отдела закупок с расширенным отчетом по остаткам материалов для производства.

## Что делает / Доработки
Расширяет форму отчета для группы закупщиков. Основная доработка — процедура `ОстаткиДляПроизводстваВ4`, которая формирует отчет по остаткам материалов в разрезе рабочих центров (ячеек). Запрос анализирует:
- Остатки регистра `ТоварыВЯчейках` по списку рабочих центров
- Группировку по объектам номенклатуры (`ЯССМ_ОбъектНоменклатуры`)
- Поля: втулка, нарезка, артикул, код ценовой группы
- Расчет «намотки» с группировкой по диапазонам (для бригадиров)
- Признак незавершенной продукции

## Ключевые процедуры
- `ОстаткиДляПроизводстваВ4(ТабДокументГотовый, ВыводитьШапку)` — отчет по остаткам для производства с запросом к `ТоварыВЯчейках`

## Параметры
- `ПоРабочимЦентрам` — флаг фильтрации по РЦ
- `СписокРЦ` — список рабочих центров (ячеек) для отбора

# Лико_ПравилаПодписиДокументов

> Правила подписи документов списания: определение правила по виду номенклатуры с приоритетами и СКД-настройкой.

## Что хранит
Правила для определения подписи документов расхода (списания материалов). Каждое правило привязано к `ВидНоменклатуры` и `Организация`, имеет приоритет и может использовать сложную СКД-настройку.

**Основные реквизиты:** ВидНоменклатуры, Организация, Приоритет, СложнаяНастройка, ОтборНастройки (ХранилищеЗначения для СКД), Выключить.

**Простая настройка** (СложнаяНастройка=Ложь): проверка дополнительных реквизитов номенклатуры на соответствие/исключение.

**Сложная настройка** (СложнаяНастройка=Истина): выполнение СКД-пакета через макет `ОтборПоУсловию` с параметрами Номенклатура, ДокументРасхода, Количество, КоличествоУпаковок.

## Ключевые процедуры

### ObjectModule
- `ПередЗаписью()` -- автонумерация приоритета для новых элементов; формирование наименования из ВидНоменклатуры и описания доп. реквизитов
- `ПриЗаписи()` -- пустой обработчик
- `ОбработкаПроверкиЗаполнения()` -- снимает все проверки заполнения

### ManagerModule
- `ОпределитьПравило(Организация, Номенклатура, ДокументРасхода, Количество, КоличествоУпаковок)` -- основной метод: перебор правил по приоритету, проверка простых условий (доп. реквизиты) или сложных (СКД через `ИспользоватьПравилоСКД`)
- `ИспользоватьПравилоСКД(Выборка, Номенклатура, ...)` -- выполняет СКД-макет `ОтборПоУсловию`, возвращает Истина/Ложь
- `ПолучитьПриоритетМакс(ВидНоменклатуры)` -- возвращает максимальный приоритет для вида
- `ПереместитьПоПриоритету(Ссылка, Шаг)` -- атомарный swap приоритетов между двумя правилами в транзакции
- `ПолучитьПравилоПоПриоритету(ВидНоменклатуры, Приоритет)` -- поиск правила по приоритету

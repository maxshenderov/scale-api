# Лико_ПаллетыВСекциях

> Регистр накопления остатков: отслеживает размещение паллет по секциям и адресам склада.

## Что хранит

Остатки паллет в складских секциях с привязкой к адресам (ячейкам). Каждая паллета имеет количество и может быть заблокирована.

## Измерения

| Измерение | Тип | Описание |
|---|---|---|
| Секция | Справочник.Лико_СкладскиеСекции | Складская секция |
| Паллет | Справочник.Лико_Паллеты2_0 | Паллета |
| Адрес | Справочник.СкладскиеЯчейки | Адрес (ячейка) размещения |

## Ресурсы

| Ресурс | Тип | Описание |
|---|---|---|
| Количество | Число | Количество |
| Заблокирован | Число | Заблокированное количество |

## Регистраторы

`Документ.Лико_ПеремещениеПаллета2_0`, `Документ.Лико_ФормированиеПаллета2_0`, `Документ.Лико_ЗаданиеНаОтборРазмещение`

## Ключевые процедуры

- `ОстаткиПоАдресамСекции(Секция)` — возвращает `Соответствие` (ключ — Адрес, значение — Структура с полями: Секция, Паллет, Количество, Заблокирован, Типоразмер, Высота, Ширина, Глубина, Вес). Использует виртуальную таблицу `Остатки` с отбором по секции и левое соединение с `Лико_ПараметрыПаллет.СрезПоследних` для получения типоразмера.
- `ПолучитьАдрес(Паллет)` — возвращает текущий адрес (СкладскаяЯчейка) размещения паллеты по виртуальной таблице `Остатки`.

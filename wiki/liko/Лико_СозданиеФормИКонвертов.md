# Лико_СозданиеФормИКонвертов

> Обработка создания форм и конвертов для производства — с привязкой конверта к форме, цветоделением и группировкой.

## Что делает

Управляет созданием форм (печатных форм, штампов) и конвертов (envelope-объектов, группирующих формы по типу цвета). Использует документ `Лико_ВозвратТоваров` как источник номенклатуры для создания форм. Поддерживает:
- Создание формы с автоматической привязкой к конверту (создаёт конверт если нужно).
- Создание и печать конверта отдельно.
- Группировку конвертов по цветности (CMYK, Pantone/спеццвета).
- Автоматическое определение следующего порядкового номера конверта в группе.
- Предустановку цветности из настроек по умолчанию.

## Ключевые процедуры

- `СоздатьФормуСПривязкойККонверту()` — создаёт форму и привязывает её к существующему или новому конверту. Определяет группу конверта по цветности.
- `СоздатьРаспечататьКонверт()` — создаёт и отправляет на печать конверт.
- `ОпределитьКодДляНового()` — вычисляет следующий порядковый номер конверта в заданной группе.

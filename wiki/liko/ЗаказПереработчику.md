# ЗаказПереработчику (типовой, доработан)

> Доработка Лико: расчет роликов (Намотка/Втулка/КолРоликов) в строках «Продукция» и «Материалы» на форме документа.

## Доработки

- **Расчет роликов в табличных частях** — для строк «Продукция» и «Материалы» при изменении характеристики, втулки, намотки или количества роликов автоматически пересчитывается `КоличествоУпаковок` по формуле: `(Размер нарезки / 1000) * Намотка * КолРоликов`.
- **Автоподстановка втулки 76 мм** — если характеристика имеет нарезку `ЯССМ_Нарезка`, и втулка не заполнена, автоматически подставляется втулка размером 76 мм из справочника `Лико_Втулки`.

## Ключевые процедуры

- `ПриВвводеРоликовПродукция(Таблица)` (на клиенте) — универсальная функция расчета роликов для таблиц «Продукция» и «Материалы». Получает нарезку из характеристики, подставляет втулку 76, вычисляет `КоличествоУпаковок`.
- `ВтулкаСервер76()` (на сервере без контекста) — запрос к справочнику `Лико_Втулки` для получения втулки с размером 76.
- Обработчики изменений реквизитов на клиенте (`Лико_ПродукцияХарактеристикаПриИзмененииПосле`, `Лико_ПродукцияЛико_ВтулкаПриИзмененииПосле`, `Лико_ПродукцияЛико_НамоткаПриИзмененииПосле`, `Лико_ПродукцияЛико_КолРоликовПриИзмененииПосле` и аналоги для «Материалы») — вызывают `ПриВвводеРоликовПродукция`.

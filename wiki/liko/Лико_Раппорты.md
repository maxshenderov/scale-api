# Лико_Раппорты

> Раппорты (раппортные соотношения) для этикеток — расчёт высоты этикетки по длине печати и количеству.

## Что хранит
Справочник раппортов для печати этикеток. Раппорт -- это соотношение, используемое при расчёте размера этикетки при тиражировании на печатной форме.

Неиерархический справочник. Код строковый (до 9 символов), наименование до 25 символов. Содержит реквизит `ДлинаПечати` (числовой).

### ФормаПредложенияРазмераЭтикетки
Форма выбора для предложения размера этикетки. На вход получает `ФормаОтбор` -- массив структур с Раппорт и КоличествоЭтикеток. Вычисляет `ВысотаЭтикетки = Окр(ДлинаПечати, 2) / КоличествоЭтикеток`. При выборе возвращает структуру `(ВысотаЭтикетки, Раппорт)`.

При наличии параметра `Заказ` и виде заказа Повтор/ПовторСИзменением -- предупреждает, что вид заказа изменится на "Новый".

## Ключевые процедуры
ObjectModule и ManagerModule отсутствуют. Вся логика в форме:

### ФормаПредложенияРазмераЭтикетки
- `ПриСозданииНаСервере()` -- заполняет список предложений из параметра `ФормаОтбор`, рассчитывает ВысотаЭтикетки
- `Выбрать()` / `СписокВыбор()` -- возвращает выбранный вариант (ВысотаЭтикетки, Раппорт)

# Лико_БланкЭтапа

> Документ фиксации бланков (партий) по этапам производства. Учитывает расход материалов по номеру бланка и закрывает бланк в регистре накопления.

## Что делает

Документ группирует продукцию по номеру бланка (партии) в рамках этапа производства. Каждый бланк связывается с заказом клиента, рабочим центром и номером проката. Табличная часть «Товары» содержит номенклатуру с признаками расхода (`Списать`, `ВидСекции`, `ДопРасход`). 

Основное назначение — формирование движений по регистру `Лико_ЗакрытиеБланка`: приход и расход по бланкам с учётом перемотки, сборки и списания.

## Ключевые процедуры

- `Лико_ТекстЗапросаТаблицаДвиженияЛико_ЗакрытиеБланка()` (ManagerModule) — формирует текст запроса для движений по регистру `Лико_ЗакрытиеБланка`. Использует временные таблицы `ВтТаблицаТовары` и `ВтТаблицаРасход`. Объединяет приход и расход, фильтрует по НомерПроката, исключает сборку и списание на расходы. Параметризуется: ЗаказКлиента, Ссылка, НомерПроката, ВидОперации, Период, ЭтапПроизводства.

## Связь с ЗаказКлиента

Связан через реквизит `ЗаказПокупателя` (ссылка на [[ЗаказКлиента]]). Каждый бланк этапа принадлежит конкретному заказу. Используется в запросах ЗаказКлиента для сопоставления бланков и засчитанных этикеток.

## Используемые модули

- `Лико_ПроведениеДокументов` — `ТребуетсяТаблицаДляДвижений()`, `ЕстьТаблицаЗапроса()`
- Тексты запросов регистров (`ВтТаблицаТовары`, `ВтТаблицаРасход`)

## Реквизиты

- `ЯчейкаПолучатель` — складская ячейка

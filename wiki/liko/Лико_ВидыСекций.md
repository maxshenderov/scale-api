# Лико_ВидыСекций

> Справочник видов секций печати — ключевой классификатор всех технологических операций на производстве этикетки и упаковки.

## Что хранит

Иерархический справочник видов секций (операций) с возможностью настройки параметров секций для каждой позиции.

**Реквизиты:**
- `ВидПечати` — связанный вид печати
- `ОтображениеНаФорме` (Строка) — режим отображения на форме заказа: `ГруппаЦвета`, `ГруппаМатериалыРаботы`
- `ПараметрыСекций` (ТЧ) — настраиваемые параметры для секции (тип, вид на форме, синоним)
- `ЗначенияПараметров` (ТЧ) — предопределенные значения параметров

**Предопределенные значения (40+ видов):**
- Группа `Глубокая`: ГлубокаяПечать, ГлубокаяЛаминация
- Группа `Флексо`: ФлексоПечать, ЛаминацияФлексо, SofttouchЛаминация, ЛаминацияСамоклейкой, ТиснениеХолодноеФлексо, ХолотрансфернаяЛаминация
- Группа `ЦифровойМодуль`: ЦифровоеТиснение, ЦифровойЛак
- Одиночные: Активация, Аппликация, БессольвентнаяЛаминация, Вырубка, ГорячееТиснение (несколько вариантов), Гравировка, Инкджет, Конгрев, Нумератор, ОфсетнаяПечать, Перфорация, Праймирование, ПродольнаяРезка, ПоперечнаяРезка, РаскройМатериала, СклейкаТУ, СпайкаПакетов, ТрафаретнаяПечать и др.

## Ключевые процедуры

Форма `Лико_РедактированиеПараметровСекции`:
- `ПриСозданииНаСервере()` — динамически создает реквизиты и элементы формы на основе `ПараметрыСекций` (переключатели, флажки, поля ввода). Управляет видимостью групп `ГруппаЦвета` и `ГруппаМатериалыРаботы`
- `ЗаписатьВХранилище()` — сериализует значения параметров в строку для передачи между формами
- `НачалоВыбораРеквизита()` — кастомный выбор номенклатуры/ценовой группы с вопросом "Это Ценовая группа?"
- `ДоступностьПолей()` — управляет видимостью полей ТипЦвета/ВидЗаливки в зависимости от ВидТМЦ (Краска или нет)

Форма элемента:
- Работа с изображениями (как в [[Лико_ВидыКонтактовСПищевойПродукцией]])
- Навигация по вложенным секциям

# mcp_APIBackend

> MCP HTTP-сервис: принимает JSON-RPC 2.0 запросы, реализует полный цикл MCP-протокола.

## Что делает

HTTP-сервис 1С, реализующий MCP Streamable HTTP поверх JSON-RPC 2.0.
Это главная точка входа MCP-сервера — все внешние запросы проходят через этот модуль.

## Endpoints

- `POST /rpc` — универсальный JSON-RPC endpoint
- `POST /mcp` — MCP Streamable HTTP endpoint
- `GET /mcp` — возвращает 405 (Method Not Allowed), согласно спецификации MCP
- `GET /health` — healthcheck, возвращает `{"status": "ok"}`

Все `/rpc` и `/mcp` POST-запросы обрабатываются единой функцией `ОбработатьJSONRPCЗапрос()`.

## Маршрутизация JSON-RPC методов

| Метод | Обработчик | Описание |
|---|---|---|
| `initialize` | `ОбработатьInitialize()` | MCP handshake: `protocolVersion: 2025-03-26`, `capabilities`, `serverInfo` |
| `tools/list` | `ПолучитьСписокИнструментов()` | Возвращает все инструменты из контейнеров с inputSchema |
| `tools/call` | `ВызватьИнструмент()` | Ищет инструмент по имени в таблице, вызывает через `mcp_Выполнение`, возвращает content + isError |
| `resources/list` | `ПолучитьСписокРесурсов()` | Возвращает все ресурсы из контейнеров |
| `resources/read` | `ПолучитьРесурс()` | Ищет ресурс по URI, читает через `mcp_Выполнение` |
| `prompts/list` | `ПолучитьСписокПромптов()` | Возвращает все промпты с аргументами |
| `prompts/get` | `ПолучитьПромпт()` | Ищет промпт по имени, получает сообщения через `mcp_Выполнение` |

## Ключевые процедуры

- `ОбработатьJSONRPCЗапрос(Запрос)` — универсальный обработчик: парсит JSON-RPC тело, проверяет версию, извлекает method/params/id, маршрутизирует. Для notifications (нет id) возвращает 204 No Content. Ошибки обработки возвращает как JSON-RPC error с кодом -32603.
- `ОбработатьInitialize(Параметры)` — handshake: capabilities (tools, resources, prompts), serverInfo (name: "1C MCP Server", version: "1.0.0").
- `СформироватьJSONУспех(HTTPОтвет, ИД, Результат)` — оборачивает результат в `{jsonrpc: "2.0", id, result}`.
- `СформироватьJSONОшибку(HTTPОтвет, ИД, Код, Сообщение)` — оборачивает ошибку в `{jsonrpc: "2.0", id, error: {code, message}}`.
- `СформироватьОтвет204()` — пустой ответ для notifications.

## Обработка ошибок

- Неподдерживаемая версия JSON-RPC: код -32600
- Неизвестный метод: код -32601
- Внутренняя ошибка сервера: код -32603
- Ошибки в инструментах оборачиваются в content с `isError: true` (не прерывают HTTP-ответ)

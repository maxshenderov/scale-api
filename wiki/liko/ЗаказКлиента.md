# ЗаказКлиента

> Центральный документ ERP — заказ клиента на производство этикеток. Расширен кастомной логикой через расширение liko.

## Что делает

Типовой документ `ЗаказКлиента` из ERP расширен бизнес-логикой Лико. В расширении переопределены ObjectModule и ManagerModule. Документ является точкой входа для всего производственного цикла: от заявки на дизайн до отгрузки. Содержит табличные части Товары, ВидыРабот, Цвета и кастомные реквизиты (Этикетки, НомерБезПрефикса, Контрагент и др.).

Расширение добавляет логику соответствия бланков и засчитанных этикеток по потреблению следующего проката — ключевой механизм учёта движения материалов между этапами.

## Ключевые процедуры (расширение)

- `расш_СформироватьСоответствиеЗасчитанныхЭтикетокПоПотреблениюСледующегоПроката(ТекНомерПроката)` — формирует соответствие бланков и засчитанных этикеток. Для типа заказа «Термоусадка» делит на количество ручьёв, для «СамоклеящаясяЭтикетка» берёт чистые метры. Запрашивает данные из документов [[Лико_БланкЭтапа]] по фильтру ЗаказКлиента + НомерПроката.
- `Лико_СоздатьЗаказНаполуфабрикат()` (в ManagerModule) — создаёт дочерний заказ типа «Полуфабрикат» для оснастки/гравировки.

## Используемые модули

- `Лико_БланкЭтапа` — источник данных о расходе по бланкам этапов
- `Лико_ТипыЗаказов` — определяет логику расчёта (Термоусадка / СамоклеящаясяЭтикетка)
- `Лико_ВидыСекций` — фильтрация по виду секции «Печать»
- `Лико_ОбщегоНазначенияСервер` — `ЗаписатьРСЛико_ЭтапыЗаказа()`
- `Лико_ЭтапыВыполненияЗаказа` — этапы для полуфабрикатов

## Формы (расширение)

- `Лико_ФормаДокумента` — основная форма документа (модуль пуст в расширении, логика в основной конфигурации)
- `Лико_ФормаДокумента_ЗаказОснастки` — форма для работы с оснасткой
- `Лико_ФормаЗаявкиНаЦветоделение` — форма заявки на цветоделение
- `Лико_ФормаСозданияПолуфабриката` — форма создания полуфабриката
- `Лико_ФормаСписка` — форма списка
- `ФормаМонтажа` — форма монтажа

# Лико_МастерЗаполненияПоПрокату

> Общая форма — мастер заполнения секций для проката (передела) по выбранному рабочему центру.

## Что делает

Форма предоставляет интерфейс для настройки секций рабочего центра по конкретному прокату. Позволяет:
- Выбрать рабочий центр через форму выбора `Лико_ФормаВыбора`
- Автоматически заполнить таблицу секций на основе данных справочника `РабочиеЦентры.Секции` (20 колонок для основных секций)
- Просматривать и редактировать дополнительные секции в виде дерева
- Настраивать параметры каждой секции через форму `Лико_РедактированиеПараметровСекции`
- Перетаскивать дополнительные секции из дерева в таблицу
- Сохранять результат и передавать данные в вызывающую форму через оповещение `ПередаваемыеДанные`

Использует перечисление `Лико_ТипСекции` (Основная / Дополнительная). Условное оформление: зелёный фон для доступных секций, перламутровый/лимонный для секций с нулевым количеством.

## Ключевые процедуры

- `ПриОткрытии()` — если рабочий центр не задан, открывает форму выбора РЦ; иначе сразу заполняет таблицы
- `ПриСозданииНаСервере()` — принимает параметры: `РабочийЦентр`, `НомерПроката`, `ТЗСекции`, `Площадка`
- `ЗаполнитьТаблицуСекцийНаСервере()` — динамически создает реквизиты формы (до 20 колонок) по видам работ РЦ
- `ПолучитьТаблицуСекцийПоРЦ()` (сервер без контекста) — запрос к `РабочиеЦентры.Секции`, возвращает пакет из двух выборок (основные и доп. секции)
- `ОбходДереваТаблицаДопСекций()` — разворачивает дерево доп. секций, агрегирует параметры
- `ТаблицаСекцииКолонкиСекцийПриИзменении()` — логика выбора колонки: снимает остальные флажки, обновляет количество
- `ТаблицаСекцииПеретаскивание()` — drag-and-drop из дерева доп. секций в таблицу
- `ПрименитьИЗакрыть()` — формирует массив структур с данными секций и возвращает в вызывающую форму
- `ДобавлениеУсловногоОформления()` — три уровня УО: зелёный (доступно), перламутровый (количество <= 0), лимонный (доступно + количество <= 0)

# Лико_ЗакрытиеБланка

> Регистр накопления остатков: отслеживает движение (приход/расход) материалов и продукции при закрытии бланков этапов производства.

## Что хранит

Остатки по номенклатуре в разрезе заказа клиента, этапа производства и номера проката. Контролирует остатки — при проведении документов-регистраторов проверяет, не уходят ли остатки в минус (механизм контроля через `ДополнительныеСвойства`).

## Регистраторы

`Документ.Лико_БланкЭтапа`, `Документ.ЭтапПроизводства2_2`, `Документ.ПеремещениеТоваров`, `Документ.ДвижениеПродукцииИМатериалов`

## Ключевые процедуры (RecordSetModule)

- `ПередЗаписью(Отказ, Замещение)` — при записи набора помещает текущие остатки во временную таблицу `ДвиженияЛико_ЗакрытиеБланкаЗаписью`. Вычисляет количество «до записи» с учетом знака `ВидДвижения`.
- `ПриЗаписи(Отказ, Замещение)` — рассчитывает изменение остатка (с учетом накопленных изменений из других регистров), помещает результат во временную таблицу `ДвиженияТоварыНаСкладахИзменение`. Контролирует чтобы остаток не уходил в минус (`СУММА(...КоличествоИзменение) < 0`). Результат проверки сохраняется в `ДополнительныеСвойства.СтруктураВременныеТаблицы.ДвиженияЛико_ЗакрытиеБланка`.

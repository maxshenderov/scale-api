# Лико_Диадок

> Модуль интеграции с Диадок (EDI) — дополнение наименований номенклатуры, заполнение данных реализаций для электронного документооборота.

## Что делает
Обеспечивает интеграцию с системой электронного документооборота Диадок (Контур.Диадок): дополняет наименования номенклатуры специфичными данными (код этикетки заказчика, номер контракта, намотка) для требований P&G, заполняет дополнительные данные счетов-фактур (банковские реквизиты, курсы валют, суммы, номера транспортных накладных, РО) для корректной выгрузки в EDI.

## Ключевые процедуры
- `ДополнитьНаименованиеНоменклатуры()` — дополняет наименование продукта кодом этикетки заказчика, номером контракта, намоткой (для требований P&G)
- `ЗаполнитьДопДанныеПоРеализации()` — заполняет Content счёт-фактуры: транспортная накладная, банковские реквизиты (БИК, НаимБанк, НомерСчета), РО (номера контрактов), валюта, сумма, курс. Поддерживает корректировочные счета-фактуры. Работает только для контрагентов с признаком «ДиадокВыгружатьПоТребованиямPG».

## Используется в
- Выгрузка счетов-фактур в Диадок (документы РеализацияТоваровУслуг, КорректировкаРеализации)
- Специфичная логика для клиента P&G (Проктер энд Гэмбл)

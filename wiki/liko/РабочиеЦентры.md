# РабочиеЦентры (типовой, доработан)

> Печать штрихкодов (Code 128) для рабочих центров с автоопределением принтера этикеток.

## Доработки

### Печать этикетки рабочего центра (все формы: `ФормаВыбора`, `ФормаСписка`, `СтруктураРабочихЦентров`)
- **`Лико_ПечатьЭтикеткиПосле`** — команда печати: получает выделенные строки, для каждой вызывает серверную процедуру формирования табличного документа. Если включено свойство рабочего места `ПечатьСразуНаПринтер`, отправляет сразу на принтер; иначе показывает в просмотре.
- **`Лико_ПечатьЭтикеткиПослеНаСервере`** — вызывает `ВыводИнформацииПоДокументу()`.
- **`ВыводИнформацииПоДокументу()`** — формирует этикетку с макетом `ПФ_MXLСтикерРабочегоЦентра`:
  - Запрашивает `Лико_Код` рабочего центра
  - Формирует штрихкод Code 128 (тип 4) формата `2015` + `Лико_Код` (7 цифр с лидирующими нулями) + контрольная сумма через `Лико_Дополнительно.ПосчитатьКонтрольнуюСуммуШК()`
  - Выводит наименование рабочего центра
  - Направляет печать на принтер из настройки `ИмяПринтераЭтикеток` рабочего места

## Ключевые процедуры

- `ВыводИнформацииПоДокументу()` — формирование этикетки со штрихкодом (экспортная)
- `Лико_ПечатьЭтикеткиПосле()` — клиентский обработчик команды печати
- `Лико_ПечатьЭтикеткиПослеНаСервере()` — серверный обработчик команды печати

# РабочееМестоРаботникаСклада

> Рабочее место сотрудника склада с постраничным интерфейсом и сканированием штрихкодов. Поддерживает операции перемещения товаров, отбора и инвентаризации.

## Что делает
Основной инструмент складского работника. Интерфейс построен как пошаговый wizard с навигацией по страницам: Старт, Шапка, Товары, Завершение, Сообщения. Основной способ ввода данных — сканирование штрихкодов:

- **ШК сотрудника** — определяет оператора
- **ШК адреса/ячейки** — определяет склад и ячейку
- **ШК объекта номенклатуры** — добавляет товар в список сканирования
- **ШК табличного документа** — находит документ-основание (ОтборРазмещениеТоваров) и заполняет форму

Поддерживаемые типы операций:
- `Перемещение` — создаёт документ `ОтборРазмещениеТоваров` с видом `Перемещение`
- `Отбор` — дополняет существующий документ `ОтборРазмещениеТоваров` (вид `Отбор`)
- `Инвентаризация` — аналогично перемещению

## Ключевые процедуры
- `ОбработатьШтрихкоды()` — диспетчер: в зависимости от вида ШК вызывает обработку сотрудника, ячейки или номенклатуры
- `ОбработатьШтрихкодыНоменклатуры()` — маршрутизация по типу операции (Перемещение/Отбор/Инвентаризация)
- `ОбработатьШтрихкодыНоменклатурыПеремещение()` — проверяет наличие товара на складе, добавляет/обновляет строку сканирования с заполнением ячейки
- `ОбработатьШтрихкодыНоменклатурыОтбор()` — аналогично для отбора, но с текущим хранением
- `ЗакрытьИПровестиНаСервере()` — создаёт и проводит документы `ОтборРазмещениеТоваров`: отдельно перемещение и отдельно отбор
- `ПровестиДокументОтборРазмещение_Перемещение()` — создаёт новый документ перемещения, заполняет ТоварыОтбор и ТоварыРазмещение
- `ПровестиДокументОтборРазмещение_Отбор()` — дополняет существующий ордер на отбор
- `ТекущееМестоХранениеТоваров()` — запрос к `ТоварыВЯчейках.Остатки` для определения текущего местоположения
- `ЕстьНаСкладе(Структура, Склад)` — проверка наличия товара на складе по номенклатуре/серии/характеристике
- `ОтобразитьСтраницу(Действие)` — навигация по страницам wizard (Далее/Назад)
- `ПолучитьСсылкуПоШтрихкодуТабличногоДокументаСервер()` — поиск документа по ШК печатной формы

## Используемые модули
- `Лико_ДополнительноКлиент` — обработка ШК не-товара
- `Лико_Дополнительно` — значения реквизитов объектов
- `РабочееМестоРаботникаСкладаСервер` — обновление заданий, состояние выполнения

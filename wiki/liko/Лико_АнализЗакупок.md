# Лико_АнализЗакупок

> Общая команда «Анализ закупок» — открывает отчет `Лико_АнализЗакупок` с контекстным отбором по заказу поставщику.

## Что делает

При вызове из формы заказа поставщику открывает отчет `Отчет.Лико_АнализЗакупок.Форма` с предустановленным отбором:
- `Отбор.ЗаказПоставщику` = выбранный заказ
- `СформироватьПриОткрытии` = Истина
- `КлючВарианта` = `КонтекстныйЗаказПоставщику`
- Уникальный ключ пользовательских настроек (новый GUID)

## Ключевые процедуры

- `ОбработкаКоманды()` — формирует параметры открытия с отбором по `ПараметрКоманды` (ЗаказПоставщику) и открывает форму отчета

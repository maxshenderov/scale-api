# Лико_ОшибкиПравилПеремещенияТМЦ

> Регистр сведений для хранения ошибок валидации правил перемещения ТМЦ. При проведении документов движения проверяются на соответствие правилам — несоответствия записываются сюда для последующей обработки и отправки сообщений.

## Что хранит

- **Измерения:** Документ (регистратор), Серия
- **Ресурсы:** поля из структуры проверки правил (Правило, ТекущийАдрес, АдресХраненияНовый, Стратегия, Комментарий, НеИспользоватьПравило, ОтправкаСообщения и др.)
- Периодичность: по секундам, независимый

## Ключевые процедуры

- `СформироватьЗаписи(Объект, Отказ)` — универсальная проверка любого документа. Вызывает `Лико_ПравилаПеремещенияТМЦ.ВыполнитьПроверку()`. Если система запущена (`СтартСистемы()`), для каждого Товара из результата создает или обновляет запись с полями из проверки.
- `СформироватьЗаписиЗаявкаНаСклад(Объект, Отказ)` — специализированная проверка для `Лико_ЗаявкаНаСклад`. Дополнительно: пропускает товары без правила, устанавливает `НеИспользоватьПравило = Истина`, определяет `АдресХраненияНовый` (для передачи в производство — ячейка РЦ, иначе — адрес склада), заполняет `Стратегию` из правила и `Комментарий` через `ТекстОтменыПравила()`.
- `УстановкаПризнакаОтправкиСообщения(ДокументСсылка, Серия)` — помечает запись об ошибке как отправленную (`ОтправкаСообщения = Истина`). Автор: m.shenderov 02.03.2026.

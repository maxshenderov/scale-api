# Лико_ТиражМетраж

> Расчёт тиража и метража — производственные параметры печатных заказов.

## Что делает

Вычисляет производственные параметры: тираж, метраж, вид вырубки по рабочему центру. Центральный модуль для расчёта количественных показателей производства.

## Ключевые процедуры

- `ПолучитьВидВырубки(ЗаказСсылка, СпецификацияСсылка)` — определяет тип вырубки по рабочему центру заказа:
  - Поддерживаемые рабочие центры: **Schober, Indigo, Cartes, Omega, NewFoil, GallusInkjet, Omet, Weigang, Tatani, Comexi**
  - Каждый рабочий центр имеет свой вид вырубки (штанц, ротационная, лазер и др.)

## Рабочие центры Лико

| Рабочий центр | Технология |
|---|---|
| Schober | Флексо |
| Indigo | Цифровая (HP Indigo) |
| Cartes | Комбинированная |
| Omega | Офсет |
| NewFoil | Фольгирование |
| GallusInkjet | Цифровая (Gallus) |
| Omet | Комбинированная |
| Weigang | Термоусадка |
| Tatani | Термоусадка |
| Comexi | Флексо широкаяформат |

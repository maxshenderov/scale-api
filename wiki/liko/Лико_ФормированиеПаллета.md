# Лико_ФормированиеПаллета

> Документ формирования паллеты (старая версия). Собирает коробки/серии в паллету и создаёт цепочку типовых документов: этап производства, передача продукции, приходный ордер, сборка/разборка.

## Что делает

Объединяет серии (коробки) из ТЧ `Содержимое` в паллету на ячейке-получателе. При проведении:
- Проверяет, что коробки не были уже выпущены в другом формировании
- Формирует движения по регистрам `Лико_АдресноеХранение` и `Лико_УчетГотовыхЭтикеток`
- Для типа `ВыпускПродукции` — создаёт цепочку документов (этап, передача, приходный ордер, перемещение, корректировка регистров)
- Для растарки — обрабатывает разборку паллет

## Ключевые процедуры

### ObjectModule
- `ОбработкаПроведения()` — главный обработчик: проверка серий, создание типовых документов через `СоздатьТиповыеДокументы()`, запись движений.
- `СоздатьТиповыеДокументы()` — создаёт цепочку: `ЗаказНаПроизводство` этап, `ПередачаПродукции`, `ПриходныйОрдерНаТовары`, `КорректировкаРегистров`, `СборкаТоваров`.
- `СоздатьЭтап()` — создаёт этап производства (`ЗаказНаПроизводство`) с привязкой к заказу клиента.
- `СоздатьПередачуПродукции()` — создаёт документ `ДвижениеПродукцииИМатериалов` (передача на склад).
- `СоздатьПриходныйОрдер()` — создаёт `ПриходныйОрдерНаТовары` для приёмки.
- `СоздатьДокументКорректировкаРегистров()` — корректирует движения по регистрам для корректного учёта.
- `СоздатьСборкуТоваров()` — создаёт документ `СборкаТоваров` для объединения серий в паллету.
- `СоздатьДокументОтборРазмещениеТоваров()` — создаёт задание на отбор/размещение.
- `УдалитьЗаписиДвиженияПеремотки()` — очищает записи движения перемотки (для площадки Линкс).
- `ОбработкаУдаленияПроведения()` — отменяет проведение, проверяет зависимые документы.

### ManagerModule
- `СоздатьПередачуПродукцииВФоне()` — создаёт документ `ДвижениеПродукцииИМатериалов` в фоновом задании.
- `ДобавитьКомандыПечати()`, `Печать()` — заглушки печати.
- `СформироватьТаблицуДляКорректировкиРегистров()` — формирует таблицу серий с приходными ордерами для корректировки.

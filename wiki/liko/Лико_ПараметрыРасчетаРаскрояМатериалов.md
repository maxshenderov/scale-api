# Лико_ПараметрыРасчетаРаскрояМатериалов

> Иерархический справочник параметров для расчета раскроя (nesting) материалов — содержит правила с временными нормативами и таблицей параметров резки для оптимизации раскроя.

## Что хранит

Набор правил раскроя, привязанных к организации и виду номенклатуры, с возможностью сложной настройки через СКД (схема компоновки данных). Включает временные параметры работы оборудования (юмба, ролик, настройка ножей) и таблицу параметров резки.

**Реквизиты (блок правил):**
- `Выключить` (Булево) — отключение правила
- `Организация` (Справочник.Организации) — организация
- `ВидНоменклатуры` (Справочник.ВидыНоменклатуры) — фильтр по виду номенклатуры
- `Приоритет` (Число) — приоритет правила
- `СложнаяНастройка` (Булево) — использовать СКД для сложного отбора
- `ОтборНастройки` (ХранилищеЗначения) — настройки СКД
- `Описание`, `Комментарий` (Строка)

**Реквизиты (блок раскроя):**
- `ДлинаЮмбы` (Число) — длина юмбы (намоточного вала)
- `Скорость` (Число) — скорость резки
- `ВремяСъема` (Число) — время съема рулона
- `ВремяРолика` (Число) — время замены ролика
- `ВремяЮмбы` (Число) — время работы с юмбой
- `ВремяНастройкиНожей` (Число) — время настройки ножей

**Табличная часть «ДополнительныеРеквизиты»:**
- `Свойство`, `Значение`, `Исключить`, `ТекстоваяСтрока` — фильтрация по свойствам номенклатуры

**Табличная часть «ТаблицаПараметров»:**
- `КоличествоНожей` (Число) — количество ножей для раскроя
- `Метры` (Число) — метраж
- `НормативРезки` (Число) — коэффициент сложности резки

## Ключевые процедуры

- `Лико_ОпределитьПравило()` (Менеджер, закомментирована) — определяет подходящее правило раскроя по виду номенклатуры и документу расхода, с поддержкой сложной настройки через СКД и фильтрацией по дополнительным реквизитам

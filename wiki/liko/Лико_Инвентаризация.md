# Лико_Инвентаризация

> Документ-обёртка над типовым ПересчетТоваров — автоматически создаёт и заполняет пересчёт по адресному складу с группировкой по сериям.

## Что делает

Адаптер для проведения инвентаризации в адресном хранении. При проведении:
1. Проверяет отбор ячеек через СКД — содержимое документа должно соответствовать установленному отбору.
2. Формирует движения по регистру `Лико_АдресноеХранение`.
3. Автоматически создаёт типовой документ `ПересчетТоваров` в статусе «ВнесениеРезультатов», заполняя его содержимым из ТЧ `Содержимое` с сериями и ячейками.

При отмене проведения помечает связанный ПересчетТоваров на удаление.

## Ключевые процедуры

- `ОбработкаПроведения()` — проверяет отбор, формирует движения по `Лико_АдресноеХранение`, создаёт типовой ПересчетТоваров.
- `СоздатьТиповыеДокументы()` — пересоздаёт связанный ПересчетТоваров (помечает старый на удаление, создаёт новый).
- `СоздатьДокументПересчетТоваров()` — формирует документ ПересчетТоваров: заполняет ТЧ из содержимого инвентаризации (с сериями, ячейками), проводит через цепочку статусов (Подготовлено -> ВРаботе -> ВнесениеРезультатов).
- `ЗаполнитьУчетныеДанныеПересчета()` — заполняет ТЧ пересчёта через СКД-макет «ОтборПересчетаПоЯчейкам».
- `ПроверкаОтбора()` — проверяет, что все ячейки в содержимом соответствуют отбору.
- `ПередЗаписью()` — запрещает проведение документа (сообщение: «Данный документ запрещено проводить» — проведение только через собственную логику).
- `ОбработкаУдаленияПроведения()` — помечает связанный ПересчетТоваров на удаление.

### ManagerModule

Минимальный — содержит только заглушки `ДобавитьКомандыПечати()`, `Печать()`, `ДобавитьКомандыОтчетов()`.

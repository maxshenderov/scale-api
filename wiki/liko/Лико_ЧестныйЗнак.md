# Лико_ЧестныйЗнак

> Справочник кодов маркировки «Честный знак» — GTIN и GUID для идентификации продукции в системе цифровой маркировки.

## Что хранит

Коды маркировки товаров для интеграции с системой «Честный знак».

**Реквизиты:**
- `Gtin` — Global Trade Item Number (штрихкод товара)
- `Guid` — уникальный идентификатор записи
- `ДатаЭмиссии` — дата выпуска кода

## Ключевые процедуры

- `ПриСозданииНаСервере()` — скрывает поля `Код` и `Guid` для пользователей без полных прав; при создании нового элемента автозаполняет `Gtin` из `Наименования`.
- `GtinПриИзменении()` / `ДатаЭмиссииПриИзменении()` — при изменении полей пересчитывают наименование через `Лико_ДополнительноКлиентСервер.ПолучитьНаименованиеЧестногоЗнака()`.
- `ОбработкаПроверкиЗаполнения()` (ManagerModule) — на площадке ИксПак дополнительно проверяет `Номенклатура`, `ВидТМЦ`, `ВидПечати`, `ЦеноваяГруппа`.

# Лико_Планирование

> Логика планирования и генерации номеров заказов по правилам Лико.

## Что делает

Управляет нумерацией заказов. Генерирует уникальные номера по сложной схеме с учётом организации, типа заказа, региона и порядкового счётчика.

## Ключевые процедуры

- `ПолучитьНомерДляЗаказа(Организация, ТипЗаказа, ВидЗаказа, Регион)` — генерирует номер заказа по формуле:
  - `Организация.Префикс` + 5-значный код + 4-значная последовательность
  - 3-й символ: `Перечисления.Лико_ТипыЗаказов.Индекс(ТипЗаказа)` — признак типа в номере
  - Регион Линкс: нумерация от 2xxx
  - Регион ВеликийНовгород: своя логика нумерации

## Структура номера заказа

```
[Префикс орг][Год][ТипЗаказа][ВидЗаказа][NNNN]
Пример: ЛК26101234
  ЛК    — префикс организации Лико
  26    — год
  1     — индекс типа заказа (из перечисления)
  0     — вид заказа
  1234  — порядковый номер
```

## Связь с ЗаказКлиента

Вызывается при создании [[ЗаказКлиента]] для присвоения номера. Номер определяет тип заказа из перечисления `Лико_ТипыЗаказов`.

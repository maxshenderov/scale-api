# Лико_QR_code

> Общая форма для отображения QR-кода рабочего места. Использует WebSocket-сервер для коммуникации с мобильными устройствами.

## Что делает

При создании на сервере инициализирует WebSocket-соединение через `WebSocketСервер.Инициализация(ЭтаФорма, ПоказыватьQRCode)` с параметром `ПоказыватьQRCode=Истина`.

Форма предназначена для авторизации мобильных клиентов ERP — сканирование QR-кода на экране связывает мобильное устройство с рабочим местом 1С.

Есть закомментированная функция `ПолучитьQRCode()` (04.04.2021) — генерировала HTML с QR-кодом через библиотеку `qr.js` по коду `ERP_mobile_<КодРабочегоМеста>`.

## Ключевые процедуры

- `ПолучитьКодРабочегоМеста()` — возвращает `ПараметрыСеанса.Лико_РабочееМесто.Наименование`, если заполнено `ИмяКомпьютера`
- `ПриСозданииНаСервере()` — вызывает `WebSocketСервер.Инициализация()`
- `WebSocketURLПриНажатии()` — вызывает `WebSocketКлиент.ОбработкаСообщения()`
- `WebSocketДокументСформирован()` — заглушка
- `WebSocketОбработкаШтрихКода()` — экспортная, обрабатывает штрихкоды с мобильного (заглушка)

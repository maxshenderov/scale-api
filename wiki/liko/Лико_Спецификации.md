# Лико_Спецификации

> Центральный справочник спецификаций заказа — хранит полный состав заказа: товары, цвета (краски), виды работ, формы, нормативы, стоимость. Является ключевым объектом для расчета себестоимости и планирования производства.

## Что хранит

Полную спецификацию этикеточного заказа: какие этикетки, сколько, какими красками, на каком оборудовании, с какой оснасткой, по какой цене.

**Основные реквизиты:**
- `Площадка` (Справочник.Лико_Площадки) — производственная площадка
- `Менеджер`, `Дизайнер` (Справочник.Пользователи)
- `Партнер` (Справочник.Партнеры)
- `Контрагент` (Справочник.Контрагенты)
- `ТипЗаказа` (Перечисление.Лико_ТипыЗаказов) — самоклейка, термоусадка, упаковка и т.д.
- `ОсновнойМатериал` (Номенклатура/ЦеновыеГруппы) — базовый материал
- `Соглашение` (Справочник.СоглашенияСКлиентами)
- `ВидУпаковки` (Справочник.Лико_ВидыУпаковки)
- `СпособНаклейки` (Перечисление.Лико_СпособыНаклейки)
- `ОбразецЦвета` (Перечисление.Лико_ОбразцыЦвета)
- `ДавальческоеСырье`, `ЧестныйЗнак`, `Datamatrix`, `ЧЗ` (Булево)
- `СерийныйЗаказ`, `ПервыйВСерии` (для серийных заказов)
- `Регион` (Справочник.БизнесРегионы)
- `РасходКраски`, `Праймер`, `ШиринаЭтикетки`, `ДлинаЭтикетки`, `ЭтМЭР`
- Параметры печати: `Нарезка`, `Ручьи`, `ШагПечати`, `ДлинаПечати`, `Книжка`, `Цифровой`, `ТипографскийАгрегат`, `КнижныйМодуль`

**Табличные части:**
- **Товары** — список этикеток: `Номенклатура`, `Количество`, `Цена`, `Сумма`, `NКонтракта`, `ВерсияНоменклатуры`, параметры намотки, вес
- **Цвета** — краски по секциям: `ВидПечати`, `ТипКраски`, `Название`, `ПроцентЗаливки`, `Грамматура`, `ВидСекции`, `Форма`, `ФормулаПантона`, `Вал`, `Анилокс`, `ТрафаретнаяСетка`, `НомерПроката`, `НомерВарианта`, `Номенклатура`, `Оснастка`, `Цена`
- **ВидыРабот** — операции: `ВидРабот`, `РабочийЦентр`, `Оснастка`, `Материал`, `Нарезка`, `Клей`, `ПроцентЗаливки`, `НомерВарианта`, `НомерПроката`, `Цена`
- **Формы** — привязанные печатные формы: `Значение` (Справочник.Лико_Формы), `Цветоделение`
- **Перемотка** — варианты перемотки: `Наименование` (Справочник.Лико_Перемотка)
- **Стоимость** — расчет стоимости по вариантам: `НомерВарианта`, `РабочийЦентр`, `Себестоимость`, `Цена`, `Доходность`, `ПогонныйМетраж`, `КвадратныйМетраж`, `Рентабельность`, `ВремяВыполнения`, `СтавкаНДС`, `Вес`
- **Нормативы** — нормативы по прокатам: `НомерПроката`, `РабочийЦентр`, `МетрыНаНастройку`, `МетрыНаБрак`, `ВремяПечати`, `СкоростьПечати`, `ПроцентНаБрак`, `Нарезка`, `КоличествоКликов`, `ВремяНаСменуРоликов`
- **Добавки** — компоненты краски: `Номенклатура`, `ПроцентВСмеси`, `Грамматура`

## Ключевые процедуры

- `Лико_РасчетДляТендераПосле()` (ФормаЭлемента, клиент) — открывает внешний отчет «РасчетЗаказаДляТендера» с отбором по текущей спецификации
- `Лико_ЗаполнитьИзРаботВместо()` (ФормаЭлемента, клиент) — заполняет таблицу «Цвета» на основе таблицы «ВидыРабот»: обрабатывает ламинацию (включая флексо-ламинацию с секциями), горячее тиснение (плоское продольное/поперечное), остальные виды работ (связка через `Лико_ВидСекции`); заполняет краски, материал, нарезку, процент заливки, оснастку, нумераторы
- Закомментированы: `ЗаполнитьПараметрыСтоимостиНаСервере()` (расчет погонного/квадратного метража), `ПараметрыШтампаЭтМЭРПриИзмененииВместо()`

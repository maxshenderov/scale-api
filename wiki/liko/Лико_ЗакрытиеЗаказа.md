# Лико_ЗакрытиеЗаказа

> Документ массового закрытия заказов клиентов. Проверяет дубликаты, наличие выпусков, закрывает этапы заказов, списывает остатки в ячейках. Имеет особую логику для площадки Линкс (проверка роликов, НЗП, тачпадов).

## Что делает

- Две табличные части: `Заказы` и `ЗаказыРаскрой`
- При проведении:
  1. `ПроверкаДублей()` — проверяет, что заказ не указан несколько раз и не закрыт ранее
  2. `ПроверкаДублейРаскрой()` — то же для заказов на раскрой
  3. `ПроверитьНаличиеВыпусков()` — для Ликофлекс: если есть закрытие материалов, должен быть выпуск
  4. Закрытие заказов:
     - Для **Линкс**: проверка незавершённых роликов после перемотки, остатков НЗП, тачпада; очистка вкладки Производство, заполнение затрат
     - Для **остальных**: `Лико_Дополнительно.ЗакрытьЭтапыИЗаказ()` + `Лико_Планирование.ПеренестиЗаказ()` в «ЗакрытиеЗаказа»
  5. Актуализация резерва материалов
  6. Закрытие заказов на раскрой (статус «ЗакрытиеЗаказа»)
  7. `УстановитьДатуОбработкиЭтаповВРегистреЭтапыЗаказа()` — фиксирует дату обработки этапа ОПП
  8. Отмена заявок на формы при закрытии
  9. Для **Линкс**: письмо о расхождении выпуска и переданного на ВК
  10. Стандартное проведение через `ПроведениеДокументов`

## Ключевые процедуры

- `ПроверкаДублей(Отказ)` — запрос к ТЧ Заказы: поиск дубликатов в документе и в других проведённых закрытиях
- `ПроверитьНаличиеВыпусков(Отказ)` — запрос: есть Лико_БланкЭтапа (закрытие материалов) но нет Лико_ФормированиеПаллета (выпуск) -> отказ
- `ЗакрытьЗаказыНаРаскрой(Заказ)` — устанавливает Состояние = ЗакрытиеЗаказа для заказа на раскрой
- `СформироватьИОтправитьПисьмоОПроверкеКоличестваВыпускаИКоличестваПереданногоНаВК()` — сложный запрос сравнения расхода материала и переданного на ВК для Линкс

## ManagerModule

- `ДанныеДокументаДляПроведения()` — формирует таблицу для движений регистра `ТоварыВЯчейках` (расход остатков рулонной продукции в ячейках РЦ и НП ЦУ)
- `УстановитьДатуОбработкиЭтаповВРегистреЭтапыЗаказа(МассивЗаказов, МассивЭтапов)` — проставляет `ДатаОбработкиЭтапа` в `Лико_ЭтапыЗаказа`
- `ЗарегистрироватьУчетныеМеханизмы()` — регистрирует механизмы «АдресныйСклад» и «Лико_Склад»

# Лико_РешенияПоБракуМатериалов

> Решения по браку материалов — классификатор действий при забраковке материалов.

## Что хранит
Справочник возможных решений/действий, принимаемых при обнаружении брака материалов. Используется в документах `Лико_ЗабраковкаМатериалов` для указания что делать с забракованным материалом (списать, вернуть поставщику, использовать с ограничениями и т.д.).

Неиерархический справочник. Код строковый (до 9 символов), наименование до 150 символов. Комментарий метаданных: `++ kit:mih web 08.07.21`.

## Ключевые процедуры
ObjectModule и ManagerModule отсутствуют. Форма:

### ФормаВыбораИнфопад
- `СписокПриАктивизацииЯчейки()` -- при клике на поле Наименование закрывает форму с текущей строкой (быстрый выбор)
- `СписокКнопкаВНиз()` / `СписокКнопкаВверх()` -- навигация по коду: переход к следующему/предыдущему решению

# mcp_Выполнение

> MCP-модуль: движок выполнения — вызывает инструменты, читает ресурсы, получает промпты из обработок-контейнеров.

## Что делает

Принимает строку из таблицы инструментов/ресурсов/промптов (содержит имя обработки-контейнера
и имя конкретного элемента), находит менеджер обработки и вызывает соответствующий метод.

Является мостом между слоем HTTP-маршрутизации (`mcp_APIBackend`) и конкретными
обработками-контейнерами.

## Ключевые процедуры

- `ВыполнитьИнструмент(СтрокаТаблицыИнструментов, Параметры)` — находит обработку-контейнер по `ИмяОбработкиКонтейнера`, вызывает `ВыполнитьИнструмент(ИмяИнструмента, Параметры)` и возвращает результат.
- `ПрочитатьРесурс(СтрокаТаблицыРесурсов, Адрес)` — находит обработку-контейнер, вызывает `ПрочитатьРесурс(Адрес)` и возвращает содержимое.
- `ПолучитьПромпт(СтрокаТаблицыПромптов, Имя, Параметры)` — находит обработку-контейнер, вызывает `ПолучитьПромпт(ИмяПромпта, Параметры)` и возвращает сообщения.

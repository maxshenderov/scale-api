# РасходныйОрдерНаТовары (типовой, доработан)

> Исключение регистра СвободныеОстатки из контроля для складов СИМ; автогенерация цепочки ЗаказМатериаловВПроизводство и ДвижениеПродукцииИМатериалов.

## Доработки

- **`Лико_СформироватьСписокРегистровДляКонтроля`** (`&После("СформироватьСписокРегистровДляКонтроля")`) -- для складов с типом `СИМ` удаляет регистр `СвободныеОстатки` из массива контролируемых регистров. Это отключает проверку свободных остатков при проведении расходного ордера для складов СИМ.
- **`СоздатьРаспоряжение(Объект)`** (ManagerModule) -- создает цепочку документов: `ЗаказМатериаловВПроизводство` (со статусом "КВыполнению", хозоперация "ПередачаМатериаловВКладовую") и на его основании `ДвижениеПродукцииИМатериалов` (со статусом "Принято"). Товары сворачиваются по Номенклатура+Характеристика+Назначение+Упаковка. При ошибке транзакция отменяется.

## Ключевые процедуры

- `Лико_СформироватьСписокРегистровДляКонтроля()` -- исключение СвободныеОстатки для СИМ (ObjectModule).
- `СоздатьРаспоряжение(Объект)` -- точка входа для создания цепочки документов производства (ManagerModule, экспорт).
- `СоздатьЗаказПередачуМатериаловВПроизводство(Объект)` -- создание заказа материалов в производство (ManagerModule).
- `СоздатьПередачуВПроизводство(Объект)` -- создание движения продукции и материалов на основании заказа (ManagerModule).

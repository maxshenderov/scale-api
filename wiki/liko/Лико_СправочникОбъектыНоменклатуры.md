# Лико_СправочникОбъектыНоменклатуры

> Форма выбора номенклатуры для склада — упрощённый вариант, получает Склад/Помещение из рабочих мест.

## Что делает

Аналог формы выбора из `Лико_ПодборНоменклатуры`, но с упрощённой логикой:
- Склад и Помещение определяются из регистра `РабочиеМеста` (привязка к рабочему месту пользователя), а не передаются явно.
- Более простой запрос остатков (без сложной фильтрации по множеству параметров).
- Открывает форму элемента серии напрямую (без промежуточной формы подбора).
- Поддерживает поиск по штрихкодам, коду, артикулу.

## Ключевые процедуры

- `ПриСозданииНаСервере()` — инициализирует склад и помещение из рабочих мест, настраивает видимость и параметры формы.
- `ТекстЗапросаОстатковНоменклатуры()` — упрощённый запрос остатков (по сравнению с версией из `Лико_ПодборНоменклатуры`).
- `ОбработатьШтрихкоды()` — поиск номенклатуры по штрихкодам.

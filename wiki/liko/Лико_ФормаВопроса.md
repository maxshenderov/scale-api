# Лико_ФормаВопроса

> Общая форма диалога вопроса с настраиваемыми кнопками и таймером блокировки.

## Что делает

Универсальная форма вопроса/подтверждения. Поддерживает несколько режимов кнопок через параметр `Кнопки`:
- `ДаНет` — две кнопки, Отмена скрыта
- `ДаОтмена` — две кнопки, Нет скрыта
- `СнятьЗакрытьОтмена` — кнопки «Снять» и «Закрыть»
- `ПроблемаРешенаПечатьМП` — кнопки «Проблема решена» и «Печать МП»
- `Сообщение` — одна кнопка «ОК» (Нет), Да и Отмена скрыты

Поддерживает таймер блокировки (`ПодождатьСек`): кнопка «Да» блокируется на N секунд, в заголовке отображается обратный отсчет.

## Параметры формы

- `ТекстВопроса` — выводится в декорацию `ДекорацияНадписьТекстВопроса`
- `Кнопки` — строка-режим кнопок (см. выше)
- `ПодождатьСек` — секунд блокировки кнопок (0 = без блокировки)

## Ключевые процедуры

- `ПриСозданииНаСервере()` — настраивает видимость/заголовки кнопок по режиму; запускает таймер при `ПодождатьСек > 0`
- `ПриОткрытии()` — подключает обработчик ожидания `РазблокироватьКнопки` каждые 0.1с
- `РазблокироватьКнопки()` — обновляет заголовок кнопки Да с обратным отсчетом; разблокирует по истечении времени
- `Да()` / `Нет()` / `Отмена()` — закрывают форму с соответствующим `КодВозвратаДиалога`

# Лико_ЗаполнениеТЧПТУ

> Обработка заполнения табличной части ПТУ (приходный ордер) по остаткам регистра `Лико_ТоварыКПоступлению`.

## Что делает

Открывает форму подбора товаров к поступлению из регистра накопления `Лико_ТоварыКПоступлению.Остатки`. Обязательные параметры: `Партнер` и `Склад`. Поддерживает фильтрацию по номенклатуре и характеристике.

Два режима работы:
- **ПоНоменклатуреДокумента** — предварительно загружает номенклатуру из переданной таблицы товаров документа, затем по ней фильтрует остатки.
- **БезХарактеристики** — показывает товары без характеристик (пустая ссылка на характеристику), скрывает колонку характеристики и кнопку добавления в документ (только выбор ПриходногоОрдера).
- С характеристиками — показывает и характеристику, и кнопку добавления выбранных строк в документ.

При выборе конкретной номенклатуры пользователь видит упрощённую форму: выбирает одну строку из остатков и возвращает ПриходныйОрдер. При пустой номенклатуре — таблица с флажками «Выбрать» и возможностью множественного выбора, возвращает массив структур.

## Ключевые процедуры

- `ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)` — инициализирует параметры (Партнер, Склад, Номенклатура, Характеристика, НоменклатураДокумента), заполняет таблицу товаров документа, управляет видимостью элементов.
- `ЗаполнитьТаблицуТоваров()` — формирует запрос к `РегистрНакопления.Лико_ТоварыКПоступлению.Остатки` с фильтрами по партнёру, складу, номенклатуре и характеристике. Имеет 4 варианта запроса (с/без характеристики x с/без номенклатуры документа).
- `ДобавитьВДокумент(Команда)` — возвращает выбранные строки: либо один ПриходныйОрдер (при заданной номенклатуре), либо массив структур (Номенклатура, Характеристика, Количество, ПриходныйОрдер).
- `ТолькоНоменклатураДокументаПриИзменении(Элемент)` — перезаполняет таблицу при смене режима.
- `БезХарактеристикиПриИзменении(Элемент)` — перезаполняет таблицу при смене режима.
- `ВыбратьВыделенные(Команда)` — инвертирует флажок «Выбрать» для выделенных строк.

# Лико_QdrantИндексация

> Модуль формирования данных для индексации заказов в Qdrant — часть RAG-пайплайна.

## Что делает

Подготавливает данные из [[ЗаказКлиента]] для отправки в векторную БД Qdrant (:6334). Создан 12.05.2026.

## Ключевые процедуры

- `СформироватьДанныеДляИндексации(ЗаказСсылка, ПараметрыМакета = Неопределено)` — главная функция, возвращает структуру:
  ```
  {
    success: Булево,
    error: Строка,
    order_id: Строка,
    text_for_embedding: Строка,  // текст для векторизации
    payload: Структура            // метаданные для фильтрации
  }
  ```
- `СформироватьPayloadЗаказа(ЗаказОбъект, ПараметрыМакета)` — формирует payload с 30+ полями:
  - Из реквизитов 1С: `order_type` (Лико_ТипЗаказа), `label_type` (Лико_ТипЭтикетки), клиент, организация, даты
  - Из Vision LLM (ПараметрыМакета): `technology`, `label_shape`, `varnish_type`, `maket_confidence`, `colors`
  - Рассчитанные: `product_category` (30+ категорий по наименованию)

## Интеграция с AI-пайплайном

```
ЗаказКлиента → СформироватьДанныеДляИндексации() → {text, payload}
    ↓ HTTP POST
batch_indexer (Python) → Qdrant :6334 коллекция orders_phase1
    векторы: phase1_text_dense (384d) + phase1_text_bm25 (sparse)
```

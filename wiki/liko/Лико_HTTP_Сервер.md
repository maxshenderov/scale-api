# Лико_HTTP_Сервер

> Серверный модуль HTTP-утилит — GET/POST запросы, сериализация JSON, JWT-токены, обмен с другими базами 1С.

## Что делает
Предоставляет универсальные функции для HTTP-коммуникации: GET и POST запросы (с SSL и без), сериализацию структур/таблиц в JSON, парсинг JSON-ответов, генерацию JWT-токенов доступа (HS256), отправку запросов в другие базы 1С (ОтправитьПоHttp1с, Запрос1с), работу с таблицами значений (приведение типов, конвертация в JSON/массив структур).

## Ключевые процедуры
- `HttpResponsGet()` — HTTP GET запрос с поддержкой SSL
- `HttpResponsPost()` — HTTP POST запрос с JSON-телом и заголовками
- `СтруктураВJSON()` — сериализация структуры 1С в JSON-строку (ISO-даты)
- `ПолучитьОтветJSON()` — парсинг тела HTTP-ответа как JSON
- `Ответ()` — создание HTTPСервисОтвет(200) с JSON-телом
- `ВернутьТзКакJSON()` — конвертация таблицы значений в JSON HTTP-ответ
- `ТPJSON()` — таблица значений в JSON-строку (через массив структур)
- `ПриведениеТЗКСтандартнымТипам()` — приведение нестандартных типов колонок ТЗ к строке
- `ТзВМассивСтруктур()` — конвертация ТЗ в массив структур
- `QueryFree()` — выполнение произвольного запроса и возврат JSON-ответа
- `GetToken()` — генерация JWT-токена доступа (HS256) для HTTP-сервисов 1С
- `GetKeyJWT()` — возвращает ключ подписи JWT
- `СвойстваПользователяИБ()` — получение свойств пользователя ИБ
- `ОтправитьПоHttp1с()` — отправка POST-запроса в другую базу 1С (ERP)
- `HttpRecuest1с()` — низкоуровневый HTTP POST с Basic-авторизацией
- `Settings()` — получение настроек HTTP-подключения из справочника HTTPConnections
- `Запрос1с()` — выполнение запроса в удалённой базе 1С через QueryFree
- `TimestampВДату()` — конвертация Unix timestamp в дату 1С

## Используется в
- Все серверные HTTP-вызовы к другим базам 1С и внешним API
- REST API для внешних систем

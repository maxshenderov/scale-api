# УпаковкиЕдиницыИзмерения (типовой, доработан)

> Автоопределение упаковки из нарезки ЯССМ при создании из документа, с проверкой рулонных материалов.

## Доработки

### Автозаполнение упаковки при создании (`ФормаВыбораИзДокументов`)
- **`Лико_ПриСозданииНаСервереПеред`** — перед созданием формы:
  - Если передана характеристика с заполненной `ЯССМ_Нарезка` — получает упаковку через `ЯССМ_Нарезки.УпаковкаПоНарезке()`
  - Для рулонных материалов (`ВидНоменклатуры.Лико_РулонныйМатериал`) без заполненной упаковки из нарезки — `Отказ = Истина` с сообщением «Необходимо заполнить характеристику»

## Ключевые процедуры

- `Лико_ПриСозданииНаСервереПеред()` — проверка характеристики и автоподбор упаковки для рулонных материалов

## Связи

- [[ЯССМ_Нарезки]] — `УпаковкаПоНарезке()` для определения упаковки
- [[ХарактеристикиНоменклатуры]] — реквизит `ЯССМ_Нарезка`

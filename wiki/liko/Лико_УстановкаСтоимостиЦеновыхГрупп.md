# Лико_УстановкаСтоимостиЦеновыхГрупп

> Документ для фиксации стоимости ценовых групп на определённую дату. Записывает данные в регистр сведений `Лико_СтоимостьЦеновыхГрупп`.

## Что делает

Устанавливает цену, валюту и количество для каждой ценовой группы в табличной части `ЦеновыеГруппы`. При проведении вызывает метод `ЗаписатьСтоимтостьЦеновыхГрупп()` регистра сведений. При записи наследует валюту из шапки в строки ТЧ, если валюта строки не заполнена.

## Ключевые процедуры

### ObjectModule
- `ОбработкаПроведения()` — вызывает `РегистрыСведений.Лико_СтоимостьЦеновыхГрупп.ЗаписатьСтоимтостьЦеновыхГрупп(Организация, Ссылка)`.
- `ПередЗаписью()` — если валюта шапки заполнена, проставляет её в строки `ЦеновыеГруппы`, где валюта не указана.

### ManagerModule
- `НовыйДокумент(Дата, Организация, ЦеноваяГруппа, Валюта, Цена, Наценка, Ответственный)` — программно создаёт и проводит документ с одной строкой ценовой группы. Используется для вызова из других модулей.

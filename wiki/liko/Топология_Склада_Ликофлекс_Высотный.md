## Программное создание в 1С

### Порядок действий

```
1. Создать склад «ЛК Высотный» (Справочник.Склады)
2. Создать 20 типоразмеров секций (Лико_ТипоразмерыСкладскихСекций)
3. Для каждой группы стеллажей:
   a. Создать элемент в Лико_Стеллажи
   b. Заполнить табличную часть «Этажи» типоразмерами по этажам
   c. Установить Мин/МаксШиринаПаллета, Мин/МаксГлубинаПаллета
   d. Вызвать Лико_Стеллажи.ДобавлениеИзменениеТопологииСклада(Стеллаж)
4. Проверить созданные ячейки и секции
```

### Создание типоразмеров (Лико_ТипоразмерыСкладскихСекций)

Для каждого уникального типа создаётся элемент справочника:

| Реквизит | Значение |
|---|---|
| Высота | из таблицы (мм) |
| Ширина | из таблицы (мм) |
| Глубина | из таблицы (мм) |
| Вес | из таблицы (кг), 0 = не ограничена |
| ВысотаЕИ | мм (справочник единиц измерения) |
| ШиринаЕИ | мм |
| ГлубинаЕИ | мм |
| ВесЕИ | кг |
| НеОграниченаПоГрузоподъемности | Истина для типов с «не огранич.» |

Наименование автоформируется: `"{Высота}мм x {Ширина}мм x {Глубина}мм ({Вес}кг)"`

### Создание стеллажей (Лико_Стеллажи)

Для каждой группы (1–7, 8, 9) создаётся элемент:

| Реквизит | Стеллажи 1–7 | Стеллаж 8 | Стеллаж 9 |
|---|---|---|---|
| Склад | ЛК Высотный | ЛК Высотный | ЛК Высотный |
| КоличествоСекций | 17 | 17 | 18 |
| КоличествоЯчеекВСекции | 3 | 3 | 3 |
| КоличествоЗонПриемкиОтгрузки | по проекту | по проекту | по проекту |

Табличная часть «Этажи» заполняется по порядку этажей снизу вверх.

### Формат кода секции

```
Р{Ряд}-М({Место}-{Место+1}-{Место+2})-Э{Этаж}
```
Пример: `Р1-М(1-2-3)-Э1` — ряд 1, места 1-3, этаж 1.

### Адреса хранения

Каждая секция содержит 3 адреса (Адрес1, Адрес2, Адрес3), каждый — ссылка на `СкладскиеЯчейки`. Адрес2 = АдресЦентр.

## Контрольные суммы

```
Группа 1–7 : 153 × 7  = 1071
Стеллаж 8  : 170 × 1  =  170
Стеллаж 9  : 162 × 1  =  162
─────────────────────────────

```

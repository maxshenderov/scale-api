# Лико_АсинхронныеПроцедуры

> Асинхронное выполнение процедур через фоновые задания — СИМ-склад и связанные операции.

## Что делает

Запускает длительные операции асинхронно через механизм фоновых заданий 1С. Основное применение — обработка поступлений на СИМ-склад.

## Ключевые процедуры

- `Лико_ПроведениеДокументовАсинхронноОбработчик(Источник)` — обработчик подписки на событие проведения документов СИМ-поступлений:
  1. Записывает задание в РС `Лико_АсинхронныеВызовыВПроведенииДокументов`
  2. Запускает фоновое задание через `ФоновыеЗадания.Выполнить()`
  3. Фоновое задание обрабатывает список накопленных вызовов
- `УстановкаДокументаПриходаВОбъектахНоменклатуры(ДокументПрихода, МассивОбъектов)` — устанавливает ссылку на документ прихода в `ЯССМ_ОбъектыНоменклатуры` (справочник объектов склада)

## Зависимости

- РС `Лико_АсинхронныеВызовыВПроведенииДокументов` — очередь асинхронных вызовов
- Справочник `ЯССМ_ОбъектыНоменклатуры` — объекты СИМ-склада (ячейки/паллеты)
- [[Лико_ПроведениеДокументов]] — взаимодействие при проведении

## Паттерн

```bsl
// Подписка на событие ПередЗаписью складских документов СИМ:
Лико_АсинхронныеПроцедуры.Лико_ПроведениеДокументовАсинхронноОбработчик(Источник);
// → РС.Лико_АсинхронныеВызовыВПроведенииДокументов.Записать(...)
// → ФоновыеЗадания.Выполнить("Лико_АсинхронныеПроцедуры.ФоновоеЗадание")
```

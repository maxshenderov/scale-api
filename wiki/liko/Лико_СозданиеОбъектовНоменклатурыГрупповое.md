# Лико_СозданиеОбъектовНоменклатурыГрупповое

> Обработка массового создания объектов номенклатуры — ролики, пробники, палеты, с расчётом длины, BRC-критериями и прослеживаемостью.

## Что делает

Массовое создание объектов номенклатуры (`ЯССМ_ОбъектыНоменклатуры`) для рулонов/роликов, пробников, упаковочных листов, палет. Ключевые возможности:
- **Создание роликов**: расчёт длины ролика по весу, диаметру, типу намотки. Автоматический подбор упаковки (палета, коробка). Расчёт планового количества.
- **Создание пробников**: создание пробных образцов с привязкой к BRC-критериям контроля (пищевая безопасность).
- **Создание палет**: группировка роликов в палеты с контролем уникальности.
- **Прослеживаемость**: привязка к партиям производства, сериям, номерам пропусков.
- **Контроль заполнения**: проверка наличия упаковки, корректности данных перед созданием.
- **Печать**: печать этикеток объектов номенклатуры сразу после создания.

Работает в связке с `Лико_РасчетДлиныРолика` для вычисления длины.

## Ключевые процедуры

- `СоздатьИРаспечататьОбъектНоменклатуры()` — основной метод: создаёт объекты и сразу отправляет на печать.
- `СоздатьРолики()` — создание рулонов/роликов с расчётом длины и подбором упаковки.
- `СоздатьПробники()` — создание пробных образцов с BRC-критериями.
- `СоздатьОбъектыНоменклатуры()` — общий метод создания объектов номенклатуры с формированием движений.
- `ПроверитьНаличиеУпаковки()` — проверка, что упаковка (палета, коробка) заполнена перед созданием.
- `ОбработкаПроверкиЗаполнения()` — пустая заглушка в ObjectModule.

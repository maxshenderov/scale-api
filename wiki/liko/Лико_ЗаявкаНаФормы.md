# Лико_ЗаявкаНаФормы

> Общая команда: открывает внешнюю обработку «ТС Управление заявками на ремонт» с предустановленным подразделением-получателем **Формщики**.

## Что делает

Ищет внешнюю обработку через `Лико_Дополнительно.НайтиДополнительнуюОбработкуПоИмениОбъекта("ТС_УправлениеЗаявкамиНаРемонт")` и открывает её форму с параметром `ПодразделениеПолучатель = Формщики`.

Отличается от [[Лико_ЗаявкаМеханику]] способом поиска обработки (через `Лико_Дополнительно`, а не прямой поиск по наименованию).

## Ключевые процедуры

- `ОбработкаКоманды()` — клиент: структура с `Формщики`, поиск через `НайтиДополнительнуюОбработкуПоИмениОбъекта`

## Связи —

- [[Лико_ЗаявкаМеханику]] — аналог для Механики
- [[Лико_ЗаявкаТехнологу]] — аналог для Технологов
- [[Лико_Дополнительно]] — используется `НайтиДополнительнуюОбработкуПоИмениОбъекта`

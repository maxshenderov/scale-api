# Лико_РегистрацияОперацийДляОбмена

> Регистр сведений: очередь событий для обмена между 1С и внешними системами (Python-сервисы, HTTP-клиенты).

## Что хранит
События, требующие передачи во внешние системы. Каждое событие имеет уникальный UUID, тип (listener/event), JSON-данные, статус обработки и временные метки.

## Измерения
- **uuid** — уникальный идентификатор события (ключ)
- **listener** — целевая система-получатель (например "dfm")
- **event** — тип события (create_article, send_order_to_work, send_notify, rename_product)
- **data** — JSON-строка с данными события
- **status** — статус обработки
- **created_at / modified_at** — временные метки

## Ключевые процедуры
- `ДобавитьСобытие(listener, event, dataJson)` — создаёт запись в регистре с новым UUID, возвращает uuid. Используется как универсальная точка входа для постановки событий в очередь.
- `ТипыСобытийОбмена()` — возвращает соответствие (Структура) русских названий событий их англоязычным кодам: СозданиеНоменклатуры -> create_article, НаправитьЗаказВРаботу -> send_order_to_work, ОтправитьСообщение -> send_notify, ИзменитьНаименование -> rename_product.
- `НаправитьЗаказВРаботу(Заказ)` — формирует JSON с номером, версией и датой заказа и вызывает ДобавитьСобытие.
- `ИзменитьСтатус(uuid, status)` — обновляет modified_at и status для события с указанным uuid.

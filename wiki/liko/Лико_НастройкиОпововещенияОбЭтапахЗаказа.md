# Лико_НастройкиОпововещенияОбЭтапахЗаказа

> Регистр сведений для настройки подписки пользователей на уведомления об этапах заказа. Позволяет включать/отключать оповещения и контроль этапов для конкретных пользователей.

## Что хранит

- **Измерения:** Заказ, Пользователь, Этап
- Периодичность: по секундам, независимый. Форма: `Форма`

## Ключевые процедуры

- `ПриСозданииНаСервере()` — устанавливает параметры динамического списка `ВыборЭтапов`: отбор по Заказу и Пользователю. Если `ПолныеПрава = Ложь`, поле Пользователь блокируется.
- `ОбработатьВыборЭтапаНаСервере(Этап)` — основная логика:
  1. Пытается прочитать запись по Заказу, Пользователю и Этапу
  2. Если запись существует — удаляет (отписка от этапа), `КонтрольЭтапов = Ложь`
  3. Если записи нет — создает (подписка), `КонтрольЭтапов = Истина`
  4. Если признак `КонтрольЭтапов` у заказа изменился — обновляет его в объекте заказа (с флагом `ОбменДанными.Загрузка = Истина`)
- `ВыборЭтаповВыбор()` — клиентский обработчик клика по полю «Оповестить», вызывает `ОбработатьВыборЭтапаНаСервере()`
- `ПользовательПриИзменении()` — при смене пользователя обновляет параметры списка этапов; если пользователь пустой — блокирует список

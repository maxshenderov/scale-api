# Лико_ТипоразмерыПаллет

> Классификатор типоразмеров паллет — габариты (ВхШхГ) и вес, используется для подбора складских ячеек и размещения.

## Что хранит
- **Код** — автонумерация (числовой, длина 10)
- **Высота, Ширина, Глубина** — габариты в мм (единица измерения — из констант)
- **Вес** — максимальный вес паллеты
- **Объем** — расчетный объем
- **НеОграниченаПоГрузоподъемности** — флаг: если Истина, вес = 0 и не проверяется
- **НеОграниченаПоРазмерам** — флаг: если Истина, габариты = 0 и не проверяются
- **ВысотаЕИ, ШиринаЕИ, ГлубинаЕИ, ВесЕИ, ОбъемЕИ** — единицы измерения
- Наименование автоформируется: `"{Высота}{ЕИ} х {Ширина}{ЕИ} х {Глубина}{ЕИ} ({Вес}{ЕИ})"`

## Модуль объекта

### `ПередЗаписью`
- При загрузке обменом — выход без обработки
- Если `НеОграниченаПоГрузоподъемности` — обнуляет `Вес`
- Если `НеОграниченаПоРазмерам` — обнуляет `Высота, Глубина, Объем, Ширина`
- Автогенерация `Наименования` из габаритов и веса

### `ОбработкаПроверкиЗаполнения`
Исключает из проверки поля Вес/Габариты при установленных флагах «Не ограничена».

### `ОбработкаЗаполнения`
Заполняет единицы измерения по умолчанию: длина — мм, вес — из константы `ЕдиницаИзмеренияВеса`, объем — из константы.

## Модуль менеджера

### `ШтрихКод(ТипоразмерСсылка)` / `ШтрихКодСтрокой(ТипоразмерСсылка)`
Генерация штрих-кода типоразмера (префикс "8" + вид информации "01").

### `НайтиСоздатьТипоразмер(Высота, Ширина, Глубина, Вес)`
Поиск существующего типоразмера по точному совпадению всех 4 параметров + единиц измерения. Если не найден — создает новый с заполнением по умолчанию. Использует `УстановитьПривилегированныйРежим(Истина)`.

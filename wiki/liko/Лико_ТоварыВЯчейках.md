# Лико_ТоварыВЯчейках

> Отчет по остаткам товаров в ячейках склада с коэффициентами упаковки, весом и объемом. Есть одноименная общая команда для быстрого открытия.

## Что делает

**Отчет**: расширяет типовой отчет «Товары в ячейках» — подставляет в СКД текст запроса для коэффициента упаковки, объема и веса через `Справочники.УпаковкиЕдиницыИзмерения`. При создании на сервере автоматически устанавливает отбор по параметру команды (ячейка, номенклатура, область хранения, складская группа). При компоновке включает отбор по сегменту номенклатуры.

**Общая команда**: открывает форму отчета `Отчет.ТоварыВЯчейках.ФормаОбъекта`.

## Ключевые процедуры

- `ОпределитьНастройкиФормы()` — регистрирует обработчик `ПриСозданииНаСервере`
- `ПриСозданииНаСервере()` — по `Параметры.ОписаниеКоманды.ДополнительныеПараметры.ИмяКоманды` устанавливает отбор: `ПоЯчейке`, `ПоНоменклатуре`, `ПоОбластиХранения`, `ПоСкладскойГруппеНоменклатуры`
- `ПриКомпоновкеРезультата()` — подменяет в тексте запроса макросы `&ТекстЗапросаКоэффициентУпаковки`, `&ТекстЗапросаОбъем`, `&ТекстЗапросаВес` на вызовы `Справочники.УпаковкиЕдиницыИзмерения.*`; включает отбор по сегменту номенклатуры
- `УстановитьЗаголовкиПолей()` — заменяет `%ЕдиницаВеса%` и `%ЕдиницаОбъема%` на значения констант

## Варианты отчета (команды)

- `ПоЯчейке` — отбор по ячейке
- `ПоНоменклатуре` — отбор по номенклатуре
- `ПоОбластиХранения` — отбор по области хранения
- `ПоСкладскойГруппеНоменклатуры` — отбор по складской группе

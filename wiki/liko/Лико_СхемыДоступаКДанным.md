# Лико_СхемыДоступаКДанным

> Классификатор схем доступа к данным — конфигурация прав и ограничений доступа к объектам системы.

## Что хранит
Простой справочник-классификатор для настройки схем доступа (RLS / ограничения на уровне записей). Содержит перечень схем, которые затем настраиваются в механизме ограничения доступа к данным 1С.

## Ключевые процедуры
- Модуль объекта содержит только пустой обработчик `ПриЗаписи` — логика реализуется на уровне подсистемы ограничения доступа.
- Есть формы: `ФормаЭлемента`, `ФормаВыбораОбъекта` с расширениями.

## Связи
Используется стандартным механизмом 1С для ограничения доступа к данным на уровне записей (RLS).

# Лико_СерверВзаимодействияСервер

> Модуль интеграции с Системой взаимодействия 1С: обсуждения, QR-коды рабочих мест, проверка регистрации ИБ.

## Что делает
Обеспечивает интеграцию с Системой взаимодействия 1С. Создаёт групповые обсуждения с ключом `ERP_mobile_<РабочееМесто>`, генерирует HTML-страницу с QR-кодом для идентификации рабочего места, проверяет регистрацию информационной базы в системе взаимодействия (отменяет регистрацию для нерабочих баз).

## Ключевые процедуры
- `СоздатьОбсуждение(КлючОбсуждения, ИдентификаторТекущегоПользователя)` — создаёт групповое обсуждение с заданным ключом, если оно ещё не существует. Для ключа `ERP_mobile` добавляет суффикс рабочего места.
- `РабочееМестоИмя()` — возвращает имя текущего рабочего места из параметров сеанса.
- `ВывестиUserQRCode(Форма, Группа)` — добавляет на форму HTML-поле с QR-кодом для рабочего места.
- `ПолучитьUserQRCode()` — формирует HTML-страницу с QR-кодом (использует qr.js).
- `ПроверкаВозможностиИспользованияСистемыВзаимодействия()` — отменяет регистрацию ИБ в системе взаимодействия, если это нерабочая база.

## Используется в
- Формы с QR-кодами для мобильных рабочих мест (ERP_mobile)
- Проверка регистрации ИБ при запуске

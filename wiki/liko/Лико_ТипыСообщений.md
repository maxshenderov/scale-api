# Лико_ТипыСообщений

> Классификатор типов сообщений/уведомлений. Хранит привязку типов сообщений к площадкам и контактным адресам для рассылки.

## Что хранит
- **Наименование** — название типа сообщения
- **Площадки** — табличная часть с привязкой к площадкам и контактными адресами:
  - **Площадка** — ссылка на `Лико_Площадки`
  - **Контакты** — строка с адресами (email), разделенными `;`

## Модуль менеджера: `ПолучитьПочтовыеАдреса(ТипСообщений, Площадка)`
Извлекает все email-адреса для заданного типа сообщения и площадки:
1. Если `Площадка` — организация, преобразует в площадку через `Лико_Площадки.ПлощадкаПоОрганизации()`
2. Находит строки табличной части `Площадки` по фильтру
3. Разбирает строку `Контакты` по разделителю `;`
4. Фильтрует только строки, содержащие `@` (email-адреса)
5. Возвращает адреса строкой через `;`

Использует `УстановитьПривилегированныйРежим(Истина)`.

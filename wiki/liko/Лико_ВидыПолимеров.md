# Лико_ВидыПолимеров

> Справочник видов полимеров, используемых в производстве упаковки. Классификатор типов полимерных материалов.

## Что хранит

Перечень видов полимеров (PP, PE, PET, PVC и т.д.) с возможностью исключения из формы выбора через реквизит `НеПоказыватьВФормеВыбора`.

## Ключевые процедуры

Модуль менеджера содержит закомментированный код `ОбработкаПолученияДанныхВыбора()` с фильтрацией по реквизиту `НеПоказыватьВФормеВыбора` — используется для скрытия устаревших позиций.

Логика работы с полимерами сосредоточена в других модулях.

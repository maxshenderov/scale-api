# Лико_ПараметрыПроизводстваЗаказа

> Регистр сведений (периодический). Расчётные параметры производства по заказу клиента: метраж на настройку/брак, время печати, скорость, себестоимость, рентабельность.

## Что делает

Хранит ключевые производственные параметры для каждого заказа в разрезе рабочих центров, прокатов и вариантов расчёта. Используется повсеместно для планирования производства: `Лико_ЗаказНаРаскрой`, `ЛикоЗаказИнфо`, `Лико_ПланировщикЗагрузкиРабочихЦентров`, печатные формы.

**Измерения включают Спецификации:** `Заказ` может быть как `ЗаказКлиента`, так и `Лико_Спецификации` (для расчёта параметров спецификаций).

## Измерения (4)

| Измерение | Тип | Назначение |
|---|---|---|
| Заказ | ЗаказКлиента / Лико_Спецификации | Заказ или спецификация |
| НомерПроката | Число | Номер проката |
| РабочийЦентр | Справочник.РабочиеЦентры | Рабочий центр |
| НомерВарианта | Число | Вариант расчёта |

## Ключевые потребители

- `Лико_ЗаказНаРаскрой` — `ПолучитьДанныеЗаказуКлиента()`, `ЗаполнитьСтруктуруПоЗаказуКлиента()`
- `ЛикоЗаказИнфо` — `ЗаполнитьРасчетныеПараметры()`, `ДанныеПоРЦ()`
- `Лико_ПланировщикЗагрузкиРабочихЦентров` — `ПланРаботЗпПериод()` для расчёта загрузки
- `ПриложениеКВБЗЕРП` — печатная форма (метры на настройку/брак)
- `AIАссистент` — анализ заказа (экономический/технологический)

# Лико_НамоткаПрисоединенныеФайлы

> Справочник присоединённых файлов для намоток — хранит изображения рулонов/намоток. Построен на подсистеме РаботаСФайлами.

## Что хранит
- Стандартные реквизиты подсистемы РаботаСФайлами (файл, владелец, автор и т.д.)
- Используется как хранилище изображений для справочника Лико_Намотка

## Ключевые процедуры
- `РеквизитыРедактируемыеВГрупповойОбработке()` — возвращает список реквизитов, доступных для группового редактирования (делегирует в РаботаСФайлами).
- `ПриЗаполненииОграниченияДоступа()` — настраивает RLS: чтение и изменение разрешены, только если разрешены для ВладелецФайла.

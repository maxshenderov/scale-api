# ОтветственныеЛицаСервер

> Переопределение заполнения ответственных лиц: исключает `Лико_ПередачаТоваров` из стандартной обработки.

## Что делает
Расширяет типовую функцию `ОтветственныеЛицаДокументаОбработкаЗаполнения` (аннотация `&Вместо`). Для документа `Лико_ПередачаТоваров` прерывает стандартную обработку заполнения ответственных лиц — этот документ не требует заполнения ответственных лиц по типовой логике.

## Ключевые процедуры
- `Лико_ОтветственныеЛицаДокументаОбработкаЗаполнения(Источник, ДанныеЗаполнения, СтандартнаяОбработка)` — если Источник = `Лико_ПередачаТоваров`, возврат без заполнения; для остальных документов вызывает типовую `ЗаполнитьОтветственныхЛицДокумента()`.

## Используется в
- Документ Лико_ПередачаТоваров — исключение из заполнения
- Все остальные документы с реквизитами ответственных лиц — стандартное заполнение

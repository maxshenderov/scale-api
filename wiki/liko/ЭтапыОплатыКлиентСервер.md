# ЭтапыОплатыКлиентСервер

> Типовой общий модуль БСП «Этапы оплаты (клиент-сервер)». Расширен через [[ЭтапыОплатыСервер]] — переопределение логики расчёта даты платежа с учётом Лико-специфики.

## Что делает

Типовой модуль подсистемы «Этапы оплаты» — содержит клиент-серверные процедуры для работы с этапами графика оплаты в документах.

## Доработки Лико

Расширение `liko` переопределяет серверную часть через модуль [[ЭтапыОплатыСервер]]:
- `&Вместо("ЗаполнитьЭтапыОплаты")` — поддержка Лико-формулы расчёта даты платежа из [[СоглашенияСКлиентами]]
- Учёт `Лико_ФормулаРасчетаДатыПлатежа` при заполнении этапов

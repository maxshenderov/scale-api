# Лико_ВыполненныеРаботыМеждуОрганизациями

> Акт выполненных работ между организациями -- при проведении обновляет цены и ставки НДС в связанных `ЗаказКлиента`.

## Что делает
Расширяет документ межорганизационного акта выполненных работ для вида `АктВыполненныхРабот`. При проведении автоматически синхронизирует цены и ставки НДС из этого документа в табличные части `Товары` всех связанных `ЗаказКлиента`.

## Ключевые процедуры

### ObjectModule
- `Лико_УстановитьЦеныВЗаказахКлиента()` -- `&Вместо`. Только для `ВидДокумента = АктВыполненныхРабот`. Выполняет сложный запрос: собирает работы и их ценовые группы из ТЧ `Работы`, цены и ставки НДС из ТЧ `Цены`, соединяет с `ЗаказКлиента.Товары`, находит расхождения. Для каждого расхождения обновляет в `ЗаказКлиента` цену, ставку НДС, пересчитывает суммы (НДС, с НДС, ручная скидка, автоскидка) через `ОбработкаТабличнойЧастиСервер.ОбработатьСтрокуТЧ()`. Записывает заказ в режиме `ОбменДанными.Загрузка = Истина`.

## Связь с ЗаказКлиента
Прямая связь через `Работы.ЗаказПокупателя`. Цены из этого документа синхронизируются обратно в `ЗаказКлиента.Товары`.

## Табличные части
- **Работы** -- выполненные работы (номенклатура, заказ, ценовая группа)
- **Цены** -- цены и ставки НДС в разрезе ценовых групп

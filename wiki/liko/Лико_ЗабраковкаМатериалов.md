# Лико_ЗабраковкаМатериалов

> Забраковка материалов -- оформление брака поступивших материалов. Автозаполнение цен и печатные формы.

## Что делает
Оформляет забраковку материалов, поступивших от поставщиков. Расширение добавляет автозаполнение цен из регистра `Лико_ЦеныГруппНоменклатуры` (тип цен "ЦенаПоставщика"), автоопределение поставщика по серии, и кастомные печатные формы (Акт брака, Образец НП).

## Ключевые процедуры

### Форма документа
- `Лико_ЗаполнитьЦеныПосле()` -- `&НаКлиенте`. Вызывает `ПроверитьЦены()`.
- `ПроверитьЦены()` -- автозаполнение цен: для каждого материала без цены получает цену из `Лико_ЦеныГруппНоменклатуры` (через `ПолучитьЦенуСервер`), заполняет валюту, считает итоговую сумму брака (`Цена * МетражКВМ`). Если поставщик не заполнен -- ищет документ поступления через `Лико_ОбщегоНазначенияСервер.НайтиДокументПоступления()` по серии.
- `ПолучитьЦенуСервер()` -- `Экспорт`. Запрашивает срез последних цен по номенклатуре/площадке/типу цен "ЦенаПоставщика".
- `Лико_Подключаемый_ВыполнитьКоманду()` -- `&Вместо`. Обрабатывает кастомные печатные команды:
  - `АктБрака` -- открывает обработку `ЯССМ_АктБрака`
  - `ОбразецНПБракМатериала` -- автофиксирует текущего пользователя как оформившего образец

## Связь с ЗаказКлиента
Не привязан напрямую. Связан с поставщиком и сериями материалов.

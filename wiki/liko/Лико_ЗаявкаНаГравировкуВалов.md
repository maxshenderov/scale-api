# Лико_ЗаявкаНаГравировкуВалов

> Заявка на гравировку валов для глубокой печати. Заполняется из ЗаказКлиента по секциям с цветоделением. Регистрирует заявки в регистре накопления.

## Что делает

- Заполняется из ЗаказКлиента: выбирает строки Цветов, где `Цветоделение = Истина` и `ВидСекции.Родитель = Глубокая`
- Табличная часть `Валы` содержит: Вал, Форма
- При проведении: приход в регистр `Лико_ЗаявкиНаГравировкуВалов` (одна запись на каждый вал, количество = 1)

## Ключевые процедуры

- `ОбработкаЗаполнения(ДанныеЗаполнения)` — из ЗаказКлиента: перебирает Цвета, фильтрует по Цветоделение + Глубокая печать, добавляет строки Валы (Вал, Форма)
- `ОбработкаПроведения()` — формирует движения прихода в регистр `Лико_ЗаявкиНаГравировкуВалов`

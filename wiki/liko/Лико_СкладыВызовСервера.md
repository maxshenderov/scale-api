# Лико_СкладыВызовСервера

> Серверные вызовы для складов: получение нарезки/упаковки, запрос типовых документов, признак сканов в реестре.

## Что делает
Предоставляет серверные функции для складского интерфейса. Получает нарезку и упаковку по характеристике номенклатуры (через справочник ЯССМ_Нарезки). Содержит два варианта большого SQL-запроса для поиска типовых документов, связанных с Лико_-документами (через реквизит Лико_Документ и регистр Лико_СвязиСТиповымиДокументами). Устанавливает признак наличия сканов в регистре РеестрДокументов.

## Ключевые процедуры
- `ПолучитьНарезку(Характеристика)` — возвращает значение `ЯССМ_Нарезка` из характеристики.
- `ПолучитьУпаковку(Нарезка)` — возвращает упаковку по нарезке через справочник ЯССМ_Нарезки.
- `ТзТиповыеДокументы(Ссылка, ПоказыватьДокумент, Распоряжение, Распоряжение2, АдресВХ, ИмяСобытия)` — выполняет запрос типовых документов и помещает результат во временное хранилище.
- `ПолучитьТекстЗапросаТиповыеДокументы()` — актуальный текст запроса типовых документов (включает Лико_СвязиСТиповымиДокументами).
- `ПолучитьТекстЗапросаТиповыеДокументOld()` — предыдущая версия запроса (без регистра связей).
- `УстановкаПризнакаСканыВРеестреДокументов(МассивСсылок)` — устанавливает `Лико_Сканы = Истина` в регистре РеестрДокументов для переданных ссылок.

## Используется в
- Формы документов с табличной частью Товары (поиск связанных типовых документов)
- Клиентские формы складов (получение упаковки по характеристике)

# Лико_КартаПерерасхода

> Производственный документ — фиксирует перерасход материалов по заказу/бланку/прокату для конкретного оператора, с контролем дублирования и рассылкой уведомлений.

## Что делает

Учёт перерасхода материалов в производстве. Привязан к заказу клиента, номеру бланка, номеру проката и оператору. Ключевая особенность — проверка на дубликат: нельзя создать две карты с одинаковым набором (Заказ + НомерБланка + НомерПроката + Статус + Оператор). При подтверждении карты к закрытому заказу отправляется email-уведомление на `Uchet@okil-sato.ru`.

Имеет состояния: `Создан`, `Подтвержден` (перечисление `Лико_СостоянияДокументаКартаПерерасхода`). Подтверждение требует специальных прав (`Лико_ПодтверждениеКартПерерасхода` или `ПолныеПрава`).

## Ключевые процедуры

- `ПередЗаписью()` — устанавливает состояние по умолчанию «Создан»; вызывает проверки; при подтверждении к закрытому заказу отправляет email.
- `ПроверитьНаличиеКартыСТакимиПараметрами()` — проверяет уникальность комбинации Заказ + Бланк + Прокат + Статус + Оператор (исключая текущий документ).
- `ВыполнитьПрверки()` — агрегирует проверки перед записью.
- `ПроверитьПравоНаПодтверждение()` — проверяет права на изменение подтверждённой карты.

### ManagerModule

- `НайтиСоздать()` — программный поиск или создание карты перерасхода (поддерживает параметры через Структуру или JSON). Используется AI-интеграцией.
- `ДокументПоПараметрам()` — поиск карты по ключевым параметрам.
- `ЕстьКартаСТакимиПараметрами()` — проверка на существование дубликата, возвращает Структуру(Номер, Дата) или Неопределено.
- `ЕстьПравоНаПодтверждение()` — проверка ролей.
- `КартыПерерасходаПоРабочемуЦентру()` — возвращает массив карт по рабочему центру.
- `КартаПерерасходаВСтруктуру()` / `КартыПерерасходаВМассив()` — сериализация карт в структуру/массив структур для внешних потребителей (AI).

# Лико_ПланировщикЗагрузкиРабочихЦентров

> Обработка — визуальный планировщик загрузки рабочих центров: план работ и онлайн-статус в виде табличного документа с почасовой/поминутной шкалой.

## Что делает

Основной инструмент диспетчера производства. Строит план загрузки РЦ на основе регистра `ПооперационноеРасписание2_2` и онлайн-статус из `ТССтатистикаСкорости` (внешний источник УПП). Отображает каждый заказ как цветной блок на временной шкале.

Функции:
- Построение плана загрузки на выбранный период (день/несколько дней)
- Отображение онлайн-статуса РЦ (номер РЦ, заказ, форма, оснастка, этап, %, остаток времени)
- Цветовая индикация: зелёный (материалы есть), красный (нет форм / нет оснастки)
- Детализация по заказам с процентами выполнения, временем работы, комментариями
- Настройка внешнего вида (цвета, шрифты, масштаб, видимость колонок)
- Расшифровка по клику — открытие формы заказа
- Создание комментариев к заказу через `ТС_ЗагрузкаРЦКомментарии`
- Учет наличия форм и оснастки через `ТС_НаличееФормОснастки`
- Сохранение настроек в `ХранилищеНастроекДанныхФорм`

Имеет три формы: основная (`Форма`), настроек (`ФормаНастроек`), заказа (`ФормаЗаказа`).

## Ключевые процедуры (основная форма)

- `ПриСозданииНаСервере()` — загружает настройки из хранилища, устанавливает цвета, вызывает `ФормированиеПериода()`, `ФормированиеШапки()`, `ЗаполнитьПланировщикНаСервере()`
- `ПриОткрытии()` — подключает обработчик ожидания `Сформировать` с интервалом 300 сек
- `Сформировать()` — периодическое обновление плана
- `ФормированиеШапки()` — строит шапку табличного документа: колонки РЦ, Заказ, Ф, О, Этап, Начало, Длит., %, Остал., временная шкала с часами и 15-минутными интервалами
- `ЗаполнитьПланировщикНаСервере()` — заполняет строки плана: для каждого РЦ выводит online-статус и план загрузки из `ПланРаботЗпПериод()`
- `ПланРаботЗпПериод()` (сервер без контекста) — сложный пакетный запрос к `ПооперационноеРасписание2_2` + `ТССтатистикаСкорости` + `Лико_ПараметрыПроизводстваЗаказа`, вычисляет проценты выполнения, остаток времени, наличие форм/оснастки
- `ЗаказыOnline()` (сервер без контекста) — запрос к внешнему источнику УПП `ТсСтатистикаСкорости` для online-статуса РЦ
- `Настройки()` — открывает форму настроек
- `УстановитьНастройкиСервер()` — применяет настройки внешнего вида
- `Инфо()` — открывает обработку `ЛикоЗаказИнфо` для выбранного заказа
- `ПланировщикТДОбработкаРасшифровки()` — сохраняет данные расшифровки в `ДанныеЗаказа`
- `ПланировщикТДВыбор()` — при клике на заказ открывает `ФормаЗаказа` с данными
- `ДатаНачалаПриИзменении()` / `ДатаОкончанияПриИзменении()` — перестраивают период и план
- `ФорматДлительности()` — форматирует длительность в минутах в "ММ:СС"

## Ключевые процедуры (ФормаНастроек)

- `ПриСозданииНаСервере()` — принимает параметры (цвета, шрифты, масштаб, флаги)
- `Сохранить()` — возвращает структуру с настройками в основную форму

## Ключевые процедуры (ФормаЗаказа)

- `ПриСозданииНаСервере()` — принимает параметры: `Заказ`, `РЦ` (рабочий центр), `ВремяВыполнения`, `ПроцентВыполнения`, `НаличиеФорм`, `НаличиеОснастки`
- `Создать()` — открывает форму записи регистра `ТС_ЗагрузкаРЦКомментарии`
- `Инфо()` — открывает обработку `ЛикоЗаказИнфо`
- `ВБЗ()` — печатает внутренний бланк заказа
- `НаличиеФормНажатие()` / `НаличиеОснасткиНажатие()` — переключение флагов наличия
- `Сохранить()` — при изменении флагов создает записи в `ТС_НаличееФормОснастки` через `СоздатьЗаписьВРегистреСервер`
- `СоздатьЗаписьВРегистреСервер()` — создает запись в регистре сведений `ТС_НаличееФормОснастки`

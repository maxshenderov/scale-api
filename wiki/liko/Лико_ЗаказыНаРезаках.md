# Лико_ЗаказыНаРезаках

> Регистр сведений для отслеживания того, какой сотрудник в данный момент работает над заказом на раскрой (резак). Хранит факт начала работы сотрудника на рабочем центре.

## Что хранит

- **Измерения:** Период, ЗаказНаРаскрой
- Периодичность: по секундам, независимый. Используется `СрезПоследних` для определения текущего состояния.

## Ключевые процедуры

- `РегистрацияНачалаРаботыСотрудника(РабочийЦентр, ЗаказНаРаскрой)` — если заказ ещё не закреплен за текущим сотрудником (проверка через `ТекущийСотрудникНаРЦ()`), создает запись с текущей датой и ЗаказНаРаскрой. Автор: m.shenderov 19.08.2022.
- `ТекущийСотрудникНаРЦ(ЗаказНаРаскрой)` — запрашивает `СрезПоследних` по заказу на раскрой. Если есть запись — возвращает `ЗаказНаРаскрой` (заказ занят).

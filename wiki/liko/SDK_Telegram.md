# SDK_Telegram

> Клиент Telegram Bot API — получение обновлений, отправка сообщений, документов и фото через Telegram.

## Что делает
Реализует методы Telegram Bot API: getUpdates (получение новых сообщений), sendMessage (отправка текста), sendDocument (отправка файлов), sendPhoto (отправка изображений). Поддерживает multipart/form-data для загрузки файлов. Использует константу update_id для отслеживания обработанных сообщений. Демо-режим с командами /start, /txt, /pdf, /jpg.

## Ключевые процедуры
- `ПолучитьСпиокСообщений()` — получает новые сообщения через getUpdates(), обрабатывает команды /start, /txt, /pdf, /jpg, обновляет update_id
- `getUpdates()` — вызывает метод Telegram API getUpdates с параметрами offset, limit, timeout
- `sendMessage()` — отправляет текстовое сообщение в чат
- `sendDocument()` — отправляет файл (multipart/form-data) в чат
- `sendPhoto()` — отправляет фото (multipart/form-data) в чат
- `ОтправитьHTTPЗапрос()` — низкоуровневый HTTP-запрос к api.telegram.org через HTTPS (OpenSSL), поддержка прокси
- `СформироватьМетод()` — формирует URL метода: `bot<token>/<method>?<params>`
- `СформироватьТекстЗапроса()` — формирует тело multipart/form-data для загрузки файлов
- `ОбработатьJSON()` — парсит JSON-ответ от Telegram API
- `ПолучитьAccessToken()` — переопределяемая функция для получения токена бота
- `ПолучитьПутьКФайлуЛога()` — переопределяемая функция пути к лог-файлу

# Лико_ВыполненныеРаботы

> Акт выполненных работ -- фиксирует выполненные производственные работы. При проведении формирует затраты по заказу с учётом трафаретных засветок.

## Что делает
Расширяет типовой документ акта выполненных работ. Добавляет проверку заполнения, удаление проведения через `ПроведениеДокументов`, регистрацию учётного механизма `Лико_Склад`, и специальную логику расчёта затрат для трафаретных засветок.

## Ключевые процедуры

### ObjectModule
- `Лико_ОбработкаПроверкиЗаполнения()` -- `&После`. Если в таблице `Работы` есть работа `Засветка` -- требует заполнения `РабочийЦентр`, иначе исключает `ЗаказКлиента` из проверки.
- `Лико_ОбработкаУдаленияПроведения()` -- `&Вместо`. Делегирует в `ПроведениеДокументов.ОбработкаУдаленияПроведенияДокумента()`.

### ManagerModule
- `Лико_ЗарегистрироватьУчетныеМеханизмы()` -- `&Вместо`. Регистрирует `Лико_Склад`.
- `Лико_ТекстЗапросаТаблицаЛико_ЗатратыПоЗаказу()` -- `&Вместо`. Формирует текст запроса для `Лико_ЗатратыПоЗаказу` -- вычисляет стоимость трафаретных засветок через `Лико_ЦеныГруппНоменклатуры` (тип цен "Табаш"), связывая с прокатами из `ЗаказКлиента.Цвета`.
- `Лико_ЗаполнитьПараметрыИнициализации()` -- `&Вместо`. Устанавливает параметры запроса: Период, ЗаказКлиента, Организация, Ссылка.

## Связь с ЗаказКлиента
Прямая связь через реквизит `ЗаказКлиента`. Затраты по работам попадают в `Лико_ЗатратыПоЗаказу` в разрезе `ЗаказКлиента`.

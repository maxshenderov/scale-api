# Лико_ПараметрыШтампа

> Регистр сведений: параметры штампа (оснастки) для номенклатуры. Центральный справочник параметров печати/вырубки для этикеток.

## Что делает

Хранит полный набор параметров штампа для каждой единицы номенклатуры: геометрия этикетки, ручьи, нарезка, раппорт, тиснение, фольга, подложка, заточка и другие производственные параметры. Данные используются в форме [[ЗаказКлиента]] при автозаполнении параметров печати.

## Связь с ЗаказКлиента

Параметры штампа используются в форме `Лико_ФормаДокумента`:
- `ЗаполнитьПараметрыШтампа()` — автозаполнение параметров из оснастки
- `ПараметрыШтампаПриИзменении()` — обработка изменений
- `ПроверитьЗаполнениеПараметровШтампа()` — валидация

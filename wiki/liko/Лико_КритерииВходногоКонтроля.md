# Лико_КритерииВходногоКонтроля

> Справочник критериев входного контроля. Хранит критерии качества с визуализацией (картинки), используется для проверки входящих материалов.

## Что хранит

Критерии входного контроля со следующими реквизитами:
- **Общий** — признак общего критерия (для всех)
- **ВидКонтакта** — вид контакта (скрыт на форме)
- **ДляУпаковки** — признак использования для упаковки
- **БлокироватьУпаковку** — признак блокировки упаковки (скрыт)
- **ФайлКартинки** — ссылка на присоединенный файл с изображением критерия
- **ВидыКонтактов** (ТЧ) — табличная часть с колонками ВидКонтакта, Блокировать

Форма элемента содержит поле для отображения/добавления/редактирования изображения критерия.

## Ключевые процедуры

### Модуль формы элемента
- `ПриСозданииЧтенииНаСервере()` — при создании/чтении загружает адрес картинки из ФайлКартинки.
- `ПослеЗаписиНаСервере()` — если был добавлен новый файл картинки (ДанныеФайлаКартинки), создает присоединенный файл в подчиненном справочнике `Лико_НамоткаПрисоединенныеФайлы` (через `РаботаСФайлами.ДобавитьПрисоединенныйФайл()`).
- `АдресКартинкиНажатие()` / `ДобавитьИзображение()` / `ОчиститьИзображение()` / `ИзменитьИзображение()` / `ПросмотретьИзображение()` — команды управления картинкой критерия.
- `ВыбратьКартинкуИзПрисоединенныхФайлов()` — открывает форму присоединенных файлов для выбора существующего изображения.

### Модуль формы списка
- `СписокПриАктивизацииСтроки(Элемент)` — при выборе строки загружает адрес картинки для отображения.
- `ФайлКартинкиНажатие()` — открывает файл изображения на просмотр.

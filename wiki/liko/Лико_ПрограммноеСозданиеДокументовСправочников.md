# Лико_ПрограммноеСозданиеДокументовСправочников

> Программное создание документов и справочников из кода — стандартный паттерн Лико.

## Что делает

Централизованный модуль для программного создания/редактирования объектов 1С из BSL-кода. Реализует паттерн "получить или создать" — не дублирует объекты при повторном вызове.

## Ключевые процедуры

- `СоздатьРедактироватьЗаказПереработчику(Заказ, МассивДанных, Отказ)` — создаёт или обновляет `ЗаказПереработчику` на основе данных из [[ЗаказКлиента]]:
  1. Поиск существующего по связи с Заказом
  2. Если не найден — `СоздатьОбъект()`; если найден — `ПолучитьОбъект()`
  3. Заполнение реквизитов шапки и ТЧ из МассивДанных
  4. `Записать(РежимЗаписи.Проведение)` или `Записать()` в зависимости от типа

## Паттерн "получить или создать"

```bsl
// Стандартный паттерн всех функций этого модуля:
НайденнаяСсылка = НайтиСуществующий(...);
Если ЗначениеЗаполнено(НайденнаяСсылка) Тогда
    ОбъектДокумента = НайденнаяСсылка.ПолучитьОбъект();
Иначе
    ОбъектДокумента = Документы.ИмяДокумента.СоздатьДокумент();
КонецЕсли;
// Заполнение реквизитов...
ОбъектДокумента.Записать(РежимЗаписи.Проведение);
```

## Связь с ЗаказКлиента

Используется в Этапе 1 AI-пайплайна: после извлечения параметров из PDF создаёт новый [[ЗаказКлиента]] программно. Также создаёт связанные документы (ЗаказПереработчику и др.) на основе данных заказа.

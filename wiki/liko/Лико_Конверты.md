# Лико_Конверты

> Справочник конвертов (единиц упаковки). Генерация штрихкодов и печать стикеров конвертов.

## Что хранит

Иерархический справочник конвертов — физических упаковок продукции. Каждый конверт имеет:
- Код (с префиксом группы, индексом и типом)
- Наименование, ТипКонверта
- Организация, Площадка (авто-заполнение)
- Штрихкод (генерируемый)

Имеет макет ПФ_MXL_СтикерКонверта для печати стикеров.

## Ключевые процедуры

### ObjectModule
- `ПередЗаписью(Отказ)` — для групп: авто-заполнение ПлощадкаГруппы по ОрганизацияГруппы через `Лико_Площадки.ПлощадкаПоОрганизации()`. Для элементов: авто-заполнение Площадка по Организация.

### ManagerModule
- `ПолучитьШтрихКод(ЭтотОбъект, ШКСтрокой)` — генерирует 13-значный штрихкод: `6` + вид информации (2 цифры) + код (7 цифр) + контрольный символ. Возвращает ШК и заполняет ШКСтрокой (с пробелами для отображения).
- `ПечатьКонверта(Конверт)` — печать одного конверта через макет ПФ_MXL_СтикерКонверта.
- `СоздатьРаспечататьКонверт(ГруппаКонвертов, Тип, Индекс, ТабличныйДокумент, Конверт)` — если конверта с полным кодом не существует, создает новый, иначе использует существующий. Печатает стикер.
- `ПолучитьБезПрефикса(КодНомер, УдалятьВедущиеНули)` — удаляет буквенный префикс из кода (все нецифровые символы в начале), затем опционально удаляет ведущие нули.
- `МаксимальныйНомерКонверта(ТипКонверта, ГруппаКонвертов)` — запросом получает максимальный код конверта по типу и группе.
- `НомерКонверта(Конверт)` — возвращает числовой номер из кода (до `/`).
- `ДобавитьКомандыПечати(КомандыПечати)` — добавляет команду `ПечатьКонверта` в список команд печати.
- `Печать(МассивОбъектов, ПараметрыПечати, ...)` — печать списка конвертов через УправлениеПечатью.
- `ПечатьЗадания(МассивОбъектов, ОбъектыПечати)` — формирует табличный документ по макету ПФ_MXL_СтикерКонверта: для каждого объекта выводит шапку с наименованием и штрихкодом (Code128, 4), настраивает поля и принтер.

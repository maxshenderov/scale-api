# Лико_ФормулыПантонов

> Справочник формул пантонных красок — хранит рецептуру смешивания красок (состав и проценты) для получения конкретного пантонного цвета, с автосозданием номенклатуры смеси.

## Что хранит

Рецептуру краски: базовая номенклатура-основа, список компонентов смеси с процентами, привязка к виду печати, ТМЦ и площадке. Созданная номенклатура смеси сохраняется в реквизит `Номенклатура`.

**Реквизиты:**
- `Площадка` (Справочник.Лико_Площадки) — производственная площадка
- `ВидПечати` (Справочник.Лико_ВидыПечати) — вид печати
- `ВидТМЦ` (Справочник.Лико_ВидыТМЦ) — вид ТМЦ
- `ЦеноваяГруппа` (Справочник.ЦеновыеГруппы) — ценовая группа краски
- `Номенклатура` (Справочник.Номенклатура) — созданная номенклатура смеси (заполняется автоматически)
- `КодЛинкс` (Строка) — код в системе Линкс
- `Комментарий` (Строка)

**Табличная часть «Состав»:**
- `Номенклатура` (Справочник.Номенклатура) — компонент (базовая краска)
- `ПроцентВСмеси` (Число) — доля компонента в смеси

## Ключевые процедуры

- `Лико_СодатьНоменклатуруСмеси()` (Менеджер) — создает или находит элемент номенклатуры для краски-смеси. Имя формируется как `ВидТМЦ_ВидПечати_НаименованиеФормулы`. Копирует свойства с базовой номенклатуры (единицы измерения, вес, упаковки, группы учета, ставка НДС, складская группа и др.). Заполняет `ВидНоменклатуры` = `Краска`, дополнительный реквизит `КраскаВид`
- `Лико_СодатьНоменклатуруСмеси2()` (Менеджер, старый вариант) — упрощенная версия без доп. реквизитов
- `Лико_СоздатьНоменклатуруПантонаВместо()` (ФормаЭлемента, клиент, асинх) — запускает создание номенклатуры пантона из формы: проверяет заполнение состава, запрашивает подтверждение у пользователя
- `Лико_ПроверкаЗаполненияПолей()` (ФормаЭлемента, клиент) — валидирует заполнение: Состав, ВидПечати, ВидТМЦ, Наименование. Для площадки ИксПак дополнительно проверяет ЦеновуюГруппу
- `Лико_СоздатьНоменклатуруНаСервере()` (ФормаЭлемента, сервер) — вызывает менеджер `СодатьНоменклатуруСмеси()` с параметрами из формы

# Лико_ПричиныЗаявокНаФормы

> Причины заявок на изготовление форм — простой справочник для классификации.

## Что хранит
Перечень причин, по которым могут создаваться заявки на изготовление форм (оснастки). Используется в документе `Лико_ЗаявкаНаИзготовлениеФорм` для указания основания заявки.

Неиерархический справочник. Код строковый (до 2 символов), наименование до 100 символов.

## Ключевые процедуры

### ManagerModule
- `ОбработкаПолученияДанныхВыбора()` -- добавляет в отбор `НеПоказыватьВФормеВыбора = Ложь`, позволяя скрывать архивные причины из форм выбора

ObjectModule отсутствует -- логика элемента минимальна.

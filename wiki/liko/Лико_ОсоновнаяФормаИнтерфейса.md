# Лико_ОсоновнаяФормаИнтерфейса

> Форма основного интерфейса с командой быстрого создания документа «Передача товаров».

## Что делает

Предоставляет команду `ДобавитьПередачаСоСклада`, которая открывает форму нового документа `Лико_ПередачаТоваров`. Это точка входа из основного интерфейса для создания передачи товаров со склада.

## Ключевые процедуры

- `ДобавитьПередачаСоСклада(Команда)` — открывает `Документ.Лико_ПередачаТоваров.ФормаОбъекта`.

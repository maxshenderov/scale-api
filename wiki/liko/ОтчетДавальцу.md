# ОтчетДавальцу (типовой, доработан)

> Доработка Лико: очистка регистров для контроля при проведении, интеграция с `Лико_Планирование` при удалении проведения.

## Доработки

- **Снятие контроля регистров при проведении** — массив регистров для контроля очищается (аналогично `ВозвратСырьяДавальцу`).
- **Очистка данных по отгрузке при удалении проведения** — при удалении проведения вызывается `Лико_Планирование.ОчиститьДанныеПоОтгрузке(Ссылка)`. Не выполняется при перепроведении без изменений (проверка свойства `Лико_ЭтоПерепроведениеДокументаБезИзменений`).

## Ключевые процедуры

- `Лико_СформироватьСписокРегистровДляКонтроля()` (после `СформироватьСписокРегистровДляКонтроля`) — очищает список регистров для контроля.
- `Лико_ОбработкаУдаленияПроведения()` (вместо `ОбработкаУдаленияПроведения`) — вызывает штатное `ПроведениеДокументов.ОбработкаУдаленияПроведенияДокумента()`, актуализацию счетов-фактур через `УчетНДСУП`, локализацию `ОтчетДавальцуЛокализация.ОбработкаУдаленияПроведения()`, и очистку данных планирования.

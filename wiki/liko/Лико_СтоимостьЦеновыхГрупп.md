# Лико_СтоимостьЦеновыхГрупп

> Регистр сведений (подчинённый регистратору) — расчёт и хранение средневзвешенной стоимости ценовых групп при поступлении товаров от поставщиков.

## Тип регистра
**Периодичность: по позиции регистратора** (`RecorderPosition`), **Подчинённый регистратору** (`RecorderSubordinate`). Записи привязаны к документам-регистраторам (`Лико_УстановкаСтоимостиЦеновыхГрупп` и `ПриходныйОрдерНаТовары`).

## Измерения
- **Организация** (`CatalogRef.Организации`) — организация
- **ЦеноваяГруппа** (`CatalogRef.ЦеновыеГруппы`) — ценовая группа
- **УдалитьВалюта** (`CatalogRef.Валюты`) — вспомогательное измерение для валюты

## Ресурсы
- **Цена** (`Число(15,4)`) — средневзвешенная цена ЦГ
- **Валюта** (`CatalogRef.Валюты`) — валюта цены

## Реквизиты
- **Количество** (`Число(15,4)`) — общее количество
- **ЗаказПоставщику** (`DocumentRef.ЗаказПоставщику`) — связанный заказ поставщику
- **Рассчитывается** (`Булево`) — признак того, что цена рассчитывается (а не установлена вручную)
- **ЦенаОстаток** (`Число(15,4)`) — цена остатка на складе
- **ВалютаОстаток** (`CatalogRef.Валюты`) — валюта остатка
- **КоличествоОстаток** (`Число(15,4)`) — количество остатка на складе
- **КроссКурс** (`Число(15,4)`) — кросс-курс между валютами
- **ЦенаОстатокКрос** (`Число(15,4)`) — цена остатка в кросс-валюте
- **КоличествоПриход** (`Число(15,4)`) — количество прихода
- **ЦенаПриход** (`Число(15,4)`) — цена прихода

## Ключевые процедуры (из расширения)

### ManagerModule (весь код закомментирован)

**`Лико_ЗаписатьСтоимтостьЦеновыхГрупп(Организация, Регистратор)`** — основная процедура расчёта:
1. Очищает предыдущие записи по регистратору
2. Если регистратор — `ПриходныйОрдерНаТовары` со связанным `ЗаказПоставщику` → `Рассчитывается = Истина`
3. Собирает данные из `Лико_УстановкаСтоимостиЦеновыхГрупп.ЦеновыеГруппы` (ручные цены)
4. UNION с данными из `ЗаказПоставщику.Товары`, где включен авторасчёт (`Лико_АвтоРасчетЦенЦГ`)
5. JOIN с `ТоварыВЯчейках.Остатки` и `Лико_СтоимостьЦеновыхГрупп.СрезПоследних` для получения остатков
6. Если цена/валюта изменились или количество > 0 — записывает новую стоимость
7. При расчёте вызывает `РассчитатьСреденеВзвешеннуюЦену()` для средневзвешенной цены
8. Дополнительно обновляет `Лико_ЦеныГруппНоменклатуры` ценой поставщика

**`Лико_ПересчитатьСтоимостьЦеновыхГрупп(Организация, Дата)`** — пересчёт стоимости:
- Выбирает все проведённые `Лико_УстановкаСтоимостиЦеновыхГрупп` и `ПриходныйОрдерНаТовары` за период
- Для каждого вызывает `ЗаписатьСтоимтостьЦеновыхГрупп()`

**`Лико_РассчитатьСреденеВзвешеннуюЦену(МассивЦен, Валюта, Дата)`** — расчёт средневзвешенной:
- Пересчитывает все цены в целевую валюту через `РаботаСКурсамиВалют`
- Вычисляет кросс-курсы на основе рейтинга валют (`Лико_Рейтинг`)
- Возвращает структуру `Цена` + `Валюта` (соответствие валют с КроссКурс и КросЦена)

Всё выполняется в транзакции с привилегированным режимом.

## Связь с закупками
Ключевой регистр цепочки закупок: `ЗаказПоставщику` → `ПриходныйОрдерНаТовары` → расчёт средневзвешенной стоимости ЦГ. Данные используются для ценообразования и учёта себестоимости.

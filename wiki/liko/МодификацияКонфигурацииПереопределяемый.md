# МодификацияКонфигурацииПереопределяемый

> Переопределение `ПриСозданииНаСервере`: добавление реквизитов на формы номенклатуры, безналичных платежей и заказа поставщику.

## Что делает
Расширяет типовое событие `ПриСозданииНаСервере` (аннотация `&После`). Добавляет на форму элемента номенклатуры поле `Лико_ВесТары`, на форму журнала безналичных платежей — отбор по организации с действием при изменении, на форму заказа поставщику — колонку `Прайс` в табличную часть Товары. Также исправляет путь к данным подвала для формы ОтражениеЗарплатыВФинансовомУчете.

## Ключевые процедуры
- `Лико_ПриСозданииНаСервере(Форма, Отказ, СтандартнаяОбработка)` — переопределение события ПриСозданииНаСервере:
  - **Номенклатура**: добавляет поле `Лико_ВесТары` в группу дополнительных реквизитов
  - **ОтражениеЗарплатыВФинансовомУчете**: исправляет `ПутьКДаннымПодвала` для взносов по единому тарифу
  - **Журнал безналичных платежей**: добавляет поле Организация с отбором, привязывает действие `Лико_ОрганизацияПриИзменении`
  - **Заказ поставщику**: добавляет колонку `Прайс` (Число 15,4) в ТЧ Товары, размещает после колонки Цена

## Используется в
- Форма элемента справочника Номенклатура
- Форма документа ОтражениеЗарплатыВФинансовомУчете
- Форма обработки ЖурналДокументовБезналичныеПлатежи
- Форма документа ЗаказПоставщику

# ПоступлениеОтПереработчика (типовой, доработан)

> Подбор товаров по приходным ордерам через обработку `Лико_ЗаполнениеТЧПТУ`. m.shenderov 24.01.2018.

## Доработки

- **Подбор по приходным ордерам** -- кнопка `ЛикоПодборПоПриходныиОрдерам` открывает обработку `Лико_ЗаполнениеТЧПТУ` с фильтром по Партнер, Склад и списку номенклатуры из текущих строк ТЧ. После выбора -- строки с совпадающим `Лико_ПриходныйОрдер` обновляются по количеству, новые строки добавляются с копированием цены.
- **Условное оформление** (`&После("УстановитьУсловноеОформление")`) -- строки с заполненным `Лико_ПриходныйОрдер` подсвечиваются зеленым фоном (205, 255, 205).
- **Выбор приходного ордера в строке** -- при выборе значения в поле `ТоварыЛико_ПриходныйОрдер` открывается та же обработка подбора для одной номенклатуры.

## Ключевые процедуры

- `Лико_ЛикоПодборПоПриходныиОрдерамВместо(Команда)` -- открытие формы подбора (клиент).
- `Лико_ЗаполнитьПоОрдерамПослеЗавершение(ФормаРезультат, ФормаПараметры)` -- обработка результата подбора (клиент).
- `Лико_ТоварыВыборПосле(Элемент, ВыбраннаяСтрока, Поле, СтандартнаяОбработка)` -- выбор приходного ордера в строке ТЧ (клиент).
- `Лико_УстановитьУсловноеОформление()` -- зеленый фон для строк с ордером (сервер).

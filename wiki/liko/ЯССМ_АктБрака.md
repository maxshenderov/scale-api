# ЯССМ_АктБрака

> Печатная форма «Акт брака» для документов `Лико_ПередачаТоваров` и `Лико_ЗабраковкаМатериалов`. Формирует акт с перечнем товаров, ценами поступления и подписями комиссии.

## Что делает
Генерирует печатную форму акта брака. Принимает через параметры: `СсылкаНаОбъект`, состав комиссии (`ПредседательКомисии`, `ГлавныйТехнолог`, `НачальникОтделаЗакупок`), `ОписаниеНедостатков`.

### Логика по типам документов
- **`Лико_ПередачаТоваров`** — берёт ТЧ `Товары`, организацию, дату, контрагента
- **`Лико_ЗабраковкаМатериалов`** — берёт ТЧ `Материалы`, пересчитывает количество в метраж КВМ, форма «Ф-07», автозаполнение председателя и начальника отдела для Ликофлекс

### Цена поступления
Для каждой строки находит приходный ордер через `НайтиПриходныйОрдер()` (по регистру `ТоварыВЯчейках`), затем через `ПолучитьПоступлениеТоваров()` получает цену/номер/дату прихода из `ПриобретениеТоваровУслуг.Товары`.

### Печатная форма
- Заголовок с организациями, контрагентом, номером и датой акта
- Таблица ТТН (приходные документы)
- Таблица товаров с номенклатурой, нарезкой, втулкой, количеством, ценой
- Итого по количеству и сумме
- Подвал с описанием недостатков и подписями комиссии (Фамилия И.О.)

## Ключевые процедуры
- `ПечатьАкта(ТабДокумент)` — основной метод сборки печатной формы
- `НайтиПриходныйОрдер(Серия)` — рекурсивный поиск приходного ордера по серии через `ТоварыВЯчейках` и `Лико_БланкЭтапа.Товары`
- `ПолучитьПоступлениеТоваров(СтрокаТз, ПриходныйОрдер)` — получает цену/дату/номер прихода из `ПриобретениеТоваровУслуг`
- `ЗаполнитьЦенуПоПоступлению(СтрокаТз, ПриходныйОрдер)` — рекурсивное заполнение цены
- `ПриСозданииНаСервере()` — автозаполнение состава комиссии и описания недостатков для `Лико_ЗабраковкаМатериалов`

## Используемые модули
- `Лико_Дополнительно` — не используется напрямую, но зависит от данных `ЯССМ_ОбъектНоменклатуры`

# Лико_КартаСнятия

> Производственный документ — фиксирует снятие материалов (возврат) по заказу/бланку/прокату/оператору с контролем дублирования.

## Что делает

Учёт возврата (снятия) материалов с производства. Аналог `Лико_КартаПерерасхода`, но для операции снятия. Привязан к тем же ключевым полям: Заказ, НомерБланка, НомерПроката, Оператор. При создании к закрытому заказу отправляет email-уведомление на `Uchet@okil-sato.ru`.

Проверяет уникальность комбинации (Заказ + НомерБланка + НомерПроката + Оператор) среди проведённых карт — дубликаты запрещены.

## Ключевые процедуры

- `ПередЗаписью()` — вызывает проверку на дубликат; при создании карты к закрытому заказу отправляет email.
- `ПроверитьНаличиеКартыСТакимиПараметрами()` — запрос по регистру: ищет проведённый документ с теми же Заказ + Бланк + Прокат + Оператор (исключая текущий). При нахождении дубликата — отказ с сообщением.
- `ОбработкаЗаполнения()` — заполнение из структуры.

### ManagerModule

Минимальный — только заглушки `ДобавитьКомандыПечати()` и `Печать()`.

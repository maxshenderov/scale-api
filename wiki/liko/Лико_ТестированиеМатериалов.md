# Лико_ТестированиеМатериалов

> Документ фиксирует результаты тестирования материалов: записывает результаты в регистр `Лико_РезультатыТестированияМатериалов` и при отрицательном входном контроле автоматически отправляет email-уведомление в отдел закупок.

## Что делает

Ведет учет тестирования материалов по партиям. Каждая строка ТЧ `Товары` может иметь несколько тестов (ТЧ `Тесты`) с результатами. При отрицательном результате (`Лико_ДаНет.Нет`) по любой строке общий результат документа становится отрицательным. При проведении с операцией "ВходнойКонтроль" и отрицательным результатом -- автоматически формирует HTML-письмо с таблицей несоответствий и отправляет на адреса отдела закупок.

## Ключевые процедуры

### ObjectModule

- `ПередЗаписью()` -- устанавливает ответственного и общий результат документа: если есть хотя бы одна строка с результатом "Нет" -- общий результат "Нет", иначе "Да".
- `ОбработкаПроведения()` -- формирует движения в регистр `Лико_РезультатыТестированияМатериалов`: для каждой строки товаров записывает все связанные тесты с результатами.

### Форма документа

- `ПодборНоменклатуры()` -- открывает форму выбора номенклатуры со склада с фильтром по периоду для подбора материалов на тестирование.
- `ПоискПоШтрихкодуВыполнить()` -- ввод штрихкода вручную для быстрого поиска.
- `WebSocketОбработкаШтрихКода()` -- обработка штрихкодов со сканера через WebSocket.
- `ОбработатьШтрихкоды()` -- разбор штрихкода (через `Лико_ДополнительноКлиент`), поддержка видов ШК: `ЯС_ВидыШК.ШК_ОбъектаНоменклатуры` и `ШК_ОбъектаНоменклатуры_Короткий`.
- `ОбработатьШКОбъектаНоменклатуры()` -- добавление в ТЧ по штрихкоду: Номенклатура, Серия, Нарезка, Партия, КлючСтроки.
- `ТоварыПриАктивизацииСтроки()` -- фильтрация ТЧ `Тесты` по ключу строки.
- `ТестыПриНачалеРедактирования()` -- авто-заполнение ключа строки для привязки тестов.
- `ПослеЗаписи()` -- при проведении с операцией "ВходнойКонтроль" и наличии отрицательных результатов -- отправка email.
- `СформироватьИОтправитьПисьмоСОтрицательнымРезультатомВК()` -- полный цикл отправки:
  1. Формирование табличного документа на основе макета
  2. Заполнение данных по строкам с отрицательным результатом
  3. Конвертация в HTML5
  4. Отправка через `Лико_Планирование.ОтправитьПисьмо()`
  5. Установка флага `ПисьмоСОтрицательнымРезультатомВКОтправлено` для отправленных строк
- `ТоварыСерияПриИзменении()`, `ТоварыНоменклатураПриИзменении()` -- сброс флага отправки письма при изменении серии/номенклатуры в строке с отрицательным результатом.

## Состояния и режимы

- `Лико_ОперацииТестированиеМатериалов.ВходнойКонтроль` -- операция, при которой отправляются письма при отрицательном результате
- `Лико_ДаНет` -- результаты "Да"/"Нет" для строк товаров
- `ПисьмоСОтрицательнымРезультатомВКОтправлено` -- флаг отправки для каждой строки

## Используемые модули

- `Лико_ДополнительноКлиент` -- разбор штрихкода
- `Лико_Планирование` -- отправка email
- `ШтрихкодированиеНоменклатурыКлиент` -- ввод штрихкода

# Лико_РезервПодЗаявкуНаСклад

> Регистр сведений: движения резерва под заявки на склад. Формируется при проведении и перепроведении документа `Лико_ЗаявкаНаСклад`.

## Что хранит
Резерв номенклатуры (в разрезе серий и объектов номенклатуры), создаваемый заявками на склад. Записи формируются только для уникальных объектов номенклатуры.

## Измерения
- **Период** — дата заявки
- **ЗаявкаНаСклад** — документ-регистратор (`Лико_ЗаявкаНаСклад`)
- **Серия** — серия номенклатуры
- **ОбъектНоменклатуры** — ссылка на `ЯССМ_ОбъектыНоменклатуры`

## Ключевые процедуры
- `Проведение(ДокументОбъект)` — вызывается при проведении документа. Загружает подготовленные движения в регистр.
- `СформироватьДвижения(ДокументСсылка)` — формирует и записывает движения в регистр по ссылке документа. Используется для переформирования.
- `ПолучитьДвиженияПоДокументуЛико_ЗаякаНаСклад(Ссылка, Движения)` — запрос к табличной части Товары документа `Лико_ЗаявкаНаСклад` с фильтром по статусам «Подготовлен» и «ВОбработке», только для уникальных объектов номенклатуры.

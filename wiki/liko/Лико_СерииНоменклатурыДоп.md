# Лико_СерииНоменклатурыДоп

> Регистр сведений: дополнительная информация о сериях номенклатуры — организация-владелец и вид запаса. Заполняется при проведении документов поступления, выпуска и возврата.

## Что хранит
Для каждой серии номенклатуры хранит организацию и вид запаса. Периодический, с привязкой к документу-регистратору. Позволяет определить владельца товара (собственная организация или давалец).

## Измерения
- **Период** — дата документа-регистратора
- **Регистратор** — документ, создавший запись
- **Серия** — серия номенклатуры
- **Организация** — организация-владелец
- **ВидЗапаса** — вид запаса (свой/давальческий)

## Ключевые процедуры

### Программный интерфейс
- `Записать(Регистратор)` — точка входа. Принимает ссылку или объект документа, вызывает специализированные обработчики для трёх типов документов:
  - `ЗаписатьПоПриходномуОрдеру` — для `ПриходныйОрдерНаТовары`
  - `ЗаписатьПоЗакрытиюБланка` — для `Лико_БланкЭтапа`
  - `ЗаписатьПоЛико_ВозвратТоваров` — для `Лико_ВозвратТоваров`
- `РегистраторПоСерии(Серия, Период)` — по серии находит последний документ-регистратор из ТоварыНаСкладах (приходные ордера, бланки этапов, возвраты товаров). Фильтрует по распоряжениям для записи серий (ЗаказПоставщику, ЗаказДавальца, ЗаказПереработчику и др.).
- `ОрганизацияВладельцаТовара(Серия, Период)` — определяет организацию-владельца. Если вид запаса давальческий — возвращает `ВидЗапаса.ВладелецТовара` (через свойство партнёра `Лико_СобственнаяОрганизация`), иначе `Организация`.

### Служебные процедуры
- `ЭтоРаспоряжениеДляЗаписиСерий(Распоряжение)` — проверяет, что документ-распоряжение относится к одному из типов: ЗаказДавальца, ЗаказПереработчику, ЗаказПоставщику, ПриобретениеТоваровУслуг, ПрочееОприходованиеТоваров.
- `Организация(РегистраторОбъект)` — диспетчер: вызывает `ОрганизацияПоПриходномуОрдеру`, `ОрганизацияПоЗакрытиюБланка`, `ОрганизацияПоЛико_ВозвратТоваров`.
- `ВидЗапаса(РегистраторОбъект)` — диспетчер: вызывает `ВидЗапасаПоПриходномуОрдеру` и `ВидЗапасаПоЗакрытиюБланка`.
- `СформироватьНаборЗаписей(РегистраторОбъект, МассивСерий)` — для каждой серии из массива добавляет запись с Организацией и ВидЗапаса и записывает набор.

# ЗаказПоставщику (типовой, доработан)

> Ключевые доработки Лико: кастомный расчет процента поступления по регистрам `Лико_ТоварыКПоступлениюПоЗаказамПоставщику`, заполнение из отбора с расчетом роликов, внутренние заявки на закупку, валидация для разных организаций.

## Доработки

### ManagerModule

- **`Лико_ПроцентПоступленияПоЗаказу()`** — кастомный расчет процента поступления товаров по заказу поставщику. Использует два регистра накопления: `Лико_ТоварыКПоступлениюПоЗаказамПоставщику` и `Лико_ТоварыКПоступлениюПоПредзаказамПоставщику`. Запрашивает остатки и обороты, вычисляет процент = Расход / Приход * 100. Возвращает структуру с процентом и датой последнего поступления.
- **`Лико_ДанныеДокументаДляПроведения()`** — замена штатной функции, отключено отражение взаиморасчетов (комментарий Маковеевой А.Ю. от 14.05.2018: «взаиморасчеты двигаем только документом поставки»).

### ObjectModule

- **`Лико_ЗаполнитьДокументПоОтбору()`** — расширенное заполнение документа по данным отбора:
  - При наличии `лкСтрТовары` заполняет таблицы `Товары` и `Лико_РезервПодЗаказКлиента` с расчетом роликов (Намотка=2000, втулка 76, расчет через нарезку характеристики).
  - При наличии `ВнутренняяЗаявкаНаЗакупку` — заполняет контрагента (ОКИЛ), номенклатуру для внутренней заявки, цену=1, количества=1. Для организации ИксПак устанавливает `Лико_ВидКонтактаСПищевойПродукцией = НетКонтакта`.
- **`Лико_ОбработкаПроверкиЗаполнения()`** — дополнительные проверки:
  - Для организаций с `Лико_УчетНаСкладеПоBRC` — обязателен реквизит `Лико_ВидКонтактаСПищевойПродукцией`.
  - Добавление `Лико_ВалютаРасчета` в непроверяемые реквизиты.
  - Для организации ИксПак (статус <> `Лико_Создан`) и Ликофлекс (статус `НеСогласован`) — обязательна `ДлительностьДоставки`.
  - Для партнеров с `Лико_ОформлятьПредзакзыПоставщикам` — обязателен реквизит `Лико_Основание`.
  - Корректировка проверки дат поступления/отгрузки (Яцун С.В., 03.10.2024) с проверкой `ДатаПоступления < ДатаОтгрузки` только при заполненной `ДатаПоступления`.
  - Проверка заполнения соглашения — если у партнера есть соглашения, но соглашение не выбрано, выдается ошибка.

## Ключевые процедуры

- `Лико_ПроцентПоступленияПоЗаказу()` (вместо `ПроцентПоступленияПоЗаказу`, экспортная, ManagerModule) — кастомный расчет процента поступления.
- `Лико_ДанныеДокументаДляПроведения()` (вместо `ДанныеДокументаДляПроведения`, экспортная, ManagerModule) — подмена данных для проведения.
- `Лико_ЗаполнитьДокументПоОтбору()` (вместо `ЗаполнитьДокументПоОтбору`, ObjectModule) — заполнение из отбора с расчетом роликов и внутренними заявками.
- `Лико_ОбработкаПроверкиЗаполнения()` (вместо `ОбработкаПроверкиЗаполнения`, ObjectModule) — расширенная валидация.

## Используемые регистры

- `Лико_ТоварыКПоступлениюПоЗаказамПоставщику` — учет поступления по заказам поставщикам
- `Лико_ТоварыКПоступлениюПоПредзаказамПоставщику` — учет поступления по предзаказам

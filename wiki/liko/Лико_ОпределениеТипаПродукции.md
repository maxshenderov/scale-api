# Лико_ОпределениеТипаПродукции

> Определение типа продукции по наименованию — функция классификации для RAG-индексации.

## Что делает

Классифицирует заказ по наименованию номенклатуры. Используется при формировании payload для Qdrant. Создан 12.05.2026.

## Ключевые процедуры

- `ОпределитьТипПродукции(Наименование)` — эвристическая классификация по строке наименования:
  - Возвращает: `{ТипЗаказа, ТипЭтикетки, КатегорияПродукции}`
  - `КатегорияПродукции` — 30+ категорий: шампунь, вина, масла_автохимия, молочка, бытовая химия, алкоголь, пиво и др.
  - Реализован через набор ключевых слов / регулярных выражений в наименовании

## Использование

Вызывается из [[Лико_QdrantИндексация]].СформироватьPayloadЗаказа() для поля `product_category` в payload Qdrant.

```bsl
// В Лико_QdrantИндексация:
ТипПродукции = Лико_ОпределениеТипаПродукции.ОпределитьТипПродукции(
    ЗаказОбъект.Наименование);
Payload.Вставить("product_category", ТипПродукции.КатегорияПродукции);
```

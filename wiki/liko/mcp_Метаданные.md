# mcp_Метаданные

> MCP-модуль: создание таблиц описания объектов и схем параметров, сбор инструментов/ресурсов/промптов из обработок-контейнеров.

## Что делает

Центральный модуль мета-описания MCP-расширения. Решает три задачи:
1. Создает заготовки таблиц (колонки) для инструментов, ресурсов, промптов
2. Заполняет эти таблицы, обходя обработки-контейнеры из соответствующих подсистем
3. Строит JSON-схемы параметров инструментов и JSON-описания параметров промптов

## Ключевые процедуры

### Создание таблиц
- `ТаблицаИнструментов()` — создает `ТаблицаЗначений` с колонками: `ИмяОбработкиКонтейнера`, `Имя`, `Описание`, `СхемаПараметров`.
- `ТаблицаРесурсов()` — колонки: `ИмяОбработкиКонтейнера`, `Адрес`, `Имя`, `Описание`.
- `ТаблицаПромптов()` — колонки: `ИмяОбработкиКонтейнера`, `Имя`, `Описание`, `Параметры`.

### Добавление строк
- `ДобавитьИнструмент(Таблица, Имя, Описание, СхемаПараметров)` — добавляет строку в таблицу инструментов с установкой `ИмяОбработкиКонтейнера`.
- `ДобавитьРесурс(Таблица, Адрес, Имя, Описание)`
- `ДобавитьПромпт(Таблица, Имя, Описание, Параметры)`

### Заполнение из контейнеров
- `ЗаполнитьТаблицуИнструментов(Таблица)` — обходит подсистему `mcp_MCPСервер.mcp_КонтейнерыИнструментов`, для каждой обработки вызывает `ДобавитьИнструменты()`, проставляет `ИмяОбработкиКонтейнера`.
- `ЗаполнитьТаблицуРесурсов(Таблица)` — аналогично через `mcp_КонтейнерыРесурсов`, вызывает `ДобавитьРесурсы()`.
- `ЗаполнитьТаблицуПромптов(Таблица)` — аналогично через `mcp_КонтейнерыПромптов`, вызывает `ДобавитьПромпты()`.

### Схема параметров инструментов
- `ПараметрИнструмента(Имя, Тип, Описание, ...)` — создает `Структура` описания простого параметра (тип, default, required, enum).
- `ПараметрИнструментаМассив(Имя, ТипЭлемента, ...)` — создает описание параметра-массива.
- `СхемаПараметровИнструмента(МассивОписанийПараметров)` — из массива описаний параметров строит полную JSON-схему (type: object, properties, required) и сериализует через `mcp_ОбщегоНазначения.СтруктураВJSON()`.

### Параметры промптов
- `ПараметрПромпта(Имя, Описание, Обязательный)` — создает описание параметра промпта.
- `ПараметрыПромпта(МассивОписанийПараметров)` — из массива описаний строит JSON-массив параметров промпта.

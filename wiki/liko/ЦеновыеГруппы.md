# ЦеновыеГруппы

> Типовой справочник ценовых групп. Доработка — автонумерация групп, уведомления о новых металлизированных материалах, регистрация в авто-расчете цен.

## Что делает / Доработки
- **Группировка номенклатуры по ценовым группам** для расчета себестоимости и цен.
- **Расширение `ObjectModule`**:
  - **Автонумерация групп**: при создании новой группы автоматически присваивается код = максимальный код группы + 1.
  - **Уведомление о новых металлизированных материалах**: при создании нового элемента с признаком `Metal` отправляется email через `Лико_Планирование.ОтправитьПисьмо()` на адреса mlipatov, iivanov, mbuyanov.
  - **Регистрация в авто-расчете цен**: при записи элемента вызывается `РегистрыСведений.Лико_АвтоРасчетЦенЦГ.Установить()` — актуализирует настройки авто-расчета для ценовой группы.

## Ключевые процедуры
- `Лико_ПередЗаписью(Отказ)` — &Вместо штатной, ветвление: для групп — автонумерация кода; для элементов — уведомление о Metal + регистрация авто-расчета цен

# Лико_ПакетноеФормированиеДокументов

> Справочник настроек пакетного формирования документов. Позволяет выбрать документ-основание, список документов и настроить формулы для реквизитов каждого документа в пакете.

## Что хранит

- **ДокументОснование** — документ-основание для пакетного создания
- **СписокДокументов** (табличная часть) — какие документы создавать в пакете:
  - ДокументИмя — имя метаданных документа
  - ДокументСиноним — представление документа
- **РеквизитыДокументов** (табличная часть) — реквизиты каждого документа в пакете:
  - ДокументИмя, РеквизитИмя, РеквизитСиноним
  - Формула — BSL-выражение для вычисления значения реквизита
  - ЕстьФормула — флаг наличия формулы

## Ключевые процедуры

### ФормаЭлемента
- `ДокументОснованиеНачалоВыбора()` — открывает `ФормаПодбораМетаданных` для выбора документа из метаданных конфигурации
- `ДокументОснованиеНачалоВыбораЗавершение()` — при выборе документа заполняет ДокументОснованиеИмя и Наименование
- `СписокДокументовДокументСинонимНачалоВыбора()` — открывает форму подбора с флажковым выбором (множественный выбор документов)
- `СписокДокументовДокументСинонимНачалоВыбораЗавершение()` — заполняет табличную часть СписокДокументов выбранными документами
- `СписокДокументовВыбор(Элемент, ВыбраннаяСтрока)` — открывает `ФормаРеквизитовДокумента` для настройки реквизитов конкретного документа в пакете
- `СписокДокументовВыборЗавершение()` — сохраняет выбранные реквизиты с формулами в табличную часть РеквизитыДокументов
- `СписокРеквизитов(ДокументИмя)` — возвращает массив структур {Имя, Формула} сохранённых реквизитов документа
- `СписокВыбранныхДокументов()` — возвращает массив имён выбранных документов (автор: m.shenderov 08.09.2017)
- `РедактироватьСписок(Команда)` — открывает форму подбора метаданных для редактирования списка документов

### ФормаПодбораМетаданных
- `ПриСозданииНаСервере()` — заполняет список метаданных для выбора (все документы конфигурации); поддерживает режим флажкового выбора и предустановку отмеченных документов
- `СписокДокументовВыбор()` / `Выбрать()` — возвращает выбранный документ / список отмеченных документов через `Закрыть()`

### ФормаРеквизитовДокумента
- `ПриСозданииНаСервере()` — заполняет список всех реквизитов выбранного документа (реквизиты шапки + реквизиты табличных частей в формате `ТЧ.Реквизит`); восстанавливает ранее сохранённые формулы
- `СписокРеквизитовДокументаФормулаПриИзменении(Элемент)` — при вводе формулы устанавливает флаг ЕстьФормула
- `Сохранить(Команда)` — возвращает только строки с заполненными формулами

## Связи с ЗаказКлиента

Используется для пакетного создания цепочки документов на основании ЗаказаКлиента. Позволяет задать формулы для автоматического заполнения реквизитов создаваемых документов.

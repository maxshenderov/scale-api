# Лико_КонтрольПартийПоризводстваНоменклатуры

> Иерархический справочник правил контроля партий производства номенклатуры — определяет, для каких видов номенклатуры и при каких условиях действуют правила контроля партий.

## Что хранит

Набор правил с привязкой к организации и виду номенклатуры. Каждое правило может иметь сложную настройку через СКД (схема компоновки данных) и дополнительные реквизиты для фильтрации.

**Реквизиты:**
- `Выключить` (Булево) — отключение правила
- `Организация` (Справочник.Организации) — организация, для которой действует правило
- `ВидНоменклатуры` (Справочник.ВидыНоменклатуры) — фильтр по виду номенклатуры
- `Приоритет` (Число) — приоритет правила
- `СложнаяНастройка` (Булево) — признак использования СКД для сложного отбора
- `ОтборНастройки` (ХранилищеЗначения) — настройки отбора СКД
- `Описание`, `Комментарий` (Строка)

**Табличная часть «ДополнительныеРеквизиты»:**
- `Свойство` (ПВХ.ДополнительныеРеквизитыИСведения) — свойство для фильтрации
- `Значение` (составной тип) — значение свойства
- `Исключить` (Булево) — инвертировать условие
- `ТекстоваяСтрока` (Строка) — текстовое представление значения

## Ключевые процедуры

Модуль менеджера пуст — логика контроля партий реализована в других модулях (вероятно, в [[Лико_ПроведениеДокументов]]).

# Лико_ВыработкаПеремоткиРезки

> Регистр накопления: учитывает выработку по операциям перемотки/резки в разрезе заказов, сотрудников и смен.

## Что хранит

Движения формируются документом `Лико_ДвиженияЗаказаПоЭтапам`. Фиксирует выработку (метраж, время) по перемотке/резке в разрезе сотрудника, заказа, номера бланка, смены и типа операции.

## Измерения

| Измерение | Тип | Описание |
|---|---|---|
| Сотрудник | Справочник.Сотрудники | Сотрудник, выполнивший операцию |
| Заказ | Документ.ЗаказКлиента, Документ.Лико_ЗаказНаРаскрой | Заказ-основание |
| НомерБланка | Число | Номер бланка |
| ДатаОперации | Дата | Дата операции |
| Смена | Число | Номер смены |
| ТипОперации | Справочник.Лико_ТипыОперацийПеремотка | Тип операции перемотки |

## Ресурсы

| Ресурс | Тип | Описание |
|---|---|---|
| МетражКвМ | Число | Метраж в кв. метрах |
| МетражПМ | Число | Метраж в погонных метрах |
| Время | Число | Затраченное время |

## Реквизиты

| Реквизит | Тип | Описание |
|---|---|---|
| ВсегоКвМ | Число | Всего кв. метров |
| Настройка_ЗП | Число | Настройка зарплаты |

## Регистратор

`Документ.Лико_ДвиженияЗаказаПоЭтапам`

## Ключевые процедуры

- `КолЭтВРоликеПачке(ЗаказКлиента, Количество, Автор, ДатаПеремотки, НомерБланка, Сотрудник, РабочийЦентр, ДокументОснование)` — вычисляет количество этикеток в ролике/пачке:
  - Для площадки **Линкс**: ищет по `Лико_ФормированиеПаллета.Содержимое` и справочнику `СерииНоменклатуры.Лико_Содержимое`, возвращает `КоличествоВРоликеПослеПеремотки * 1000`.
  - Для остальных площадок: определяет город доставки по регистру `Лико_ЭтапыЗаказа`, затем получает `КоличествоЭтикетокВРолике` из строки заказа по этому городу.

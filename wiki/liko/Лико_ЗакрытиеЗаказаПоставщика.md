# Лико_ЗакрытиеЗаказаПоставщика

> Общая команда «Закрытие заказа поставщика» — закрывает выбранные заказы поставщикам с подтверждением.

## Что делает

При вызове показывает диалог подтверждения («Закрыть заказ?» / «Закрыть заказы?»). После подтверждения для каждого заказа вызывает `Лико_Склады.ЗакрытьЗаказНаСервере()`.

После закрытия обновляет источник:
- Если источник — форма списка: обновляет список (`Обновить()`)
- Если источник — форма документа: пересчитывает состояние через `Документы.ЗаказПоставщику.РассчитатьСостояние()`

## Ключевые процедуры

- `ОбработкаКоманды()` — формирует текст вопроса (ед.ч/мн.ч), показывает диалог
- `ЗакрытьЗаказЗавершение()` (экспорт, клиент) — обработчик результата диалога, для каждого заказа вызывает `ЗакрытьЗаказНаСервере()`, затем обновляет источник
- `ЗакрытьЗаказНаСервере()` — делегирует в `Лико_Склады.ЗакрытьЗаказНаСервере()`
- `ОбновитьСостояниеСервер()` — вызывает `Документы.ЗаказПоставщику.РассчитатьСостояние()`

# ЭтапыОплатыСервер

> Переопределение заполнения этапов оплаты документа по шаблону с Лико-специфичной логикой расчёта даты платежа.

## Что делает
Модуль заменяет типовую процедуру `ЗаполнитьЭтапыОплатыДокументаПоШаблону` через аннотацию `&Вместо`. Добавляет кастомную логику: если в соглашении с клиентом заполнен реквизит `Лико_ФормулаРасчетаДатыПлатежа`, то дата платежа для этапа со сдвигом вычисляется через `Выполнить()` — динамическое исполнение BSL-строки из соглашения. Это позволяет настраивать сложные формулы расчёта дат платежа без изменения кода.

## Ключевые процедуры
- `Лико_ЗаполнитьЭтапыОплатыДокументаПоШаблону()` — расширенная версия типового заполнения этапов:
  - Поддержка реквизита `Лико_ФормулаРасчетаДатыПлатежа` в соглашениях
  - Динамический расчёт даты через `ВЫПОЛНИТЬ("ЭтапГрафикаОплаты.ДатаПлатежа = " + Формула)`
  - Доработка Яцун С.В. от 12.11.2025

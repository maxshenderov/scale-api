# Лико_УстановкаСрокаГодностиМатериаловПрисоединенныеФайлы

> Присоединённые файлы к документу `Лико_УстановкаСрокаГодностиМатериалов`. Стандартный шаблон подсистемы «ПрисоединенныеФайлы», адаптированный под нужды Лико.

## Что хранит

Файлы, прикреплённые к документу установки срока годности материалов: сертификаты, сканы, фото. Поддерживает версионирование, шифрование, ЭП.

**Реквизиты:**
- `ВладелецФайла` — ссылка на документ `Лико_УстановкаСрокаГодностиМатериалов`
- `ФайлХранилище` — бинарные данные файла
- `ТекстХранилище` — извлечённый текст
- `СтатусИзвлеченияТекста` — НеИзвлечен / Извлечен / ИзвлечьНеУдалось
- `Лико_ТипФайла` — BRC / BRCБирка
- `Лико_Тип` — ссылка на справочник `Лико_ТипыФайлов`
- `ПутьКФайлу`, `Расширение`, `Размер`, `Том`, `ТипХраненияФайла`, `ХранитьВерсии` — стандартные файловые реквизиты
- `Зашифрован`, `ПодписанЭП` — флаги безопасности
- `Автор`, `Изменил`, `Редактирует` — аудит

## Ключевые процедуры

- `РеквизитыРедактируемыеВГрупповойОбработке()` — делегирует в `РаботаСФайлами`, возвращает массив редактируемых реквизитов.
- `ПриЗаполненииОграниченияДоступа()` — RLS: чтение и изменение разрешены только если `ЧтениеОбъектаРазрешено(ВладелецФайла)` / `ИзменениеОбъектаРазрешено(ВладелецФайла)`.

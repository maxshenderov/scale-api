# mcp_ОбщегоНазначения

> MCP-модуль: утилиты — парсинг JSON из контекста LLM, разбор URL, нормализация ключей, сериализация в JSON.

## Что делает

Общий вспомогательный модуль MCP-расширения. Предоставляет функции для работы с JSON
(включая «грязный» JSON из вывода LLM), разбора URL и нормализации ключей структур.

Особенность: `JSONВСтруктуру()` умеет извлекать JSON из текста, который может содержать
лишние символы до/после JSON-блока (важно для парсинга ответов LLM, которые часто
добавляют markdown-разметку или пояснения вокруг JSON).

## Ключевые процедуры

- `JSONВСтруктуру(СтрокаJSON)` — извлекает JSON из строки (по первому `{` и последнему `}`), парсит в структуру. Если не удается как структуру — читает как соответствие и рекурсивно нормализует ключи. Позволяет парсить JSON даже с нестандартными ключами.
- `СтруктураВJSON(Объект)` — обратная операция: сериализует структуру/массив в строку JSON.
- `РазобратьURL(URL)` — разбирает URL на составляющие: `Схема`, `Хост`, `Порт`, `Путь`. Поддерживает `http` и `https`, определяет порт по умолчанию (80/443).
- `НормализоватьКлюч(Ключ)` — приводит ключ к допустимому для структуры 1С виду: первый символ — буква или `_`, остальные — буквы/цифры/`_`, недопустимые символы заменяются на `_`. Поддерживает латиницу и кириллицу.
- `СоответствиеВСтруктуруСНормализациейКлючей(Значение)` — рекурсивно преобразует `Соответствие` (и вложенные) в `Структуру` с нормализованными ключами.

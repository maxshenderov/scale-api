## Контекст проекта

### Что такое OKIL
- 1С ERP для типографии **Лико** — печать этикеток (флексо, офсет, цифра, глубокая, термоусадка)
- Центральная сущность: `ЗаказКлиента` — все производственные процессы вокруг него
- Все кастомные объекты имеют префикс `Лико_` — главный маркер доработок
- Формат хранения: EDT (папки + XML + BSL файлы)

### Структура проекта
```
D:\project\OKIL\
├── 1s\ERP\Conf\        — 1С EDT исходники (~12 ГБ)
├── 1s\ERP\obrab\       — обработки и расширения
│   ├── AIАссистент\    — AI ассистент в 1С
│   ├── ZagSklad\       — загрузка склада
│   └── ТестLLM\        — тестирование LLM
├── services\           — Python FastAPI микросервисы
│   ├── parser\         — парсинг PDF/JPG (PyMuPDF, EasyOCR) порт 8002
│   ├── docling\        — структурный парсинг PDF (IBM Docling) порт 8001
│   ├── hybrid_search\  — поиск в Qdrant (BM25 + Dense) порт 8002
│   ├── rag_llm\        — RAG pipeline → LLM → параметры заказа порт 8003
│   └── batch_indexer\  — индексация заказов из 1С в Qdrant
├── mcp\qdrant-code-search\ — MCP сервер для поиска по коду
├── qdrant_storage\     — векторная БД (port 6333 код, port 6334 заказы)
├── wiki\               — эта вики (Claude пишет, ты читаешь в Obsidian)
├── output\             — готовый BSL-код от Claude
├── MD\                 — документация и чаты
├── plans\              — планы разработки
└── ТЗ\                 — техническое задание
```

### AI pipeline
```
1С (ЗаказКлиента + PDF) → Parser → Docling → Hybrid Search → RAG LLM
                                                    ↕
                                              Qdrant :6334
                                           (orders_phase1)
```

### Общие модули (Лико_-префикс)

- [[Лико_ДополнительноКлиентСервер]] — общий клиент-серверный код: стандартное сообщение пользователю и проверка ролей

- [[Лико_Планирование]] — логика планирования и генерации номеров заказов по правилам Лико
- [[Лико_ТиражМетраж]] — расчёт тиража и метража, производственные параметры печатных заказов
- [[Лико_АсинхронныеПроцедуры]] — асинхронное выполнение процедур через фоновые задания: СИМ-склад и связанные операции

- [[Лико_СкладыВызовСервера]] — серверные вызовы для складов: получение нарезки/упаковки, запрос типовых документов
- [[Лико_СкладыКлиент]] — клиентские складские операции: заполнение упаковки по характеристике, отчёт по остаткам
- [[Лико_СерверВзаимодействияКлиент]] — клиентский модуль системы взаимодействия: подключение/отключение мобильных устройств
- [[Лико_СерверВзаимодействияСервер]] — модуль интеграции с Системой взаимодействия 1С: обсуждения, QR-коды рабочих мест
- [[Лико_HTTP_Сервер]] — серверный модуль HTTP-утилит: GET/POST, сериализация JSON, JWT-токены, обмен с другими базами 1С
- [[Лико_Диадок]] — модуль интеграции с Диадок (EDI): дополнение наименований номенклатуры, заполнение данных реализаций
- [[Лико_QdrantИндексация]] — модуль формирования данных для индексации заказов в Qdrant, часть RAG-пайплайна
- [[Лико_ОпределениеТипаПродукции]] — определение типа продукции по наименованию, функция классификации для RAG-индексации

### Общие модули (внешние подсистемы)
- [[DFMКлиент]] — клиентский модуль DFM (Design For Manufacturing): управление номенклатурой и версиями продуктов
- [[DFMСервер]] — серверный модуль DFM: создание команд формы, проверка технологии, создание номенклатуры
- [[SDK_Telegram]] — клиент Telegram Bot API: получение обновлений, отправка сообщений, документов и фото
- [[WebSocketКлиент]] — клиентский обработчик WebSocket-сообщений: приём обновлений форм и данных сканирования
- [[WebSocketСервер]] — серверный модуль подсистемы WebSocket: инициализация соединений, токены, HTTP-коммуникация

### Общие модули MCP (сервер внутри 1С)
- [[mcp_ОбщегоНазначения]] — MCP-модуль утилит: парсинг JSON из контекста LLM, разбор URL, нормализация ключей, сериализация в JSON
- [[mcp_Метаданные]] — MCP-модуль: создание таблиц описания объектов и схем параметров, сбор инструментов/ресурсов/промптов
- [[mcp_Выполнение]] — MCP-модуль движка выполнения: вызывает инструменты, читает ресурсы, получает промпты из обработок-контейнеров

- [[mcp_Содержимое]] — MCP-модуль: фабрика MCP-структур (text, image, blob, prompt message)

# 📋 РАСШИФРОВКА СТРУКТУРЫ ОТВЕТА ОТ LLM API

## 🎯 Обзор

Данный документ описывает полную структуру JSON-ответа, который возвращает API LLM (в нашем случае - `aichat-okil-sato.kartochka.tech/api/v1/chat/completions`).

На изображении показан **парсированный JSON** в табличном формате с тремя колонками:
- **Свойство** — ключ/путь в структуре
- **Значение** — пример значения
- **Тип** — тип данных (Строка, Число, Структура и т.д.)

---

## 📊 ПОЛНАЯ СТРУКТУРА ОТВЕТА

### 1. **ДанныеОтвета** (корневой уровень)
**Тип:** `Структура`

Это корневой объект, содержащий весь ответ от API. Основные свойства:

```
{
  "choices": [],           // Массив вариантов ответа
  "created": 1777980579,   // Unix timestamp создания ответа
  "id": "gen-...",         // Уникальный ID ответа
  "model": "anthropic/...", // ID использованной модели
  "object": "chat.completion", // Тип объекта (всегда "chat.completion")
  "provider": "Amazon Bedrock", // Провайдер (OpenAI, Anthropic и т.д.)
  "usage": {}              // Статистика использования токенов
}
```

---

### 2. **CHOICES** — Варианты ответа
**Тип:** `Массив` структур

Массив возможных ответов модели. Обычно содержит 1 элемент (индекс 0).

#### **choices[0]**
```
{
  "finish_reason": "stop",     // Причина завершения ("stop", "length" и т.д.)
  "index": 0,                  // Индекс варианта в массиве
  "message": {
    "role": "assistant",       // Роль сообщения ("user", "assistant", "system")
    "content": "Текст ответа..." // ОСНОВНОЙ ОТВЕТ МОДЕЛИ
  },
  "logprobs": null             // Логарифм вероятностей (если включено)
}
```

**Ключевой элемент:** `choices[0].message.content` — это основной текст ответа от LLM!

---

### 3. **USAGE** — Статистика токенов
**Тип:** `Структура`

Информация о расходовании токенов в API:

```
{
  "completion_tokens": 13630,      // Токены в ответе модели
  "completion_tokens_details": {
    "audio_tokens": 0,             // Аудио токены
    "cache_write_tokens": 0,       // Токены кэша (запись)
    "cached_tokens": 0,            // Кэшированные токены
    "reasoning_tokens": 0          // Токены рассуждения (для моделей с reasoning)
  },
  "prompt_tokens": 3207,           // Токены в запросе
  "prompt_tokens_details": {},     // Дополнительные детали запроса
  "total_tokens": 16837            // ИТОГО токенов (prompt + completion)
}
```

**Значение для биллинга:** `total_tokens` определяет стоимость запроса.

## 🔍 ДЕТАЛЬНОЕ ОПИСАНИЕ КАЖДОГО ПОЛЯ

| Поле | Тип | Описание | Пример |
|------|-----|---------|--------|
| **id** | Строка | Уникальный идентификатор ответа | `"gen-1777980579-xXXXX"` |
| **created** | Число | Unix timestamp момента создания ответа | `1777980579` |
| **model** | Строка | Идентификатор использованной модели | `"anthropic/claude-haiku-4.5"` |
| **object** | Строка | Тип объекта ответа (всегда `"chat.completion"`) | `"chat.completion"` |
| **provider** | Строка | Провайдер LLM | `"Amazon Bedrock"`, `"OpenAI"` |
| **choices[0].index** | Число | Индекс варианта (обычно 0) | `0` |
| **choices[0].finish_reason** | Строка | Причина завершения генерации | `"stop"` - нормально завершено |
| **choices[0].message.role** | Строка | Роль отправителя сообщения | `"assistant"` - ответ модели |
| **choices[0].message.content** | Строка | **ОСНОВНОЙ ТЕКСТ ОТВЕТА** | HTML, Markdown или plain text |
| **choices[0].logprobs** | Null/Структура | Логарифм вероятностей токенов | `null` или структура данных |
| **usage.prompt_tokens** | Число | Количество токенов в вашем запросе | `3207` |
| **usage.completion_tokens** | Число | Количество токенов в ответе | `13630` |
| **usage.total_tokens** | Число | **Сумма всех токенов** (для биллинга) | `16837` |

## 🎨 ФОРМАТ ОТВЕТА В content

Поле `choices[0].message.content` может содержать:

### 1️⃣ **HTML** (рекомендуется для UI)
```html
<html>
  <head><meta charset='utf-8'></head>
  <body>
    <h2>Технологический анализ</h2>
    <p>Сложность: <strong>7/10</strong></p>
    <table>...</table>
  </body>
</html>
```

### 2️⃣ **Markdown** (требует преобразования)
```markdown
## Технологический анализ
1. **Сложность:** 7/10
2. **Технологии:** Флексо, Офсет
- Риск 1
- Риск 2
```

### 3️⃣ **Plain Text** (простой текст)
```
Сложность: 7/10
Технологии: Флексо, Офсет
Риски: 
- Риск 1
- Риск 2
```

**В коде Module.bsl** (строки 507-522) есть логика для обработки всех трёх форматов!


```bsl
Если ДанныеОтвета["choices"].Количество() = 0 Тогда
    Лико_ДополнительноКлиентСервер.СообщитьДляКлиента(
        "Ошибка: LLM не вернул ответ");
```

## 📌 ИТОГОВАЯ СХЕМА ПОТОКА

```
1️⃣ Пользователь нажимает кнопку "AI Анализ" 
   ↓
2️⃣ Функция АнализЗаказа() вызывает ОтправитьЗапросАнализаЗаказа()
   ↓
3️⃣ ОтправитьЗапросАнализаЗаказа():
   - Получает JSON заказа: ПолучитьДанныеЗаказаДляАИ()
   - Формирует системный промпт: ПолучитьСистемныйПромпт()
   - ОТПРАВЛЯЕТ ЗАПРОС: ОтправитьЗапросКLLM()
   ↓
4️⃣ ОтправитьЗапросКLLM() отправляет HTTP POST:
   POST aichat-okil-sato.kartochka.tech/api/v1/chat/completions
   ↓
5️⃣ API ВОЗВРАЩАЕТ JSON (со структурой как в этом документе)
   ↓
6️⃣ ОтправитьЗапросКLLM() парсит JSON:
   ДанныеОтвета = ПрочитатьJSON()
   ТекстОтвета = ДанныеОтвета["choices"][0]["message"]["content"]
   ↓
7️⃣ ОбработатьРезультатLLM():
   - Проверяет формат (HTML/Markdown/Plain text)
   - Преобразует в HTML если нужно
   ↓
8️⃣ Результат отображается в htmlЗаказ на форме
```

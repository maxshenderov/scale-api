# Правила кодирования для проекта Лико

## Ключевые правила

- Все кастомные объекты используют префикс `Лико_`. Стандартные объекты 1С расширены атрибутами/табличными частями с этим префиксом.
- Теги авторства обязательны: `//+Лико m.shenderov ДД.ММ.ГГГГ` в начале процедуры/функции.
- Центральный реестр констант: `Справочники.Лико_ПредопределенныеЗначения` — используйте его вместо хардкода ссылок.
- Динамические атрибуты: `УправлениеСвойствами.ЗначениеСвойства(Объект, СсылкаНаСвойство)` — не ищите доп. реквизиты напрямую.
- Клиент-серверные сообщения: `Лико_ДополнительноКлиентСервер.СообщитьДляКлиента()` — не используйте стандартный `Сообщить()`.
- Параметры сеанса: `ПараметрыСеанса.ТекущийПользователь`, `ПараметрыСеанса.Лико_РабочееМесто`.

## Паттерн создания документа

1. Проверить существование (по ссылке или ключевым реквизитам)
2. Если существует — получить объект через `ПолучитьОбъект()`, иначе — `СоздатьДокумент()`
3. Заполнить реквизиты шапки и табличные части
4. Записать/провести в транзакции с обработкой ошибок

## Паттерн запроса

```
Запрос = Новый Запрос;
Запрос.Текст = "ВЫБРАТЬ ... ИЗ ... ГДЕ ...";
Запрос.УстановитьПараметр("Имя", Значение);
Результат = Запрос.Выполнить();
Выборка = Результат.Выбрать();
Пока Выборка.Следующий() Цикл ... КонецЦикла;
```

## Обработка ошибок

```
Попытка
    // операция
Исключение
    Лико_ДополнительноКлиентСервер.СообщитьДляКлиента("Описание: " + ОписаниеОшибки());
    ОтменитьТранзакцию();
КонецПопытки;
```

## Ключевые модули для работы

- `Лико_ОбщегоНазначенияСервер` — серверные утилиты (~10900 строк)
- `Лико_ПрограммноеСозданиеДокументовСправочников` — программное создание документов
- `Лико_ПроведениеДокументов` — логика проведения
- `Лико_ТиражМетраж` — расчёт тиража и метража
- `Лико_Дополнительно` — доп. утилиты (получение доп. реквизитов, поиск организаций)

## Центральная сущность

ЗаказКлиента — основной документ. Форма: `Лико_ФормаДокумента`. Табличные части: Товары, Цвета, ВидыРабот, Производство, Секции.

# Контекст документации проекта Лико

## Структура проекта

- `1c/ERP/Конф/` — XML-дамп конфигурации 1С:Предприятие ERP (формат EDT). Это НЕ исходный код в привычном понимании — это экстракт метаданных конфигурации.
- `MD/` — документация и чаты с проектированием AI-интеграции.

## Важные уточнения

- Конфигурация основана на `УправлениеПредприятием` (бинарник в `Ext/ParentConfigurations/`). Стандартные объекты 1С расширены кастомными атрибутами с префиксом `Лико_`.
- Документ `ЗаказКлиента` — центральная сущность, но это СТАНДАРТНЫЙ объект 1С, расширенный кастомными табличными частями и реквизитами.
- Справочник `Лико_ОригиналМакеты` хранит ссылки на файлы макетов (PDF/JPG), привязанные к заказам.
- Справочник `Лико_ВерсииНоменклатуры` содержит версии номенклатуры с параметрами технологии печати (Флексо, Офсет, Цифра и т.д.).
- Справочник `Лико_ПредопределенныеЗначения` — центральный реестр конфигурационных констант (не путайте с предопределёнными элементами других справочников).

## Планируемая AI-интеграция

Полная спецификация в `MD/RouterAI Chat 4 мая 2026.md`. Ключевые этапы:
0. Кнопка AI-ассистента в форме ЗаказКлиента
1. PDF → JSON → программное создание заказа в 1С
2. Мультитехнологический расчёт стоимости
3. Поиск тендеров + расчёт + вероятность выигрыша

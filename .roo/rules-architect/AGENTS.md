# Архитектурные ограничения проекта Лико

## Структура конфигурации

- Базовая конфигурация: `УправлениеПредприятием` (бинарник в `Ext/ParentConfigurations/`). ВСЕ изменения — через расширение стандартных объектов с префиксом `Лико_`.
- XML-файлы — это EDT-дамп конфигурации. Редактирование и компиляция происходят в 1С:Конфигураторе.
- Нет внешних зависимостей (npm, pip и т.д.) — всё внутри платформы 1С.

## Ключевые архитектурные решения

- `Лико_ПредопределенныеЗначения` — центральный реестр констант. Все «магические ссылки» хранятся здесь, а не хардкодятся в модулях.
- Динамические атрибуты через `УправлениеСвойствами` — основной механизм расширения объектов без изменения их структуры.
- Параметры сеанса (`ПараметрыСеанса.Лико_РабочееМесто`, `ПараметрыСеанса.ТекущийПользователь`) — контекст текущего пользователя/рабочего места.
- Программное создание документов: [`Лико_ПрограммноеСозданиеДокументовСправочников`](1c/ERP/Конф/CommonModules/Лико_ПрограммноеСозданиеДокументовСправочников.xml) — паттерн: проверка существования → создание/получение → заполнение → запись/проведение.

## Точки интеграции

- HTTP-сервисы: Биллинг, ПередачаДанных, СерверЛояльности, ЭДО, exchange_dsl
- Web-сервисы: Exchange (синхронизация с другими базами), Liko_ERP_Rest (REST API), WMS (мобильный клиент), RemoteControl
- Планируемая AI-интеграция: MCP-коннектор → Python FastAPI → Qdrant + PostgreSQL → LLM

## Ключевые бизнес-сущности

- ЗаказКлиента — центральная сущность. Связан с ~20 кастомными регистрами накопления и ~10 регистрами сведений.
- Технологии печати: Флексо, Офсет, Цифра, Глубокая, GallusInkjet + комбинации.
- Типы этикеток: ЭТ, КЭ, Кльр, Комплект, Пакет, ФЛ, ПП.
- Секции производства: Печать, Флексо, Глубокая, ЦифровойМодуль — каждая со своими параметрами.

## Скрытые зависимости

- Справочник `Лико_ПредопределенныеЗначения` используется повсеместно — изменение его элементов может сломать многие процессы.
- Динамические атрибуты через `УправлениеСвойствами` не видны в структуре метаданных — их наличие определяется только при чтении кода.
- Регистры `Лико_ЗатратыПоЗаказу`, `Лико_Отгрузки2`, `Лико_СебестоимостьЗаказов` связаны с ЗаказКлиента через измерение `ЗаказКлиента` — изменение ключевых реквизитов заказа затрагивает все эти регистры.

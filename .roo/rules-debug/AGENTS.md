# Правила отладки для проекта Лико

## Ключевые особенности

- Это конфигурация 1С — отладка происходит в 1С:Конфигураторе или 1С:Предприятии, не через CLI.
- XML-файлы в репозитории — это дамп конфигурации для контроля версий. Изменения в XML применяются через загрузку в 1С:Конфигуратор.
- Логирование: используйте `Лико_ДополнительноКлиентСервер.СообщитьДляКлиента()` для вывода отладочной информации.
- Транзакции: все критические операции должны быть обёрнуты в `НачатьТранзакцию()`...`ЗафиксироватьТранзакцию()` с `ОтменитьТранзакцию()` в блоке `Исключение`.

## Типичные проблемы

- Ошибки в XML-дампе могут возникнуть при ручном редактировании — проверяйте валидность XML перед коммитом.
- Предопределённые значения (`Справочники.Лико_ПредопределенныеЗначения`) могут изменяться между версиями — не хардкодьте ссылки.
- Параметры сеанса (`ПараметрыСеанса.Лико_РабочееМесто`) доступны только в серверном контексте.
- Динамические атрибуты через `УправлениеСвойствами` могут вернуть `Неопределено`, если свойство не заполнено.

## Ключевые регистры для диагностики

- `Лико_ЭтапыЗаказа` — текущее состояние заказа
- `Лико_ЗатратыПоЗаказу` — затраты по заказу
- `Лико_Отгрузки2` — история отгрузок
- `Лико_СебестоимостьЗаказов` — себестоимость

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Architecture:** В `РендерЗагрузкиСтеллажаНаСервере` при определении класса ячейки инкрементируем счётчики (общий и поэтажные). Процент вычисляется после цикла, вставляется в заголовки через плейсхолдеры. Функция `ПолучитьПроцентЗагрузкиСтеллажа` исправляется на `КоличествоАдресов=0→3`.

**Tech Stack:** BSL (1С:Предприятие), один файл.

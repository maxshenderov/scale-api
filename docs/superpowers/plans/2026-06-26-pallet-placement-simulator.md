# Симулятор размещения паллет — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Реализовать in-memory симуляцию размещения паллет в обработке ЗагрузкаСклада — полная реплика логики `ПодобратьЯчейку` без обращений к СУБД.

**Architecture:** Один SQL-запрос загружает все секции + occupants в ТЗ `СекцииСОстатки`. Функция `ПодобратьЯчейкуВПамяти` фильтрует и сортирует в BSL (реплика WHERE + ORDER BY из SQL). Цикл размещения дописывает результаты в ТЗ после каждого размещения. HTML рендерится из ТЗ при включённом чекбоксе "Виртуальный склад".

**Tech Stack:** 1C:Enterprise BSL, XML EDT format, SQL queries within BSL

**Spec:** `docs/superpowers/specs/2026-06-26-pallet-placement-simulator-design.md`

## Global Constraints

- Формат файлов: 1C EDT XML (Module.bsl, Form.xml)
- Все новые процедуры — в `#Область СимуляторРазмещения`
- Тег авторства: `//+Лико m.shenderov <дата>`
- Подбор ячейки — полная реплика WHERE + ORDER BY из `ПодобратьЯчейку` (ManagerModule.bsl:505)
- SQL-запрос загрузки — реплика CTE из `ПодобратьЯчейку` без фильтров по размерам паллета
- Виртуальные паллеты: коды "В001", "В002"... (префикс "В"), оранжевый цвет в HTML
- Тестирование: ручное (1C:Enterprise не поддерживает автоматические тесты BSL)

### Task 1: Добавить колонку `Адрес` в ТЧ `Паллеты`

- Modify: `1s/ERP/obrab/ZagSklad/ЗагрузкаСклада/Forms/Форма/Ext/Form.xml`

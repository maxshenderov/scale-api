# РазмещениеПаллетНаСкладе — План реализации

> **Для исполнителя:** Реализовать задачу за задачей. Шаги используют checkbox (`- [ ]`) для отслеживания.

**Цель:** Реализовать 6 процедур обработки «РазмещениеПаллетНаСкладе» и добавить недостающий реквизит формы.

**Архитектура:** Одна внешняя обработка (ExternalDataProcessor). Вся бизнес-логика в модуле формы. Клиентские процедуры делегируют работу серверным через вызовы `&НаСервере`. Используются существующие API менеджеров справочников (НайтиСоздатьТипоразмер, НовыйПаллет, ПодобратьЯчейкуПоПаллету).

**Файлы (2 файла):**
- Modify: `Forms/Форма/Ext/Form.xml` — атрибут НачалоСтрокиExcel + поле ввода
- Modify: `Forms/Форма/Ext/Form/Module.bsl` — 6 процедур (2 клиентских + 4 серверных)

---

## Глобальные ограничения

- Обработка ошибок: Попытка…Исключение, при ошибке — пропуск строки/документа, продолжение
- Итоговое сообщение: сколько создано, сколько пропущено
- Чтение Excel: `ТабличныйДокумент.Прочитать()`, первая строка — заголовок (НачалоСтрокиExcel=2)
- После СозатьТипоразмеры: схлопывание одинаковых Типоразмеров с суммированием Количества
- ТЧ «Товары» в Формировании: только Серия = ОбъектНоменклатурыБазовый
- Документы создаются через `Документы.Лико_ФормированиеПаллета2_0.СоздатьДокумент()`

    // Шаг 1: Нормализация и создание типоразмеров
    Для Каждого СтрокаПаллеты Из Паллеты Цикл

        // Нормализация ГлубинаПлан/ШиринаПлан → Глубина/Ширина
        Макс = Макс(СтрокаПаллеты.ГлубинаПлан, СтрокаПаллеты.ШиринаПлан);
        Мин = Мин(СтрокаПаллеты.ГлубинаПлан, СтрокаПаллеты.ШиринаПлан);

        Если Макс <= 1200 Тогда
            СтрокаПаллеты.Глубина = Макс;
            СтрокаПаллеты.Ширина = Мин;
        Иначе
            СтрокаПаллеты.Глубина = СтрокаПаллеты.ГлубинаПлан;
            СтрокаПаллеты.Ширина = СтрокаПаллеты.ШиринаПлан;
        КонецЕсли;

        // Создание/поиск типоразмера
        Попытка
            СтрокаПаллеты.Типоразмер = Справочники.Лико_ТипоразмерыПаллет.НайтиСоздатьТипоразмер(
                СтрокаПаллеты.Высота,
                СтрокаПаллеты.Ширина,
                СтрокаПаллеты.Глубина,
                СтрокаПаллеты.Вес);
        Исключение
            Сообщить("Ошибка создания типоразмера: " + ОписаниеОшибки());
        КонецПопытки;

    КонецЦикла;

    // Шаг 2: Схлопывание строк с одинаковым Типоразмером
    // Строим соответствие: Типоразмер → сумма Количества
    Соответствие = Новый Соответствие;
    Для Каждого СтрокаПаллеты Из Паллеты Цикл
        Если Не ЗначениеЗаполнено(СтрокаПаллеты.Типоразмер) Тогда
            Продолжить;
        КонецЕсли;
        ТекКоличество = Соответствие.Получить(СтрокаПаллеты.Типоразмер);
        Если ТекКоличество = Неопределено Тогда
            ТекКоличество = 0;
        КонецЕсли;
        Соответствие.Вставить(СтрокаПаллеты.Типоразмер, ТекКоличество + СтрокаПаллеты.Количество);
    КонецЦикла;

    // Пересоздаём ТЧ с одной строкой на Типоразмер
    // Находим эталонную строку для каждого Типоразмера
    Эталоны = Новый Соответствие; // Типоразмер → строка для копирования
    Для Каждого СтрокаПаллеты Из Паллеты Цикл
        Если ЗначениеЗаполнено(СтрокаПаллеты.Типоразмер)
           И Эталоны.Получить(СтрокаПаллеты.Типоразмер) = Неопределено Тогда
            Эталоны.Вставить(СтрокаПаллеты.Типоразмер, СтрокаПаллеты);
        КонецЕсли;
    КонецЦикла;

    Паллеты.Очистить();
    Для Каждого КлючЗначение Из Соответствие Цикл
        Типоразмер = КлючЗначение.Ключ;
        СуммаКоличество = КлючЗначение.Значение;
        Эталон = Эталоны.Получить(Типоразмер);

        НоваяСтрока = Паллеты.Добавить();
        НоваяСтрока.Высота       = Эталон.Высота;
        НоваяСтрока.Ширина       = Эталон.Ширина;
        НоваяСтрока.Глубина      = Эталон.Глубина;
        НоваяСтрока.Вес          = Эталон.Вес;
        НоваяСтрока.ШиринаПлан   = Эталон.ШиринаПлан;
        НоваяСтрока.ГлубинаПлан  = Эталон.ГлубинаПлан;
        НоваяСтрока.Типоразмер   = Типоразмер;
        НоваяСтрока.Количество   = СуммаКоличество;
    КонецЦикла;

    Сообщить("Типоразмеров создано: " + Паллеты.Количество());

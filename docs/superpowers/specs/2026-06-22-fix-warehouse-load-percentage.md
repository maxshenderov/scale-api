# Исправление процента загрузки в визуализации ЗагрузкаСклада

> Считать процент занятости ячеек как `(всего − зелёных) / всего × 100`, консистентно с HTML-визуализацией.

## Контекст

Обработка `ЗагрузкаСклада` визуализирует поперечное сечение стеллажа: секции, ячейки, паллеты. В HTML ячейки раскрашиваются:

| Состояние | CSS-класс | Цвет | Смысл |
|-----------|-----------|------|-------|
| Свободна | `cell cell-free` | зелёный | Можно разместить |
| Занята паллетом | `cell` | белый | Паллет стоит |
| Перекрыта соседним паллетом | `cell` | белый | Физически наезжает — недоступна |
| Запрет размещения | `cell` (в `section-restricted`) | светло-красный | Размещение запрещено |

**Проблема**: текущий `ПолучитьПроцентЗагрузкиСтеллажа` считает занятость по данным регистра (уникальные адреса с `Количество > 0`) и сумме `КоличествоАдресов` — без учёта дефолта `0→3`, без перекрытий, без запретов. Процент не совпадает с визуализацией. Поэтажного процента нет вообще.

## Решение: подход 3 — гибридный подсчёт при рендере

### 1. Счётчики в `РендерЗагрузкиСтеллажаНаСервере`

В момент определения класса ячейки (зелёная / нет) инкрементируем счётчики:

- **Общие**: `ВсегоЯчеекВсего`, `ЗеленыхЯчеекВсего`
- **Поэтажные**: `Соответствие(НомерЭтажа → Структура(Всего, Зеленых))`

Инкремент — сразу после `Если ДанныеПаллетаВЯчейке <> Неопределено Тогда ... ИначеЕсли ЯчейкаПерекрыта ... Иначе ... КонецЕсли` (строка 933).

### 2. Процент занятости в заголовке стеллажа

Вместо `ПроцентЗагрузки` из параметра — вычисляем из счётчиков:

```bsl
ПроцентЗанятости = ?(ВсегоЯчеекВсего > 0,
    Окр((ВсегоЯчеекВсего - ЗеленыхЯчеекВсего) / ВсегоЯчеекВсего * 100, 0), 0);
```

Строка 748: `"Загрузка: " + Формат(ПроцентЗанятости, ...) + "%"`.

### 3. Процент занятости в заголовке каждого этажа

В строке 794 (метка этажа `ЭN`) — добавить процент:

```bsl
ПроцентЭтажа = ?(Счетчик.Всего > 0,
    Окр((Счетчик.Всего - Счетчик.Зеленых) / Счетчик.Всего * 100, 0), 0);
// → "Э3 67%"
```

Цвет процента этажа — через существующую `ЦветЗагрузкиПроцент()`.

### 4. Исправление `ПолучитьПроцентЗагрузкиСтеллажа`

Для консистентности кнопок стеллажей с визуализацией — исправить только `КоличествоАдресов = 0 → 3`:

```bsl
// В запросе: вместо прямой суммы КоличествоАдресов
// ВЫБОР КОГДА КоличествоАдресов = 0 ТОГДА 3 ИНАЧЕ КоличествоАдресов КОНЕЦ
```

Перекрытие в кнопках не учитываем — это быстрый индикатор, полная точность в HTML.

### 5. CSS

Новый класс для процента этажа:

```css
.floor-pct { font-size: 9px; font-weight: bold; }
```

## Верификация

1. Открыть обработку «ЗагрузкаСклада» в 1С
2. Выбрать склад → кнопки стеллажей показывают проценты
3. Нажать на стеллаж → проверить:
   - **Общий процент** под названием стеллажа — цветной, соответствует доле незелёных ячеек
   - **Поэтажный процент** рядом с `Э1`, `Э2`, ... — цветной
4. Визуальная сверка: этаж с 3 паллетами из 6 ячеек → `50%`
5. `ЗапретРазмещения`: ячейки не зелёные → в занятости
6. Перекрытые ячейки (наезжает соседний паллет) — не зелёные → в занятости
7. Проценты на кнопках стеллажей и в HTML-заголовке совпадают (с точностью до перекрытий)

# WMS Explain Access Time — LLM Tool

> LLM-инструмент `explain_access_time`: пошаговый расчёт времени доступа для ячеек и секций склада.

## Контекст

Функция `ЗаполнитьВремяДоступаКСекциям` ([ManagerModule.bsl:902](../../1s/ERP/Conf/Catalogs/Лико_СкладскиеСекции/Ext/ManagerModule.bsl#L902)) заполняет реквизит `ВремяДоступа` для стеллажей и секций склада. Формула:

```
ВремяДоступаСтеллажа = Склад.Лико_ВремяСтеллажа * НомерСтроки
ВремяДоступа = ВремяДоступаСтеллажа + (Место * Склад.Лико_ВремяМеста) + (Этаж * Склад.Лико_ВремяЭтажа)
```

Где `НомерСтроки` — порядковый номер стеллажа в ТЧ `Склад.Лико_Стеллажи`.

LLM-инструмент делает этот расчёт прозрачным: пользователь спрашивает "как посчитано время доступа для Р1М2Э1?" — и получает пошаговую расшифровку.

Обработка `ЗагрузкаСклада` уже имеет:
- AI-чат с function calling через `СпроситьLLM` (цикл tool_calls)
- Инфраструктуру инструментов: `НовыйИнструмент`, `ДобавитьПараметр`, диспетчер `ВыполнитьИнструмент`, реестр `ПолучитьОпределенияИнструментов`
- 2 рабочих инструмента: `find_cell_for_pallet`, `validate_pallet_placement`
- Макет `WMS_ВремяДоступа` с MD-описанием алгоритма (уже создан, но не подключён к LLM)

## Дизайн

### Принцип: адаптер → бизнес-функция

Существующий паттерн (без изменений):
```
ИнструментВремениДоступа()           — определение для LLM (OpenAI function schema)
Адаптер_ВремяДоступа(Аргументы)     — LLM-аргументы → бизнес-функция → JSON
ВремяДоступаБизнес(МассивКодов)     — чистая логика (ничего не знает про LLM)
```

### Бизнес-функция `ВремяДоступаБизнес(МассивКодов)` (`#Область БизнесФункции`)

Для каждого элемента массива:

1. **Найти объект** — поиск по коду:
   - Сначала в `Справочники.СкладскиеЯчейки` (ячейка)
   - Если не найдено → в `Справочники.Лико_СкладскиеСекции` (секция)
   - Поддержка поиска по наименованию fallback'ом

2. **Если ячейка** → получить секцию через `Ячейка.Лико_Секция`
3. **Если секция** → использовать напрямую

4. **Определить стеллаж и склад** — из `Секция.Стеллаж.Склад`

5. **Найти НомерСтроки** — обход `Склад.Лико_Стеллажи`, поиск позиции стеллажа

6. **Взять константы**: `Лико_ВремяСтеллажа`, `Лико_ВремяМеста`, `Лико_ВремяЭтажа`

7. **Посчитать**:
   ```
   ВремяСтеллажа  = Лико_ВремяСтеллажа * НомерСтроки
   ВремяМеста     = Секция.Место * Лико_ВремяМеста
   ВремяЭтажа     = Секция.Этаж * Лико_ВремяЭтажа
   ВремяДоступа   = ВремяСтеллажа + ВремяМеста + ВремяЭтажа
   ```

8. **Вернуть** структуру с полным breakdown

### Выход (структура на каждый код)

| Поле | Тип | Описание |
|------|-----|----------|
| `code` | Строка | что искали |
| `found` | Булево | найден ли объект |
| `error` | Строка | если не найден — причина |
| `type` | Строка | "cell" или "section" |
| `cellCode` | Строка | код ячейки (если type=cell) |
| `sectionCode` | Строка | код секции |
| `rack` | Строка | наименование стеллажа |
| `rackRowNumber` | Число | `НомерСтроки` стеллажа в ТЧ склада |
| `place` | Число | `Место` секции |
| `floor` | Число | `Этаж` секции |
| `warehouseRackTime` | Число | константа `Лико_ВремяСтеллажа` |
| `warehousePlaceTime` | Число | константа `Лико_ВремяМеста` |
| `warehouseFloorTime` | Число | константа `Лико_ВремяЭтажа` |
| `rackTimeComponent` | Число | `ВремяСтеллажа * НомерСтроки` |
| `placeTimeComponent` | Число | `Место * ВремяМеста` |
| `floorTimeComponent` | Число | `Этаж * ВремяЭтажа` |
| `totalTime` | Число | итоговое ВремяДоступа |
| `formula` | Строка | "R(120×2) + M(12×5) + F(8×3) = 240+60+24 = 324" |

### Адаптер `Адаптер_ВремяДоступа(Аргументы)`

- Извлекает `codes` (массив строк) из аргументов LLM
- Вызывает `ВремяДоступаБизнес(МассивКодов)`
- Сериализует в JSON
- Если `codes` не массив → пытается распарсить как строку с одним кодом

### Инструмент `ИнструментВремениДоступа()` (`#Область LLM_Инструменты`)

```bsl
НовыйИнструмент("explain_access_time",
    "Показывает пошаговый расчёт времени доступа для одной или нескольких "
    + "складских ячеек или секций. Возвращает для каждой: формулу, "
    + "компоненты (время стеллажа, места, этажа), константы склада, "
    + "итоговое время. Используй когда пользователь спрашивает "
    + "'как посчитано время доступа' или 'почему такое время доступа'.");
ДобавитьПараметрМассив(Инструмент, "codes", "Коды ячеек (например Р1М2Э1) "
    + "и/или секций (например Р1-М(01-02-03)-Э02). Можно передать один или несколько.", "string", Истина);
```

### Регистрация

**`ПолучитьОпределенияИнструментов()`**: добавить `"explain_access_time"` → `ИнструментВремениДоступа()`.

**`ВыполнитьИнструмент()`**: добавить `"explain_access_time"` → `Адаптер_ВремяДоступа(Аргументы)`.

**`ЗадачиДляLLM()`**: в `WMS_Эксперт.Инструменты` добавить `"explain_access_time"`.

### Что не меняется

- `СпроситьLLM()` — цикл tool_calls уже работает
- `ЗаполнитьВремяДоступаКСекциям()` — не трогаем, только читаем её данные
- Физически время доступа НЕ пересчитывается — инструмент диагностический, read-only
- Паттерн «адаптер → бизнес-функция» — как у `find_cell_for_pallet` и `validate_pallet_placement`

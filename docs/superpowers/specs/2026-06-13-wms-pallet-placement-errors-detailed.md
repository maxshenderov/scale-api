# WMS Validate Pallet Placement — Детализация ошибок размещения

> Добавление параметра `ПолныйОтвет` в функции валидации размещения паллета для выдачи сообщений с числовыми значениями (габариты, вес, превышения).

## Контекст

Функция `ОшибкиРазмещенияВАдрес()` в модуле менеджера `Лико_СкладскиеСекции` выполняет 14 проверок размещения паллета в ячейку. Сейчас все сообщения — качественные («превышает максимальную ширину»), без конкретных цифр. LLM-инструмент `validate_pallet_placement` (добавленный в ЗагрузкаСклада) передаёт эти сообщения пользователю — без цифр они малоинформативны.

## Дизайн

### Принцип: параметр `ПолныйОтвет` (по умолчанию `Ложь`)

Добавляем булев параметр `ПолныйОтвет` в обе функции. По умолчанию `Ложь` — поведение не меняется, обратная совместимость сохранена. При `Истина` — сообщения содержат точные значения, единицы измерения и дельты.

### Изменяемый файл

`1s/ERP/Conf/Catalogs/Лико_СкладскиеСекции/Ext/ManagerModule.bsl`

### Сигнатуры

```bsl
// Было:
Функция ОшибкиРазмещенияВАдрес(Ячейка, Высота, Ширина, Глубина, Вес) Экспорт
Функция ОшибкиРазмещенияПаллетаВАдрес(Ячейка, Паллет, Типоразмер = Неопределено) Экспорт

// Стало:
Функция ОшибкиРазмещенияВАдрес(Ячейка, Высота, Ширина, Глубина, Вес, ПолныйОтвет = Ложь) Экспорт
Функция ОшибкиРазмещенияПаллетаВАдрес(Ячейка, Паллет, Типоразмер = Неопределено, ПолныйОтвет = Ложь) Экспорт
```

### 14 проверок — короткий и подробный формат

Единицы измерения: **мм** для линейных размеров, **кг** для веса.

| # | Проверка | Короткий (ПолныйОтвет=Ложь) | Подробный (ПолныйОтвет=Истина) |
|---|---|---|---|
| 1 | Нет адреса | `Ошибка: не указан адрес для размещения.` | Без изменений |
| 2 | Адрес занят | `Ошибка: выбранный адрес уже занят. Выберите другой адрес в секции.` | `Ошибка: выбранный адрес уже занят паллетом "П-123" (1250×1100×1400 мм, 850 кг). Выберите другой адрес в секции.` |
| 3-6 | Конфликт соседа (>1/3) | `...паллет большого размера (>1/3 ширины секции)...` | `...паллет шириной 950 мм, что > 1/3 ширины секции (2400/3 = 800 мм)...` |
| 7-8 | Новый >1/3 в центр | `...паллет слишком широк (>1/3 ширины секции)...` | `...ширина паллета 950 мм > 1/3 ширины секции (2400/3 = 800 мм)...` |
| 9-10 | Новый >1/2 в край | `...паллет слишком широк (>1/2 ширины секции)...` | `...ширина паллета 1350 мм > 1/2 ширины секции (2400/2 = 1200 мм)...` |
| 11 | Ширина > секции | `...ширина паллета превышает максимальную ширину секции...` | `...ширина паллета 1450 мм превышает макс. ширину секции 1200 мм (превышение 250 мм)...` |
| 12 | Высота > секции | `...высота паллета превышает максимальную высоту секции...` | `...высота паллета 2100 мм превышает макс. высоту секции 1800 мм (превышение 300 мм)...` |
| 13 | Глубина > секции | `...глубина паллета превышает максимальную глубину секции...` | `...глубина паллета 1300 мм превышает макс. глубину секции 1100 мм (превышение 200 мм)...` |
| 14 | Вес > лимита | `...общий вес паллетов в секции превышает максимальную грузоподъемность...` | `...общий вес 3200 кг (текущий: 2400 кг + новый: 800 кг) превышает грузоподъемность секции 3000 кг (превышение 200 кг)...` |

### Изменения в ЗагрузкаСклада

В `Адаптер_ОшибкиРазмещенияПаллета` — передать `Истина` в вызов:

```bsl
// Было:
Данные = ОшибкиРазмещенияПаллета(КодЯчейки, КодПаллета);

// Стало:
Данные = ОшибкиРазмещенияПаллета(КодЯчейки, КодПаллета, , Истина);
```

### Что не меняется

- Возвращаемый тип (`Массив` строк)
- Логика проверок
- Поведение существующих вызовов (параметр по умолчанию `Ложь`)
- `СпроситьLLM()` и цепочка LLM-инструментов в ЗагрузкаСклада

## Verification

1. Вызвать `ОшибкиРазмещенияВАдрес(Ячейка, В, Ш, Г, Вес)` без 6-го параметра — убедиться что сообщения короткие (как раньше)
2. Вызвать с `ПолныйОтвет = Истина` — убедиться что сообщения содержат конкретные цифры (мм, кг, дельты)
3. Проверить негативный сценарий: паллет шире секции — сообщение должно содержать оба значения и разницу
4. Проверить сценарий с весом: три занятых адреса + новый паллет — сообщение должно раскладывать текущий/новый/превышение
5. В ЗагрузкаСклада: выбрать WMS Эксперт, спросить про размещение — LLM должен получить детальные сообщения с цифрами

# WMS Validate Pallet Placement — LLM Tool

> Добавление инструмента `validate_pallet_placement` в обработку ЗагрузкаСклада для вызова `ОшибкиРазмещенияПаллетаВАдрес()` через LLM function calling.

## Контекст

Обработка `ЗагрузкаСклада` имеет AI-чат с поддержкой function calling (`СпроситьLLM` с циклом tool_calls). Инфраструктура инструментов уже есть (паттерн: адаптер → бизнес-функция, диспетчер `ВыполнитьИнструмент`, хелперы `НовыйИнструмент`/`ДобавитьПараметр`). Но инструменты не подключены к чат-потоку: 4-й параметр `СпроситьLLM` всегда пуст.

Задача `WMS_Эксперт` уже зарегистрирована в `ЗадачиДляLLM()`, системный промпт содержит описание алгоритма `ОшибкиРазмещенияВАдрес` из макетов. Осталось дать LLM возможность вызывать функцию.

## Дизайн

### Принцип: инструменты как свойство задачи

Вместо хардкода инструментов в `ОтправитьЗапросLLMНаСервере()`, каждая задача в `ЗадачиДляLLM()` декларирует свой набор инструментов. Поток:

```
ЗадачиДляLLM()
  └─ WMS_Эксперт.Инструменты = ["validate_pallet_placement"]

ВыполнитьЗапросКLLМ()  (&НаКлиенте)
  └─ извлекает Инструменты из задачи → передаёт на сервер

ОтправитьЗапросLLMНаСервере(..., ИменаИнструментов)
  └─ ПолучитьОпределенияИнструментов(Имена)
  └─ СпроситьLLM(..., Инструменты)
```

### Точки изменений

Все изменения в одном файле: `1s/ERP/obrab/ZagSklad/ЗагрузкаСклада/Forms/Форма/Ext/Form/Module.bsl`

#### 1. `ЗадачиДляLLM()` — добавить поле Инструменты

В структуру задачи WMS_Эксперт добавить:
```bsl
МассивИнструментов = Новый Массив;
МассивИнструментов.Добавить("validate_pallet_placement");
ПараметрыЗадачи.Вставить("Инструменты", МассивИнструментов);
```

#### 2. `ВыполнитьЗапросКLLМ()` — извлечь и передать имена

После получения `ЗадачаLLM`:
```bsl
ИменаИнструментов = Новый Массив;
Если ТипЗнч(ЗадачаLLM) = Тип("Структура") И ЗадачаLLM.Свойство("Инструменты") Тогда
    ИменаИнструментов = ЗадачаLLM.Инструменты;
КонецЕсли;
```
Передать 7-м параметром в `ОтправитьЗапросLLMНаСервере()`.

#### 3. `ОтправитьЗапросLLMНаСервере()` — новый параметр + резолвинг

Добавить параметр `ИменаИнструментов = Неопределено`. Перед вызовом `СпроситьLLM`:
```bsl
Инструменты = ПолучитьОпределенияИнструментов(ИменаИнструментов);
```

#### 4. Новая функция `ПолучитьОпределенияИнструментов(Имена)`

Маппинг имён в определения инструментов (массив структур для LLM). При добавлении новых инструментов — только добавляется ветка `ИначеЕсли`.

#### 5. Новая функция `ИнструментОшибкиРазмещения()` (`#Область LLM_Инструменты`)

Определение инструмента `validate_pallet_placement`:
- `cell` (string, required) — код или наименование ячейки (например `Р1М2Э1`)
- `pallet` (string, required) — код или наименование паллета

#### 6. Бизнес-функция `ОшибкиРазмещенияПаллета(КодЯчейки, КодПаллета)` (`#Область БизнесФункции`)

- Ищет `СкладскаяЯчейка` по коду → наименованию
- Ищет `Лико_Паллеты2_0` по коду → наименованию
- Вызывает `Справочники.Лико_СкладскиеСекции.ОшибкиРазмещенияПаллетаВАдрес(Ячейка, Паллет)`
- Возвращает `Структура(Ячейка, Паллет, Ошибки, Валидно)`

#### 7. Адаптер `Адаптер_ОшибкиРазмещенияПаллета(Аргументы)` (диспетчер-адаптер)

- Извлекает `cell`, `pallet` из аргументов LLM
- Вызывает бизнес-функцию
- Сериализует результат в JSON

#### 8. Регистрация в диспетчере `ВыполнитьИнструмент()`

Добавить ветку:
```bsl
ИначеЕсли Имя = "validate_pallet_placement" Тогда
    Возврат Адаптер_ОшибкиРазмещенияПаллета(Аргументы);
```

### Что не меняется

- `СпроситьLLM()` — уже поддерживает цикл tool_calls
- `Лико_СкладскиеСекции.ОшибкиРазмещенияПаллетаВАдрес()` — только оборачиваем
- Системный промпт WMS_Эксперт — уже содержит описание алгоритма из макетов
- `ОтправитьЗапросLLMНаСервере()` — только добавляется параметр, существующая логика не трогается

## Verification

1. Открыть обработку ЗагрузкаСклада в 1С
2. Выбрать задачу "WMS Эксперт"
3. Спросить: "Проверь, можно ли разместить паллет X в ячейку Y" (где X и Y — реальные коды)
4. LLM должен вызвать `validate_pallet_placement`, получить результат и ответить на естественном языке

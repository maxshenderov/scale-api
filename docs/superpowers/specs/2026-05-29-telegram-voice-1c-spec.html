Telegram Voice → 1С ПолеHTML Фаза 1 AI-ассистента склада | 29 мая 2026

Python BSL Docker 1С

Суть: диктовка в Telegram → faster-whisper транскрипция → текст в форме 1С. Внутри сети OKIL, ничего не публикуется.

1. Архитектура

┌──────────┐ голос (.ogg) ┌──────────────┐ │ Telegram │ ──────────────→ │ api.telegram │ │ (телефон) │ │ .org │ └──────────┘ └──────┬───────┘ │ getUpdates (long polling) ┌──────────┐ ┌──────▼───────┐ │ 1С Форма │ HTTP GET │ Python │ │ ПолеHTML │ ← /latest │ FastAPI │ │ [текст] │ (каждую 1с) │ :8004 │ └──────────┘ │ │ │ aiogram │ ← Telegram Bot │ faster-whisper│ ← STT локально │ Docker │ └──────────────┘

Ключевые решения

  • Long Polling — бот сам опрашивает Telegram API. Публичные URL не нужны.
  • faster-whisper small — 2 GB, русский язык, CPU, бесплатно.
  • XMLHttpRequest в ПолеHTML — 1С не поддерживает fetch(). JS опрашивает /latest и сам обновляет DOM.
  • Docker + volume — модель кешируется, не перекачивается.

2. Поток данных — 7 шагов

1
Голосовое в Telegram — тип Voice, file_id, .ogg
2
aiogram long polling — GET /getUpdates каждые 2-3 сек
3
Скачивание .ogg — bot.get_file(file_id) → /tmp/*.ogg
4
faster-whisper — ffmpeg ogg→wav (16kHz, mono), модель small, язык ru
5
Broadcast + _latest — JSON сохраняется в ws_manager._latest
6
ПолеHTML опрашивает /latest — XMLHttpRequest каждую 1с
7
Текст на форме 1С — JS обновляет DOM, пользователь видит результат

from dotenv import load_dotenv
load_dotenv()                          // TELEGRAM_BOT_TOKEN из .env

from fastapi import FastAPI, WebSocket, WebSocketDisconnect
from fastapi.responses import HTMLResponse
from fastapi.middleware.cors import CORSMiddleware

ws_manager = WSManager()              // Хранит WS-подключения + последнее сообщение
stt = STT()                          // Модель Whisper загружается при старте
voice_bot = VoiceBot(stt, ws_manager)  // aiogram бот

@asynccontextmanager
async def lifespan(app):
    bot_task = asyncio.create_task(voice_bot.start())  // Фоновый polling
    yield
    await voice_bot.stop()
    bot_task.cancel()

app = FastAPI(lifespan=lifespan)
app.add_middleware(CORSMiddleware, allow_origins=["*"], allow_methods=["*"])

@app.get("/latest")
async def latest():
    return ws_manager.latest or {"text": "", "type": "empty"}  // Опрашивается 1С

@app.websocket("/ws")
async def ws_endpoint(ws: WebSocket):
    await ws_manager.connect(ws)
    try: while True: await ws.receive_text()
    except: ws_manager.disconnect(ws)

4. Python — bot.py

services/telegram_voice/bot.py — aiogram 3.x
class VoiceBot:
    def __init__(self, stt, ws_manager):
        self.stt = stt              // faster-whisper (модель уже в памяти)
        self.ws = ws_manager        // Хранилище _latest для HTTP-опроса
        self.bot = Bot(token=TOKEN)
        self.dp = Dispatcher()       // Маршрутизатор aiogram
        self.router = Router()
        self.router.message(F.voice)(self._handle_voice)  // Голос → STT
        self.router.message(F.text)(self._handle_text)    // Текст → сразу

    async def start(self):
        await self.bot.delete_webhook(drop_pending_updates=True)  // Очистка старых
        await self.dp.start_polling(self.bot)  // Long polling старт

    async def _handle_voice(self, msg):
        voice = msg.voice
        file_info = await self.bot.get_file(voice.file_id)
        ogg = tempfile.NamedTemporaryFile(suffix=".ogg").name  // /tmp/xxx.ogg
        await self.bot.download_file(file_info.file_path, ogg)
        await msg.reply("Распознаю...")
        text = self.stt.transcribe(ogg)  // .ogg → ffmpeg → .wav → Whisper → текст
        await self.ws.broadcast({"type": "transcription", "text": text, "user": "Макс"})
        await msg.reply(f"Готово: {text}")

    async def _handle_text(self, msg):  // Текст для теста — без STT
        await self.ws.broadcast({"type": "transcription", "text": msg.text, "user": "Макс"})
        await msg.reply(f"Готово: {msg.text}")

5. Python — stt.py

services/telegram_voice/stt.py — faster-whisper
// Патч SSL для корпоративной сети (MITM прокси)
import httpx
_orig_init = httpx.Client.__init__
def _patched(self, *a, **kw): kw['verify'] = False; _orig_init(self, *a, **kw)
httpx.Client.__init__ = _patched

from faster_whisper import WhisperModel

class STT:
    def __init__(self):
        self.model = WhisperModel("small", device="cpu", compute_type="int8",
                                   download_root="/app/whisper_models")

    def transcribe(self, ogg_path):
        wav = ogg_path + ".wav"
        subprocess.run(["ffmpeg", "-y", "-i", ogg_path, "-ar", "16000", "-ac", "1", wav])
        segments, _ = self.model.transcribe(wav, language="ru")
        return " ".join(s.text.strip() for s in segments)

6. Python — ws_manager.py

services/telegram_voice/ws_manager.py — хранилище
class WSManager:
    def __init__(self):
        self._connections: list[WebSocket] = []   // Для будущей Фазы 2 (двусторонний WS)
        self._latest: dict | None = None          // Последнее сообщение для HTTP-опроса

    async def broadcast(self, msg):
        self._latest = msg  // ← Ключ: сохраняем для /latest
        for ws in self._connections: await ws.send_text(json.dumps(msg))

    @property
    def latest(self): return self._latest  // Читается GET /latest

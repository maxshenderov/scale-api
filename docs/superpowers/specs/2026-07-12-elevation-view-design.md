# Elevation View стеллажа — чертёж с размерами

> Добавление технического чертежа стеллажа (вид сбоку) с размерными линиями в обработку ЗагрузкаСклада.

## Контекст

Сейчас в ЗагрузкаСклада есть поперечное сечение стеллажа (вид спереди) и таблица «Паллеты на полу». Нужен отдельный elevation view (вид сбоку) с размерами по вертикали: внутренняя высота секций, расстояние между этажами, высота от пола, общая высота.

## Данные

Источник: `Справочник.Лико_Стеллажи.Этажи` (ТЧ):

| Реквизит | Тип | Назначение |
|----------|-----|-----------|
| `Типоразмер` | CatalogRef.Лико_ТипоразмерыСкладскихСекций | Высота, Ширина, Вес секции |
| `Зазор` | Число | Зазор над паллетом внутри секции |
| `ВысотаБалки` | Число | Высота балки перекрытия между этажами |
| `ВысотаОтПола` | Число | Расстояние от земли до пола первого этажа |

## Формулы

- **Внутренняя высота секции** = `Типоразмер.Высота + Зазор`
- **Расстояние до пола следующего этажа** = `Типоразмер.Высота + Зазор + ВысотаБалки`
- **Общая высота** = `ВысотаОтПола + Σ(Типоразмер.Высота + Зазор + ВысотаБалки)` для всех этажей

## Что рисуем

Снизу вверх:

1. **Пол** — заштрихованный прямоугольник
2. **ВысотаОтПола** — размерная линия слева
3. **Этажи** (снизу вверх) — блоки с размерами:
   - Внутренняя высота (справа внутри блока)
   - Расстояние до пола следующего этажа (слева, размерная линия)
   - Вес/габариты типоразмера (текст внутри блока)
4. **Общая высота** — итоговая размерная линия справа

## Реализация

Два варианта (оба вывести в HTML, выбрать визуально):

### Вариант A: HTML/CSS
- `<div>` блоки, абсолютное позиционирование
- Размерные линии через CSS-бордеры
- Стрелки через CSS-треугольники / Unicode
- Штриховка пола через `repeating-linear-gradient`

### Вариант B: SVG
- `<svg>` с `<marker>` стрелками
- `<rect>` блоки этажей
- `<pattern>` штриховка пола
- `<text>` надписи
- `<line>` размерные линии

## Интеграция

- Внутри `РендерЗагрузкиСтеллажаНаСервереЧистая()` — новая функция `СформироватьElevationView()`
- Вставляется перед `</body>` (после ПаллетыНаПолу)
- Масштабируется общим зумом через `#sc` контейнер
- Данные этажей уже загружены в `ДанныеЭтажей` (Соответствие: НомерСтроки → Структура(Ширина, Высота, Вес))
- Нужно дополнить выборку: Зазор, ВысотаБалки, ВысотаОтПола из ТЧ Этажи

## Верификация

1. Открыть ЗагрузкаСклада в 1С
2. Выбрать склад → выбрать стеллаж
3. Пролистать ниже «Паллеты на полу» → увидеть оба чертежа
4. Проверить: зум работает, размеры совпадают с данными справочника

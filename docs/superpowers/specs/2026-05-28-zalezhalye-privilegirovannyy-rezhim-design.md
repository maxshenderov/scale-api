# Привилегированные запросы для "Залежалые объекты номенклатуры"

> Обход ограничений прав доступа: запросы к регистрам выполняются в привилегированном режиме в ObjectModule, результат подгружается в СКД как внешние источники данных.

## Проблема

Обработка `ЗалежалыеОбъектыНоменклатурыОстаткиИОбороты` — внешний отчёт на СКД. Запросы обращаются к регистрам `ТоварыВЯчейках`, `СебестоимостьТоваров`, `СтоимостьТоваров`. Не у всех пользователей есть права на эти регистры. Добавить полные права в обработку нельзя.

## Решение

1. **ObjectModule**: добавить экспортные функции, которые выполняют все запросы в `УстановитьПривилегированныйРежим(Истина)` и возвращают ТЗ
2. **СКД**: добавить `ВнешниеИсточникиДанных` → `ЛокальнаяБазаДанных`. Наборы данных ссылаются на внешние таблицы вместо inline-запросов
3. **ПриКомпоновкеРезультата** в ObjectModule: читает параметры СКД, вызывает привилегированные запросы, передаёт ТЗ во внешние источники

**Без формы.**

## Изменения в ObjectModule

### Новые экспортные функции

1. `ПолучитьПараметрыИзСКД(НастройкиКомпоновкиДанных)` — извлекает Период, СрокДавности, РазделУчета из настроек СКД
2. `ПолучитьДанныеОтчета(ДатаНачала, ДатаОкончания, СрокДавности, РазделУчета)` — выполняет 3 запроса (ВТ_ОстаткиИОбороты → ВТ_Себестоимость → ВтСтоимостьТоваров + финальные SELECT) в привилегированном режиме, возвращает `Структура("ОстаткиИОбороты, Себестоимость")` с ТЗ
3. `ПриКомпоновкеРезультата(ДокументРезультат, ДанныеРасшифровки, СтандартнаяОбработка)` — обработчик: читает параметры → вызывает `ПолучитьДанныеОтчета()` → передаёт ТЗ в СКД

### Запросы в ObjectModule

Тексты запросов совпадают с текущими запросами СКД:

**Запрос 1 (ВТ):** Creates 3 temporary tables:
- `ВТ_ОстаткиИОбороты` — из `РегистрНакопления.ТоварыВЯчейках.ОстаткиИОбороты` с фильтром по уникальным объектам и сроку давности
- `ВТ_Себестоимость` — из `РегистрНакопления.СебестоимостьТоваров.Остатки` с отбором по ВТ_ОстаткиИОбороты
- `ВтСтоимостьТоваров` — из `РегистрСведений.СтоимостьТоваров.СрезПоследних` с отбором по ВТ_ОстаткиИОбороты

**Запрос 2 (НаборДанных1):** Финальный SELECT из ВТ с JOIN'ами и вычислением суммовых полей. Результат → ТЗ `ОстаткиИОбороты`

**Запрос 3 (НаборДанных2):** SELECT себестоимости из ВТ. Результат → ТЗ `Себестоимость`

### Параметры запросов

| Параметр | Источник | Тип |
|---|---|---|
| Дата1 | Период.ДатаНачала | Дата |
| Дата2 | Период.ДатаОкончания | Дата |
| СрокДавности | СрокДавности | Число |
| РазделУчета | РазделУчета | ПеречислениеСсылка |

## Изменения в СКД

### Добавить ExternalDataSources

```xml
<externalDataSource>
  <name>ЛокальнаяБазаДанных1</name>
  <dataSourceType>Local</dataSourceType>
</externalDataSource>
<externalDataSource>
  <name>ЛокальнаяБазаДанных2</name>
  <dataSourceType>Local</dataSourceType>
</externalDataSource>
```

### Изменить DataSource

- Было: `<dataSource>ИсточникДанных1</dataSource>` (Local)
- Стало: `<dataSource>ЛокальнаяБазаДанных1</dataSource>` для НаборДанных1, `<dataSource>ЛокальнаяБазаДанных2</dataSource>` для НаборДанных2

### Изменить DataSet

Каждый dataSet:
- Убрать `<query>` (inline SQL)
- Добавить `<externalTable>` с именем таблицы (`ОстаткиИОбороты` / `Себестоимость`)
- Поля остаются БЕЗ ИЗМЕНЕНИЙ — имена колонок в ТЗ совпадают с полями СКД

## Поток данных

```
Пользователь → СКД (параметры) → ПриКомпоновкеРезультата
  → ПолучитьПараметрыИзСКД() → ДатаНачала, ДатаОкончания, СрокДавности, РазделУчета
  → ПолучитьДанныеОтчета() → УстановитьПривилегированныйРежим(Истина)
    → Запрос 1: ВТ_ОстаткиИОбороты + ВТ_Себестоимость + ВтСтоимостьТоваров
    → Запрос 2: SELECT → ТЗ ОстаткиИОбороты
    → Запрос 3: SELECT → ТЗ Себестоимость
  → ТЗ → ВнешниеИсточникиДанных СКД
  → СКД выполняет компоновку (читает из ТЗ, не из регистров)
  → ДокументРезультат
```

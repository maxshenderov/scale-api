# Spec: Обработка «РазмещениеПаллетНаСкладе»

> Дата: 2026-06-17
> Статус: design-approved
> Путь: `1s/ERP/obrab/РазмещениеПаллетНаСкладе/`

## Назначение

Массовая загрузка плана паллет из Excel, нормализация типоразмеров, создание виртуальных паллет и документов их формирования/перемещения, расчёт статистики.

## Изменяемые файлы

| Файл | Что меняется |
|---|---|
| `Forms/Форма/Ext/Form.xml` | Атрибут `НачалоСтрокиExcel` (Число, по умолчанию 2), поле ввода |
| `Forms/Форма/Ext/Form/Module.bsl` | 6 процедур: вся бизнес-логика |

## Используемые API (не изменяются)

| Вызов | Модуль |
|---|---|
| `НайтиСоздатьТипоразмер(Высота, Ширина, Глубина, Вес)` | `Лико_ТипоразмерыПаллет.Менеджер` |
| `НовыйПаллет(ТипПаллета)` | `Лико_Паллеты2_0.Менеджер` |
| `ПодобратьЯчейкуПоПаллету(Склад, Паллет)` | `Лико_СкладскиеСекции.Менеджер` |
| `ТипоразмерПаллета(Паллет)` | `Лико_Паллеты2_0.Менеджер` |

## Процедуры

### 1. ЗагрузитьИзExcel

- **Контекст**: &НаКлиенте → серверный вызов
- Очистить ТЧ «Паллеты»
- `ТабличныйДокумент.Прочитать(ПутьКФайлу)`
- Читать с Лист1, начиная со строки `НачалоСтрокиExcel` (по умолчанию 2)
- Маппинг: A=ГлубинаПлан, B=ШиринаПлан, C=Высота, D=Вес, E=Количество
- Остановка: колонка A пустая

### 2. СозатьТипоразмеры (включает нормализацию)

- **Контекст**: &НаСервере
- Для каждой строки «Паллеты»:
  1. Нормализация: если MAX(ГлубинаПлан, ШиринаПлан) ≤ 1200 → Глубина=MAX, Ширина=MIN; иначе без перестановки
  2. `НайтиСоздатьТипоразмер(Высота, Ширина, Глубина, Вес)` → записать в Типоразмер
  3. Попытка…Исключение: ошибка → пропустить строку
- Схлопнуть строки с одинаковым Типоразмером → одна строка, Количество = сумма

### 3. СоздатьДокументыФормированияПаллет

- **Контекст**: &НаСервере
- Для каждой строки «Паллеты», для каждого i от 1 до Количество:
  1. `НовыйПаллет()` → установить `Виртуальный = Истина`, записать
  2. Создать документ `Лико_ФормированиеПаллета2_0`
  3. Заполнить: Паллет, Типоразмер, АдресХранения, АвторДокумента
  4. ТЧ «Товары»: одна строка, только Серия = ОбъектНоменклатурыБазовый
  5. Попытка: Записать + Провести; Исключение: пропустить
  6. Добавить ссылку в ТЧ «ФормированияПаллет»

### 4. СоздатьДокументыПеремещенияПаллет

- **Контекст**: &НаСервере
- Для каждой строки ТЧ «ФормированияПаллет»:
  1. Взять документ-формирование, из него: Склад, Паллет, АвторДокумента
  2. Создать документ `Лико_ПеремещениеПаллета2_0`
  3. Заполнить Склад, Паллет, АвторДокумента
  4. Попытка: `ПодобратьЯчейкуПоПаллету(Склад, Паллет)` → АдресХранения
  5. Если заполнен → Попытка Провести; иначе → Записать
  6. Добавить ссылку в ТЧ «ПеремещенияПаллет»

### 5. ЗаполнитьСтатистику

- **Контекст**: &НаСервере
- Очистить ТЧ «ФормированияПаллет» и «ПеремещенияПаллет»
- Запрос к документам: фильтр Склад + Паллет.Виртуальный=Истина
- Заполнить обе ТЧ из результатов запроса
- По Типоразмерам в «Паллеты»:
  - `КоличествоСозданныхФормирований` = COUNT(Проведен)
  - `НеСозданныеФормирования` = Количество(из Паллеты) - Созданные
  - Аналогично для Перемещений

## Обработка ошибок

Единая стратегия: Попытка…Исключение на каждую операцию, при ошибке — пропустить строку/документ, продолжить. В конце показывать итог: сколько создано, сколько пропущено.

## Не делается (out of scope)

- Справочник `Лико_ТипыПаллет` — не требуется, не упоминается в ТЗ
- Прогресс-бар — опционально, не блокирует
